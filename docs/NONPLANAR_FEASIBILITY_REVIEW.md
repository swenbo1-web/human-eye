# NV 非平面取景的反证审查与后续选择

2026-11-01。先审查fe18d1f原型，再改verification候选；85运行源e610保持冻结。[主计划](PRODUCT_ROADMAP.md)是唯一队列。

结论：问题区域驱动、有限候选、独立几何与真实像素验收的架构值得保留；现有原型只证明一组对称扭曲开口可行，尚不具备直接生产接入条件。本批不扩大射线预算，不把所有非平面问题归为同一种算法。

| 直接邻接三角身份过严 | 保留边界与相同表面，将四个邻接三角分出极薄带；总28三角，原12/12机会变成0、无图 | P0：需可验证的局部表面来源/连通邻域，不能只认直接含边的单个三角。此缺口本批保留为生产阻断，不放宽到同物体任意面 |

## 本批实现前冻结的修正

1. 对象级保守二维投影包围界预筛。每个乘法/加法向外扩一浮点邻值，无法确定时保留对象；只在射线投影区间与完整对象范围严格分离时排除。既不删除遮挡物，也不只取目标。独立验收用Fraction精确点积重建边界，不能调用生产端筛选函数。每射线记录被保留的对象ID，独立端检查不存在漏掉的精确可能对象，再做独立3D相交。
2. 射线测试按实际保留对象的三角数预留生产＋回放上界，总额仍8192；对象筛选/顶点投影另有界，合计上限分别32768/65536，不把三角开销偷偷转成无限包围界遍历。预算不足仍停止并标搜索不完整。先选正反局部法向，再考虑世界Z/Y；输入数量上限不升级为普适质量保证。
3. 邻接法向改用边界长度加权的单位面法向。只保证同一共面面片的内部细分稳定，不保证曲面重拓扑或有翻面/退化时朝向稳定。保留法向抵消拒绝。

对象层筛选只是第一步，单个高面数目标仍需有界三角簇/BVH；本批不声称已实现BVH。射线包围界加速的原则可参考[PBRT BVH](https://www.pbr-book.org/4ed/Primitives_and_Intersection_Acceleration/Bounding_Volume_Hierarchies)，保守浮点边界必须防止漏交，参考[PBRT 舍入误差](https://www.pbr-book.org/4ed/Shapes/Managing_Rounding_Error)。文献解释方法，不替代本项目的预算、反例或像素证据。

## 验收和下一出口

原七类决定与12/12、12/12、10/12像素门保持；新增远处高细分场景必须恢复12/12，投影重叠的高细分遮挡物不得被排除，预算不足须诚实拒绝。普通重心细分法向变化≤1e-8（向量范数）并保持可见数；薄带细分反例继续登记为已知缺口。不同旋转检查已知正反局部视角机会，不将少量旋转当全域证明。包围界对随机/极端数值的精确Fraction包容测试及篡改检查通过。

真实owned Blender至少3轮复核新增远处密集场景和遮挡负例，核对实际RNA、独立Pillow、状态恢复及正常退出；首次/热态与所有失败保留。候选与冻结原型在同一输入中分别计时，计入筛选/独立回放开销，不只报告减少了多少三角测试。未通过原型可靠性前，NV-02生产协议接入继续等待；下一首要项是局部表面归属证据，其次是单目标密集几何加速，满足后才接MCP。

## 实施结果与可接受性

对象级向外舍入投影筛选、边界长度加权单位法向、局部法向优先均已实现于verification，未修改运行源。独立端使用精确Fraction点积重建被省略对象不可能与射线投影相交，再做独立三维相交；不以生产端自己的包围界列表替代消费者证明。203组随机/极端点积（下溢、溢出、大数抵消）满足精确值包容，伪造移除可能对象被拒绝，9个已知旋转保持机会；不作为完整输入空间或任意旋转证明。

3轮×11类真实Blender共33次：30次符合预登记判断，另外3次是保留的薄带过度拒绝。远处296三角场景恢复12/12，普通共面重心细分的方向向量差≤1e-8且保持12/12；密集遮挡仍0/12，预算不足未被当可见。原七类12/12、12/12、10/12及负例保持。薄带原生参考依然12/12可读而算法不选，不能把全部33次称为质量通过。

实验66帧中30帧属于候选会返回的上下文/局部，36帧为负例/已知失败oracle参考，公开MCP交付0。最多预留3072三角测试、384对象范围测试、1608投影操作，低于8192/32768/65536限额。规划约0.16–8.54毫秒；状态恢复，三个进程退出。全量1678项运行，1675通过、3项既有跳过；14项候选检查中7项本批新增。已知失败作为支持域阻断，未写成产品成功。

同一真实native输入，候选＋独立回放交错30对×3轮：普通扭曲中位约5.35–5.37→3.71–3.73毫秒，共面重心细分约6.33–6.36→4.57–4.60毫秒。远处密集原版约0.43毫秒拒绝，新版8.09–8.13毫秒返回12对机会，质量不同不能算加速比。均不含来源采集、PNG、MCP、模型或完整生产consumer，不宣称完整任务/发布性能通过。

取舍可接受于验证原型：已减少无关数据开销、提高普通共面细分稳定性，未增加射线预算。不能接受直接产品化：薄带漏机会、单目标密集三角和完整consumer仍阻断。对象级筛选不能解决三角集中在同一对象包围界中的情况，不能冒称BVH。

## 后续唯一顺序与停止边界

1. **局部表面归属与采样稳定性**：用来源绑定的有限连通表面见证代替单个邻接三角身份；限制邻域、距离和法向变化，不退化为同物体任意面。普通/薄带细分保持观察决定，近邻但不连通的表面不冒充。当前三点/边可能让新增短边获得更大投票权，是由规则推出、尚待独立反例核验的风险；后续比较弧长/几何特征采样，不能靠放宽2/3门规避。
2. **单目标密集几何**：第一项稳定后引入有界三角簇/BVH，分别预算构建、遍历、消费者和回查，拆分不重置总额度。四方向只称有限候选搜索，search_complete仅表示该列表完成，不是全视域最优。单位缩放/极大坐标和相机量化另验。
3. **NV-02生产协议与consumer**：重建raw/native/显示/世代、候选基、采样、选中项、收益和总工作量，验证正交性、真实RNA视野/深度/恢复/时间戳，再接MCP。试验回放尚不验证完整决策，不能直接替代。
4. 回到M1-05固定包、安装、成本和真实资产验收。不将任意内壁语义、凹陷/自交或卷曲角色塞入本批；有限邻域若仍不能证明归属则输出unknown、冻结失败域，恢复满足条件的有限版发布，不在同一反例无限扩域。
