# M4-OBSERVATION-BASELINE-001：完整观察任务独立复核

## 结论

本轮两组均 3/3 完整正确，插件没有通过预定的完整耗时中位数门槛。插件为 53.7364 秒，原生为 52.6611 秒，慢 2.04%；实际 input + output 累计多 26.30%。插件三次总耗时低 4.77%，这项结果保留，但不替换预定中位数指标。当前能确认质量保持，不能确认完整观察任务已有净效率收益。

事实消费已经发生：插件组三次都采用其三对关系、距离和见证，没有用原生重新求解全部关系。主要可见缺口是局部依据交付：每次 relations 后仍读原生几何，补框边材料和孔内边界，完成更具体的解释。额外调用不等于模型“不信任插件”；也没有删除该调用的实验来证明它整体必要或可以直接去掉。

下一项只保留并交付已有横向穿越判定的局部证据，见 [单项计划](M4_LOCAL_RELATION_EVIDENCE_001_PLAN.md)。工程通过后至多安排一次受控消费验证；若没有实际净收益，停止扩写此候选，不继续对同题堆字段。

## 实际瓶颈及最小改动理由

六格均先用原生读取全 28 个网格的 bounds/center 等目录信息。原生后续可在一次局部读取中取得筛选条件和局部几何，以合法解析方法答对；不能人为限制这条捷径来制造插件收益。

插件三格均走“原生目录 → relations → 原生局部几何”。relations 一次返回三对有效事实，N13 穿入、N08 约 0.100007 毫米间隙、N28 约 23 毫米间隙均被采用。最后一次原生调用补 N16 框边/孔内几何；部分导轨/管件顶点和条件算术与先前 bounds 重复。

源码核查发现横向穿越成功分支已持有实际相交三角片、交线与中点，但结果只留证书类别。保留这些已有局部量，能让模型指认“哪里穿过材料”，有机会减少补查。该证据不直接描述孔结构；不能提前承诺三次调用一定降为两次。

必须取最终横向穿越分支的三角片，不能复用可能更早出现的第一处边界接触。零表面距离和源边界点也不是双方严格体积内部点。本批不构造新内部点、不研究孔洞识别、不增加一个求解服务。
