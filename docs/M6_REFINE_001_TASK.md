4. 位移高于0.5h的点形成覆盖中部的连通区域。报告边上位移差/原边长、受影响面法向变化和边界过渡，评价局部细节保持。初始建议最大归一位移梯度0.2、最大面法向变化5度，先用一个公开确定性参考构造核查可行性，再固定准确规则。绝对曲率下降不能单独作为精修成功依据。
5. 新退化、局部反向及新增表面自交检查覆盖受影响面与完整网格的相关候选，合法共享边/点单独处理。使用已有几何核和空间裁剪。无法判定项记具体原因，独立副本试验保留结果，最终通过状态按实际测量报告。
