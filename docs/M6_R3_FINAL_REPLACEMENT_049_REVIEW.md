# R3 最终版能否替代 032

**可以。** 固定候选 `9.7.2+k049final` 通过了 049 事前约定的验收，可以独立安装，接替 032 的现有 BVH 几何查询。BVH 是按空间范围把三角形分组、跳过无关几何的索引。这次验收涵盖最近距离、阈值扫描、局部选区及相关几何关系的既有入口。正式安装仍在原版本；本次优化循环到此结束。[049 事前标准](M6_R3_FINAL_REPLACEMENT_049_TASK.md) · [独立复算数据](../verification/m6_r3_final_replacement_049_review/RESULTS.json)

## 原先答不出的 9.568319 毫米

两件测试网格各有 129 个三角面，共 16,641 种面配对。在普通 Blender 入口的同一份输入上，032 做了 1,918 次精确三角形比较，算出距离。049 之前的局部修正版 R3 做满单对允许的 16,384 次，仍未排除其余可能，所以返回未知。它触及的是精确比较次数上限，当时总工作额度仍有剩余。上一轮较小的 125×125 测试已经表现出同类浪费，只是 15,625 次还在上限内，答案一直能出来。[045 原始故障](M6_R3_REPLACEMENT_ENTRY_045_REVIEW.md)

最终版在开始求解前，按两边的面数估算要证明答案最多可能花多少工作。能容纳的情况走 R3，压力较高的情况直接走同一安装包里的原 032 算法。每次求解只走选中的一条路，额度照旧。这里用的是新建单对账本的保守上界；复杂组合查询、剩余额度、到期和最终发布仍由执行路径各自检查。[候选设计](C:/Users/Administrator/.codex/worktrees/m6-model-selection/hefe/verification/m6_r3_final_replacement_049/candidate/DESIGN.md)

我从本轮 Blender 原生捕获重建前两例的几何，用有理数检查全部 16,641 和 15,625 个面配对。每例只有表中一对面能达到已证明的最小距离平方 `3/32768 m²`，其原始顶点也确实达到这个距离。普通入口回包给出了距离和点；面编号另由原生数据及独立安装重跑核定。两例普通入口的总工作单位分别为 406,421 和 356,974，与 032 相同。

84 个固定输入的结果与 032 逐项相符，83 个得到距离，1 个保持同原因未知。复核 504 份普通及诊断记录，独立验证 498 个精确点确实属于记录的原三角面。覆盖包括等距、距离有值但显示精度不足以交付点、闭合物体在同一点相接，以及几何来源变动、位宽、面数限制、协作取消与原截止时间。闭合物体允许复用第一个已证明的接触。共享查询由第 9、4 号面证明接触点是世界坐标 `(1,1,1)`，普通最短距离查询在同一点按自身规则选第 2、0 号面。[正确性与原生几何复算](../verification/m6_r3_final_replacement_049_review/recompute.py)
