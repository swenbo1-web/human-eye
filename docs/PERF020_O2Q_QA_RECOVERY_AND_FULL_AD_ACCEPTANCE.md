# PERF-020-O2Q QA 访问恢复与完整 A/D 验收

## 判定

同一固定 D 完成新的五组、30 运行、300 观察完整对照。全部事实和来源核验通过，原性能门限 12/12 类通过，批内独立有理数重算一致。小档完整调用中位改善 22.83%–30.79%，中档 11.16%–16.38%，大档 30.06%–31.29%。中大档八类均为五组达改善门限。

本批只修正 QA 启动访问恢复与离线内存汇总。D 沿用原提交、wheel、安装和入口，A 工作源码保留。D 的组合收益包含此前增量接收与绑定身份检查删减，本批 QA 修复本身没有新增产品算法收益。固定候选及完整报告交主复核，模型任务收益和整个 PERF-020 模块仍待后续验收。

新系列独立于旧 O2 的 100 次中断观察。原失败及已发生成本保留，新分母为独立的 300 次。

## 资格与独立审核

作者对实际新 helper 执行原 26 项探针，其中 25 项测新 helper、一项旧 helper 真实共享锁对照。七项补充检查、两个实际 tiny Client 场景及一个纯 controller 接线单元通过。实际 Client 覆盖拒绝后恢复、构造未返回时事件保留和原进程清理，四个 Python 进程实例正常回收。

真实 Windows 共享锁见证支持允许的 open 拒绝恢复，持续拒绝和目录同码到原期限退出。读取开始后错误、关闭错误、恢复后的坏记录、错绑定、超限和非有限值仍拒绝。旧故障的具体原生原因仍为 unknown。

未计分 A/D 烟雾各十次，共 20/20 观察通过。独立审阅源码、断言、实际结果、版本、完整事实、输入输出及进程实例后，冻结本次新正式系列。独立审核结果与作者实际执行分栏记录，资格分母未混入正式 300 次。
