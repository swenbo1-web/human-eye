默认观察仍将目标标为A、调用者参照标为B，最多再显示两个相关对象。量测查询`query.object_ids`不会自动增加标签数量；所有原几何、身份映射和已知风险事实保持。

需要在一张图中定位多个已知对象时，可在同一次观察的现有`query`中传入`label_object_ids`。它接收1至6个唯一的当前完整对象ID；核心A/B之外最多六个相关标签，总标签上限八个。未知、删除、重复或超额ID拒绝。调用者应使用当前观察返回的完整ID，短标仅用于显示。

完整视觉请求集合包含被明确指定的核心A/B；它们不占相关标签名额，但不能从交付回执中删除。只请求被遮挡的核心时，仍会报告该完整ID未画出；混合六个请求若包含A/B，相关预算只按其余四个计算。

```json
{
  "mode": "exact_pairs",
  "object_ids": ["current_full_id_1", "current_full_id_2"],
  "label_object_ids": ["current_full_id_1", "current_full_id_2"],
  "max_exact_pairs": 3
}
```

示例ID是占位符。精确量测与视觉定位可以请求不同的对象集合；定向展示不新增量测，也不将未知或下界升级为精确结果。定向对象优先进入标签候选，原已知穿透等原因保留。空间不足、不可见或像素不足仍可能无法画标签。

完整与brief观察均保留以下信息：

- `label_presentation`：当前已知相关候选、获选数量、未选已知穿透数量、定向对象画出数量及未画出ID。计数范围是现有任务证据的展示选择，不证明全场风险完备。
- `canvas.views[].label_layout.visual_focus_coverage`：每视图已画定向对象及未画原因，最多六项，不受一般省略诊断截断影响。
- `canvas.object_labels`与`projected_labels`：完整对象身份、显示别名和已画标签当前深度表面锚点，供模型直接绑定画面位置。不可见对象没有伪造锚点。

新选项适用于已建立目标/参照的有图观察。无配对返回`target_pair_not_established`；未请求图片返回`image_not_requested`；自然画布无法生成返回`scene_canvas_unavailable`。这些状态仅说明展示未交付，不改变几何结论或执行资格。CONTACT近景仍只聚焦其实际对象对，定向对象在其他自然视图中的标注及逐视图省略原因单独保留。

显式定向自然标签的引线可连到最近框边；只有实际深度归属统计证明每个核心及总前景覆盖均不增加时才替换旧端点。默认对象对图片和CONTACT兼容布局保持。

大范围NAV图先绘地图标记和工作区框，再绘标签。标题到第16行结束，安全表面锚点可从第17行开始；文字框仍保持原第19行边距。128像素及以上为MAP说明带保留区域，较小NAV图仍避让标题和标尺。只有在当前深度赢家中有足够安全像素、且合法文字框可排布时才报告已画；否则返回`no_surface_anchor_outside_navigation_overlay`或`no_label_space_outside_navigation_overlay`。这是界面遮盖造成的交付限制，不表示对象几何不存在。

当前不承诺六个请求一定全部贴标。小图、长别名、遮挡、像素不足或渲染预算限制均可能阻止交付。超过六个视觉ID明确拒绝，不静默截断；分批和跨帧调度属于后续独立能力。显式定向请求可追加一个128像素的局部视图，但必须实际增加可读对象身份，遵守10毫秒增量及40毫秒共享预算；它不代替原四视图，也不把完全遮挡的对象画成可见。详见[局部视图验证](../verification/fixes/20261027_gain_local_view/REPORT.md)与[当前聊天核验](../verification/fixes/20261027_local_view_reload/REPORT.md)。
