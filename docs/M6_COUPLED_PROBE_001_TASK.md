## 只实现一个最小评价函数

输入为同一源状态的坐标/三角形、允许改变的源 ID、目标/保持量、当前与候选坐标，以及明确声明的表面关系要求。输出保留每项实际量、覆盖集合、接触关系变化和联合状态。

1. **完整依赖。** 由写集合取全部 incident 源三角形，不局限于完全包含在 patch 中的面。真实 410 点写集合的上界是 898 面，含 150 个跨框面。接触候选使用完整同角色表面，包括同一组件内远拓扑近空间的面。
2. **共同状态。** 所有量来自同一源 ID、坐标语义和帧；明确输入是已保存 world binary64 数组，不能混用原生矩阵精确仿射和 float32 渲染坐标后不说明差异。
3. **共同结果。** 形状目标误差、保持误差、原有/新出现的表面相交分别保存。所有声明的必达条件同时成立才返回该有限任务通过；一个分数改善不能抵消另一个条件失败。缺目标时可输出几何事实，不能输出修正成功。
4. **共享准备。** 静态坐标/拓扑/空间准备复用；候选只更新实际受影响内容，并重新产生与新位置有关的候选。先实现可对照的全量准备版本，再验证一次共享准备候选，结果必须相同。记录冷准备、受影响面更新量、全部求值和遗漏项，不以缓存热耗时代表完整任务。

优先复用固定版本 `human_eye_plugin/surface_geometry.py` 的三角形相交和公共单形判断。复用叶级几何函数与空间候选接口不等于原产品入口支持整个 27,304 点资产。本批用独立离线试验入口，不修改产品的预算常量、来源域或正式接口，不复制整套引擎。

这里检查端态三角表面的相交。通用最小间距、封闭体包含关系、有符号穿透深度和运动路径另记未评估。本批不实现它们，也不将表面无交点写成完整实体无碰撞。退化面或未完成覆盖不得被当作无相交。

## 在运行前固定的控制

先保存 `CASE_PLAN.json`，明确每个样例的输入、所测属性、答案来源和预期状态，再运行。至少覆盖下列必要分支，可用少量小型有理坐标夹具组合验证：

- 形状和接触都满足的正控制，以及仅形状满足但新相交的联合失败。
- 仅接触满足、形状目标未满足；联合条件冲突不能平均成通过。
- 修改边界顶点影响跨 patch 的三角形；故意只评价完整框内面的对照应被检出覆盖不足。
- 同一组件中的非邻接表面发生相交；不能按组件 ID 排除。
- 正常共享边/点不算额外相交；邻接面在公共边/点以外重叠必须检出。重复面也不能因共享三个顶点而自动忽略。
- 状态或 ID 不匹配、非有限数值、一个子评价失败时，联合结果不误报通过；单项结果和失败原因仍能交付。

夹具答案需用可解析的几何或独立高精度实现核对。生产被测函数与 oracle 不能仅是同一函数的两次调用。几何事实、输入错误和语义接受分别记录。

## 真实输入的一次有限对照

原始完整角色作为不作改动的控制。在内存复制坐标，给选中的 410 个源顶点施加固定世界 Y 方向 `+0.001 m` 位移，其他点不变；这个幅度与方向在本合同中预先固定，不能看结果后反复调整以制造成功或冲突。

它是测试依赖与接触传播的人工候选，不是建议用户采用的美术修改。没有角色接受目标，所以真实输入分支只报告前后实际量和新旧相交关系，不宣布修复成功。若未出现新相交，保留该结果，必要错误分支由上面已固定的小夹具验证。

评价范围为所有至少有一个面属于 898 个受影响面的无序面对应关系。避免重复计算受影响面彼此之间的同一对；相同三角形不与自身配对。无关联面可以由完备的包围盒排除，记录完整 pair 分母、排除、实际求值、退化/未知和未完成数量。不得只保留最邻近五个组件来做评价。

空间候选覆盖用一个独立、分块的全量 AABB 对照核对，单块内存有限；无需对 898×53,264 全部面逐一执行昂贵精确求交。全量 AABB 对照只证明候选覆盖，三角形谓词正确性另外由解析/高精度控制验证，两者不能混为一个证明。

报告固定原始坐标与候选的散列、写集合、898 面依赖集合、各项结果、冷准备和更新次数、实际 CPU/墙钟、所有失败与未测。原 `.blend` 和作者旧私有数组不写入，新增完整几何留本机且不进入 Git。
