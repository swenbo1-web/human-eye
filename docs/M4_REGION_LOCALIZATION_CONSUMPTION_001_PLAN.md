## 同一个空间任务

沿用 anchors 已冻结 joined 场景：1 mesh、1913 顶点、3337 三角形；相机仍为原六个512视角。双方可按需读取相同原始世界几何、面绕序、相机参数和可读标准；这些输入在工具内驻留，不强制把完整网格预先塞进两路模型上下文。不提供管理员答案、ROI映射、预计数量或前轮报告。

题目要求完成一次有限相机池内的观察巡检：同平面、共边连通、边界为矩形的表面视为一个面；其它表面单列。完成候选池中能够取得完整可读证据的全部支持面，尚未查看但可以补齐的面不算巡检完成。报告已经取得完整可读证据的面和剩余面，明确剩余原因与六视角范围，并完成三项具体定位：

1. 在 SCENE 图片的 `[109,247]` 像素处，指出实际表面中心、正面方向和范围，给出当前图片引用。输入只给点击位置，不附该面的世界答案。
2. 判断中心为 `[0,0,0]`、朝向 `+Z` 的面在 SCENE 中是否有可见像素；区分被遮挡和背向。若其它实际观察已读清它，给出该视角及一个属于该面的像素，否则说明缺什么证据。
3. 判断中心 `[0.15625,-0.15625,0.11572265625]`、朝向 `-Z` 的面，在这组相机中能否得到正面可读证据。把有限相机池的结论与“任何角度都不可见”分开。

共同可读规则沿原工程定义：完整几何可见、正向，实际表面像素至少16、有效对比边界至少4、RGB距离至少24。给双方同一规则说明。模型可以编程求解或看图，自由选择余下视角，不强迫原生六图、逐片问答或长篇视觉推理。

最终人类回答应简短，覆盖集合可以由本次工具结果或本次生成并明确引用的机器可读证据承载，不要求手抄138行。定位接受世界几何/源面标识；原生无需生成插件的ROI哈希。域外剩余必须保留，不能把它凑成矩形或宣称全部资产已观察。没有要求仅凭brief证明某个未知空间点对应triangle48；如自行给出这类精确声明，需要共同原生读取支持并计成本。

## 两路能力与执行来源

N：普通持久Python、NumPy/Fraction、原始几何/相机、按需批量渲染、RGB/depth/object-owner及原始三角形ID缓冲、同次调用附图、scratch。模型自行发现面、选择视角、计算状态和位置。

P：上述公共能力相同，额外提供当前隔离安装产品的观察入口。该入口执行本版本发现/索引/选眼/光栅/像素反馈，并返回实际默认brief-v3与原生图片，不能由适配器预选答案、读取旧报告或回放已算好的事实。P可直接采用事实，也可使用共同原生工具补查；补查全部计入。

复用已经通过的 `m4_active_coverage_consumption_002/launcher.py`、`m4_consumer_error_contract_001` 的结果绑定，以及既有 actor/image_content/stdio/CLI 归档链。只在新命名空间接入当前安装产品与新输入，不修改旧封存，不新增通用评测平台、权限或缓存层。

本批采用**同源捕获重放**：双方从 anchors 实际捕获且与源几何已核对的同一原始capture开始，各新会话在线计算。它测当前产品的观察与交付模块加模型消费；不把重放写成新Blender采集或完整桌面MCP安装收益。模型可见的是原始几何/相机，不是capture中可能附带的审核派生信息。P调用实际安装的生产者及既有公开投影，保留运行时来源链。新图必须在各会话中实际构造，不能读取旧PNG或旧owner答案作为该次观察。

公共渲染可直接复用当前 `rasterize_attention`。两组统一使用当前产品表面颜色 `(180,190,205)`，不要直接采用capture里原始的白色字段，否则会改变图像和对比判据。原始三角ID用输入顺序的 int32 ID 作为 face_patch_ids，在同一深度获胜步骤输出；这是通用原始buffer，不提供发现器的区域分组、面片ID、coverage或定位答案。模型可自行将三角ID合并成面。N不得调用产品发现器、可见性索引、选眼器或锚点聚合。两路公共helper能力一致，P额外产品内部缓存照实计量；若原生补查造成再次构造，同样扣实际次数，不能只按不同相机数计费。不得改RGB/深度/材质制造边界。
