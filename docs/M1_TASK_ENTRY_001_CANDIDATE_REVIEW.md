## 一次有依据的精简

普通 scene_observe 的 `_validate_arguments` 对同一请求重复调用 validate_query：合法 nearest 五次、显式 task 四次；简洁入口已经各一次。下一批只将普通适配层的规范化结果保存并复用一次。

最小方式：显式 query 在原位置校验；缺省 query 在原 include_image 类型检查后归一化。随后 mode、alignment 和 task 判断复用局部结果。保留 service.observe 的独立校验，不添加 trusted 标志、缓存系统、路由器或新公开参数，不重写调用者字典。

验收使用固定前后版本的定向等价检查，包含 overview/task/nearest、缺省及显式 null、非法 query 与非法 image 同时出现的错误先后、session/目标互斥、额外字段及 stdio 恢复；用调用计数证明适配层去重。复用本批离线正确性检查，原 Blender 证据继续标为首版记录，不机械重跑或称为新版本实测。

这项精简有维护价值并减少确定的重复工作，不预计它解释此前几十秒的模型耗时。仅此一项，不为继续优化而新增层或反复跑性能矩阵。
