# M2-A1b：原预算内的区域位置摘要

登记于实现前，2026-11-01。修复的是公开选区信息缺口，不是完整成员交付或模型收益。

默认继续输出 `raw-mesh-structure-v2`。只有受信本地配置 `structure_region_mode=summary_v1` 才请求独立的 v3 typed host 能力；不支持、协议错配或源码混用均拒绝，不静默降级。模型请求不能切换配置。旧消费者不接受 v3；新版消费者须显式选择 v3。

v3 保留原报告与完整 patch 格式，新增 `region_summary`。其 entries 仅补充未交付成员列表的分量：类别、原分量序号、成员数量及摘要、位置、源绑定的 summary_id。摘要不是 patch_ref，没有渲染或写入权限。成员完整度、位置完整度、扫描完整度分别记录。源位置是固定 typed host 的报告；客户端没有全量 raw，结构验证不等于独立重算几何。

预算保持：总区域数 128、每完整 patch 最多 64 成员、工作量 262144、诊断 64 KiB，以及原任务图片/文本/请求/期限限制。完整 patch 和摘要合计占区域槽位。额外成员摘要与坐标计算计入同一工作账本。超限、未知坐标、扫描未完或位置未覆盖全部分量时，全局选区继续未知；并列不猜。不得把摘要补齐当成成员补齐。

验收覆盖：超过 64 成员的边界；超过 128 分量；报告、工作、期限边界；非有限坐标；错误源绑定、重复序号、虚假完整度、错协议；默认 v2 回归；真实独立 Blender 和公开 MCP 诊断仅凭锚点选区，选择摘要区域时不得获取图片。既有相机、像素、恢复、任务生命周期与配额保持。

仅安装隔离候选，正式 22fb 和共享 Blender 不变。历史封存、旧质量与成本失败、M2 全量成员要求均保留。工程功能验收不是新 HE/Native 配对成本试验；后者需要重新固定两端版本、对齐证据写入策略并登记门限。正式模型试验仍不开放。
