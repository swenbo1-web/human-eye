# CF-S 必要性审定：当前版本采用精确 TD 展示

日期：2026-11-06。决定：**ACCEPT_CURRENT_SCOPE_WITHOUT_LEARNED_S**。S 必要性审查收口；当前版本不部署学习 S，保留既有完整 TD 与精确 Top-K。CF V+A、TD、AO 源码和已验收收益不变。不将此决定表述为 S 模型训练/性能通过或三个学习头均已实现。

## 决策依据

当前已验收 AO 第 13 题在完整 TD 归约后消费有序六个原面、六项指标及世界米制质心，没有提前消费截止、预取入口或未完成 TD 时的第一卡发布。生产 TD 已对完整 score 做分区选择，仅排序选中的 K 行。在同一分数定义与六行预算下，精确 Top-6 已达到该任务的召回和顺序上限，增加学习排序不能进一步提高这项指标。

这只针对既定展示任务，不把复合 score 当作通用风险真值。独立解析例中，复合 Top-6 是原面 3–8，伸长、面积、法向与位移各自极值是 0/3/1/2。若需要单项查询，应从已持有的完整指标数组精确选面，再用 AO 现有显式选面能力发布原值/原 ID；不能从当前六行猜测未发布面的极值，也不能乘 S 权重改写原始事实。

提前稀疏观察也存在信息限制：保持允许读取的采样面、参考、占用和请求完全相同，只改变一个未采样面，就能让唯一热点分别出现在三个不同桶。两个桶预算无法对所有这些可能状态保证召回。该反例不否定学习在特定分布上的平均收益；当前缺的是实际提前消费需求、可重叠工作和已证明的净收益。

## 实际复核

- 实施端 10 项便携预检由主干复跑通过。四个预定训练样本共 598 个原面，独立 QR/SVD 与 TD 数值一致，解析例的 ID 和原值通过。
- 16 个来源/产物身份与四份 manifest 重新生成核对一致：1,098 个规格条目、1,089 个同源 group；每 seed 240/60/60 主组及 6 个诊断规格。验证、留出和诊断未物化，数量不代表这些场景已验收。
- 独立审查另做 1,085 项生产 Top-K 对 Python 独立排序比较及 84 个六面子集枚举；同分原 ID 和 NaN 排除行为一致。用另一组幅度和角度复现复合/单项极值反例，并验证三个同输入热点桶的反例。
- 独立公开消费者重放 AO 原归档两个状态，公开结果逐字段一致；另解析重建 2×70 个原面，验证全部六列、原面 0–5 和第 8 帧世界质心。两状态属于全同分平移控制，不冒充广泛热点数据集。

本阶段没有运行 Blender、GPU、S 训练或性能测试，没有任何 S 延迟收益数字。所有测试和独立审查都未更改生产算法，也没有启动另一轮优化。

## 草案与后续边界

[条件实验草案](CF_S_ACCEPTANCE_DRAFT.md) 保留为设计记录，**未冻结为正式实验**。其中第一卡 p95≤.90、完整发布≤1.10、召回和内存阈值均是有真实新消费入口后需重新审定的建议，不是已通过的验收门。未来若出现明确提前准备需求，仍需冻结生产入口、实际重叠机会、一般变换下的尺度、单位/诊断真实构造、浮点近同分原面规则及完整成本。

当前六模块的既有能力继续复用，CF 包含已验收 V+A 两个学习头，S 的当前展示职责由精确 TD 承担。下一项是 [统一生产引擎接线](ENGINE_INTEGRATION_WORK_ORDER.md)：现有完整编排仍在 verification，统一生产 Session、模型载入和同场景观察—动作—回读—反馈循环尚待实施及验收。附件的 <12 ms 和旧 MCP 切换均未获证明。
