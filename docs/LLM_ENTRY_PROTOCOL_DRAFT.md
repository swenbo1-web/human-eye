# 本地间隙任务入口验收协议草案

2026-11-06。首个公开任务限定为 `close_gap`，目标是用固定对象对的实际间隙完成用户任务。`eye_run` 提交目标与容差，可以明确请求终态图。`eye_inspect` 按需查询绑定对象目录、最近任务的结果或见证，以及当前图像或同源相机证据。Blender 宿主管理连接与会话生命周期，并保证绑定的刚体平移前提。数值任务默认路径不生成 AO、PNG、TD 或 CF，模型不参与每一步预评分。本文给出 CPU 验收矩阵和整任务成本边界。此前按单动作编排的候选归档为 `artifacts/llm_entry/preflight_001/provisional_candidate_001/sources.zip`。 [引擎验收](ENGINE_V1_ACCEPTANCE.md) · [完整任务协议草案](LLM_TASK_PROTOCOL_DRAFT.md)

## CPU 验收矩阵

调用真实 JSON-RPC dispatcher，以可计数的本地任务服务替身固定实际返回值、异常、证据字节和所有权。每个案例核对一条输入和最终返回，并单独记录实际 dispatch、测量、写入、查询、渲染和释放次数。替身案例只证明工具合同及生命周期，实际 Blender RNA、几何与 PNG 由独立功能资格核验。

| ID | 输入和故障注入 | 必须检查的行为 |
| --- | --- | --- |
| MCP-01 | 合法握手，初始化通知，工具发现，ping，无任务 ID 查询目录 | 只发现 `eye_run` 和 `eye_inspect`。匹配请求 ID，单行 UTF-8/LF 响应，通知无响应且不触发任务。初始化前不能调用工具。目录只含绑定对象 ID/标签/角色、世界米单位和支持任务，无需打开任务会话。 |
| MCP-02 | 不支持的任务、证据类型、旧工具、空/未知任务 ID、缺参数、额外字段、布尔值、负值、非有限值及溢出 | 协议层拒绝非法 JSON 和未知工具。工具拒绝未登记参数与超出数值域的合法 JSON。拒绝发生在写入或渲染之前，已有合法结果可继续查询。 |
| MCP-03 | 目标和容差合法，替身给出与命令意图不同的实测终值 | 只有一个公开请求和应答。结果反映固定对象对的起末实际状态与写入次数，成功由实测终值和任务谓词确定。默认负载只含必要任务事实，不交付 AO、图、预测、图像评分或私有候选历史。 |
| MCP-04 | 目标起始即满足，或首次写入后同参提交新任务 | 当新测量已在容差内，写入为零，见证绑定新的初始实测。每次合法调用取得新任务 ID，JSON-RPC ID 只用于关联请求及响应。 |
| MCP-05 | 写前失败、已写的阶段错误（有或无可用回读）、实际未达标 | 区分写入状态、实测终值及未知项。错误保留已知 Outcome 并清除失效图像证据。下一次显式请求重新观测。禁止以目标值、建议位移、旧结果或自动重试冒充成功。 |
| MCP-06 | 请求当前 witness，然后重复读取 | 可核对见证归属的任务、对象、单位和真实测量绑定。仅按需投影证据，重复读不会写场景或重跑局部求解。缺见证有可区分的状态。 |
| MCP-07 | `eye_run` 明确 `image_mode` 或按需请求当前 image，覆盖 PNG sentinel bytes、未配置图片及图像不可用 | `eye_run` 在真实回读后同回包交付请求模式的终态图。标准 MCP `image/png` 内容块解码后与原字节一致，同模式重读不重复渲染。图片包含任务、实测观察、frame、对象及模式和面板绑定。失败、缺图或状态过期不能标成有图。真实渲染、像素和宿主模型可见性另验。 |
| MCP-08 | 恢复当前结果及相机，切换图像模式，再请求旧证据并关闭宿主 | 恢复结果或相机只返回 JSON 文本，无新动作或渲染。两种模式有各自的实际图像 ID，复用连接级渲染器。旧任务引用失效，关闭最多释放一次，数值连接不创建渲染器。 |

CPU 用例还应区分 MCP 错误和真实任务停止，固定错误结果仍用机器可判别的状态。替身若注入非有限的测量或回读异常，返回必须是合法 JSON 且保留不可确认的部分。用例不把旧语义的 `eye_open`、`eye_step`、`eye_close` 纳入 v2 公开调用序列。

## 整任务效果与计时边界

正式任务集合先冻结对象对、初态、世界米单位、允许控制、目标、容差、写入边界、停止规则和独立验收。独立读取真实 RNA 和场景几何，核对实际目标与各对象不变量。无符号最小表面距离只支持本任务的间隙判断，不能用零距离推断接触与穿透类别。正负例、初始已达标、空面、无进展、见证变更及失败留在预登记集合中。失败、超时及不能判定的数据均保留原始状态。

主指标从用户意图和已登记材料可用起，到首次得到独立认可的真实终态止。总耗时包含所需初始化、任务提交、测量、写入、纠正以及用户任务确需的查询或图像。脚本独立核验、故障探针及留档单列时间，冻结结束事件后再读取评分真值。成功率和完成时间一起报告，超时/失败按预登记截止点保留，避免只比较成功样本。辅指标包括公开工具往返、本地 IPC、实际测量、写入、证据查询与重读次数、文字和 PNG/wire 字节、CPU 与持有峰。冷、热和纯数值/按需证据分组。

合理原生对照可以使用同一场景的 Blender API、可用几何计算、常驻辅助函数、批处理、缓存和按需取图，享有相同目标信息与写入范围。双方可本地完成的步骤不强制模型逐步确认。若本地脚本代替模型驱动，结果只能说明该本地任务与整条本地调用链。真实模型条件另冻结相同的模型、任务、可见输入、允许的操作与失败上限。模型实际决策、补查及原始使用量单列。API 未提供 token 或费用时记为未测，字节数据用于传输成本分析。

窄传输开销可另测 engine-direct、direct-handler 及真实 wire-entry。与候选比较的同责薄层需共用同一 relay/pump/IPC 并生成同一最终工具内容。若另列旧 addon，使用真实 `execute_code` 上的常驻薄处理及相同职责。局部 IPC、序列化与轮询结果用于归因，独立于整任务成效。样本数、配对调度、阈值、机器和命令由正式工作单先登记。
