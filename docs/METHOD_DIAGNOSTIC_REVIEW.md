# 限定计量诊断审定：冻结前瞻方法，不改写历史失败

2026-11-06。决定：**FREEZE_FORWARD_COST_PROTOCOL**。同一 B 的两次限定诊断和一个资源方法进程已独立复核；可以事前固定 [正式成本协议](INTEGRATION_COST_PROTOCOL.md)，生产功能自测和质量等价通过后执行一次正式对照。无需再开 B/B 探针，也不重开任何已验收算法优化。生产实现、正式成本及整机结果仍待独立验收。

本轮只读取 `method_diagnostic_001` 的 `42ddcf2` 源归档并运行 CPU 审计，没有启动 Blender/GPU，也没有将实施者正在修改的 control 当成旧实验源码。两次时延和一次资源进程均退出 0，580 项源 ZIP 与 manifest 一致，登记输入、观测项目导入及运行环境相符。manifest SHA256 为 `a2d5d9639c174de13fe46f3ff7b04f8473b23206e5fe2cca46554e6410325508`。

## 两次时延诊断

每进程 15 对预热、93 对计量；总计 432 臂记录，其中 372 实测臂。原始绝对 t0…t4 和五段汇总独立重算一致。

两进程内上述观察均 ≤1.05。审查对 432 条 next 明文字段重新规范化，对两进程共 8 份 NPZ 的十组数组逐项核对 dtype/shape/bytes，并读取实际 PNG；同案例/重复/物理臂的跨进程 216 组一致。另以封存参数和独立 NumPy 公式复算三例 V/A 更新及 shape next 预测，逐位一致。

这些证据证明所保存的活跃 CF 状态、规范化 next 视角/动作字段及图像可重复。冻结源码也表明 next 确实执行 capture/BC、TD、VG、AO 和更新后模型推理。**它们不是完整 AO/TD/全部网格或每根 ray 几何的独立 oracle**；正式 I/B 仍须执行原完整质量门。作者 expected_state 使用相同学习函数及实际写库 key，属于编排重放；本次独立公式复算扩大了检查，但没有重新证明所有特征/几何真值。

首次 `preflight_002` 的 next 1.076810 继续记录为失败。两次诊断改变了创建次序、执行相位，并加入 GC/时间观测及区间外证明工作，不能据两次通过断言旧偏差已消除、由某一个因素引起，或噪声永远 ≤5%。此次决定是：在未发现不同工作或状态复位错误、两次限定复现可比较且数据齐全的前提下，主干采用同样明确节奏的有限前瞻 I/B 实验。原 5% 和旧 CF 10% 门保持，所有局部、顺序和慢事件继续公开，不用后验较好统计覆盖失败。

GC 两进程各记录 11 次，其中各 3 次与实测 next-observe 重合，持续 55.5–407.7 μs；每场景最慢的三个 next 均没有 GC 重合，不能把全部尾延迟或旧失败归给 GC。臂间区间外间隔中位为 9.3698/8.7594 ms，证明整理与落盘会影响整体节奏；正式两臂采用同量审计，不声称计时外工作没有观察影响。

## 资源读数及承诺边界

单条 B 链时长 98.4804 ms。正确 reset_peak 后，起始 traced current 为 6,621,253 B，返回 current 为 6,818,879 B，窗口 peak 为 7,445,833 B，比起始高 824,580 B。该方法探针含采样器的 Python 活动，不能作为生产 I 资源成绩；正式托管轮和 OS/DXGI 轮分开。

6 个有效周期记录，最大间隔 **22.402 ms**、单次查询最长 0.554 ms。样本可见工作集为 285,716,480 B，LOCAL/NON_LOCAL 各为 11,931,648/12,652,544 B。它们不能证明 2 ms 覆盖或真实瞬时峰。正式协议在任何 I 成绩前明确采用“预定阶段点＋有效周期记录的观测最大值”，GPU 取同一记录两组 CurrentUsage 之和；8 MiB 数值不变，但声明只限该可测对象，并另设逻辑 GPU 资源等价及所有权硬门。未采到的瞬时分配不作通过声明。

探针确实完成一次 offscreen free、移除两相机及数据、清空声明的会话 NumPy 根，并在 close 后重读了旧 AO/PNG。但是 `for frame,...` 的最后一个私有 ObservedFrame 仍被循环局部变量持有，未纳入根清单。故“外部释放后登记 owner 为零”不能扩大为所有活 backing 都为零。正式 harness 在 census 前清除该局部变量及其它私有审计引用即可；不修改旧原档，不要求为这一验证脚本遗漏再开方法探针，也不认定生产泄漏。

托管增量 ≤256 KiB/1 MiB、逻辑资源/释放和明确的 RSS/GPU 观测增量门，均在正式协议列出保留点、窗口、归属、缺测及判定方式。数值预算不以本次单个 B 的占用倒推。这次冻结的是如何验收，不是已经取得了资源收益。
