# M4-A2：控制来源与最终求值的有限可行性验证

2026-11-02。此批交付验证代码和求值边界，**没有增加产品约束/IK支持**。运行源仍为109份、`03acbda388b24f948a8688cc45e8aa1afdfb80333f3b7fbb551d7068913d66ce`；A1入口、隔离安装和默认MCP/Hook保持。排期仅见[唯一主计划](PRODUCT_ROADMAP.md)。

## 结论与选择

静态、单一、全轴、全影响、WORLD/WORLD REPLACE Copy Rotation，目标为独立本地Empty，是下一批可优先产品化的求值域。有限原型已经把输入通道和实际姿态分开，在9个原生准入例中用独立旋转矩阵核对；另18个复制旋转配置被明确排除。这是选择下一域的依据，不能外推为任意旋转轴、控制器、约束组合或完整角色已经通过产品验收。

IK继续保留为求值事实和残差调查。18个IK资产中，13个有独立端点真值：8个通过，5个未通过预登记位置门限；另5个只检查来源、排除与只读性，没有端点或完整朝向认证。没有把域外拒绝、未检查或成功启动算成IK解算正确。

## 为什么必须分开数据层

1. 原始骨架ID上的rest矩阵与层级，是角色参考。
2. 原始对象上的当前通道和`matrix_basis`，是当前控制状态。动画/驱动启用时，这些数值本身可能已被求值，不能称为作者未求值常量。
3. 动画关键帧、插值、action/slot、驱动表达式及变量/目标，是控制来源，必须另存；不能从一个当前通道值恢复它们。
4. 约束的目标/极点、顺序、空间、混合、影响、启停、有效状态，以及IK骨骼限制/刚度/伸展和solver配置，是求值依赖。
5. `evaluated_get`后的pose/world矩阵和端点，是实际求值结果。它们不必等于输入通道，也不直接表示损伤或解剖异常。

复制旋转例中，Tip输入通道约20°，最终局部视觉旋转约65°。物体转20°、父骨转30°、世界目标65°时，Tip自身约15°。不能按旧FK要求“最终局部旋转必须等于basis”，也不能把65°当成作者设置的20°丢弃。父/rest相对矩阵公式与swing/twist数学可以复用；**来源合同、支持域与一致性判据须独立建立**。A1的约束/IK unsupported没有删除。

## 有限捕获与来源失效

`verification/rig_evaluation_contract.py`是验证层只读探针，不属于运行包。最多8对象、8骨、8约束、8条曲线、每曲线16关键帧、每driver4变量和512KiB快照。它保守捕获整份小场景的相关对象/原始rest/当前通道/约束设置/控制源及求值矩阵；NLA、复杂slot/曲线形态和本批未实现的RNA来源拒绝。它不证明通用rig依赖闭包，也不是面向不可信输入的生产协议。

所有捕获在新factory文件的独立后台Blender内进行，固定文件SHA，关闭autoexec；controller给每个完整子进程30秒超时，完成后检查stdio尺寸。快照绑定进程内文档epoch、对象/数据session身份、帧/子帧及完整内容摘要。相同名称不能替代实例；SHA绑定内容，不能单独证明来源真实性。输入前后比较、双读和外部显式RNA观察器分别记录，观察器先使场景进入已求值状态，不把它说成冷启动性能测试。

同一进程另有固定测试actor做14步操作：静态8步、动画3步、driver3步。actor只改独立文件的内存副本，不保存；探针本身没有RNA setter、切帧或保存API。11次相邻状态变化均改变source并拒绝旧证据；其中仅改目标附加属性、仅改帧时，求值输出完全相同；同名删除重建目标后，rig矩阵相同但目标实例不同。动画同文档1/6/11帧得到10/40/70°，driver变量和表达式变化有独立角度核对。

这说明缓存不能只比较最终姿态或对象名称。现有整小场景捕获也会因无关属性保守失效，未来有限生产域应收窄为已证明的固定依赖集合；不能把此原型直接接入默认高频路径并声称成本通过。

## 原生矩阵与失败边界

实际环境为Blender 5.2.1 LTS，构建`9e2066aef7ef`。45个不同资产全部完成双读、来源/端点对应、外部RNA前后一致及原文件SHA不变；复验不累计为更多不同场景。0产品几何setter、0保存、0图像、0正式模型试次。

| 组别 | 结果 | 能证明什么 |
| --- | --- | --- |
| 静态复制旋转准入9例 | 独立NumPy旋转矩阵全部一致 | 含输入/结果不同、负向目标、父转动、物体转动、rest roll、子帧和同名重建；原生目标旋转主要为Z轴，不代表所有三维旋转组合已验 |
| 复制旋转排除18例 | 全部按登记边界排除 | 部分影响、mute、LOCAL/offset、轴选项、缺目标、非均匀尺度、父级/骨目标、多约束、目标动画/driver及rig driver |
| 原始直链IK11例 | 6个有端点真值，2过/4失败；5未认证 | 失败保留，不与排除正确混成“全部通过” |
| 新增对照IK7例 | 同门限6过/1失败 | 六例12°rest初始弯曲；一例直链去极点。新增前登记，未替换旧夹具或放宽容差 |

预登记位置容差为0.0002场景单位，不是物理校准认证。关键边界：

- 直链＋极点的4个可达例，骨长和连接关系正确，但端点误差约0.585786。例如目标(1,1,0)，实际端点约(1.414214,1.414214,0)。几何可达不能直接写为实际已到达。
- 12°rest弯曲的4个可达例误差约0.000129；直链去极点的误差约0.000044。该有限对照表明初始链/极点配置会影响此批求值结果，没有定位Blender求解器内部根因，也没有证明所有弯链稳定。
- 弯链不可达例应径向停在(0,2,0)，实际约(-0.00045948,1.99999356,0)，径向端点误差约0.00045952，仍失败；保持原门限。
- 完全伸展可有正确端点而关节方向不唯一；零距离、近零及共线极点不能提供完整朝向结论。近零例端点误差接近2，不能以“读取成功”称为解算正确。
- 仅开启约束`use_stretch`并未伸展，因为实际骨骼`ik_stretch=0`。这一项只检查配置和实际结果，不认证伸展解算；也说明记录约束开关不足以覆盖IK依赖。

本批IK真值仅使用单位双骨的连接、长度和解析端点可达约束，没有完整关节朝向/弯曲分支真值。逆运动学端点正确、角色关节规则满足、蒙皮没有塌缩、动作稳定，必须分别验证。
