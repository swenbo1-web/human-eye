# 本地任务 MCP 接入口草案

宿主在 Blender 主线程把场景、视图层和指定的移动物体及参考物体绑定到受信本机服务。模型只能操作绑定的这一对物体。宿主负责启动、停止和释放资源，连接只保留最后一个任务的证据。绑定方确保两个求值表面拓扑固定，移动表面只随请求做世界平移，参照表面固定。宿主在重新载入文件前停止服务，在任务及其证据读取期间保持场景稳定，并确保另一控制器不会独立写入同一对物体。

## 关闭表面间距

`eye_run` 接收 `task="close_gap"`、`target_gap_m` 和 `tolerance_m`。目标和容差采用世界米，必须是有限的非负值。场景需满足刚体平移和固定参考的前置条件。当前间距已在目标容差内时只读确认。目标要求增大间距或输入超出支持范围时拒绝执行。

本地控制器计算全局最近点对 `a,b` 和间距 `d`。当 `0 ≤ g < d` 时，沿 `b-a` 平移 `d-g`。任意点对由三角不等式得到新间距至少为 `g`。原最近点对移动后的距离为 `g`，因此该刚体模型下的新全局间距恰为 `g`。Blender 执行一次平移后重采集两个求值表面，再测一次全局间距。达标字段取实测值，命令与实际位移分别返回。

结果返回任务 ID、物体 ID、观测和帧、米单位、目标、容差、写状态、前后间距、误差、命令及实际位移。未测值为 JSON null。失败带原因或阶段，写入状态可能为 `not_written`、`written` 或 `unknown`。失败后保留已知结果并清除失效证据。下一条显式请求重新观测，再决定是否需要写入。任务不会自动重试。JSON-RPC 请求 ID 用于关联回包。

需要图像时，在 `eye_run` 增加 `image_mode`，值为 `NATURAL` 或 `SECTION`。启用图像的绑定在同一个回包附上一张终态 PNG。元数据标记实际模式、场景物体和面板含义。零间距使用 NATURAL。图像失败时保留已经获得的实际动作与间距，并报告图像状态。

## 按需读取证据

`eye_inspect` 可用 `evidence="directory"` 查看绑定的物体和支持的任务。`result`、`witness`、`image` 和 `camera` 要求最新的 `task_id`。`result` 取回原任务正文，`camera` 按当前 `image_id` 取回实际视图相机、场景单位和切面元数据。这两种读取只返回 JSON 文本，复用当时的结果和渲染数据。见证含对应观测 ID、世界米制的最近点和源三角形编号。已写入时证据来自真实动作后的观测，零写时可用已有读回。无可用证据时返回 `unavailable`。

图像复用同一控制器的目标几何，只按需捕获明确绑定的遮挡物。GPU 渲染器首次需要时创建，并随连接关闭释放。相同模式的最近终态图可复用。显式请求另一模式会生成新的当前图及 `image_id`。

默认执行路径完成真实 BC 读回和紧凑结果交付。完整 AO、TD、CF、矩阵、GPU 图像和训练反馈无需参与数值任务。宿主通过一条 UTF-8 JSON-RPC 行发送一次请求，stdio relay 只转发字节，Blender 主线程处理请求和动作。回包正文是一个 JSON TextContent，有图时另附一个 ImageContent。真实宿主发现、模型收图和任务收益另有验收。
