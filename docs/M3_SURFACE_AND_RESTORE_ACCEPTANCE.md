外部 GLB 固定到 KhronosGroup/glTF-Sample-Assets 的 `8f492390ddc7a2ae221a1369ef560589cf8c70fb`，验证 Git blob SHA-1、文件 SHA-256、大小、GLB 结构和无外部 URI。公开复现器在导入前复核固定 SHA-256。许可证来源分别是上游 [Avocado](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/8f492390ddc7a2ae221a1369ef560589cf8c70fb/Models/Avocado/README.md)、[Lantern](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/8f492390ddc7a2ae221a1369ef560589cf8c70fb/Models/Lantern/README.md)、[BoomBox](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/8f492390ddc7a2ae221a1369ef560589cf8c70fb/Models/BoomBox/README.md) 中的 CC0 声明。二进制资产未进入本仓库。

最终结构通道 21 个目标中，4 observed、12 partial、5 unavailable；16 个可读目标的取景后新鲜 raw 摘要保持，19 个原 blend 文件保持。**仅 Avocado 实际交付 1 张 384×384 原生局部 PNG。** 其他目标的图像拒绝或无完整 patch 没有被算作视觉通过；该图是结构边界观察，也不是新 B2/C 特征已可见的证明。

主要边界：

- 超出原始来源预算的细分对象明确拒绝；较密来源扫描停止时保持 partial，不能把提前停止的短耗时说成加速。

## B2：精确源事实、完整度和有限输出

`surface_geometry.py` 是 Blender 可独立加载的 stdlib helper，宿主按源字节摘要校验。使用实际 `calc_loop_triangles()` 与原多边形索引，不重造扇形三角化，不焊接 UV 接缝。原始数据、三角化和结果分别绑定摘要。

将有限 binary64 输入的矩阵、单位和顶点转为精确 dyadic 坐标，再用共同整数坐标做空间包围和几何谓词。非平行平面切片区间、共面凸多边形裁剪、合法共享顶点/边判定保留精确性。不会因为两个三角形相邻就跳过其折叠重叠。点/线/面接触和近重合均是事实；横穿还要求相交线进入双方相对内部。

初版单轴 sweep 让松散卷曲管在没有发现接触时耗尽工作预算。改为精确外包 BVH：节点分割保留所有三角形；自对子按 LL/LR/RR 遍历，互异节点分割一侧；有序源对子不重复。完整扫描必须满足“包围剔除对子＋精确测试对子＝全部 n(n−1)/2 对子”。独立小规模穷举验证了候选集合和计数。紧密卷曲管仍停止，未借优化提高原额度。

界限：4096 顶点、4096 三角形、16384 精确候选对、128 交付项、4096 坐标 bit。捕获/源校验、宿主专项扫描、consumer 重放分别有最多 262144 工作单位，**不是旧九类拓扑检查总工作量不变的承诺**；共用实际原期限，专项调用上限 30 秒。原注册任务 6 查询、2 图、180 秒和持久额度不变。文字任务不取图。未知及省略不能等价为干净网格。

完整 MCP 21 个目标：10 observed、2 partial、9 unavailable；12 个可读目标各完成诊断三次、参考、预览、撤销拒绝，共 99 次工具调用。登记参考额外读取一次来源，成本单列，没有藏在诊断耗时之外宣称零成本。

独立真值没有复用生产空间树、平面切片或多边形裁剪。另一套六边段/平面测试和共面边段半平面算法穷举球壳、Avocado、Suzanne 的 **712969 对**；接触总数 40/413/178 及交付源对/维数一致。另有固定随机种子的共面/非共面解析反例和独立 BVH 对子集合检查。近平行域另有精确阈值正负例；非平行近距离、体包含、松散线及意图仍 not_checked。

## C：参考差异的含义

仅本机 Python `ReferenceRegistry` 可登记参考意图及“从 owned 副本保留同索引”的对应合同。模型只传已交接的 ref，不能提交批准、参考正文或自行声明对应关系。该合同依赖可信来源；对于保持相同拓扑自同构的恶意重排，几何本身不能证明语义对应。不能把 hash 当来源认证。

每次重新核对对象 incarnation/document、原始索引拓扑、矩阵、单位、宿主三角化和撤销状态。首先计算精确向量位移，再按参考的面积加权法向分解。尖锐/反向/退化法向不能用于可靠有符号解释；**此时明确的源位移仍报告，法向/切向分量为 null**，不能误报没有变化。远原点位移在局部消去平移后计算，不借用原生世界坐标精度。

凹陷薄片相对明确的解析平参考检出 37 个阈值外顶点、1 个区域。正常凹槽以自身受信参考比较为零变化；纯切向移动不叫凹陷。错单位/矩阵/索引/实例、撤销、无参考负例均拒绝。区域成员和区域数的省略分别可见。输出有限 patch 成员/位置，**没有把旧结构边界的图伪装成新曲面特征局部图**。

## D：独立恢复内核及崩溃语义

只实现“恢复指定参考小块”，不做任意自由修复。最多 64 顶点，单顶点源仿射位移默认不超过 1 毫米（受信调用上限 10 毫米），回调批准绑定原来源、参考、索引、目标摘要、最多 2N 次 setter 尝试和收到时刻起的原期限。主机嵌入方必须提供独占来源/原生 setter 和真实批准回调；这不是 MCP 参数授权。

预测形状核对参考三角方向和面积；新接触/横穿关系相对当前状态不能增加。接触检查不完整或交付被截断时不执行。每次实际 setter 前/后比较完整原来源及保护区；提交后抛异常仍先回读，不能按未提交处理。恢复使用同一额度与期限；不覆盖外部变化，不在未知后重试。新写域不借用旧刚体回滚资格。

`RestoreJournal` 是执行必需项：操作者选择的现有独立目录，16 个终身 slot，OS 独占 writer 锁，每条固定大小记录；写前 pending，flush/fsync 后原子替换，终态保留原批准 scope。未完成、损坏、未知或异常发布使新实例隔离；恢复只是只读历史，不能恢复 grant、续额度或把缺记录补 0。文件哈希不是同账户安全边界，也不宣称目录断电持久化。

真实 Blender 5.2.1 factory 测试九类：平面/曲面恢复、提交后异常且恢复检查点、丢回读、恢复异常、保护区异常、拒绝、已满足、批准中撤销。平面和曲面各一次实际 RNA setter 恢复约 0.5 毫米，保护顶点保持；提交异常场景实际执行一次＋恢复一次，未抹去计数。只操作本批新建资产。

六个独立 Blender 子进程在 preparing/真实首写后/终态后各硬退出两次，`os._exit(37)` 绕过 finally。准备和首写后恢复均 unknown/null；终态后虽未回执，保留历史 1 次且不能重放。父进程按实际 Popen 句柄等待退出，只读取记录，未强制清理用户 Blender。
