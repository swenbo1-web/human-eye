## 固定生成方式

1. 下载六包、读附带说明与网格元数据后，先提交 `PLAN.json`、`SOURCE_INDEX.json` 和 `SPLIT.json`。固定每源 reference 文件与按自然排序首个不同的 poses 文件，共至多 12 个观察；如果两个几何完全相同，保留重复事实，不继续向后选到满意姿态。只从 poses 包选择，不能将 collapse 算正常形状。
2. 每姿态选择至多两个 F 区域，F 目标 384 点；在未添加损坏的网格上用确定性、面积覆盖的测地采样选择 ROI。固定 seed 1729，排除非有限、原本退化及无法建立法向的点；边界/非流形问题单列。第二 ROI 优先与第一不重叠；不足时记缺额，不复制凑数。用当前几何和拓扑确定选择，不读模型分数或损坏标签来挑 ROI。
3. 每个 F 内选择四个分散的损坏中心。用到 F 边界的测地距离定义可用内部，再以确定性最远点采样选择；中心相同或没有可用内部则记不足。选择器的精确规则、容差、顺序、失败条件在生成前固定一次。
4. 对每个中心，以该中心到 F 边界距离 D 为尺度，半径固定 `r/D ∈ {0.35,0.55}`，深度固定 `a/r ∈ {0.05,0.15,0.30}`；沿未损坏中心法向生成 `-a*(1-(d_G/r)^2)^2*n_center`，仅 `d_G<r` 范围改变。这是合成局部凹陷标签，不是人类艺术修复偏好。
5. 每个 ROI 保存一个未扰动观察，以及四中心×六强度组合的受损观察和一一配对关系。正常数据可实体去重，但每个受损观察都必须能精确取回同一部位的正常对照。
6. 公共索引分别列来源/派生组/姿态/ROI/中心/半径/深度/状态/有效性。当前输入只包含当前几何、拓扑和区域映射；未扰动坐标、位移标签及支持掩码放监督文件，不进入感知输入或候选选择器。

满额上限为 **24 ROI、96 中心、576 受损观察 +24 正常观察 =600 个唯一观察**；开发上限 400，验证 200。实际少于上限即如实记录，禁止换来源、反复改变尺度或补新中心刷满。

完整原网格每姿态只存一份；副本用有索引的局部位置/位移保存并能重建，避免每个观察重复一整份网格。后续编码器仍能读取重建后的完整当前邻域，不能用完整正常网格作为推断参考。

## 对抗固定部位捷径的抽样与审计

- 实现未来可直接复用的成对状态抽样器：按开发派生组、网格身份、姿态、ROI、损坏组合逐层均匀；每个抽中配对的正常/受损状态等权。逻辑重复正常曝光不产生额外独立样本，存储与抽样权重分开统计。
- 保存一次固定 seed 的 1200×1024 抽样索引模拟，**不训练**；核对正常/受损权重、来源权重、相同源点映射和验证零进入。未来 pos_weight 与归一化只从开发输入/监督计算，不预先沿用旧值。
- 统计损坏中心分布、ROI 交并、各点受损频次及天然凹凸部位覆盖；通过源网格 ID 与派生关系核查 train/validation 交叉。正常表面的天然凹陷仍为合成任务阴性，不按曲率自动标成异常。
- 核对配对拓扑与源 ID、全部损坏范围外逐位不变、标签由真实位移生成、目标内面积/深度/支持点数。记录相对原网格的新退化/翻面和异常法向；不靠“只沿法向”宣称零翻面。
- 检查源网格面绕向与法向一致性。闭合组件可用有向体积核对方向，开放扫描沿来源面绕向并保留方向依据；不能确认向内方向的区域记未判定，不把任意负法向位移自动解释成人体凹陷。固定代表样例用几何视图核对方向，不按模型得分挑例。
- 非有限、新退化或新翻面行保留在总分母与失败清单，标为不用于本类凹陷训练；不缩小幅度重试到通过。损坏支持过小、跨越可用 F、重建不一致也明确失败，不能悄悄忽略。
- 记录每个凹陷半径/深度相对官方编码器 `0.05*bbox_diagonal` 邻域的比例和邻域中受损点占比，帮助下一轮判断变化是否被采样稀释。本批不运行编码器、旧头、新头或阈值调参。
