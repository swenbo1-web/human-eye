# BC 距离核：事前冻结协议

2026-11-05。RB-A、RB-B已独立验收，BC按原[竞争工作流](RADICAL_V1_COMPETITION_WORKFLOW.md)正式推进。本协议把既有512面≥2倍、128面p95≤1.20倍门落实到可复现输入和计时边界，并应用[历史教训](HISTORY_LESSONS_FOR_RADICAL_V1.md)。两端独立竞争。

## 输出和搜索语义

输入为可信、有限float64世界米制顶点和合法三角索引。表面集合仅由三角索引定义；未引用顶点和松散边不参与。输出至少包含非负`distance_m`、原始`triangle_a/triangle_b`索引、世界米制`point_a/point_b`。相交/接触表面距离0，嵌套但不接触表面可以有正距离，不能由距离符号推断包含或穿透深度。等距时任意真实最小见证均可，不能返回错面ID。

完整窄相覆盖点面、边边及穿入三角内部的边面相交，包含共面重叠、退化为线或点的三角。空表面明确返回无见证/无有限距离，不能伪造0。使用float64数值算法，不称数学精确谓词；不增加哈希、重试或授权防御链。

允许AABB/BVH节点对下界剪枝、批量窄相、参考索引复用与显式refit/重建。任何启发式仅用于排序或取得上界，不能以Top32、质心最近、固定预算或提前截断丢失全局解。只构造索引和返回候选不算完成距离查询。

## 固定正确性集合

1. 分离、面内点面最近、三角外投影、纯边边最近、平行/近平行长边；点(2,2,1)到单位直角三角真值sqrt(5.5)。
2. 顶点/边接触、共面交叠、非共面边穿三角内部、穿插与嵌套闭盒；嵌套[-2,2]^3与[-1,1]^3表面距离1。
3. TF历史反例：A=[0,1]^3、B=[2,3]×[0,1]^2，给A增加未被面引用的(2,.5,.5)，距离仍1；交换对象、重排面/顶点、加入远处/重复面保持语义。
4. Top32反例：A原点单位三角；B含z=1的长三角[(0,0,1),(1000,0,1),(1000,1,1)]，另32个质心更近但z=2的短三角；全局距离仍1。
5. 细长/退化三角、共同旋转平移、尺度1e-6/1/1e6、微间隙及大世界平移；同表面重三角化不改变距离。一般比较容差`1e-10*L + 32*eps*max_abs_coordinate`，其中L为输入表面尺度；见证归属独立核验。此容差用于断言，不授权把小间隙截为0。
6. 多个小随机三角汤与独立全对oracle比较；测试oracle不得复用候选最近点或剪枝函数。原始面ID、见证点分别落在对应三角，以及见证间距等于结果，都须检查。
7. 独立Blender后台至少一次RB-B→BC真实求值接线，包含非均匀变换、单位换算、修改器和更新后重新查询；当前GUI场景不参与写入。

## 事前性能输入和边界

每侧128或512个三角，使用8×8/16×16网格单元、共享顶点，非平面高度起伏不超过0.02m。两个固定类别分别是明显分离（z偏移0.5m）和近接触（z偏移0.05m）；双方独立平面内偏移与随机相位。完整网格A和B都在两个预生成、真实不同的顶点状态间交替；拓扑保持。各类别/规模分别判门，不混池掩盖失败。

主计时为**两对象更新/准备＋完整表面查询**：两边均从相同已存在顶点数组开始，所需取面、包围盒/refit/索引维护、筛选、完整窄相和见证输出全部计入。初始建树/预打包可在主样本外，但须单独报告冷构建＋首次完整查询，不能把静态热查询冒充持续变化收益。若候选采用无状态重建，也全部计入。输入生成、断言和写盘在计时外。

基线是正确且分块向量化的全三角对穷举，同样允许预分配和拓扑复用，不用Python逐面双循环作性能基线；独立scalar/凸优化oracle只用于质量。双方输出等价，基线不能加入无关渲染、FastSession、重复校验或额外字段。两边可以共享已独立验证的数值核以隔离索引收益，但完整oracle另立。

作者和主对话各运行3独立进程，每进程每类别/规模5预热、31次AB/BA交错测量，单线程BLAS。512面两个类别均要求每进程中位数基线/候选≥2；128面各类别93样本汇总p95候选/基线≤1.20。披露128面中位数、512面p95、冷调用、索引成本及逐阶段成本，不将其与主门互换。

另固定512面密集重叠最坏案例（两组面AABB大量重叠、包含真实相交与相近表面），完整输出正确性和未截断成本单独报告；不因慢而删掉。保留每次原始样本与代码摘要。第一次失败保留，修复后使用新输出文件，不能覆盖失败或调低门槛。
