## A. 全部348观察的输入与标签核查

画清真实数据路径：观察位置/法向和图 → 7个节点标量、4个边标量 → 编码与共享传播 → 定位分数；观察向量另外参与残差输出。以代码实参为准，说明定位头实际能取得什么。

同一patch的每个凹陷观察与 `sample00` 正常参考逐点对齐，报告：

- 全量支持/正常/固定点分母，支持位移区间 `(0,.02]`、`(.02,.10]`、`(.10,+inf)` 的数量、目标位移平方和占比、冻结门限召回及漏掉的平方和比例。按来源、强度、中心/偏心分列。区间仅用于解释，不重标标签。
- 观察几何的实际差异、float32输入差异、原18个标准化参数下节点前5项与边4项的差异；分别统计支持、正常自由点、固定点。比较观察原点/尺度变化，区分真实局部差异和全图归一化变化。
- 如用共同参考原点/尺度重算作归因，只作为另列的标签辅助诊断；不将参考注入可用描述或冻结模型。
- 对完整 `forward` 输入逐一记录名称、形状、dtype、字节散列；查找完整输入完全相同却有不同归一化目标/支持标签的情形。部分标量相近不算完整输入冲突；没有发现精确冲突也不证明问题完全可辨识。
- 重算受损点到标签正常点、到输入固定点的图距离，保留不可达分母。12步可达只排除简单的拓扑距离解释，不能由此排除信息压缩或学习失败。

## B. 一次固定参考检索，比较两种描述

只做以下两种描述和同一套5近邻检索。这是利用既有标签建立参考索引的诊断，索引构建、标准化和查询成本都计入；没有优化器训练。它不产生可部署的修复模型。

**R0，13维现有局部摘要**：节点前5个连续量，加该顶点所有出边4个特征的逐维均值和总体标准差。查询均为自由点，allowed/fixed不作为区分维度。R0只是当前图输入的局部摘要，不代表整个图的信息上限。

**R1，19维多尺度摘要**：R0加以下6维。只使用同一份已保存观察context中的位置q、单位法向n和拓扑，不扩大取数域。对于图距离不超过r的邻域 `B_r(i)`，排除i，固定r为2、4、8：

`c_r = sum_j dot(n_i, q_j-q_i) / sum_j ||q_j-q_i||^2`

`v_r = mean_j (1 - clip(dot(n_i,n_j), -1, 1))`

新增 `c_2, c_4-c_2, c_8-c_4, v_2, v_4-v_2, v_8-v_4`。q为原观察归一化位置。空邻域、零分母、非有限数记录为无有效描述，不静默删除。现有context截断是两组共同限制，报告邻域实际大小，不自动扩展全网格。

采样、参考索引与比较固定为：

1. 每观察自由点按源顶点ID排序，最多取64点。N点取m=min(64,N)，下标为 `floor(j*(N-1)/(m-1))`，m=1时取0。选择不看标签或分数；两描述及冻结模型采用完全相同查询点。保存ID、选中支持/正常点数及目标能量覆盖率，全量结果仍由A列出。
2. 开发查询只从另外三个成员文件取参考，排除本文件全部patch和派生例；验证查询从231开发观察取参考。标签只用于参考点标记和最终评价，验证标签不进入距离、标准化或索引准备。
3. 每个允许的参考池各自计算描述均值和总体标准差，标准差下限1e-6；验证只使用全开发参考池的标准化量。此处标准化服务于检索，不能改原网络18项标准化。
4. 标准化欧氏距离，k=5，分数为5个参考点的支持标签均值。并列距离按 `(distance, case_id, source_vertex_id)` 排序。保存5个邻居及距离。用float64分块，查询块最多128行，沿用NumPy和现有CPU环境，不新增依赖或索引服务。
5. 在同一查询点上比较R0、R1、冻结模型p的ROC-AUC与按分数并列分组的AP；每例先算，再在patch内对凹陷例等权平均，最后patch等权平均。中心/偏心分开，另列来源/强度及点池结果。无阳性或无阴性导致指标不适用时保留空值与分母；正常控制另列分数尾部，不伪造AUC。若出现无效描述，同时列出全部查询的无效率、共同有效查询的比较和有效patch数；不能通过剔除困难点满足筛选条件。
6. 同时给出强位移 `>.10` 的定位结果，和被冻结模型p的关系。不能拿采样检索AUC去比较全量模型AUC，也不能用准确率被大量正常点稀释的结果宣称成功。

## 结论怎样决定下一步

以下是本批事前筛选规则，筛选通过也不是修复质量验收：

| 证据 | 优先提出的唯一后续方向 |
| --- | --- |
| 找到会改变标签或输入含义的具体实现错误 | 修该数据/提取错误，先复核受影响证据 |
| R0在验证中心、偏心的patch宏AUC均≥.80，且均比冻结p高≥.05 | 优先研究现有表示的学习/目标问题，依据冻结响应选一个最小变化 |
| 上项不成立；R1两组patch宏AUC均≥.80，均比R0高≥.05，AP均不降，并在强位移与几何证据上保持同向 | 优先提出一个多尺度输入变化，计入特征准备成本 |
| 不满足以上证据，或结果互相矛盾 | 明确哪些假设仍未区分，指出需要哪一种任务条件/参考或标签证据；不自动换网络 |

这两个AUC数值是固定的工程筛选差异，不是统计显著性声明。四成员文件同上游、一个验证对象、派生样本相关的限制继续列明；低检索成绩不证明任何算法都无法区分。若支持从输入改为任务条件/参考，不得将现有未扰动答案直接包装为部署时可得输入。
