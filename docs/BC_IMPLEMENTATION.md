## 接口

```python
from human_eye_fast.fast_bvh_clearance import SurfaceIndex, surface_distance

a = SurfaceIndex(mesh_a.world_m, mesh_a.triangles)
b = SurfaceIndex(mesh_b.world_m, mesh_b.triangles)
result = surface_distance(a, b)

a.update(updated_a.world_m)
b.update(updated_b.world_m)
updated_result = surface_distance(a, b)
```

`SurfaceIndex` 接收可信的 `float64` 世界米制顶点和合法三角索引，持有拓扑与当前表面快照。索引更新从传入数组重新取面并 refit，拓扑变化时新建索引。调用端串行执行同一索引的更新和查询。`SurfaceDistance` 提供 `distance_m`、原始三角行号 `triangle_a` 和 `triangle_b`、世界米制见证三元组 `point_a` 和 `point_b`。空表面返回 `inf` 和四个 `None`。接触或相交的表面距离为零，闭合表面完全嵌套时仍可有正距离。

## 搜索和数值核

- 冷建按三角 AABB 中心沿最长轴做中位切分，叶保存原始行号映射。更新取索引定义的面，重算每面几何和叶 AABB，再向根合并包围盒。孤立顶点从未进入表面快照。
- 贪心下降找到一组真实面见证作为初始上界。正式搜索从两根出发，扩展所有箱间下界未超过当前上界的节点对。叶内再用面 AABB 下界筛选，未排除的面以有界批次执行完整窄相。零是全局下界，找到零距离见证即可结束。分块限制单批工作量，密集正距离场景仍会遍历所有无法排除的面。
- 最近特征覆盖双向点面投影、双向点到闭线段、双边内部，以及双向边穿目标三角平面。共面交叠可由顶点或共面边交叉给出见证，退化三角由点和边参与。窄相使用成对局部差值、幂二缩放的边方向及线性距离，减少大平移消减和平方距离下溢。边边求解先消去主轴纵向分量，再从第二条边的选点回算第一条边的投影。见证按目标面顶点和特征重建。AABB 比较的浮点余量仅放宽搜索。
- 结果采用 float64 浮点几何。极端坐标范围、近奇异特征或已在输入舍入中消失的间隙受浮点表示和条件数限制。固定树拓扑便于连续更新，大幅形变可能降低剪枝效率。密集重叠时报告完整二次工作量。

作者正确性测试共 14 项，含点面/边边/穿面、共面与退化、嵌套、孤立顶点和 Top32 历史反例、尺度和平移、微间隙、重三角化、面与对象重排、双对象更新及空表面。15 组三角汤在两个对象顺序下与独立全对凸包 oracle 比对。该 oracle 将每对三角的差集表示为九个顶点差的凸包，以 SVD 求各候选单纯形的距离，并独立检查见证的三角归属和见证间距。

基准穷举方复用拓扑和笛卡尔配对索引，按 8192 对分块运行同一窄相并生成同字段的结果。自 `author_03` 起，穷举方找到零距离见证时停止，正距离查询遍历所有分块。双方均从预生成的顶点数组出发，每一计时调用更新两侧全量顶点并求完整距离和见证。三独立进程的 BLAS 线程环境设为 1，各用例 5 次预热、31 次 AB/BA 交错测量。冷建和阶段计量单列，主样本区间没有阶段插桩。密集用例两状态各有 100% 面对 AABB 重叠，解析距离为 0.005 m 与 0 m。
