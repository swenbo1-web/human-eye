在质量成立后比较完整墙钟、全部调用与RPC、输入输出字节、实际可取得token、准备及回退成本。不能用某个插件函数的毫秒数代替整任务收益，也不把无法归因的等待称作模型推理。费用和未暴露usage保留未测。

这三题属于小规模静态空间接口筛查。T3可以由AABB下界加实际见证快速解出，合法原生捷径应得分；细分增加计算量不等于增加空间难度。重复三次测波动，不扩称九个独立场景。本批结果用于决定接口是否值得保留，不能宣布完整类人眼能力已验收。

目标是让模型在一次完整工作中找到相关对象、理解三维关系、取得必要证据并正确使用。插件内部采集更多、输出更短或者缓存命中更高，都需反映到这条链路的正确率、遗漏和总成本。
