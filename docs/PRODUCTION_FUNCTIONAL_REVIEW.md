## 架构与算法审查

生产 session 只持有一套 controller/bridge/index；在同一依赖图上补上下文，动作后一次真实回读形成 Outcome，再发布 TD/VG/联合 AO。没有二次目标观察、备用求解器、预测降级、自动重试、来源哈希或运行时台账。部署格式检查在显式加载边界，计划/反馈绑定和资源所有权属于接口语义。

索引在可能改写借用 world 数组之前撤下，只有两目标 capture/refit/BC 成功才重新挂回。独立 CPU 使用 48 个平行面三角形，不依赖 B 或交付 StubBridge，分别注入第二目标捕获、第二 refit、BC 查询失败；均只发生一次宿主写入、不伪造 Outcome，随后显式 NONE 观察重建索引并得到解析距离 0.75 m。NONE 只表示已成功捕获几何无变化，尚未读取的宿主变化仍需调用者声明。

默认控制器的到达目标、直接空面真实执行、原始 prepare 异常语义保留；新会话写后错误携真实 Outcome，必要时携一次实测 A 票据，不自动回滚或重试。计划随新观察/执行/参考替换/关闭失效，迟到反馈仍按 owner 和一次消费绑定。before 位置只在联合 AO 真正读取时保留必要快照；关闭后旧公开 bytes 仍可消费。

shape G 只变换当前见证面三行 basis，仍是原 witness-pair 有限预测，不等于动作后全局 BC 真值。独立一般非均匀线性矩阵和 .001 m/BU 探针与解析位移相符；L 使用原完整特征。缓存绑定显式对象/key/relative_key，定义变化由显式刷新处理，不扫描整数组。未发现需要新增算法改动的正确性缺陷，收益与额外内存仍由成本门裁定。
