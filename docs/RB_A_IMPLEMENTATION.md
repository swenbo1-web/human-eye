实施范围和收益门以冻结提交 `c31f78af3868a4a8a44ce8fac41323a414fdbd0b` 的第 3 至 5 节为准。 [独立竞争工作流](RADICAL_V1_COMPETITION_WORKFLOW.md)

## 接口与视图生命周期

从 `human_eye_fast.resident_bridge` 导入 `ResidentBridge`。每个实例以调用方提供的对象 ID 持有局部坐标、世界坐标、三角面索引、变换矩阵和外观。局部顶点为连续的 `float64` 三列数组。矩阵为 `float64` 的 4×4 仿射变换，局部顶点与矩阵平移已经由调用方换算为米。三角面索引保持原顺序和整型 dtype。 [桥接实现](../human_eye_fast/resident_bridge.py)

| 操作 | 返回值与缓存行为 |
| --- | --- |
| `add(id, local_m, triangles, world_from_local, appearance=None)` | 登记新 ID。复制局部顶点、三角面、变换和外观，计算并存储世界坐标。返回 `ResidentMesh`。 |
| `get(id)` | 返回现有 `ResidentMesh`。只查对象映射。 |
| `update_full(id, local_m)` | 原位复制全部局部顶点并刷新世界坐标。返回现有描述符。 |
| `update_dirty(id, indices, local_rows_m)` | 按 `indices` 的顺序逐行传入新局部坐标，每个索引出现一次。只写对应的局部和世界坐标行。返回现有描述符。 |
| `update_transform(id, world_from_local)` | 原位更新矩阵和全部世界坐标，保留局部坐标和拓扑。返回现有描述符。 |
| `update_appearance(id, appearance)` | 复制外观并返回新描述符，复用现有数组视图。 |
| `replace_topology(id, local_m, triangles)` | 重建该对象的几何和描述符，保留变换值和外观。 |
| `remove(id)` / `clear()` | 释放桥对单个或全部对象的引用。已借出的数组随引用存活。 |

`ResidentMesh` 提供 `local_m`、`world_m`、`triangles`、`world_from_local`、`appearance`。数组是只读借用视图，全量、dirty 和变换更新后的值可通过同一视图读取。调用方也应将借用的外观视为只读。需要跨帧快照时，调用方复制所需数组和元数据。读写由调用方串行化，避免读取进行中的原位更新。

一次 dirty 更新对 `K` 个三维点分配临时世界坐标，并散写 `K` 行局部和 `K` 行世界坐标。全量刷新将矩阵乘法输出写入常驻世界坐标，随后原位叠加平移。变换更新重算全部世界坐标，平移之外也支持旋转、非均匀缩放、反射和剪切。无变化读取零数组拷贝，零数组分配。

## 复跑

从仓库根目录使用 PowerShell 运行。为独立复验指定不同的 `--output` 路径。

```powershell
& 'D:/human eye/venv/Scripts/python.exe' -B -m unittest verification.test_resident_bridge
& 'D:/human eye/venv/Scripts/python.exe' -B -m verification.benchmark_resident_bridge --seed 20261105 --output artifacts/rb_a/author_seed_20261105.json
```

基线保留预分配的局部、世界和拓扑缓冲区。全量与 dirty 比较使用相同的完整输入数组。dirty 候选在计时内执行 `incoming[indices]`、世界坐标变换和局部及世界坐标的散写。两条路径的网格构建、状态生成、正确性断言和写盘都在计时外。
