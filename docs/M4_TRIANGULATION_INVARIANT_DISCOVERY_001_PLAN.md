## 一个小算法改动

从现有已解析顶点和三角形出发，提取矩形边界，再把同样的四角边界交给已有覆盖器：

1. 一次建立有向边关联与边界，核对内部共享边和一致绕序；对实际引用的顶点核平面。
2. 遍历单个闭合边界环，合并同一直线上的连续边界点。内部细分点不进入ROI边界。
3. 对简化后的四角判定正面积矩形，核三角铺面与边界的一致性。孔洞、断开的面或相反绕序不能被当成同一完整矩形。
4. ROI身份由规范四角与front决定，不能依赖三角顺序、对角线、内部顶点数量或对象名称；保留实际triangle_indices供后续追溯。

优先一次边关联、一次边界遍历；禁止为了识别一个平面矩形做三角形两两比较。使用已有精度语义，不通过焊接容差合并本来不同的点。Fraction运算的数值位长成本另列，线性操作次数不冒称恒定机器时间。

覆盖器、相机、遮挡窄阶段、像素阈值、状态更新和短事实结构沿用固定实现。参考与优化候选必须用同一个既有optimized遮挡路径，只比较新的发现算法；不能把旧reference/optimized遮挡差异算成这次发现优化。

先保留清楚的线性参考实现，再审一次可删工作：共享边关联、复用已解析几何、让边界/平面/绕序验证复用数据，不重复构建整场索引。只落一个有证据的优化候选；若参考已没有可证实冗余，保留简化审查和操作计数，不刻意写慢版本制造收益。
