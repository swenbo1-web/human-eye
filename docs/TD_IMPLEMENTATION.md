# TD 跨帧形变

`human_eye_fast.tensor_deform.compute_cross_frame_deformation_tensor(v_frames, tris, *, reference_vertices=None, top_k=12)` 接收共享顶点编号的 `(T, V, 3)` 帧数组或逐帧序列，以及 `(F, 3)` 三角面索引。坐标为可信的同一世界坐标系输入。默认以首帧为参考。传入显式参考时，参考仅用于比较，所有统计样本仍取自 `v_frames`。

| 输出字段 | 逐面定义 |
| --- | --- |
| `max_principal_stretch` | 较大主伸长的跨帧最大值 |
| `min_principal_stretch` | 较小主伸长的跨帧最小值 |
| `max_area_strain` | `abs(当前面积 / 参考面积 - 1)` 的跨帧最大值 |
| `max_normal_angle_deg` | 绕序一致的世界法向夹角最大值，范围为 0 至 180 度 |
| `max_centroid_displacement` | 当前与参考面质心的最大欧氏距离，单位随输入 |
| `score` | 最大主伸长偏离加上两倍面积应变、三倍法向转角占 180 度的比例、以及质心位移除以参考顶点包围盒对角线 |
| `witness_triangle_ids` | 得分降序、同分时原始面行号升序，最多 `top_k` 项 |

主伸长偏离取两个主伸长极值距 1 的较大绝对值。法向角用叉积模与点积的 `atan2`，刚体旋转可产生法向角。参考退化时主伸长、面积应变、法向角与得分为 NaN，质心位移仍计算。当前面塌缩时，较小主伸长和面积比为零，角度归约跳过该帧。所有样本角度均未定义时保留 NaN，评分中的角度项取零。NaN 得分不进入候选。空帧序列返回按面排列的 NaN 与空见证，空面集返回空数组，`top_k=0` 只省略见证。

实现调用 `prepare_reference` 准备一次参考图表，再逐帧调用 `deformation_metrics` 获取主伸长和面积比。世界几何另算质心和法向，并补充检测在参考图表中可能因舍入而得到微小正面积的共线面。原始叉积在极小或非有限时用二进制幂重缩放边向量。每帧就地更新摘要，临时几何数组按面数增长。Top-K 用分区确定分界得分，再按面行号取足同分项并排序。

## 复跑

从仓库根目录运行。主对话可另指定 `--seed` 和独立输出文件。

```powershell
& 'D:/human eye/venv/Scripts/python.exe' -B -m unittest verification.test_tensor_deform -v
& 'D:/human eye/venv/Scripts/python.exe' -B verification/benchmark_tensor_deform.py --seed 29017 --output artifacts/td/author.json
```

正确性以逐面 QR、线性求解和 SVD 检查主伸长，另以直接几何和解析值检查面积、世界法向角、质心位移及排序。覆盖等面积各向异性、显式参考、刚体旋转、点和线塌缩、退化参考、跨尺度共线、同分截止、空输入和零个见证。

两组矩形连通网格分别为 20,000 面和 100,000 面，每组 16 帧。显式参考是一张带固定种子微扰的曲面，首帧已变形。候选与全张量基线均逐帧调用一次相同的主伸长核。基线保留主伸长张量，并在适中的坐标范围内批量计算全部帧的几何面积比、法向角和质心位移。两边返回相同摘要并使用相同的稳定 Top-K。计时外比较逐面数值，并用独立完整排序复核见证 ID。

每组在 3 个独立进程中分别预热 5 次、交错计时 31 次。每个进程的中位数比与汇总 p95 比门槛均为 1.25。额外分配峰值在单独调用中用 `tracemalloc` 记录，输入已预先存在，数值不表示 RSS。每个进程的峰值比门槛为 0.50。JSON 保存所有原始样本、执行顺序、数值差异、源文件 SHA-256 和门槛判定。

## 作者实测

种子为 `29017`。Windows 11、Intel64 Family 6 Model 165、16 个逻辑处理器、Python 3.13.14、NumPy 2.3.5。工作进程的线程环境变量设为 1。原始记录位于 [artifacts/td/author.json](../artifacts/td/author.json)。

| 实际规模 | 三个进程中位数比 | 汇总 p95 候选 / 基线 | 额外分配峰值候选 / 基线 |
| --- | --- | --- | --- |
| 20,000 面，10,201 顶点，16 帧 | 0.846×、0.844×、0.857× | 187.62 / 209.13 ms，0.897× | 10,961,632 / 67,531,264 字节，0.1623× |
| 100,000 面，50,451 顶点，16 帧 | 0.895×、0.934×、0.902× | 1,105.84 / 1,200.55 ms，0.921× | 54,721,632 / 337,611,264 字节，0.1621× |

两档各进程均达到作者自测门槛。主伸长、法向角及见证 ID 在基准输入上完全相同。面积应变、质心位移和评分的最大绝对差分别为 `8.89e-16`、`3.61e-16` 和 `1.89e-15`，均在 `rtol=atol=1e-11` 内。9 项 TD 正确性测试与 32 项现有 fast 核、引擎和 CLI 回归通过。Windows 沙箱运行 CLI 回归时使用 `artifacts/td` 作为可写临时目录。主对话独立复验待完成。
