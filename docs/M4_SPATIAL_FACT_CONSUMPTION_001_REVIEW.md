## 优势发生在哪

P 三格均自然请求并正确使用 spatial_relation 与 surface_proximity，三份答案直接完成任务；P 原生调用和同题原生重算都为 0。当前题目上“模型无法理解或不信任空间事实”的假设没有得到支持。

N 的实际路线需要读取对象、生成和执行几何求解代码，部分进行精度刷新或包含补证；这些操作具有当前任务作用，不能全部标作无效重复。P 用现成事实完成相同答案，工具尝试由 8 次降为 4 次，输出 token 也明显减少。与此同时，P 的局部 handler 总时间更高，业务响应包络总量为 N 26,884 B / P 26,249 B，差异很小。故本结果证明的是整题使用收益，不能声称几何内核快了 58%，也不能把收益全归于回包压缩。

调用轨迹与整题收益同时观测到，但 provider、模型计算、客户端等待之间没有完整分段计时，不能精确分配各项因果贡献。这个合成题、每组三次、零图片的结果也不覆盖广泛任务或人眼视觉能力。

## 简化深审与决定

仍有两个可定位机会：一次非法 nearest_witness 事实名请求，以及九项非必需 closed 分类最终预算 unknown。前者 handler 5.5156 ms、回包 857 B，到修正请求的空档 7.9709631 秒未归因；后者计 2,359,296 work units、值组件 2,061 B，但没有独立 closed 耗时。删去它们后的完整因果收益未测。

按既定收口规则，当前质量、消费和成本已过，不在同题继续改 schema、门槛或算法。保留机会，转到新几何结构验证迁移。训练空间回答模型在技术上可研究，但本批已有六份正确答案和三次直接采用，不能据此证明训练是眼下必要步骤或会提高正确率；应先定位跨任务的实际失败。
