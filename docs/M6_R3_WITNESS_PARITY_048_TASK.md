1. 从首次可能产生差异的位置检查贪心种子、并列入队与剪枝、最小原生行、同面组合内的特征次序、接触截面和最终发布。分别列出正距唯一、正距并列、零距单点与零距多点。查清哪些字段有稳定规范，哪些仅承诺源面上的任意有效点。两个都合法但显示不同、违反规定的规范次序、同一字段从可用变为未知，是三类不同结果。相同的发布函数只能推出相同输入时的相同处理。
