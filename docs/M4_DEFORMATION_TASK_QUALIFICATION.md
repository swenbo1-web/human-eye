# M4局部形变任务与外部来源资格

本批是唯一主计划中B2之后的有界来源/消费检查，基线为f4abfb3、116源df3c38ab。证据位于本机`verification/fixes/20261102_m4_task_qualification`，此前84份封存清单保持。程序资产、外部作者样本、真实生产资产与模型收益分别记账。

## 观察到的任务缺口

128点/256面torus的指定面128在五类默认概览中均被省略：全等距、unknown挤压下正常/拉伸、目标unknown和塌缩挤压。最强两包中只有目标面三个顶点有权重；目标分别为等距和明显拉伸，其余255面为unknown。移除完整来源引用后，两份默认几何摘要逐字段相同；拉伸的独立QR/SVD真值约为`[4.51253,0.92653]`、面积比`4.18102`。16条概览能报告总体情况，不能回答任意被省略的指定区域。

这些先是数学source doubles的实测反例，不冒充真实资产或原生Blender验证。factory原生回归另列。该缺口只需要有限定向证据，不需要改伸长算法、增加图片或放宽来源域。

## 本轮唯一功能变更

`surface_deformation.analyze`增加可选query，最多4个唯一、非布尔整数原始面ID，绑定当前完整`source_sha256`。始终校验完整源点面并计算原全量统计；默认top16和原字段保持，额外`task_query`按请求顺序返回事实。全局partial和所选区域的状态分别表达，目标unknown不会变成正常。查询不携带执行权能。

固定CLI可传`--triangle-query`，文件最大4096字节。选择文件绑定不可变scene SHA、mesh/rig对象ID及帧；第一次观察把选择绑定到当前capture SHA，第二次在同一worker内继续核对完整来源。重新打开同一固定文件会产生新epoch，因此可以用稳定文件引用发起新查询，不能沿用旧capture查询，也不继承编辑权能。文件、角色、帧不匹配会拒绝。该稳定引用只用于固定文件读取器，不保证任意活文档的面ID跨编辑稳定。

显式传入null、重复JSON键、非有限值、超字节、重复/布尔/越界/超过4个ID均拒绝，不能回退成概览成功。输入在接收时冻结，原30秒和保存/发布/编码期限守卫保留。
