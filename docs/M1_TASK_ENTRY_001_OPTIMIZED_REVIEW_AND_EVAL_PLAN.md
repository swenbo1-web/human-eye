## 二、下一批只准备并冻结，不启动消费者

### 三组与变量

| 组 | 消费者实际可用能力 |

| N | 相同普通原生 Blender Python 读取与计算工具 |
| C | 同一原生工具，加固定候选的普通大入口只读目录 |
| S | 同一原生工具，加同一候选的两个简洁空间任务工具 |

C 是大入口控制，不是旧安装版。两插件组必须来自同一个候选源与依赖，只改变公开目录/profile；不得同时改变内核、缓存策略、结果投影规则或预算。每格使用新消费者及新场景副本，组内目录差异为本次处理变量。预检记录实际 tools/list、最终命令和载入源；不只检查文件路径。

保留上一轮相同共同任务规则：只读、文本与几何、图像预算 0、证据充分即可回答。没有“必须使用/信任插件”、强制调用次数、原生禁用或答案示范。模型可选择原生回退，失败和回退都计入。统一任务文字，不额外只给某组教学提示。

### 三个未见场景

此处冻结题型与设计约束；具体资产、题目、独立答案及字节摘要由准备批次生成后再冻结。它们不得只是旧 003/D48 换名或平移。

1. **T1 目标与三个候选的空间关系装配。** 使用与旧装配不同的构型，考察真实分离/接触/穿插、最近分离集合与间隙。包含会误导中心或包围盒判断的几何；原 supported-domain 内，构造有独立解析依据。
2. **T2 非凸目标的全场最近表面。** 使用新的非凸结构与候选分布，使中心距离排序不能替代真实表面距离。要有全场覆盖的证明依据，不用大量完全无关的远物体伪装复杂度。
3. **T3 不同几何机制的全场最近表面。** 最近点在边/面内部，所有顶点对距离均偏大；与 T2 拓扑、最近点机制不同。本轮选可独立认证的唯一最优，避免同时引入并列集合这一额外变量；未来并列题必须按实际浮点网格证明等距。

物体名称与存储顺序不泄漏答案。固定种子、构造、单位、坐标域和容差；以新资产实际存储/求值后的几何确认独立真值。预注册对象、顶点/面、候选对、潜在精算工作量，而不是仅按物体数量称为“复杂”。所有题仍在当前承诺能力和预算范围内；本轮不评 M4 图像目标发现、任意大资产或动态增量。

独立答案使用解析构造、独立高精度/区间几何方法及原生读取交叉核对，不能从生产求解器输出生成期望。先保存构造规格与真值，再对候选做无模型入口预检；若发现几何/支持域不符，保留失败并回报，不逐题调整生产代码或反复换题寻找通过样本。消费者不得读 fixture 生成器、真值、评分、历史答案或其他消费者记录。

### 27 会话与预算

3 题 × 3 组 × 3 次 = 最多 27 个新的 Pro 消费者。按题内三组轮换，并跨轮换题顺序，预先固定序列；同机串行完整任务，避免组间资源争用。不补跑替换错误、unknown、超时、未调用插件或较慢样本。

复用已验证会话预算：请求 `gpt-6.1-sol/medium`，会话 450 秒、完整格 570 秒，最多 32 次工具尝试、128 次实际 RPC、工具响应合计 1 MiB、单次 30 秒、代码 256 KiB、图片 0、模型主动重试 0。核验本机当前 CLI 支持情况并记录真实请求与暴露设置；不可把未暴露 resolved effort 写成已知。Google/API 保持暂停。只在隔离测试配置预授权对应只读工具，不改正式设置。

入口预检只运行本地确定性调用，不偷跑模型试答。准备时核对消费者正式 stdio 客户端及其关闭记录；旧 005 缺 EXIT 不得重新声称已解决。若仍不可观测则单列未知，不能伪造正常关闭，也不为补遥测另开产品重构。

### 质量、采用与成本

先冻结答案和评分，再由独立评分者看匿名原始答案与必要证据，先评分后看组别及成本；答案可能透露路线，承认无法完全盲法。允许自然语言回答，不增加与空间任务无关的复杂格式要求。

- 最终质量：对象、关系、全场/局部范围、最近集合及距离区间正确。漏掉并列、将 best-known 说成全局、将表面距离说成穿透深度、给错误单位均单列。诚实 unknown 与错误断言分别记录；unknown 不等于任务完成。
- 固定 S 工程门槛：9/9 完整正确，至少 8/9 有证据地直接采用插件事实，首次插件请求有效率至少 90%，分母沿已批准方案为实际尝试插件的会话数。另报首次有效/全部9格、尝试数、未尝试数；未尝试不是参数错误，但不能计为采用。例如8次尝试均首次有效、1次未尝试，条件有效率8/8，全格率8/9，必须同时展示。不得在结果后切换分母。小样本门槛用于此轮推进，不代表总体置信保证；三题各重复三次也不是九种独立场景。
- 真实采用不能由“调用成功”代替：核对返回事实是否实际用于答案、证据充分后是否又全量原生重算。必要补查不机械当成浪费。区分有效事实已交付到最终答案的时间与模型内部推理时间，不作未经证实的归因。
- 全部成本分段：场景读取量、缓存占用（可观测则记）、文本/图片字节、实际 input/output token、缓存子集、工具调用和实际 RPC、准备/目录/求解/回退/关闭耗时、总墙钟。推理 token 或缓存 token 是子集时不重复相加；费用和 provider 计数不可见则未测。
- 同时报消费者 prompt-to-final 和每格完整生命周期时间。一次性构造、安装、审计与预检成本另列总额及摊销口径，不能悄悄排除后声称总体净收益。基础 token 成本与工作流成本都要可复核。
- 按题报告三次全分布及中位数、质量差异，再报总量；不能用质量下降换出的速度宣称有效收益，也不能以某题快掩盖另一题退化。既定简单至少快 10%、中等至少快 30%、复杂不超过原生 1/3 的产品目标保留；此小样本筛选不冒充整个档位验收。
