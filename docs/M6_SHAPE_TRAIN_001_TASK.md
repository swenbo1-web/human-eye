## 一个框架、一个网络、一个直接对照

在本批隔离虚拟环境准备 PyTorch CPU；沿现有 Python3.12，使用官方发行源，锁定实际版本、wheel 与依赖散列，记录安装下载/空间/加载成本，不改共享 Python 或正式 MCP。无需 torch_geometric 或 GPU 栈。正常证书链问题使用现有 Windows 信任配置排查，不读取任何 API key。

网络严格采用 DATA001 的 `NETWORK_CONTRACT.md` / `TRAINING_CONTRACT.json`：7标量节点、4标量边、宽24、共享cell、K12、6290参数、SO(3)向量残差头、初始末层零、fixed/halo硬零。不把源ID作为embedding。先用实际参数张量核对6290；检查两个 batch 图互不连边，正常/支持/正常自由点各损失分母，输出回原 binary64 观察，初始 no-op、非零输出的坐标变换及梯度贯通。这里只实现原候选，不能以“结构修复”悄悄换另一个架构。

前向只取输入白名单，标准化18个持久化量只用训练观察拟合。给图加载器可指定输入根目录，避免冻结清单中的作者绝对路径成为推理数据依赖。旧生成器不需要为重生成而返工。

直接基线仅实现合同预选的**门控鲁棒二次MLS**，另有no-op。固定 `d_G<=8l`、法向点积>=0.5、至少12点/满秩、距离权重、三次Tukey IRLS和训练正常残差99.5%分位门限。初次加权最小二乘作为IRLS初始解；MAD按加权前有符号残差对其中位数的绝对偏差计算，沿合同数值下限。同一冻结观察同时给全部点输出，不迭代改输入。所有不适用点返回零位移并计数，不能删掉难点。门限只校准一次，开发/验证分母照旧。
