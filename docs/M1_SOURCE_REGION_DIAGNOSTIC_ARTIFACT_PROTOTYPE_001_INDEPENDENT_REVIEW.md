指定源三角顶点映射可读出，现行读取器先读验整份文件再提取字段，并依赖独立冻结的摘要、长度、捕获身份及帧信息。计时各为一次本机模拟，使用已有序列化全文。有图样本发布的 8.734 ms 中，路径和摘要准备占 8.068 ms。实际跨进程往返、不同宿主的文件访问、现场生成全文、自然诊断追读率、模型输入及账单均未测。
