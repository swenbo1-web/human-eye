## 行为与范围

受信操作者登记的同索引参考产生变化区域及 opaque `patch_ref`；模型只提交引用。每次请求重验当前实例、文档、原始内容、参考、实际三角化、阈值及撤销。没有参考时不猜凹陷、裂开或修复目标。新通道为 `reference_patch`，不能把旧边界标签冒充曲面变化。

完整区域至多64成员；场景至多4096顶点、1024三角、64对象。两固定斜视方向、至多三个实质变化三角中心见证，保留所有场景遮挡。见证变化投影在局部图至少2px、全景不足2px、线性增益至少2倍，且至少两个合格见证可见，才交付384×384全景和局部图。近竖直5°以内的原生 track 相机方向保守排除，可用另一候选。有限候选全失败则零图，不代表所有方向都无观察机会。

producer 用投影重心深度；consumer 用独立精确有理3D线与三角相交，随后核对实际 RNA 相机矩阵、投影、完整深度、PNG、显示与场景恢复。合计射线三角工作至多16384，包含两端计划和实际方向复核。沿原登记任务6查询、2图、16MiB PNG、512KiB文字、16引用、180秒及单次原期限≤30秒；无调用续期。未知图像调用保留已预约成本，重复请求只有收据。
