# 局部凹陷模型重新筛选

日期：2026-11-15。最新用户要求：下一步筛选出处理局部凹陷的模型。

## 决定

下一批只验证 **Pointfilter 官方预训练权重**，不转蒙皮，不继续调旧6290/6339参数网络。先建立成熟学习方法的实际修复基线，再根据凹陷修复和正常保持结果决定是否做一次针对性训练；参数小型化与速度优化排在质量之后。Pointfilter 是首个待验证候选，尚未选定为产品专家。

旧首版与一次优化确实完成了训练且未达标，OBJECTIVE001也未通过换指标挽救它们。但这些结果只关闭旧候选及其跟进解释。此前过早把架构收窄到自设计小网络，随后连续诊断同一候选，缺少成熟学习基线；不能据此宣布局部凹陷没有合适模型。最新用户指示将本线重新聚焦到这一缺口。

这些是工程优先级判断，不是模型质量排名。点云方法缺少网格连接信息，邻近的不同表面可能混在邻域内；本批记录此类输入特征与现有耦合结果，不能用噪声去除成绩冒充成片凹陷恢复成绩。

## 训练分布及解释边界

原论文训练集由22个形状及高斯扰动组成，包含正常样本；目标是点集过滤。第6页图5的训练区可辨认 Armadillo 和 Bunny 外形，**存在形状层面预训练重合**；未取得训练数组逐字节对照，具体采样重合未知。因此本批 Armadillo 只作既有凹陷位置/幅度的迁移压力组，不称未见资产泛化；Bunny仍不读数组、不评分，而且不能再自动沿用为该预训练模型的全新资产保留集。

论文同时指出稀疏邻域、过大噪声与明显孔洞的限制。当前角色原始顶点的采样密度与论文表面采样不同；需要记录邻域点数、重复采样、半径和凹陷尺度。先按官方语义运行，不能看到结果后选更有利半径或删掉不合适案例。

## 本轮完成之后怎么选

固定37例：7正常控制、12角色中心凹陷、9 Armadillo中心凹陷、9偏心凹陷。另取官方 Tetrahedron 干净/噪声配对的固定128个查询点作输入流程检查。学习候选与同输入邻域的鲁棒二次 MLS、保持不动比较；旧小网络和旧门控 MLS 的历史失败保留。

本轮交付应把三件事分开：官方方法是否正确复现；它能否直接修复局部凹陷；若不能，具体差距是否支持一次凹陷领域训练。单纯预训练迁移差不等于架构不能学，单纯能运行也不算模型已选定。需要训练时，下一合同先锁定监督、正常保持目标与来源划分，不自动续调旧网络或轮训全部备选。即使首轮质量达到目标，也须经独立复核，再安排一次有明确收益目标的优化。

具体实施条件见 [M6-SHAPE-PRETRAIN-001](M6_SHAPE_PRETRAIN_001_TASK.md)。
