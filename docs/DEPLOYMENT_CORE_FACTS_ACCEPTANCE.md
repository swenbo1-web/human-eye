78↔124的新管理器QA代际有25组迁移/故障检查；125候选另外登记4组正逆向/最新状态检查，不用重复运行数扩充资产覆盖。三个合成已完成commit及预算消耗在来回切换后保持；它们是账本格式/状态夹具，不是实际几何setter。pending、inflight、quarantine、未完成目标、未知schema、未知wrapper、锁竞争、计划后修改、围栏/中断等按各自预期拒绝。73项管理器测试中72通过、1历史跳过。

回退必须用已固定的78-runtime新管理器rollback kit，对**最新完整状态**重新plan/apply。旧78 admin本身不支持新pin参数；原124 admin也保持原字节，不能称为已自动兼容。125原安装的新admin只读doctor已通过。未来schema不兼容就拒绝回退，不能删字段、清未知或覆盖旧state备份。

## 核心事实：与外围压缩分开

原B3e字节不改。新`deformation_core_facts.py`复用相同的来源与B2数学，增加显式`--core-query`；与overview、triangle、region、anchor、context互斥，仍用同一被外部原始SHA固定的policy/selection，不允许模型自行缩小core。

```mermaid
flowchart LR
    A[固定文件、角色、帧与完整来源校验] --> B[一次完整B2不可变行]
    B --> C[一次required core闭框筛选]
    C --> D[完整三态、unknown原因、四极值和core内见证]
    D --> E[本地完整audit、原期限和输入再核验]
    E --> F[worker关闭并确认退出]
    F --> G[原期限内发布ASCII JSON和单LF]
```

纯`project`可直接复用B3e已经完整算出的membership和绑定行，实际禁止调用B2、几何准备和筛选的spy验证通过。正式actor只有1次B2、1次几何准备、1次core筛选、0候选收缩。完整成员/逐面行保留本地audit；公共报告明确省略数量、完整性、数值模型及范围。四极值只覆盖可测/塌缩成员；空core与全unknown均保留null，unknown原因全部交付。

所有指标是相交整三角的事实；点/边接触算成员，不证明正面积接触。B2的分辨率守卫保留，不认证物理测量误差，不判断损伤、体积、解剖、可见性或动画时序。新模式不产生写入权、切帧、保存或新增来源能力。
