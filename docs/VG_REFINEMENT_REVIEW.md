# VG 两层验收：采用主干流式无损输出

2026-11-05。实施版先达到冻结标准，主干再实际优化并直接对比。最终选择主干formal_002，内核SHA-256为5349300f26c38f6e0ccbdf4a08109969df190b74328dabcdef3eded72a5f0528。允许推进AO；尚未完成整体观察—动作—学习链。

## 第一层实施与独立复核

author_002的3个独立Blender进程，每个固定视向10/24、主动视向24/24：natural从7/20到20/20，section从3/4到4/4；新增14例、原成功集合无丢失。93对完整热态p95为固定18.8434ms、主动18.4857ms，比0.9810；21个负例、12个零距离控制通过。主干重新核对源码与PNG摘要、三个PID、采样次序和原始时序。冻结实施内核在verification/baselines/vg_implementation.py，第一层证据在[实施验收JSON](radical_acceptance_vg_implementation.json)，冻结提交46c6fe6。

审查发现作者对HUD与底图的绑定检查豁免见证周围32px，允许“真实底图正确，但公开图关键位置被抹掉”的新反例。主干新增独立公开像素审计，重新投影、读取实际PNG、依据原生射线归属/深度重算目标支持与连续间隙，不使用作者passed/matched/is_gap字段。全部144张公开图仍复现10/24→24/24。四项测试验证擦除公开见证、伪造作者通过标志和缺失原生记录不能过门。漏洞属于验证覆盖，实际作者输出未出现该退化；未改作者算法来补第一层成绩。

## 主干架构与算法改动

实际剖析30次完整观察耗时0.491s，其中ImBuf编码0.435s，约89%；射线搜索约0.002s。主干据此优化输出而不减少真实可见性探测或几何工作。

旧路径：GPU同步读回RGBA→完整ImBuf拷贝→通用PNG滤波/编码→BytesIO。新路径：GPU同步读回→64行RGB紧凑条带→固定Up行差分→zlib level1→标准PNG。一次紧凑复制消除RGBA三通道跨步差分的低效内存访问；按条带向量运算保留连续处理能力。上一条带最后一行显式带入下一条带，首行按PNG定义直接保存。uint8减法采用模256，独立解码逐字节验证可逆性。

绘制契约本来就是不透明：几何、背景、HUD均为不透明输出，RGB PNG的隐式alpha为255。新旧PNG解码成RGBA全部相等，包括字体边缘；既有sRGB/gAMA/cHRM、eXIf和分辨率声明保持。相机、视角选择、GPU底图、HUD、帧/对象/见证及逐方向探测记录未改。每次重新绘制、读回、编码，没有最终图像缓存，也没有备用渲染/编码链。

直接跨步RGB版本虽然压缩快，滤波慢，已归档；全幅紧凑RGB版formal_001通过时延和图像门，但多约1MiB常驻工作缓冲，未最终采用。formal_002使用64行条带：扫描行1,573,376B + RGB条带196,608B + 上一行3,072B，共1,773,056B，低于原ImBuf像素缓冲2,097,152B，约下降15.45%。close显式释放新增CPU数组。这个数字只比较编码拥有的像素/滤波工作区，不等于RSS、GPU内存或zlib临时峰值。

## 正式直接比较

同一机器Blender5.2.3 LTS、RTX3060、OpenGL；3个独立factory-startup进程。四路A_fixed/A_active/R_fixed/R_active各持独立资源、交叉顺序，24例首次冷观察后5次预热、31次热采样，共93组。计时包含选择、相机、真实GPU绘制、HUD、同步读回、PNG和公开元数据；不包括已捕获事实、已准备几何、磁盘、哈希和评分。[事前协议](VG_REFINEMENT_PROTOCOL.md)及全部原始数据保留。

| --- | ---: | ---: |
| 93样本中位数 | 17.0899ms | 8.6664ms |
| 93样本p95 | 18.5161ms | 9.9370ms |
| 进程0中位数 | 16.9190ms | 8.6109ms |
| 进程1中位数 | 17.1268ms | 8.6567ms |

中位数下降49.29%，p95下降46.33%；配对差中位数95% bootstrap区间为[-8.5330,-8.2583]ms。六个场景族p95比依次0.5507、0.5424、0.5149、0.5859、0.5479、0.5998，全部下降；不能拿每例3–4个样本声称精确的单例p95。新版本active/fixed原成本门仍通过，p95比1.0534≤1.20。

每个进程仍固定10/24、主动24/24，natural20/20、section4/4。冷图、热图和零距控制共342对同方法PNG，解码后RGBA、语义元数据及色彩/分辨率声明全部相等。每张PNG均更小，主动热样本文件比中位0.9020、最大0.9096，至少减少约9.04%。主干额外用Pillow读取288张正距、24张零距公开图，交叉验证编码并重核公开关键像素。正式过程重新执行原生几何评分，不仅复用作者旧记录。

42个两版本原生造假负例、24个零距控制通过。另有2项原生回归测试覆盖非单位比例下的natural/section真实RB→BC→VG、工作区数量和显式释放。主干再审修改后的架构/算法，未发现条带边界、行序、颜色、帧关联或源几何退化。实际查看全部24例接触表及F4/F6原图。这里只接受冻结范围内的收益，不宣称任意资产/分辨率或整体引擎<12ms，也没有外部模型消费结果。

- [原始证据包](vg_refinement_raw.json.gz)：author_002、两次pilot、两次正式运行的完整JSON、源码和进程日志；gzip解压后为普通JSON。

- 核心复现：`python -B verification/benchmark_vg_refinement.py --blender <Blender路径> --output-dir <新目录>`；再运行`python -B verification/audit_vg_refinement.py <该目录>`。主干审计使用仓库author_002原始夹具记录，跨机器可从证据包恢复对应JSON和图像映射；不要覆盖旧试验目录。
- 原生回归：`blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python verification/test_vg_refinement.py`。

另有纯CPU的`verification/test_vg_png_codec.py`从实际生产源码AST提取缓冲初始化与编码段，连续处理3张随机不透明RGBA图，经Pillow独立解码逐像素相等，覆盖条带边界、首尾行及跨帧复用；没有复制一套编码算法生成预期。

决定：VG第一层PASS，第二层PASS，采用主干流式PNG输出，继续AO联合观察与真实动作回读。旧版本及非最终候选保留作对照，不在运行时加载。
