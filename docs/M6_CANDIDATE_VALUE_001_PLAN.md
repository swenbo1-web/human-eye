# M6-CANDIDATE-VALUE-001：先找出值得学习的选择问题

状态：首批任务已制定，新的候选求值/性能试验尚未运行。S0 源码、权重和保存数据核对完成。

所有权：M6 对话 `01a1d986-24a4-73f1-9689-6845d1f01ef3`，分支 `codex/m6-candidate-value`。固定产品基线 `7d42bb939c7881a98fe322c10c216398f6c7aecc`，四份 M6 源码等同已审 `d01d49bc0ec82583b24a8faf22e622e6f6ea8c5d`。本批不参与 M4 当前六轮模型消费对照。

## 问题与假设

当前三骨、截面均匀权重的修正已有闭式解，旧 145 参数网络没有提高分类或定位质量。需要找出一个真实存在的选择困难，才能确定新排序模型的训练目标。

唯一新假设：**在其余几何和动作维度不变时，截面内非均匀的相邻骨权重，可能让廉价规则不再能选出最好的扭转分配；离线候选求值能够建立答案。** 这只是待检验假设。首先推导是否仍有廉价直接解，不能把直接解藏起来制造网络优势。

## 工作顺序

1. **准备对等基线。** 复用同一 rest、section、骨矩阵及一次准备的数据；比较闭式解、合理的直接几何选择、廉价规则。所有方法知道相同目标和允许修改范围。
2. **限定一个变化。** 保持三骨同轴、固定端点、同拓扑和仅调中骨角度；仅离线改变截面内相邻骨权重分布。现有产品对不支持域的拒绝原样保留。
3. **先固定开发探针。** 最多 12 个小任务：6 个现有域控制、6 个非均匀权重探针；最多 9 个候选，包含保持不动、当前闭式解和预登记角度。登记资产参数、目标、候选生成与计分后再执行。不反复换样本直到出现几何失败。
4. **建立候选内答案。** 离线计算每个候选的实际 LBS 后顶点、截面形状和任务损失，选择候选内最好结果。面积/变形计算使用与被评估评分器独立的直接实现；新域不套用旧均匀权重的收缩闭式标签。面积不足以定义质量的情形标出缺口，不用漂亮面积掩盖折叠。
5. **拆解选择机会。** 统计候选包含好解的任务、廉价规则选错的任务、昂贵求值次数和完整处理时间。12 个开发探针只用于机会判断，不能宣称泛化率。
6. **固定结论与下一任务。** 有学习价值才建立正式的资产分组训练集和未见资产保留集；没有则采用直接方法并结束该假设。若候选缺少好解，下一任务只改候选生成，不同时训练网络。

## 用什么答案衡量

事先固定任务目标、变形度量、保护范围和单位。不把候选顺序、资产名称、构造 seed、最终网格和真实损失作为评分特征。评分器未来只能看到当前局部状态、任务和候选参数。

记录两种不同的量：

- **候选覆盖率**：全部任务中，有至少一个候选满足目标的比例。无好候选不等于整个动作空间无解。
- **选择损失**：在有好候选的任务上，廉价方法选了什么、离候选内最佳差多少。另列保持不动、多个等价解和所有候选都不理想的情况。

若靠几何能廉价直接选对，停在几何方案；若规则经常选错且局部特征有区分信息，进入任务条件排序；若当前特征无法区分两个真实不同答案，先处理表示或目标信息，不能靠加大隐藏层补缺失信息。

## 成本实验怎样才公平

正确性探针先完成，再安排独占性能窗口。与 M4 运行冲突时只推进读写文档和准备，不在共享机器上出正式速度结论。

正式采样前固定重复数、配对顺序、冷/热态及一次准备摊销口径；两种方法使用同一候选集合。原始每次耗时完整保留，不挑最快样本。分开记录：

`采集/准备、特征、候选生成、全部候选的实际求值、选择、反馈`。

计算学习型筛选的收益上界：如果即便完美选择、只求值一个方案，也省不下完整任务约 20% 的时间，且没有质量缺口，就不以速度为理由训练。后续网络新增特征和推理开销还要从上界扣除。

不得把慢速未缓存枚举作为唯一对手；直接优化器、共享骨贡献和同等准备的几何方法仍在对比中。若它们已经足够快，形成有用结论即可。
