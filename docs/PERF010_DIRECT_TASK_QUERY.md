## 产品边界

沿用 `human_eye_scene_observe`，增加有限 `query.mode=task`。输入明确名称或 ID，在一次新鲜采集中解析；不做自然语言解析，不把名称塞进旧 ID 字段。单对象 AABB 无需参照物。名称歧义、缺失和同对象 pair 不猜测。

```json
{
  "include_image": false,
  "query": {
    "mode": "task",
    "objects": [{"name": "Part"}, {"name": "Base"}],
    "requested_facts": ["surface_clearance", "center_delta", "axis_gap"]
  }
}
```

`objects` 接受 1–4 个 `{name:...}` 或 `{id:...}`，每个 selector 的 UTF-8 值不超过 256 bytes。pair 事实要求恰好两个对象，顺序 A→B。不能同时指定旧 focal/reference、goal、图片或 scene_delta。旧 full/brief、图像及动作入口保持原路径。

| 事实 | 含义与限制 |
| --- | --- |
| `aabb` | 当前世界坐标 min/max/dimensions，按 selector 顺序返回；无需实体支持证明 |
| `center_delta` | B 的世界 AABB 中心减 A 的中心；不是质心或最近点方向 |
| `axis_gap` | 世界 XYZ 投影区间的非负距离，投影相交为零；不是最短表面距离 |
| `surface_clearance` | 既有严格核的未舍入标量、方法及范围；负值为认证脱离平移量，不宣称全局最小穿透深度 |
| `solid_relation` | 沿用既有容差下实体穿透分类；未穿透不自动等于物理分离或接触 |
| `nearest_witness` | 仅接受严格核标注的原始表面点；凸组件标量不能补成见证，显示 probe 不参与。零距离的方向单独 unknown |

结果包含当前 revision/fingerprint、解析后的对象身份、产品 source SHA、米制/world、各字段状态及原因。每次重新绑定当前来源，缓存仅复用相同内容的数值。缺失严格证据不抹掉已知包围盒事实，也不产生动作 token；旧同会话 prepare 上下文会清除。

复用既有 capture、校验、`SpatialSceneCache.pair_measurement` 和 `measure_pair_geometry`。只请求包围盒事实时零 pair 求解；严格事实至多一个 pair。未增加求解域、细粒度采集、持久化框架或新传输。

内部直接传结构化结果，只构造所需字段；出口一次编码选定正文，不生成随后丢弃的 agent 消息、全量能力表或嵌套 context JSON。原请求期限贯穿 MCP 编码和交付检查。AABB-only 正文上限 2 KiB，其余 4 KiB，超限显式报错，不截断数值。

## 2026-11-06 R1 中心差数值修复

独立复核退修后，本批仅处理中心差。旧实现分别舍入两个世界中点，再相减。原始 binary64 端点 A=[1e16,1e16+2]、B=[1e16+2,1e16+4] 的精确相对答案为 2，旧接口报告 4，交换后报告 -4。此前的大原点测试使用相同区间或整倍数偏移，遗漏了这个半 ULP 中点反例。

当前实现对四个端点的半值做 `math.fsum` 补偿求和，避免独立世界中点舍入。端点半值可能丢失 subnormal 位、或补偿求和中间溢出时，才用精确有理数端点求和，最后转换为 binary64。普通和大平移路径均不进入高精度回退。当前数值含义是从已采集的 binary64 端点计算相对量，并进行最终浮点舍入。

真实溢出返回 `world_arithmetic_not_finite`。精确相对量非零、但只能舍入为零时，返回 `world_arithmetic_below_float_resolution`。这两类情况只使 `center_delta` 字段 unknown，其他事实保留各自状态。精确零仍然 measured。`A=[-MAX,MAX], B=[MAX,MAX]` 中间求和可能溢出，但最终 MAX 可表示，仍返回 measured。

公共回归新增 5 个测试方法。12 组固定端点覆盖三轴、对象交换、原点与大平移、正负区间、半 ULP 中点、接近溢出、真正溢出及下溢，共 72 个 MCP 子案例。另外以固定种子生成 2,000 组有限端点，用独立 `Fraction.from_float` 答案核对，并检查正常路径没有调用有理数回退。

- 同一新版公共测试在旧固定源码记录 29 处断言失败，新版 31/31 方法通过。

## 2026-11-06 R2 请求生命周期修复

R1 已独立通过。本批基于 `8e62665f1b7a1c1fdfcee95722e5d786159b3081`，修复原期限在外层 wire 编码前结束，以及提交后的失败回执错误报告未写状态的问题。

`budget_scope` 为 `cooperative_service_entry_through_mcp_prewrite_checkpoints`。它表示协作检查点的范围，已经开始的系统 write 由原系统调用完成或报错。终止错误编码与实际写出耗时单独计入测量。

原子 writer 在 staging、进入替换、替换完成三个阶段记录结果。错误回执通过请求快照保留连接器状态和宿主动作的各自事实。`state_write_scope` 明确指向配置的 connector state JSON，审计和锁文件属于其他写入。

| 字段 | 含义 |
| --- | --- |
| `connector_state_write_attempted` | 本请求是否调用过状态原子 writer |
| `connector_state_write_status` | 最后一次尝试为 not_attempted、not_committed、committed 或 unknown |
| `connector_state_write_attempts` | 本请求的尝试次数 |
| `connector_state_write_commits` | 已确认完成替换的次数 |
