# M4-DENSE-RASTER-CROSS-001

本批只删掉单个三角颜色计算里通用叉积的轴处理开销。现版密集两图真实纯光栅 716–777 ms。固定矩阵与原件的逐面中，SCENE 每次 6,148 次 `np.cross`，独立插桩累计约 152 ms。用等价固定三分量乘减的原件试算，两张光栅中位合计省约 126 ms，四类原始输出数组逐字节一致。[实测热点归因](M4_GLOBAL_PIXEL_BOUND_SHORT_CIRCUIT_001_INDEPENDENT_REVIEW.md)

## 唯一算法变化

固定 A `f72e648f763fb6399f82c8e5d7f2b35840597bed`／143 源 `0e71932b2bccbf8a6583460875cea8bdc55b092b7d8f3391c9b0124aef986d4f`。仅在 `attention_raster.py` 的既有逐三角颜色路径使用两个三分量 float64 向量的原等价计算。沿安装 NumPy 三维叉积的三个分量，各用相同两次乘法和一次相减，保持分量、操作数顺序及 NumPy 浮点类型，不融合或重排。既有边向量规模归一、零值、长度、光照点积、RGB 取整和异常路径沿用。深度和覆盖计算保持原流程。复用世界坐标和原亮度模型。该共同例程也被普通注意力图调用，纳入兼容控制。

## 等价与测量

1. 使用当前原件的真实求值网格、投影及颜色，离线逐字节比较 RGB、float64 深度、对象所有者、源三角或 patch 索引，覆盖密集 SCENE/LEFT、28 和 21 对象封存图及普通和明确源区域的真实或现有合成用例。定向控制包含退化三角和零尺度、极大／极小但可支持的边、near/frustum 剪裁、同深度顺序、遮挡层、隐藏与非目标来源、普通无 owner／owner／给定 patch mapping 及预算拒绝。候选数据必须来自同一归一结果。可加固定种子的多方向三分量位级对照。保留当前性能与任何旧测试失败。对局部 `region_task`、像素短证据、挡物、同代缓存、完整和简报语义作已有原件回归。分段实测只在非插桩进程计净收益，剖析时钟单列。
2. 离线等价且两帧有足量可重复的节省后，固定密集资产 `2d7c48f01665588bd7cfc93280ea50b559f4dc08196738c504ea56c88c75a164`、相同 1 m² 全场 `region_task brief` 与原两帧。按 `A1→B1→B2→A2→A3→B3` 三对实际隔离 Blender 运行，每个一次业务。逐对核三维源及实际 PNG、NPZ、可见见证、遮挡和 CLI 重放。记录纯光栅、构图发布、索引、收尾、冷 RPC 和完整独占窗。保留模型与非模型耗时的已知边界。上限 6 owned、6 业务、12 新构图，0 模型、额外资格、重建、替补、Google/API/费用。使用真实既有协议收据先做独立进程派发和路径预检。
