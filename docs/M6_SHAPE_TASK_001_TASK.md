## 先辨清三种输入情形

| 情形 | 必须说明 |
| --- | --- |
| 导入已有模型，只有观察几何、任务描述和选区 | 现有输入实际上已包含什么；“允许修改”与“知道受损位置/期望形状”的区别；能评价哪个输出，哪个艺术答案尚无来源 |
| 引擎见过修改前状态，或用户明确给出可信同拓扑参考 | 参考如何取得、何时被认可为目标、对应关系是否成立；不能把任意缓存状态当正常参考 |
| 操作者指出大致部位，但没有正常3D参考 | 部位/粗选区能实际增加哪些信息，仍缺什么；真实支持、合成扰动中心/半径/向量不能冒充用户输入 |

这三项是输入来源分类，不是再训练三组模型。只读核对本分支已有输入/缓存/任务接口，给出文件与字段依据；不要改M2/M4/M5或建立新权限/调度层。用户给过的原画是外观参考，不是同索引三维真值；本批不读取新原资产、不扩展图像配准能力。

## 具体工作

1. **输入与目标表。** 对以上情形逐项标注：现在部署时可得、需要用户提供、仅在本合成数据中可得。证据来自已有接口与保存数据。任务条件具体到字段及含义，不能只写“加入语义”。明确预测输出应是区域、位移、修正系数还是其他量。学习目标不能把艺术好坏和恢复人工扰动混成一个标签。
2. **直接基线先判断。** 若可靠同拓扑目标参考已作为输入，比较直接对应恢复/既有历史撤销是否已给出答案；若已解决则该子任务不训练。只有局部粗选区时，固定边界等约束能确定什么、仍有哪些形状自由度，用现有几何和方程说明。无需跑数学上已经确定的零误差刷分。
3. **用原件落地一个任务。** 在OBSERVE001六个固定见证及其配对中选一个代表作为说明，不新增数据或重选有利来源。写出实际可得输入、明确修复意图、输出、保留范围和验收答案的来源；声明它对应真实部署情形还是仅合成研究情形。若需最小原件验证，最多六个旧见证，仅离线读取/内存计算，记录全部成本；不得把真实支持mask或位移直接给拟议推理入口。
4. **给出一个选择。** 如果已有输入、监督和合理直接基线足以构成一个有学习机会的任务，推荐一个具体输出任务与首选模型结构，说明为什么，以及首版/一次优化的质量和完整成本验收。若缺少关键监督或直接方法已解决，则明确不训练当前子任务，列清阻止学习立项的具体缺口及最小证据来源。不要靠改名把当前失败网络再训练一轮。

输入/目标表可以说明“同一几何在不同编辑目标下应采取不同动作”，但这只是任务定义事实，不作为新增学习收益或旧任务失败的因果证明。也不把一位`保留/修改`提示直接映射到答案的对照当专家能力。
