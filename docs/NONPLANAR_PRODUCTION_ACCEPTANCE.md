# NV-02：有限非平面生产协议与完整独立消费者

本模块沿唯一主计划实现，不重新优化已冻结的全域自动密集入口。默认XY通道保持；本机受信配置显式选择nonplanar_boundary_v1或nonplanar_dense_v1，模型标签不选择能力、不新建预算身份。

## 实现前冻结的范围和出口

- 只读、完整新鲜的单目标boundary_edges patch；原始三角多边形和原生三角索引/局部及world坐标逐值绑定。暂不支持重排/改变三角化、修饰器或未建立对应关系的求值网格。最多64对象/4096顶点/2048三角/64边/4视角，两图、8192生产＋复核三角测试及既有NV-L/NV-D工作/空间门保持。
- 新typed能力/协议与固定字节加载；生产代码不导入verification。不改变旧XY请求/能力字段，不新增动作权限，不在旧默认路径预先做新路由探测。稀疏与密集模式由宿主配置选择，密集阈值只在显式密集能力内部生效。
- 完整consumer拒绝额外/缺失字段、NaN、过期、错任务/对象/patch、raw/native/display/incarnation/epoch失配，重建边界来源、候选方向/正交基、特征、投影、采样、有限搜索/理由/选择/收益和全部工作账。局部及索引证明用独立精确算法，射线用独立3D算法；生产planner不可被consumer调用。优化Python(-O)不能移除验证。
- 原生实际RNA的方向、中心、裁剪/视野和像素、图像hash/大小、状态恢复、时间序列完整检查。失败、unknown、无收益及部分预算不冒充有效局部；同物体内壁、角色、自交/损伤语义仍不扩域。
- 接入既有结构任务/worker/固定MCP模板，保留6次查询、2图、180秒、任务世代和持久去重；失败/不确定提交不返还已花额度。默认旧XY和文字域回归。
- 真实测试仅新factory Blender，三进程覆盖已可靠原生有限域、同物体密集和遮挡；实际consumer解码wire，独立像素及恢复/退出。生产完整协议成本包含源读取/规划/编码/独立检查/PNG/任务传输；同质量比较另列，不用旧拒绝计算加速比。
- 旧XY同路径不得增加新几何工作；新非平面通道首次/热态规划＋wire＋完整consumer p95≤500ms、含捕获/PNG的单请求≤30秒原截止，完整任务≤180秒。门是有限本机验收，并非硬实时SLA。若失败保留记录并收窄交付状态，不调高旧总预算。
- 完整公共回归、三个已封存批次payload不变、运行源身份更新、唯一计划与支持域一致后交付；安装/默认消息入口/正式模型收益单独待验。

## 最终验收结果（源码模块，未安装）

生产实现为nonplanar_focus、nonplanar_exact、nonplanar_replay和nonplanar_observation。固定字节生产helper不导入verification或整个引擎；consumer不调用生产planner/筛选/相交，所有验证在Python -O下仍执行。新增typed协议readonly-nonplanar-boundary-v1及明确模式；旧XY helper/consumer源字节不变，新能力只有显式配置时才进入既有结构任务链。

原型两遍邻接/范围/投影不足以覆盖新增完整决策复核，生产计为三遍，仍使用原32768局部、32768 broad-phase及65536投影门；构建/节点/证书及8192射线门保持。原始三角对应、转米局部坐标、平移分量转米矩阵与world逐值一致。搜索不完整时不发布视图，旧106面稀疏原型即使首视角可用也会转unknown，保留文字与已消耗预算。这项保守取舍显式登记，不宣称所有原型覆盖都无退化。

最终三新factory进程各30类，共90判断、60采用/30拒绝、150帧；60张有效局部由独立Pillow验证12/12或10/12。包含毫米、千米、旋转/平移、同物体1808面远处几何及真实遮挡；实际RNA/显示/几何恢复及退出通过。所有保存wire按最终checker重新回放，离线时移只用于校验/成本，原生新鲜验收在对应进程内完成，二者不混淆。

两项新owned固定worker→service→四工具MCP任务均返回2张原生图，图像请求约418/716ms；重复仅收据、额度耗尽仍有新鲜文字、持久任务共用原额度、输入blend未保存回写。固定BlenderMCP模板在真实bpy执行通过，未使用共享GUI/TCP；旧XY生产host/consumer通过。陈旧patch、过期、显示不支持、恢复不确定隔离及隔离后重试通过；16类真实响应篡改（包括实例/世代、轴/裁剪、PNG/恢复/序列、未来完成/错误耗时等）全部拒绝。

完整规划＋全响应JSON＋独立consumer（含PNG）30次×6组：稀疏中位15.511ms、26面20.944ms、40面22.836ms、80面27.241ms、1808面186.768ms；1808面/密集遮挡p95为189.971/207.605ms，均≤预登记500ms。3个新Python进程首次最大约216.375ms，启动wall另记。冻结几何基准不含新捕获/渲染/宿主传输，实际native矩阵和MCP任务另列；没有以少校验原型作加速比基线。这项新通道门不能覆盖旧M1成本失败。
