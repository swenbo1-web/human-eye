## 一个主交付，两个任务入口

主交付是共享当前几何、局部上下文和引用的任务感知原型。先在同批固定一个学习候选及运行方案，随后完成首版、一次针对性优化与同任务对照，不再拆成只交数据建议的多批等待。

- `inspect`：在给定检查范围内寻找值得继续检查的区域，并区分候选注意力与明确异常预测。
- `focus`：用户已通过点选、坐标或稳定区域引用指定目标，返回目标及周边的空间事实和可追加细读入口。正常目标不经过异常分数门槛，不因未检出缺陷拒绝读取。

本批 focus 的目标绑定是任务提供的定位信息，不声称已经学会“左颧骨”等自然语言部位识别。两种入口共享观察表示；若给定目标已可由几何直接读出，直接走已有计算，记录模型未被调用，不能把该控制成绩算作小模型的增益。

大模型负责理解用户修改意图、参考图与取舍，返回需要关注的引用、已有依据、仍需补读的信息和操作计划。它不凭文字猜测逐顶点坐标；以后通过具体几何工具完成修改与回读。本批交付到定位、理解和计划，不训练位移或改原资产。

## 候选选择与实现

首选方向为共享多尺度表面表示加轻量定位输出：先一次准备当前局部坐标、法向、拓扑/邻域与周围上下文，再批量产生点/区域表示。可复用现有预训练组件，但不自动沿用失败的 `0.05*全对象bbox` 单尺度、逐查询重复整套编码实现。

实施者根据实际可用组件确定唯一网络结构，训练前在 PLAN 中简述：输入包含什么、为何能覆盖宽凹陷与正常周边、共享计算如何实现、参数量/内存估计、与既有失败候选的实质差别。先排除不合适路线，不轮训模型目录；不以500/800等任意参数上限裁决。当前不引入生成式小语言模型、LLM隐向量对齐或另一个任务路由网络。

允许同一个候选的首版训练和一次有依据的优化，总计至多两次候选训练。首版达标也需检查一次有实质内容的优化；优化优先处理实际主导的定位或重复计算问题，复用特征/数据。正常代码错误可同批修正并记录。一次优化后报告去留，不换seed、改数据分母或另换模型继续刷分。
