# 高顶点焦点的有界原生局部观察

源码修订 `v21-dense-focus-roi-20261031`，摘要 `22fb2523bdbfb68d6e7227ea3df3b4373daa1a76461344bc1755406c5feeec8a`。独立 SDK 候选发行号为 `9.7.2+20261031.dense.focus.candidate.r1`；本轮没有替换正式入口，也没有完成此候选的固定 MCP／GUI 安装验收。

## 入口与收益条件

`plan_readonly_dense_focus` 先调用原 `plan_readonly_task_gap`。已有局部图或原结果不是 `focus_budget_exceeded` 时，直接返回原结果。V1 通用／动作、V2 任务间隙及原渲染函数保持原行为。

新增分支仅支持 XY／XZ 正交视图。焦点超过64顶点或128三角形，场景总顶点不超过4096、总三角形不超过2048，且所有面均为合法三角形。实际宿主和服务的几何准入仍须通过，不因规划成功而放宽。

O(V) 将焦点顶点相对局部原点投影到全景相机的 right/up 轴，取两个包围区间中较小的长度。公开方法名为 `projected_aabb_min_extent_upper_bound`：它是最小投影宽度的上界，不是真实薄截尺寸、细节最小宽度或间隙测量。ROI 中心由投影区间中点还原到世界坐标。

仅当全景投影上界小于12像素，局部上界至少32像素、放大倍数在2至4096之间时，才考虑新增窗口。局部跨度为 `max(4 * width, overview_span / 4096)`。这些是规划机会条件；原生图像是否有用仍须独立验证。

## 遮挡、精度与预算

生产者中央射线必须首先命中焦点；消费者使用独立三维线／三角形算法回放。平行／共面歧义、最近命中并列、隐藏焦点、预算不足或精度不足保留原结果。只有一条中央射线，不认证完整目标或 ROI 的可见性。真实遮挡物和全部场景几何仍参与渲染及深度覆盖。

生产者与消费者共享 `2 * scene_triangles <= 4096` 的射线三角形工作上限，不分别各用4096。中心精度使用局部宽度和 ULP 检查；相机位置／跨度另有 binary32 预测检查，实际 RNA 取景验证继续执行。大纵深下斜向相机基向量误差可能偏移小窗口，因此新增 V3 暂不开放 SCENE；旧 V1／V2 的 SCENE 行为保持。

每次观察仍最多两张384×384图片、294912像素，使用原只读观察期限。无图路径、动作权限、动作历史、未知写入和重试语义保持。新增射线检查与额外渲染有成本，不承诺免费放大或整任务加速。

## 显式输出与消费者

成功计划为 `native-dense-focus-plan-v3`，原因 `dense_focus_detail_gain`。新增 `bounds_feature` 记录方法、焦点顶点／三角形数、投影区间长度、宽度与像素上界、放大倍数、世界中心及质量范围。`visibility` 明确记录单条中央射线、双方工作量和 `one_sample_not_complete_visibility`。

消费者独立重建投影包围界、中心、跨度、方向、场景绑定、工作预算和首命中；篡改字段应拒绝。公开 canvas 使用 `projected_bounds_opportunity_not_thin_section_or_complete_visibility` 说明。新增版本必须由匹配身份的生产者和消费者处理；不能默认旧消费者兼容 V3。

## 本轮有限验收

五个独立 factory 场景分别运行旧正式 SDK 与候选 SDK，共10次原生观察、15帧，15个 Blender 及10个 SDK 进程全部正常退出并 wait。没有连接用户 GUI 或共享场景，没有动作、provider 请求或正式模型试验。

| 输入 | 旧版图片 | 候选图片 | 结果 |
| --- | ---: | ---: | --- |
| 65顶点闭合盒体，远处背景 | 1 | 2 | 焦点全景约0.122像素，局部约96像素；实际相机射线与PNG采样确认目标可辨 |
| 相同边界的8顶点盒体 | 2 | 2 | 原V1局部路径保持 |
| 65顶点，普通本地范围 | 1 | 1 | 全景已可读，保留单图 |
| 65顶点，完全遮挡 | 1 | 1 | 保留遮挡，不增加局部图 |
| 25微米旧版任务间隙 | 2 | 2 | 原V2侧视间隙路径保持 |

五组全景 RGBA 一致；输入文件与安装源码摘要保持；捕获几何及渲染状态恢复。连接状态只允许观察缓存字段变化，不宣称完整状态字节相同。颜色阈值仅作解析彩色资产的辅助检查，不是通用分割或完整可见性证明。

干净的规划器 CPU 测量使用每类96组交替 AB／BA。三个旧路径的配对新增耗时中位数为 -0.0011至0.0008毫秒，p95最大约0.0651毫秒，通过原定中位数0.5／p95 1毫秒的门限。新高顶点正例新增中位数约0.287毫秒；这是规划器数据，不能代替 RPC、渲染或模型任务性能。正式模型收益仍未测。

完整本地回归1595项中1594通过、1项既有Windows权限跳过；新增27个公共单测，另有46组独立纯算法检查。可移植测试用 `python -B verification/run_portable_tests.py`。本机真实资产、历史封存及验收产物不随公共源码发布。

后续先做 V3 固定入口的版本兼容与安装验收，再研究部分遮挡、真实非盒体复杂资产及斜向取景。达到有限质量门后，才进行固定模型、同题同提示词、盲评和真实成本统计的整任务对照。
