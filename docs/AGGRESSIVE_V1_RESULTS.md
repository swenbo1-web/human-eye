# aggressive-v1 第一版产出与实测

本版数值链在最新整体架构中属于 E3 的已有基础。后续采用 [Radical V1 融合方案](RADICAL_V1_INTEGRATION_PLAN.md)；以下测试与性能仍仅对应原有数组计算链，不覆盖附件的视觉、学习、动作或 <12ms 声明。

日期：2026-11-05。分支 `codex/aggressive-v1`，历史基线 `2846992`。方案与后续两端分工见 [AGGRESSIVE_V1_PLAN](AGGRESSIVE_V1_PLAN.md)。本文件所在 Git 提交交付源码和结果；原始测量见 [aggressive_v1_benchmark.json](aggressive_v1_benchmark.json)。

## 已交付

- `human_eye_fast/kernels.py`：缓存参考基、批量解析谱、选择面更新、AABB 与三角-盒体 SAT。
- `human_eye_fast/engine.py`：常驻多帧数组、CSR 顶点-面邻接、脏顶点更新、完整选区归约与跨帧同面见证。
- `human_eye_fast/cli.py`：NPZ 单次分析与常驻 JSONL load/update/query/rows/close。
- `human_eye_fast/blender.py`：Blender 进程内原始参考/求值帧采集适配器；当前未做真实 Blender 运行验收。
- 四个测试模块、可独立重跑的三方比较工具、原始计时样本与来源摘要。
- Python 发行标记 `9.7.2+aggressive.v1`，新增 `human-eye-fast` 命令。

新运行链不导入历史插件，不进行来源/依赖/内容哈希、独立来源重放、期限/配额检查、授权账本、文件发布和重复回读。对输入形状、索引与 dirty 声明直接信任。参考退化及非有限算术结果仍表达为数学未定义，JSON 为 null；这属于数值结果语义。

## 数值与集成复验

36 项测试全部通过：14 项内核、15 项常驻会话、3 项真实子进程 CLI、4 项比较工具测试。内核测试包含 400 个随机 QR/SVD 对照和 400 个有理裁剪对照；会话测试另覆盖共享顶点的局部更新、参考退化、当前塌缩、空区域、跨帧成员不同及见证输出不足。

离线 wheel 构建通过，并从 wheel 文件实际导入新包执行 demo，核对 `human-eye-fast` entry point。文件为 `artifacts/aggressive_v1/human_eye_spatial_plugin-9.7.2+aggressive.v1-py3-none-any.whl`（本地构建物，不纳入 Git），SHA-256 为 `eff297a67799282d59ab5177cfa1a1fe2306c595181cc6b2d48f8dbdae7083e2`。本机原环境缺少构建后端，setuptools/wheel 仅安装于 `artifacts/build_tools`；构建与测试曾遇 Windows 沙箱临时目录 ACL 拒绝，使用正常宿主权限后完成。真实 Blender 未运行。

正式吞吐夹具为独立、非退化的倾斜三角形，三个规模共 22,176 面。旧实现这批均为 measured；新主伸长相对独立 QR/SVD 的最大绝对差为 `1.3322676295501878e-15`。区域测量共比较 128/2048/2048 面，各次相交判定差异为 0。每个规模的 sparse/full 最终全部面结果一致。

这些数值证据适用于给定夹具和测试范围。新版本删除了原 binary32 保守误差拒绝及精确有理数谓词；极薄、极大/极小尺度或极近边界的输出语义可能改变，不声称保持旧版全域判定。

## 本机测量

环境：Windows 11，Python 3.13.14，NumPy 2.3.5，Intel64 Family 6 Model 165 Stepping 5。每方法预热 1 次、正式 7 次，方法交错顺序固定随机化；以下均为毫秒中位数。原始 JSON 保留每次样本和 p95；7 次 p95 仅作描述。

| 面数 | 旧完整逐面事实 | 独立批量 QR/SVD | 独立缓存参考 SVD | 新冷准备+计算 | 新热计算 | 缓存 SVD / 新热计算 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 128 | 13.4331 | 0.3611 | 0.2087 | 0.2485 | 0.1514 | 1.38× |
| 2048 | 228.9891 | 3.2409 | 2.1378 | 0.9373 | 0.5605 | 3.81× |
| 20000 | 2696.3438 | 37.2935 | 23.5318 | 11.7957 | 7.0279 | 3.35× |

旧完整事实 / 新热计算分别约 88.73×、408.54×、383.66×。旧函数还生成方向/误差等丰富字段，含精确零面积、误差与期限检查；这个差值同时包含算法、Python对象和合同变化。独立缓存参考 SVD 是更接近普通可信输入数值处理的对照。独立数学输入已预先聚合为逐三角数组，新内核计时仍包含索引 gather。

## 复跑

```powershell
python -B -m unittest verification.test_fast_kernels verification.test_fast_engine verification.test_fast_cli verification.test_fast_benchmark
python -B verification/benchmark_fast_v1.py --sizes 128,2048,20000 --repeats 7 --warmup 1 --region-faces 2048 --output docs/aggressive_v1_benchmark.json
python -B -m human_eye_fast demo
```

基准 JSON 的 `sources.git_head` 为测量时尚未提交的历史 HEAD；`sources.sha256` 精确绑定实际测量的五份源码。最终提交可直接重算这些 SHA 核对，不把运行时 HEAD 冒充最终新提交。环境差异会改变时间，原结果不覆盖。

## 第一版之后的直接进攻点

架构端优先把真实连续 Blender/Live 任务接到常驻数据流，测量全量捕获及模型接口，替掉每次启动/验证/搬运链。算法端优先对连通网格实现更强局部更新与 BVH/refit、普通空间距离/碰撞内核，再试 SIMD/JIT/GPU。固定同一个 v1 起点，使两端产出可分别测量和组合。

目前区域查询仍扫描缓存 AABB，Blender 适配器仍全量读取求值顶点，NPZ/JSONL 的传输也仍有复制；这些是明确可继续移除的成本。新增渲染和执行路径尚未实现，历史 MCP/Hook 入口不会自动变成快速版本。
