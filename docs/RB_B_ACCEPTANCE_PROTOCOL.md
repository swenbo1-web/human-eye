# RB-B 真实 Blender 采集：实施前冻结协议

日期：2026-11-05。继承 `RADICAL_V1_COMPETITION_WORKFLOW.md` 的收益门，实施前保存。RB-A 已通过；本项补齐真实 Blender 求值到常驻米制数组的路径，不替代后续距离、视觉或整链验收。

## 交付范围

新增 `human_eye_fast/blender_resident_bridge.py`，提供与 RB-A `ResidentMesh` 相同字段和借用生命周期的原生多对象采集器。可信调用方显式声明顶点、拓扑、变换、单位和外观变化；无需每帧哈希、重试、回退链或隐藏全量核验。首次捕获和拓扑变更建立自有缓存；稳定拓扑保持数组身份；旧借用视图不得指向已释放的 Blender 临时内存。

读取 evaluated object 的真实几何，支持修改器和连续帧求值。局部顶点及世界矩阵平移转为米；线性变换不重复乘单位比例；世界坐标与 `scale_length * (matrix_world @ vertex)` 一致。外观最小合同为对象颜色、材质槽名字及 diffuse RGBA、逐多边形材质索引及其三角关联；不宣称完整 shader/纹理求值。

“稳定拓扑”指最终 loop-triangle 连接保持稳定，不仅是顶点/多边形数量相同。四边形或 n-gon 变形可能改变三角剖分时，可信调用方须声明拓扑变化；正确性增加这一显式声明案例。主基准使用三角网格，不能把计数检查当作通用三角连接检测。

正确性必须覆盖：多对象隔离、非均匀缩放/反射/父子变换、修改器产生的顶点、单位切换、同顶点/面数但索引不同的拓扑替换、拓扑规模增减、仅外观改变、无变化、删除/释放。显式变化合同中的组合变化必须在同次采集中全部生效。当前 GUI 场景不参与变更测试。

## 固定输入与测量

- 两档网格：每个对象 100×100 或 300×300 共享顶点网格，每档两个对象。输入使用非平凡世界矩阵、非平面几何，至少一个对象具有真实形变修改器。
- 固定八步序列，次序不按结果调整：全量顶点改变、形变修改器参数改变、仅变换、无变化、仅外观、单位比例改变、同规模拓扑替换、顶点/变换/外观混合改变。顶点与修改器至少在两个不同状态间交替。拓扑增减另做正确性及独立成本报告，不混入主序列配比。
- 每个样本是一遍完整八步序列的捕获＋准备时间之和；同时保留八步各自时间。Blender 属性/网格修改命令、输入生成、正确性断言和写盘在计时外；由这些变化触发的 depsgraph 求值、evaluated object 获取、网格读取、单位转换、世界变换和输出准备在计时内。
- 同一进程交错运行基线/候选并交替先后顺序。两条路径都从相同预状态开始并执行相同真实变化；不能先让基线承担脏 depsgraph 求值，再让候选复用已求值状态。序列准备及缓存初始化在计时外，但双方必须对称，不能提前求值计时步骤的目标状态。
- 至少三个独立 Blender 后台进程，每进程每档预热五次、交错测量三十一次。固定单线程 BLAS 环境并记录 Blender/NumPy/CPU 配置；后台进程退出，不干扰用户已打开的 Blender。

## 基线与收益门

合理直接基线使用相同的常驻 local/world/topology 缓冲和相同更新声明：原生 evaluated object → `to_mesh()` → float32 `foreach_get` → 米制 float64 → 世界变换，临时网格按 Blender 生命周期释放。拓扑稳定时不重算/复制索引；仅变换、仅外观、无变化均只做合同要求的工作。禁止用 Python 逐顶点循环、每次重建 FastSession、无关形变计算或无变化强制全量拷贝膨胀基线。候选可使用 evaluated mesh 的直接访问等架构优化，但需证明数据所有权和同等输出。

每个规模、每个进程的完整序列候选中位数/基线中位数 **≤0.80**；各规模合并三进程原始完整序列样本的 p95 比 **≤1.20**。复制量列明 RNA→NumPy、类型/单位转换、自有缓存写入、世界数组写入、拓扑/外观数组和额外 Blender 临时网格；无法精确测量的 Blender 内部分配标明未知，不能叫端到端零拷贝。

性能对比前，使用与候选实现不同的原生读取/oracle核对完整 local/world/triangles/变换及外观。与相同 Blender float32 求值结果比较，float64 换算容差 `rtol=1e-10, atol=1e-10 m`；索引和分类字段精确相等。另报告相对解析输入的原生 float32 误差，不能用更宽容差掩盖单位或变换错误。

实施对话保存原始样本及命令，报告所有失败与重跑。主对话换独立种子、添加持有样例、核对计时边界，并再启动同规格三进程验收。未达标返工，不调低门槛。主对话通过后才将 RB 整体标为 PASS，允许 BC 正式推进；不因本项通过宣称整个引擎完成。
