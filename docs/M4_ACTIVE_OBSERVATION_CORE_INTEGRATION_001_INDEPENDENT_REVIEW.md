## 本次实际完成的产品化

`human_eye_plugin.active_observation` 静态组合已接受的二维面积发现、optimized可见性索引和CoverageState。完整几何只解析一次，通过显式参数共享；正常产品调用不再依赖verification导入、FunctionType私有globals置换或固定旧安装目录。默认逐面work字典、位长和计数已移除，diagnostics仅保留阶段时钟及汇总。

`human_eye_plugin.active_observation_images` 把规范四角/front用于ROI可读性，遮挡仍使用全部真实三角网格及共同RGB/depth/owner。只有实际帧可读性和预测完整可见的交集进入covered。短事实保留对象、ROI、视角、图像引用、像素依据和未知，内部triangle_indices不再发给默认摘要。

正常API为 `prepare_scene(scene, cameras)` 加 `ActiveObservationImages`。支持域仍是单对象、连通无孔、精确共面正交矩形，包括已验细分；相机为显式有限正交池。这是可直接安装调用的有限观察闭环，尚非任意角色、材质缺陷或整个复杂场景的通用理解。

wheel为 `9.7.2+m4.active.observation.core.r1`，1,143,492B，SHA256 `27f649e96728f84b72638ccce49575f21d71c15cbc3824a6c3f1b6e30d6c93d8`。140源摘要独立重算为 `29c3f2a1a312d2d5eda1d688619846ae4137832576f9ff3ddf078c42d1a866c3`；Git、当前源、wheel、隔离product和失败安装snapshot逐字节一致。旧138产品源码未变。
