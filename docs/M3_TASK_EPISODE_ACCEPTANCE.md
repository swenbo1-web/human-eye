## 传输、成本与生命周期

目标工具仍是原三个工具集合中的有限目标工具，没有新增移动工具。常规文本回执只增加 `task_episode_ref` 短引用；完整记录通过 owned 入口的 MCP `resources/list`、`resources/read` 按需获取，不在每个回合重复发送完整执行回执。资源只查当前连接中的精确 URI，不能把 URI 解释成本地文件、网络地址或新授权。

单连接仍最多 16 个原目标调用；每个记录最大 1 MiB，请求摘要输入最大 256 KiB。重复 call id 在创建新记录前拒绝，不驱逐历史以重开额度。连接重启不恢复执行能力，历史资源也不能代表当前场景。新增的复制、序列化和哈希有 CPU/内存成本；短引用的字节检查不等于完整 RPC 性能或模型收益过门。

记录默认只在连接内存中，工具回执构造不证明消费者已收到。`archive_episode` 是可选消费者侧操作，不在执行快环或每步保存中调用。它先校验记录，在操作者指定的既有目录写入并刷新完整临时文件，再以排他硬链接发布内容地址文件；已存在文件先验证，不能覆盖或静默选择损坏记录。临时文件只清理本次创建的一项。文件刷新、目录元数据持久化和消费者读取分别表述；没有宣称断电后目录项必然存在、恰好一次交付或常驻 outbox。

摘要校验用于检测损坏，不能认证来源。`summarize_episodes` 按原事件去重并拒绝同事件冲突；100 份副本仍只有一个已记录事件，事件数也不等于独立试次数。所有记录 `training_positive=false`、`human_UI_verified=false`，独立支持数为 null，不发布 Skill、训练模型或重建权限。
