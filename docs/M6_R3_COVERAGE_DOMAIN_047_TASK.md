## 一次证明与核对

1. **找到真正的判断位置。** 从普通单对表面距离、G60 最近查询和扫描、局部选区各追一次正常调用。列出在首次执行版本特有工作之前已经可得的三角面数、预算余额、来源与缓存状态，以及取得它们的成本。区分已命中、未命中、已准备的树、共享工作、已知边界接触和待求值。标明何处已经使用 R3 专有的数据结构或已产生不可忽略的准备成本。不得把需要求解后才知道的量或已跑过 A/C 的答案作为运行时条件。
2. **验证一个输入上界。** 以原始面数乘积为起点，证明或反驳单次有效求解中每个原生三角对最多进入一次窄相。逐条跟踪初始贪心、入队的兄弟子树、堆遍历、线性路径及复用；写清共享账本或复合事实前后哪些工作还需付费。比较的是当时的真实剩余额度。单独处理总工作上限、精确整数位宽、最终规范见证及发布工作。总工作若只能在某类输入上给出可在事前计算的充分上界，就写出该类、条件及取值，必要时缩小声明范围。已有投影信用的收支要同时守恒。用实例检验不等式边界；实测低水位不能代替数学上界。时限、取消或状态变化单列，工作单位不能保证墙钟。
3. **用已经存在的资产判断这个范围值不值得保留。** 先冻结样本、来源和计数口径，再做任何新的离线运行。主矩阵为 045 的 129／044 的 125、045 的 G60 六组宿主快照及原始业务、046 预选的原装配、043 的 Yanyite 高低选区与低区剩余预算反例。G60 公布 66 个可能对象对，实际进入内核的调用、提前排除、命中和重复必须分列，不能拿 66 当作新精算数。优先从原件恢复。若现有普通资产归档确有合法的高配对负载，再按预先固定的目录范围和稳定顺序取至多一个原生查询；找不到就记录缺项。不开新 Blender、不重造资产、不重复计时。对缺少必要字段的案例，可对冻结原内核做一次离线观测，并明确它的口径。
4. **输出可证结论。** 每条路径列出能否事前判定、证据属于证明还是实例、A/C 已有事实和几何见证、潜在配对、实算数、逐项限额、覆盖及未知。分别回答窄相上限和整个工作合同是否已证明，以及 G60 哪些实有负载在所证范围内。若估算历史耗时占比，须有可绑定的逐调用时间，单列准备、公共开销及未知。不得由面数或一次真实速度推算混合入口加速。

可以把保留 A 作为无法判定时的发布选项，在图纸上说明是整次请求还是整对查询、已有缓存及准备状态能否延用。在本批中每个版本仍是原始独立对照。仅恢复已知覆盖不等同于完成全域替代。本批不实现路由、混装、超限重试、双跑、借用信用或新内核。
