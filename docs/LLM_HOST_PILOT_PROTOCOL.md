## 模型实际收到什么

两次提示只给公开对象标识、目标间隙、容差、允许动作与必要任务说明。不给recipe、私有分离轴、评分答案、预期颜色/遮挡答案或隐藏真值。不把整个repo/评分目录作为上下文；consumer工作目录独立。要求只用本次Human Eye工具完成任务；非任务工具访问按实际记录，不能默认为合格。

数值题：一次`eye_run`完成缩隙，模型据实际回包报告最终间隙、达标与实际世界米位移。无需open/observe/predict/confirm/feedback/close串行对话。若实际多出inspect或其他调用，完整保留，不通过脚本替模型合并回合。

图像题：`eye_run`随目标请求终态图，实际MCP返回标准ImageContent。模型报告数值结果并描述图上可见的两个面板、目标/遮挡关系或相对颜色与位置；公开提示不泄露图中答案。没有图或看不清应据实说明。独立审查比较实际PNG及模型描述，确认它使用了图像而非只重复正文。不得用本地图片路径、提示预附PNG、文字base64或脚本client替代MCP图像消费。模糊或与文本重复的回答只能判消费证据不足，不伪造视觉通过。

真实宿主的initialize、tools/list、tools/call和实际协议版本均留存；图像任务的相机证据从当前缓存按需取得，记录该额外调用的来源及开销，不能重渲染补旧图。功能取证不拿来宣称正常业务必须多一轮。
