# M6-SHAPE-DATA-001 独立复核与训练决定

2026-11-15。固定作者提交 `efce450c1da372642010871994588a69799e268c`；来源读取计划 `465a0894`；生成前冻结 `bc2dfddb4f0d8d2304a5aa6dcb5c03d076b6f666`。原合同 `d88cf18d1a6cf564c907d980ccf0ef159a954e9f`。

## 决定

**接受当前配对数据和单一网络设计，进入有边界的首轮训练准备及训练。** 已有 33 个 patch、231 个观察足够作为这次开发训练池，48 是上限，少 15 个不是需要补齐的失败项。不能继续为凑数量收集高度重叠区域。

保留四个本地角色为一个上游关系未知组，不把文件名差异当作独立来源。来源分组不足是真实的评估缺口；已找到并预取 Stanford 官方 Armadillo 与 Bunny 两份有不同扫描对象记录的网格，分别用于验证和保留测试。当前四个角色不拆出新盲测。新来源与用途在任何训练成绩产生前固定。

唯一网络继续为 **6290 参数、宽 24、12 次共享消息传播的网格残差模型**。本轮没有发现需要换架构的证据。先做该模型一次训练，与 no-op、门控鲁棒二次 MLS 同条件比较；完成后复核，再决定唯一一次优化。保留测试在优化和版本选择完成后才打开。

## 需要在首轮解决的具体事项

1. **固定中心偏差。** 所有损坏中心都是创建宽选区时使用的中心。即使不传中心 ID，边界、径向特征及宽域几何仍带来位置规律。当前数据可检验“中心附近凹陷恢复”，不能据此宣称任意位置异常定位。下一轮在固定验证 patch 中增加预登记的偏心凹陷压力组，宽选区保持不动；先观察是否出现位置依赖，再决定一次优化，不预先换网络。
2. **任务的独立分母。** 未知上游合组继续保留。两个公开扫描对象形成新的几何来源组，但都是扫描重建物体，不能冒充真实人物修复验收，也不能等同训练大类问题全部覆盖。
3. **合理直接基线。** 批准门控鲁棒二次 MLS 作为唯一直接对照。固定观察求解、训练正常控制上一次校准门限、验证/测试不重新校准；离群噪声处理不自动等于连续凹陷恢复。旧整区双调和仅留历史，不当唯一弱对手。
4. **实际成本。** 当前每次观察重算法向/邻接特征仍扫描完整网格，这部分必须计入完整入口。静态准备可复用；暂不为了潜在性能另开模块，待训练和完整成本结果确定唯一优化。2 秒额外 p95 是首轮质量研究预算上限，不是性能收益，也不是产品延迟承诺。

没有发现当前标签错误、source ID 偷渡入特征、感受野完全接不到周边、或正常控制被排除监督的缺陷。标准化均值/方差、MLS 门限只能来自训练池；真实支持 mask 只能用于损失与评价。首轮继续合同中正常误改、尾部错误和来源分层，不只看平均恢复率。
