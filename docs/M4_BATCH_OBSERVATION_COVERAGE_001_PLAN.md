## 固定验收

- 覆盖：当前任务必要信息能在目录与选定观察两个逻辑响应内获得；所有实际补查都能映射到可提供、可派生、可省略或明确缺口，不能把第三次native暗藏进“插件内部免费工作”。
- 正确性：逐字段与独立原始捕获核对坐标、对象绑定、拓扑/世界单位及关系，不调用待测插件生成期望。重命名/打乱ID、已知刚体变换、添加同形干扰物各固定一个变体；检查变换后的事实正确，不要求旋转后仍保持原世界方向目标答案。
- 等价原生：构建同信息、同精度、同选择范围的合理原生批量投影，允许其同样缓存和合并读取；不能只跟原日志中冗余输出比。冻结比较字段后记录双方实际UTF-8字节、离线投影时间、峰值内存和需要的底层采集。已有原始模型总成本单列，不推算新token或节省费用。
- 推进条件：覆盖不丢失；两个逻辑响应可行；相比等价原生不通过多输出大几何包换调用数；有可复核的减少模型代码或数据传输的结构机会。若只是把原生脚本包一层，或仍需要第三观察，明确判定此设计收益不足。
- 只做一个候选，并完成至少一次基于账本的简化评审（能删的重复字段/遍历/层），保留前后测量；不反复调到赢，不另出更简单题。
