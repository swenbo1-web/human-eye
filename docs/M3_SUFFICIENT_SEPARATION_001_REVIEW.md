## 为什么这次可以通过

新路径先求实际表面最近距离，以返回的近点差形成唯一方向，再对全部引用顶点作精确支持检查。严格分离成立时，证明引用三角形并集及其顶点凸包分离，直接满足本题的空间关系需求。不要求先证明每个物体自身是合法闭壳。

独立检查确认三个实际证书的方向、有理坐标框架、全部引用顶点、支持极值及见证索引一致；没有漏掉退化面中被折叠的引用顶点。远处引用顶点、二进制浮点可表示/不可表示间隙、大平移、接触、包含、反向配对与工作停止均未发现错误放行。三个实际距离约为 3.000006、4.999987、12.000011 毫米；4 毫米判断为否/是/是，最近者唯一为 Peer_000，实际近点经独立三角形检查成立。

支持检查使用同一工作账本与原期限。证书未成立时才进入原分类；资源停止不会重开预算。包含控制走原分类并保持 penetrating，unsigned 表面距离未变成有效间隙。prepared trees 仅在同一对象及三角数组身份下复用；新事实 memo 与旧 closed 分离，来源/几何变化失效，未完成请求不缓存。

新集合明确采用 `task-query-set-v2` 和 `relation_fact`。旧 v1 请求仍因闭壳工作预算而 partial/unknown；mixed 请求即使空间 nearest 已完整，也不能把尚未完成的 closed 事实写成完整健康结论。未知候选仍使 nearest 不完整。这些旧失败保持，不由本批通过覆盖。

## 一次简化深审后的决定

保留现实现：核心收益来自删去本题不需要的自身闭壳扫描；支持扫描本身很小，再调计数器、树或缓存缺少足够收益依据。证明字段可能增加消费成本，但先按当前真实接口测一次，比先改格式再归因更清楚。

已确认一个消费接点：精简 `human_eye_spatial_relations` 仍硬编码旧 closed+surface，无法请求新空间事实；只有普通 `human_eye_scene_observe` 支持显式 opt-in。普通声明仍把旧事实作为主例，新事实提示较靠后。源码不能证明模型会选错，也不能证明它已会用；下一批应观察自然选择、直接采用及完整成本。

唯一下一批为 `M4_SPATIAL_FACT_CONSUMPTION_001_PLAN.md`：固定本产品，原生 N 与插件 P 各三个新 Pro 消费者，使用同一已验三对装配题；先匿名判质量，再解封成本。没有当前工程阻断。默认安装、Google、专家模型、Hook 与用户资产均不变。

派单前另经三项只读计划交叉核查：最近见证允许不同等距点，先验证完整精度再核文字舍入；usage 不重复累加流式快照，失败/未运行不改分母；旧 actor 的 1 MiB 保持每格累计语义，普通工具与无图片的硬编码同步适配。无阻断，不增加新的审批、预算校准或算法验收阶段。
