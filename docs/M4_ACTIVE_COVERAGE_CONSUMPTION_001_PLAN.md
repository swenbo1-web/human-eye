## 共同任务与规则

题面要求：发现本场景所有独立单面矩形面板；在给定六视角内，列出已有完整且可读观察证据的面板及对应实际图片引用，并列出仍未覆盖的面板和原因。以尽量少的工作获取足够证据，完成后给简明结论。未观察到不等于不存在或没有缺陷。

双方公开相同定义：目标为四个不同共面顶点、两个一致绕序三角形组成的非退化矩形独立网格；完整观察需前向、整体在视口内且无正面积遮挡；可读需至少16表面像素、4个owner变化且RGB距离至少24的边界像素。边界相切不算正面积遮挡。规则给定义，不给目标数量/ID、发现算法、正确视角或预期5/6结果。

图片证据必须本会话实际生成且可由公共入口交付/追溯。模型可以看图、计算或结合两者，不强制用原生视觉推理、不强制N六图、不要求最优两图。对固定视角池无法完整覆盖的目标可以正确说明该范围未知；不得把粗略几何可见直接当成实际像素达标。

主时间从该槽启动前到实际CLI/actor/已绑定stdio结束和结果回读发布后。完整顺序墙钟、准备时间和外围未测单列，不能仅报index函数时间。六槽均进入质量/消耗总账，不按答案正确与否筛掉慢样本。失败槽保留实际耗时/原预算，未运行不记零成本成功。
