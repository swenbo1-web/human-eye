## 不变的收益要求

视角F/R/L三臂共享当前VG的16候选、相机/窗口/剖切、渲染和输出语义，CF只重排。F是现有active规范顺序，不是零搜索射线的method=fixed。完整候选不能截断；全部实际ray计数，包括提特征的探测。采用臂每seed射线中位比<=0.75，固定臂成功例不得丢失，各族实际PNG成功率不下降。学习臂需真实监督更新及单独消融，不能拿检索过门冒充学习过门。

动作头预测同一个明确命令的真实delta。每seed米制MAE<=0.8×条件常量/有限局部几何两基线中更好者；两基线同享合法当前输入，禁止弱化几何基线。实际宿主执行、回读、全局BC重新查询生成标签，不能用预测或命令幅度冒充。平行盒零误差只作控制，不能伪造改善空间。
