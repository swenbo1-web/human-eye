# M3-A1：受信本机任务登记（实现前合同）

2026-11-01。排期仅见 PRODUCT_ROADMAP.md。本模块只登记、检查和撤销，不派发动作、不注册宿主运动目标、不调用setter；执行接续属于M3-A2。

入口供可信同进程嵌入方使用：`TrustedTaskEntry(config, fixed_owned_host, TrustedTaskAuthority)`，提交真实typed `ClearanceTaskSpec`，由既有外部批准回调返回typed `TaskApproval`。模型JSON、task/session标签、普通Codex消息和历史JSON不是批准。Python capability不是对同账户任意Python的沙箱；默认Codex尚未提供这一可信事件入口。本批不添加默认自动动作或新MCP工具。

复用OwnedGoalScheduler的原生双捕获、唯一支撑发现、独立初始检查和授权/父账本同锁提交。授权与目标仍写原connector账本，原16个授权/父目标容量、不驱逐历史、不新建并行账本。登记时冻结源build、配置指纹/原始配置字节、进程与时钟域、对象实例、原始三角形、capture/native摘要、事件/发行者/批准身份和原预算。

从本机入口接收调用时即开始原期限；捕获、发现、批准回调和提交都消耗这同一窗口。既有TaskAuthority默认调用语义不变，新增的受信起点只能取当前或过去，不能给未来起点、扩大预算或接受过期窗口。回调后再核对场景/配置/源，提交后再核对期限和来源，失败不交付可接续的内存登记。

同事件重复登记不改已提交起点/截止、预算、快照或父身份；语义或快照变化不能悄悄重绑。重启后可以只读查看记录，不能从JSON重建live capability。普通旧scheduler.run遇到已登记事件只返回复核，本模块不假装执行接续已经完成。

撤销先使本进程live登记失效，再持久冻结父目标与停止授权；撤销不等于回滚或清理未知。被撤销、到期、外部变化或保存回执不明的记录继续阻断，需要明确受信复核，不自动释放或换ID重开。提交后丢回执不能重发；提交前失败尚未产生可执行登记，不能把它称为持久接受。保持原原子保存级别，不声称断电持久化。

验收包括：错误issuer/host/JSON、拒绝批准、spec/预算/快照/配置/源变化、未来和过期起点、重复事件、原截止不续期、重启无live能力、撤销/重复撤销、保存前后异常、后回调外部变化、零setter。单测使用显式隔离的元数据与宿主替身，不能替代物理证据。真实验证须通过新隔离安装、固定owned后台worker和自建静态盒体，比较捕获前后原始几何/姿态、无运动目标注册及无setter路径；共享GUI/正式22fb不变。原A2/成本/全量成员与模型门保持未过。
