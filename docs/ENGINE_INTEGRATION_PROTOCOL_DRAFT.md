# 统一生产引擎接线验收草案

本阶段提交冻结候选。生产入口、共享捕获接缝和支持域见 [API 草案](ENGINE_INTEGRATION_API_DRAFT.md)。验收对象 I 是待实现的统一生产会话，B 是用同一已验收组件和同一部署参数直接手工编排的薄基线。V+A、BC、VG、AO 和 TD 沿用各自已验收实现。S 维持精确 TD 展示。

## 预先固定的单场景闭环

每例用一份 Blender scene、一份 view layer、同一移动对象和参考对象、显式遮挡网格清单，以及由该场景实采并拥有的 moving 世界米制参考。参考捕获单列冷成本，之后在正式前观察前复位到规定状态。主测都使用同一场景的同一对象 pair 完成以下次序。

1. 前观察从当前依赖图采集每个必要对象，原生 BC 求全局见证，TD 相对固定参考生成完整原值及精确 Top-K，VG 真实出图，返回前 AO bytes 和内存 PNG。
2. 调用者给出固定命令。生产路径仅预测该命令，按定义应用真实 Blender 写入，刷新两目标和受影响上下文，BC 重新求实际全局距离。用此回读直接生成后 TD、VG、联合 AO 及实测 Outcome。禁止为发布后观察另调用 `observe`。前后观察的 Blender frame 可相同，观察 ID 独立。
3. 对 L/R，实际消费者独立评分该次实际前、后 PNG，并在结果返回后提交与观察、附件及呈现方向绑定的反馈。L 的 A 从实际 Outcome 更新一次。基线与候选分别用自己的会话状态和实际输出。反馈后再发一个有新 ID 的下一查询，观察同一宿主场景真实状态并为预定后续命令预测，主序列不执行第二条命令。下一查询应可见更新的权重/库。

主案例的默认序列为 **before → predict → execute/after → feedback → next observe/predict**。独立预检可额外执行固定后续命令确认状态和标签。前、后、下一查询的确切帧、mode、命令及 ID 由夹具和运行清单事前给定。主场景的三次观察均使用该例已分配的 mode，正间隙 SECTION 保持正间隙。零距控制使用 NATURAL，另测请求 SECTION 时显式无图的策略，已达目标和空面无动作计划。

## 场景、分层和公开答案

主清单以 [夹具代码](../verification/integration_fixtures.py) 的族优先顺序固定，共 24 例。六个场景族为开阔尖端、单挡板、交错双翼、开槽鼓、内外双鼓和随动屏。每族四个固定变体，包含 NATURAL 正向平移、SECTION 正向相对 key、SECTION 反向平移和 NATURAL 反向相对 key。尺度为 .012/.035/.080/.150 m，初始 gap/尺度为 .004/.009/.015/.025，RNA 米/BU 规格为 1/.001/.001/1。平移用指定世界向量。shape 变体使用静态父级非均匀尺度、子级旋转及非均匀尺度形成一般 evaluated 世界线性矩阵。随动屏在同一真实动作后变化，参加前、后同次上下文采集。夹具的网格坐标、拓扑、父矩阵、作用幅度、Goal 和解析间隙均由代码固定。全部主样本进入报告，遮挡或成像困难不作为删样理由。

固定便携及原生控制含：有限接触零距、空参考、已达目标、参考随动且显式 `NONE`、真实非 Basis 相对 key、物理同尺度的单位重编码、三角行重排及新代。阶段二另补明确参考替换、零距打开间隙、零距 SECTION 无图、相同 frame 不同 ID、错误绑定及重复反馈拒绝、部署格式等价、两会话交错及释放后重开。拓扑重排测试用新的会话、代号和匹配参考，同位置的原始三角行号按新索引重新核对。早期功能探针只取主序号 0/1/20 和固定控制，不计入正式样本。

公开消费者只读 schema、AO bytes、PNG 附件和本题命令/Goal。应独立恢复目标身份、帧/代、真实 witness 原面及米制坐标、TD 范围和原始 Top-K、前后控制回读、预测和实测 delta、图像/相机/剖切及关联关系。PNG 通过现有公开读法及独立 RGBA/相机/几何证据校验。没有图片时 `image=null` 与公开状态一致。评估消费者可以有审计几何 oracle，实际消费入口只靠公开结果和附件。程序走过测试私有对象不代替生产入口可达。独立后台 Blender 示例必须以显式场景、对象、参考、部署和命令跑完一条实际链，再由公开消费者读取返回。

## B 的公平性和 I 的等价门

B 源码为 [手工基线](../verification/integration_reference.py)。使用同一 `BlenderControl` 唯一 bridge/index，目标捕获和实际写入执行沿原实现，验证侧仅通过薄捕获覆盖把非目标网格加入同一 graph。在目标已经真实回读后直接发布，不再 observe。B/I 具有相同目标/上下文顺序、图形选项、完整 TD/Top-K、当前更改标志、图像、AO schema、动作和学习责任。B 允许预建同样可缓存的静态 relative basis 及参考，复用已有前 PNG，只保存联合发布需要的一份前 moving 位置。基线不加无用重复 capture、查询、压缩、编码、模型或跨进程传输。B 必须先通过独立控制与公开消费。

阶段二可让 B 和 I 共用冻结后的最小目标 capture seam，也可保持 B 的等价薄覆盖。若 I 支持 B 预检尚未覆盖的声明掩码、图像关闭或票据检查，正式 B 调用时使用等价输入、结果和操作语义。以主清单相同能力作比较，准备成本及临时快照均对等，不以预检内部返回值冒充 I 的公开 API。F/G、R/G 与部署组合 L 分别报告质量。F 是 active 固定访问次序，G 是当前见证三角对的真实有限动作几何预测。性能主对照两侧都用部署组合 L，视角用 L，显式平移用 G，shape key 用学习 A；按实际责任更新对应经验。

I/B 的必须相等项目如下。

- 每个前观察、动作后真实 readback、下一观察的目标与上下文 RB 采集次数和图状态。对预定变更轨迹，一个目标每次采集至多一次，无第二份目标 bridge/index。主闭环的 BC 查询分别为前观察、动作实际回读、下一次明确观察各一次。VG 为相机取 graph 独立计数，不能借它重复采集网格。
- 公开对象 ID/顺序、拓扑代、参考/采样/位置帧、见证原三角行、世界米制事实、原始 TD/Top-K、明确命令、实际前后 q 或世界平移、实测与预测 delta 及 Goal 结果。原始参考及前 AO bytes 在下一状态后仍正确。真值使用独立 RNA 矩阵/网格读取及解析/独立几何计算。解析夹具以生成器的 `host_tolerance_m=64 eps32×L` 核对世界米尺度。完全相同评估网格的 BC 数值使用既有 `tau(P)`，delta 用前后预算之和。TD 沿既有 `rtol=atol=1e-11` 回归口径。公开事实由同一算术形成时比较精确数值与字节，数值预算只用于独立真值对照。
- 规范候选访问次序、逐调用 ray、选中方向、实际渲染绑定与剖切。相同硬件与场景配置要求 PNG 逐字节一致。VG 资源内部自动相机名称可在私有 metadata 中不同，该字段不属于公开 AO。若目标平台已确认仅 PNG 无损编码字节不同，主干须在正式测量前固定例外和独立 RGBA 比较；预设默认仍是字节一致。B 成功例不丢失，所有主案例均报告实际像素质量。遮挡、零距和空面有独立 oracle 控制。
- 导入既有模型的数据、初始训练统计/库、每次推理输入、实际更新前后权重、写入计数、环槽、方向 mask 与 A 残差。R 保持未观测方向为 unknown，实际方向、ray 计数和动作标签不得从预测伪造。冷加载模型的参数由离线导出器逐字段核对。两个实例同源启动时初始相等，交错学习后各自独立。释放后无旧索引、相机、GPU 和会话引用残留。

## 成本与统计建议

同一机器上依次启动三个独立 Blender 进程。每进程显式加载三个原冻结部署中的一个，使用相同软件、设备、1 个 Blender 线程与 1 个 BLAS/OMP 线程。每例 5 次 B/I 成对预热，再做 31 次 B/I 配对。臂次序按 `(process_index + case_ordinal + repeat_index) % 2` 轮换。测试完整实际场景状态，重复间在计时外复位宿主与试验模型状态。实际采集和依赖图求值在区间内。模型复位可在验证侧对固定初始 240 行快照恢复活动游标与权重，禁止把复位或 shadow API 放进生产。重复测量不成为新场景。

每次连续区间记录以下边界，所有必要结果物化和真实 I/O 操作计入。

| 边界 | 包含 |
| --- | --- |
| `t0→t1` 前观察 | 当前宿主求值及 RB/BC/TD、CF、VG GPU 同步读回和 PNG、AO bytes、附件与 V 票据 |
| `t1→t2` 动作 | 当前控制 q/有限基读取和预测、必要 before 所有权复制、真实宿主写入/求值/回读、后 TD/VG/PNG、联合 AO 和动作票据 |
| `t2→t3` 反馈 | 真实结果所对应的两个可用 V 票据与 A 更新，参数/库写入及必要复制 |
| `t3→t4` 下一查询 | 下一次原生公开观察和明确后续命令预测，使用更新状态 |
| `t0→t4` 完整服务 | 上述四段的同一次连续区间，不能用多个统计量相加 |

正式服务计时通过已经独立评分、且绑定相同 PNG bytes/观察/方向的真实反馈做确定性复放。数据读取、外部等待和身份核对放在区间外，实际反馈入口和更新在区间内。真实消费者闭环另从实际前观察开始到消费者收到可用结果、完成真实反馈和下一查询结束，报告含外部评分/等待的全段及分项。影子状态与真实连续更新两种证据分别保留。现有 GPU 读回、画面压缩和 AO 物化属于两者的实际成本，审计图读回、独立 oracle 和归档写盘另列。

每例每臂取 31 次中位，对每进程 24 个主案例中位求 `linear` p95，I/B 的前观察、动作、反馈、下一查询和完整服务逐进程各 **≤1.05**。三进程 raw、重复次序、逐例差、绝对 p95、p95 差和配对差 p95 全留存，报告 pooled 和各族。内存分开列冷启动与加载、参考建立/替换、热态 NumPy 常驻及峰值、进程 RSS 和 GPU 资源。建议 I 相对 B 的新增热态托管常驻 ≤256 KiB，额外峰值 ≤1 MiB，每例前事实允许一个 moving 世界米制快照，两个臂均计费。额外进程 RSS 和 GPU 分别建议上限 8 MiB，测量方法及设备读数可得性在冻结前由主干确定。不可得项目记待验证。拓扑代重建和异常后资源释放单列。

## 既有 CF 质量和成本回归

用现有三个封存部署与原始 V/A 清单做重放，选模及标签来源仍使用已归档数据。V 重放原 60 场景×3 seed 的原 F/R/L 方向、原生计数及真实 PNG。A 重放原 60 场景×3 seed 的合法当前命令、C/G 对照及实际 Outcome。原 L 射线比、逐例 PNG 保留、逐族成功率及 A 米制 MAE 继续适用。R 首 seed 既有失败应如实复现。单场景主试验中的新遮挡/动作族不替代该回归，也不算新未见收益证据。

按原 CF 计时边界另测同一进程内的 V 任务接独立 A 任务，仍按各 seed V、A 和原 total 的 **≤1.10** 判定。动作成本参考仍为冻结 G。保留原配对原样本及机制，本次同场景 1.05 门是另外的同功能编排成本对照。不得把旧两个场景的 58 ms 和当前同一场景的结果当成可直接比较的提速。控制器、生产入口和普通数组包导入按实际修改范围进行接口回归，依赖模块旧优化无需重做。

## 冻结、异常与交付

主干冻结前核对夹具及源码摘要、实际部署快照、参考捕获策略、目标/上下文采集掩码、后观察所有权、非适用 SECTION 处理、旧 CF 回归成本和内存门。正式每轮记录命令、代码快照、逐输入身份、设备/线程、原始公开结果和时序。失败保留当时源与原数据。任何会影响冻结输入、范围、统计或计量的补测，先报告精确影响，由主干事前固定再恢复。不因真实退化替换样本或重开已验收优化。第一阶段不产生正式性能结论。

## 已取得的预检证据

2 项便携检查及第二轮固定后台探针通过程序断言。实际执行开阔尖端 NATURAL 平移、带父变换和 .001 m/BU 的 SECTION shape、随动屏平移及非 Basis 相对 key 四条单场景闭环。零距、空面和已达目标三例按计划无动作。真实原生捕获按阶段计数，前观察、执行和下一查询分别每对象一次，预测和反馈阶段零次。公开消费者另完整重放 15 个 AO 包和 14 个独立 PNG，核对同帧前后绑定及前包不变。

固定八次 V 反馈中七次通过完整独立评分。随动屏的后图实际像素、网格及 ray 对账通过，但所选方向与局部相机方向的一个分量差约 `4.24e-6`，超出现有方向检查容差。该次保留为不合格反馈，写入 false 标签。主干需在冻结前审定该已知 B 现象及正式质量口径，建议保留原严格评分和原样本，逐例检查 I 相对 B 的等价及成功保留。此现象不触发阶段一改动 VG 或更改样本。

第一次后台启动在首例联合 AO 编码遇到夹具传入 NumPy float32 容差的序列化错误。原日志和源码归档，修改仅为同数值的 Python float，第二次对同样例运行。预检没有生产会话、部署格式加载器、公开示例或正式性能结果，剩余控制和新旧 CF 回归待阶段二。
