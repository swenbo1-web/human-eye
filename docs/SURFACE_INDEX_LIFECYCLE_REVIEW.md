## 已证明的持有机制

冻结构造函数的局部递归split捕获 `(centers, self, split, starts)`。存在 **函数 → closure tuple → split cell → 同一函数** 的循环，并通过self cell持有SurfaceIndex。索引的packed和bounds等数组因此即使外部所有者已释放，也可能一直存活到循环GC。

独立CPU探针使用weakref与精确referrer检查，避免把探针自己的强引用当成证据：历史版1/64面索引、order/topology/packed、split和centers在外部owner删除后仍活，显式full GC后全部消失；0面不建立该闭包。仅解绑候选同样场景立即释放。根端另一个回归测试在原源码上对1/4/5/33/512面保留了5个真实失败，候选后全部通过。

GC禁用/显式collect只用于独立CPU测试证明生命周期，不进入生产、原生验收或运行策略。此机制与诊断的异步GC及离根数组相容，但没有原33点的对象级快照，不能倒推它独占全部旧差异。
