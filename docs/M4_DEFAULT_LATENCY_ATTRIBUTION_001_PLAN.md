## 固定矩阵

只执行四个顺序会话B、C、C、B，不并发抢占Blender QA资源。每会话：

1. 一个cold OFF业务请求（profiler OFF），单列冷数据。
2. 一个相同业务请求预热（profiler OFF），单列不混入暖样本。
3. 十组相同OFF业务请求配对，每组两次，仅QA profiler ON/OFF不同。每会话5组ON→OFF，5组OFF→ON，交替排列。会话1/2从ON→OFF开始，会话3/4从OFF→ON开始，使B和C各覆盖两种起始序列。
4. 正常关闭并保留真实退出与完整成本。

计划为每会话22个关系调用，合计88个；关闭与启动额外RPC如实计数，不算作免费。若现有入口必需额外初始化调用，须在测量前写定且四会话一致。没有原生补读、vertices/full、变更、刚体变换、图像或模型调用。

四个测量会话没有追加样本。启动前可恢复准备错误自行修正；测量开始后若业务失败、状态改变、身份不符、开关不符或资源冲突导致无法解释，保留已发生记录并停止这一矩阵，不替换坏会话重新跑满。原期限内清理自己拥有的进程。不得触碰共享GUI、默认配置、用户原资产或竞争分支。
