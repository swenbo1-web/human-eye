# 旧输入与本轮交付合同的差异

旧 QUAL002 的7份 shared 原件完整保留在 `input/original/`；旧私有 oracle、几何和评分实现原件只在 `scoring/source/`。`INPUT_BINDING.json` 逐文件记录原摘要并绑定最终共同文本。未修改旧目录任何文件。

| 旧条款 | 本轮处理 | 空间语义是否保留 |
|---|---|---|
| 四个同形通孔框架，三条公开位置条件取交集 | `input/TASK.txt` 保留严格 Z/Y 条件、闭0.70m XY半径及中心定义 | 保留；没有改成最近框架或最近导轨 |
| 识别近右隔片、左定位块、穿孔探杆 | 保留三个自然角色并要求给编号 | 保留；不向消费者注入正确编号 |
| 内部重叠、0.25mm容差内、分离、unknown | 保留四类含义与阈值 | 保留；接触容差不等于精确接触 |
| 每对局部证据，可用点/面/量测/新视图 | 保留可核验几何点、特征、量测和材料/开口依据；本轮没有新图 | 几何证据任务保留，取景范围明确缩窄 |
| 强制 ANSWER_SCHEMA JSON、固定字段、数组项、ID正则和长度限制 | 消费者不接收或遵循旧 schema；接受自然语义和等价单位 | 移除交付格式硬门槛；目标与三对仍分别评分 |
| 手填 scene/catalog/image/camera SHA 和字段引用 | 由执行器绑定文件与实际交付，答案无需手抄 | 来源真实性仍检查，但不再测拼写或复制摘要 |
| witness_points/source_features/image_refs 必备字段及固定索引列表 | 依据按实质检查，不要求字段名、面索引列表或指定表达 | 不降低依据充分性；空泛工具断言仍不够 |
| 旧 DIRECTIONS 允许临时相机、渲染及补图后恢复 | 原件保留，正式正文采用本轮 DIRECTIONS：初图1张、新图0，不改相机设置 | 这是预先声明的同N/P阶段限制，不冒充旧合同原字节 |
| 历史不同 lane 的 native 使用限制、15分钟提案等 | 不作为本轮执行权限；两组共用合理 native 能力，P另有固定精简空间工具 | 沿根的新6消费者合同，非重跑旧AB001 |
| 旧M1公共规则‘图片0’ | 不沿用；本轮新 SESSION_RULES 明确共同初图1与工具文字预算分开，新增图片0 | 无额外0.001mm答案精度要求或工具偏好 |

最终 `PROMPT.txt` 的组成是新共同预算、新任务、新方向、原完整目录及原相机数据；目录/相机附录原字节保留。图像通过运行器单独真实交付，正文路径或执行器“准备好”不是模型已收到图像的证据。

旧 schema、旧目标选择失败、旧AB001负收益及旧裁判输出不被改写。QUAL001证书内的旧 nearest-rail target_uniqueness 不是本轮目标定义；目标必须使用 QUAL002 的三个公开条件，关系几何则可复用同一未改资产的独立证书。本批与N/P另一组比较，不能直接宣称旧负收益已经翻转。

新正文只读且未附任何工具名、代码解法、正确目标/邻件标签、私有真值、评分表或另一组结果。目录中本来就有全部中性编号；这不等于预选答案。
