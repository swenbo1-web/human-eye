# 本批实际能力与归因边界

两组获得同一张原有初图、完整中性目录、相机元数据、世界方向和自然语言任务。初图为共同输入，不是插件新增采集结果。新增图像构造和工具图像交付均为零；准备完成不代表未来消费者已经收到或理解初图。

| 环节 | N | P | 本批可据以归因的范围 |
| --- | --- | --- | --- |
| 观察初始图片 | CLI 初始图片输入 | 完全相同 | 模型原生图像输入；非 Human Eye 主动取景收益 |
| 读取中性目录 | 共同提示中的完整原目录 | 完全相同 | 目录没有目标/角色标签；顶点数、颜色等公开信息可合法使用 |
| 对应图片外观与对象编号 | 模型理解、必要的原生读取 | 同一能力 | 未新增自动目标发现或像素到对象映射算法 |
| 三位置条件、框架和邻件发现 | 原生只读 Python 与模型推断 | 同一原生能力，插件工具还需显式 selector | 若位置或编号来自原生，必须归因原生；不能称插件完成视觉发现 |
| 读取表面、变换和计算 | 原有 execute_blender_code | 完全相同 | 支持有依据的解析快捷解法，不强制通用逐面算法或禁止合理补查 |
| 指定目标与至多三个候选的表面/闭体事实 | 原生计算 | 另有固定 human_eye_spatial_relations | 原捕获、源检查及未知语义；是否被选择及直接使用留待消费者记录 |
| 全场最近三角表面 | 原生计算 | 目录包含固定 human_eye_surface_nearest，但本资产来源域拒绝 | 原资产含四边形/多边形，此工具现要求原始三角面；没有在本任务证明新增见证的消费者收益 |
| 从测量转为 0.25mm 分类 | 模型据实际依据解释 | 完全相同 | 表面零距离本身不能证明实体重叠；unknown 不能充当完整答案 |
| 新增局部图片、扫视、取景 | 不提供 | 不提供 | 不评价尚未开放的采集算法、场景暂留或局部图收益 |
| 最终自然语言解释 | 模型 | 模型 | 依据与结论的对应由共同语义评分核查；不考手抄摘要和 JSON 拼写 |

P 的产品只有已安装候选的两个精简工具，N 不启动无用插件进程。两组共同原生工具的 schema、后端、32 次工具尝试、128 次实际 RPC、30 秒单工具、1MiB 工具响应及 256KiB 每次代码限制保持一致。1MiB 由 owner 的完整序列化 MCP 响应计数，包含 JSON 封装，并非只计 content 正文。初图 1,185,069 字节单独计量，不塞进工具响应额度，也不套用旧 helper 对新构造图片的限制。

原生 Python 执行沿用原独占背景 Blender helper。终态几何/文件摘要、已有 render hooks 和工作目录 PNG 事件提供可观察证据；这不是任意 Python 的安全沙盒，不承诺发现所有被恢复的瞬态变更或目录外行为。若观察到本轮禁止的新增渲染/图片，按共同预算违例保留样本并停止，不从总体中剔除。原 GUI 和原场景文件不参与写入。

正式结果必须分别记录目标发现、角色、关系、局部依据、unknown 与错误。原生读取目录/位置、插件事实、必要的原生补充和重复完整计算分别标注；新增 nearest 证据只有在自然请求并实际用于任务时才计消费者收益。当前能力表不构成这些收益已发生的证据。
