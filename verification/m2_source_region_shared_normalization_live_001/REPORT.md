# M2 同捕获跨选区复用真实 Blender 验收

两个隔离 Blender 槽完成 8 次生产 MCP 观测并正常退出。冻结评分 **1/2 槽通过，整对未通过**。A 在业务和关闭成功后被计时断言拒绝，B 正式通过。对同一批原件的只读补充核验确认，两臂几何、量测和像素一致，双选区归一化 **2→1**。原始失败和补充结果分别封存。[固定方案](PLAN.md) · [原判与逐调用分段](RESULT.json)

## 真实现场结果

- 使用同一 Blender 二进制、两个字节相同的 Yanyite 只读副本与现有 A `31e9b46a`、B `ee385e98` 隔离安装。两臂先后运行上区无图、下区无图、上区首次有图和同请求热读。五项工具目录相同，按同一入口预飞到 Blender 启动边界并核对生产 MCP 握手和退出。
- 两臂的实际宿主几何资源都为 **2、0、0、0**。第一条 TCP 回复 3,318,955 B，后续每条 3,123 B。A 归一计数为 1、1、0、0，B 为 1、0、0、0。两次独立选区准备各有一次，B 的下区仍检查完整场景，耗时 19.492 ms。
- 两区 311／184 与 331／192 个求值三角／关联点，分别距隐藏 Cube 整件 **0.370117193892 m** 与 **0.435546882075 m**，均沿世界 +Z。保留同代有序来源和有效最近点对。各槽初末原生与求值数组、姿态、显示、相机和文件指纹均核过。
- 各槽冷图实构造 1 张，热读复用原帧。闭槽后可读各自交付的同槽原 PNG，16,975 B，SHA-256 `1c2ed6d23fdd8c92bedd7d94a19ebe86cebdebc1ef9d5e9968191131f9d63837`，也与原 QP 原图完全一致。上区有 49,480 个选区像素和 116 个有样本源三角。已有简报直接交付文件路径，额外读图 0 次。

## 冻结失败与补充核验

A 第 1 条原始宿主记录在服务端 `accept` 返回后开始计时，比客户端 `_connect` 返回早 **0.2019 ms**。宿主区间完整落在实际 TCP 交换内，并在外层 JSON 解析开始前 **18.4343 ms** 结束。冻结断言要求宿主区间完整落在客户端连接返回后的阶段，拒绝该样本。补充账本按区间交集计算连接后耗时，保留完整服务与线包原时钟。

独立复核还复现冻结对照器的跨槽 NPZ 整包相等断言失败。A、B 两个真实 Blender 的 `ViewLayer` 运行实例不同。14 项像素及归属数组和其他字段相同，只有 `display_identity` 与 `image_scope_identity` 两项不同，分别与各槽真实 TCP 捕获和实际生产帧匹配。和旧 QP 比较也只有这两个字段不同。原始 NPZ 摘要分别为 `4654e05a6125ef99bc55324281bb08f04cfc0a95e0b11c50acd5fc80144c8cb7` 和 `128d2ef6cfb31057edf7737f861bedb4237afa124065cde21a7d97f199a388e5`。[原件补充核验](diagnostic.py)

## 分母与封存

正式 2 个 Blender 启动、8 次观测、2 次实构图，0 模型、替补、重建和新增安装。预飞两轮共四个真实 MCP 握手，Blender 启动为零，最终冻结只绑定后一轮。原 Yanyite 模型容量失败原样保留。冻结 SHA-256 `c0afb920d3f9120fa94e0fdf1ea00dba3d1cd8bfc89f5dd56c0720602a0be3da`，345 项输入。私有现场原件只在本机归档，411 件逐件核验，31,338,553 B，SHA-256 `534a0d0a584a0c29544d11acac1475dfa30adb952f8bb0215944c92253506960`。公开分支保留冻结、评分代码和摘要。
