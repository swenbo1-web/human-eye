# 最近表面获胜连通片的现场对照

**M4-NEAREST-SURFACE-COMPONENT-REF-001 · READY**

候选两题均通过质量验收。近片复测从 2 次降到 0 次，业务调用从 8 次降到 6 次。两题仍各为远片量测读取一次目标网格，所以同时省掉网格枚举与近片复测的正式结果为 **0/2**。两份候选原答均报告了正确连通片，但也读取过完整目标网格，无法把原答所用整片范围唯一归因给新增字段。

## 工程验收

## 停止与封存

正式 4 个 Blender 与 4 个既有 Pro 消费者，4 次实绘，零替补。Blender 和 CLI 四槽均退出 0，场景初末一致。Thin 四槽均观察到退出码 1，缺自身退出记录。双向 EOF、实际末包确认、两端原线摘要和零在途均满足冻结关闭合同。

固定了一个隔离候选、一次构建安装和 890 项私有原件，完整数据及原答留本机。产品候选推送独立分支。本目录公开方法与统计，`score_public.py` 和 `score_controls_public.py` 去掉本机路径，原执行脚本按冻结摘要留档。
