# COMPLEX-005：真实旧安装版重测

## 结论

18 个全新会话已完成，未补跑、替换或混用004结果。管理员先封存原样匿名答案及实际工具证据的评分，再允许揭盲。质量通过 **17/18**：N原生6/6、H真实旧安装6/6、C当前安装5/6。

当前版在这个固定装配题上提供了完整几何依据，三次均答对，端到端中位耗时相对旧安装可用条件减少 **33.93%**，相对原生减少 **41.97%**。全场最近表面题的九个会话最终全部由模型自写原生代码求解；当前版组出现一份错误答案，不能把它较短的耗时算作质量保持的引擎收益。

本批验证了一个有限装配任务的实际价值，尚不足以宣称当前版在全部3D场景中优于旧安装或原生模型。

## 判定边界

装配题是4网格、72顶点、132三角形；全场题是48个低面数对象。每题每组仅n=3，保留原值、均值与中位数，不报告p95或统计显著性，不外推大型资产、复杂角色、自动Hook或全部3D能力。

这次观察支持继续改善全场查询的有效调用和契约可理解性。当前实际失败仍作为产品组合任务的失败保留；全场引擎求解价值尚需真正被消费才能验证。本批比较至此收口。
