# 路由任务收益批静态复核

固定产品6d4f的141份源码在checkout与Dconsume安装中逐项匹配。bridge与bootstrap逐字节复用已验版本，N/P四项共同工具定义和顺序一致，P只追加原ACTIVE/v4与公开JSON复用。原生render_views保持fresh和全局源三角形ID。

新native只增加Droute研究根，并保留当前product_root内原三个common文件的只读白名单。其它产品源、产品写入、旧实验结果及私有capture/binding仍受原限制。

两组共用相同run_slot函数。每槽时钟始于目录、来源和连接检查前，结束于原route收尾及postcheck和SLOT_RESULT写入/fsync/关闭后。SLOT_TIMING自身及批汇总明确在外层，整体父周期另计。没有将总周期除六或给两组选择不同阶段。

实际function/code引用与源字节前后核验保持。group闭包只选对应前缀，后缀、CLI设置及审批工具集合保持原来源。原450秒、12业务工具、单槽6图、正式36图与零准备光栅上限固定。

独立静审指出的明确拒绝EXIT分支已补入batch blocker。缺失EXIT、真实held exit已证的情况保持独立unknown记录；普通任务错误保留并继续其它独立槽。初始来源/Git检查失败的六分母与actual0也进入finally发布。

唯一获授权的N无图读取首轮通过，执行geometry_safety导入、只读1字节与42。Owner.close、子进程exit0、wait及handle关闭均留原件。未启动CLI、模型、observe或raster，没有第二probe或旧fake矩阵。

审查者是夹具作者，本次代码、字节、路径与接线核验不能替代正式六槽质量、实际采用和完整成本结果。当前formal目录和启动marker均未使用，准备仅留下空raster ledger。
