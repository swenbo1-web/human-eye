# 独立正式评分

每组评分七项。实际完成答复必须与 CLI 最终事件一致，每项以原句和当前槽的独立来源核验。若出现明确而未纠正的额外错误，整体质量判为未通过并保留单项分数。

1. 完整列出三片满足任务条件的对象，无多报或重复。
2. 两片可完整取证的区域给出能唯一复核的当前求值源三角号及世界中心。中心每轴误差不超过 5 µm。
3. 第一片交付可独立证实的当前完整原 PNG。
4. 第二片交付可独立证实的当前完整原 PNG。
5. 两片分别给面积与定向单位法向的世界 Z 分量，正确给出面积差、较大片以及更朝向 +Z 的片。用独立精确几何核实，面积、面积差和法向分量的绝对误差上限均为 0.0000005。
6. 第三片只说明固定六向内缺少完整见证，避免把正面积遮挡或当前取证限制扩张为普遍、全部像素不可见。
7. 两份不同原图须在未经编辑的最终答复中以可打开的 Markdown 链接或本机 Markdown 图给出。闭槽按两地址独立复读其实际收到的同一字节，文件与对应区域、方向、帧、同次 scope 和原公开 PNG 一致。只写引用号、裸路径或截图可记录，但不足以完成本项。其他附件形态须有实际可打开地址或等价宿主凭证。

旧 read_images 的已交付路径与新首包路径用同一有效性要求。允许普通工具或任何符合冻结定义的合法视角。相同视角名称仍需核对来源。构图和所附 PNG 分别计数。首包路径采用及是否收到后续同图路径单列。
