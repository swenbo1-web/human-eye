# 导轨端面任务评分

六格顺序固定为 A1、B1、B2、A2、A3、B3。每格按对象内当前求值源三角的完整集合，对照独立真值逐一核四个端面。两个对象各有一对 +X／−X 端面，原答须能辨认配对关系。世界中心以米计，每坐标绝对误差至多 0.000001 m。单位有向法向对同一公差，明确的 +X／−X 按对应单位向量录入。允许零基含端点范围、零基求值三角清单和当前槽可唯一解析到同一源集合的 ROI 引用。

每个可检修端需要一个具名方向和可回查的同槽原图引用。按原 MCP 块和 CLI 回执绑定 PNG，核对当前 terminal 对象实例、面序、512×512 PNG 与 NPZ 原数组、前向、整个端面在视锥内及独立无正面积遮挡。表面归属至少 16 个像素，满足 RGB 欧氏差值至少 24 的四邻域边界像素至少 4 个。全场或局部来源均可。每个完全受阻端要求明确唯一前向方向，并给一个独立证明有正面积重叠的当前对象与对象内零基求值三角。多个来源都成立时接受任意一个。将受阻描述成所有像素不可见，或者给错对象或三角号，证据项失败。其他 unknown 记录原答原因与缺项。

每个真实答案按 UTF-8 原件哈希绑定人工摘录。每个摘录由原答的逐字引用支持。`rows` 记录对象名、源表达、`center_world_m`、`unit_normal`、`quote` 和 `outcome`。缺失数据保留缺项或 unknown。`outcome.kind` 为 `witness`、`geometric_occlusion` 或缺证时的实际判断，前两种均有 `direction` 和 `quote`。见证记录实际 `ref` 和原答所报像素计数。遮挡记录 `blocker_object_name` 和 `source_triangle_index`。`pairs` 记录 `object_name` 和足以支持配对的 `quote`，同一对象分组下的两个相反端面可作证。`extra_assertions` 逐项记录冲突事实的 `issue` 与 `quote`。

只有四个端面、两对归属、图像及遮挡证据全对，且没有多报、重复、额外不支持断言、生命周期失败和场景变化，才计该格质量完整。单列首调是否遵循冻结推荐，区域事实数及图像采用。B 首包同原件包含两个精确可核的遮挡三角，且原答确实使用二者，才计候选证据采用。替代遮挡三角可使质量通过，另行记录其来源。答复复述首包事实而又做补查时，采用和追加分别计，不因采用而减少成本分子。

正式门限使用两臂各 3/3 完整、B 各格使用候选证据、至少两对少做为定位遮挡而追加的读取或求证、至少两对完整任务更快且配对中位降幅至少 10%、三槽累计 CLI 原始输入加输出 token 不增加。按冻结分母分别列完成、失败与未运行。缺少供应商请求原件、内部时钟和实际费用时标记未测。
