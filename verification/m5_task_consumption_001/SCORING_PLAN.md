# M5 任务消费的冻结质量规则

共同题面和公共输出约定位于 inputs。两组使用相同字节。私有几何答案仅进入 admin。源网格、设备矩阵和本槽实际公开工具结果属于正常任务输入。正确区域数量、完整源面集合、位置、距离及见证答案均保持管理员私有。

## 独立真值

观察真值复用已接受 M4 消费批的精确源几何推导，并逐字节绑定原 oracle 与原 TRUTH。新 oracle 重新执行原纯几何推导并核原结果一致。量测真值复用 M5 工程批独立 X 间隔下界、全部目标源面与可实现最近点证明。没有生产距离内核或新光栅参与真值生成。

逐槽先验证冻结产品身份、实际宿主来源、真实世界点、原始源面顺序、对象实例和当前代，再处理公开结果、图片及数值。图片必须来自本槽同一生产者。RGB、depth、对象 owner、原始局部 source-face 与 patch-owner 身份链逐项核对。实际像素由独立已有算法计算。未构造的图像保持未运行。

## 完整答案

全部六槽按 A1、B1、B2、A2、A3、B3 保留。失败及未运行仍占分母。逐区域核完整身份集合、源面或唯一几何描述、中心、范围、绕序朝向的单位法向、有限池几何完整性、实际完整可读图片、像素计数及未知解释。沿原16表面像素、4对比边界像素、RGB欧氏距离24的可读规则。

量测核固定两对象的 A→B 顺序、whole_objects、米制距离、当前源三角表面的合法最近点和单位方向。合法等距最近点可以不同。生产者数值继续按原工程合同的正确 binary64 值核实。消费者十进制呈现沿1e-9米绝对距离、源面包含和相对位移发布容差，残差单独报告。方向和单位长度沿2e-14双精度归一化误差。该数值规则只作用于本固定输入域。

消费者必须说明观察目标与量测对象的当前来源对应。A可引用其自身观察结果与普通 task 结果的真实对象和来源。B新增父 binding 另作产品接口检查。共同输出中的父 hash 为可选字段。可选源面集合、数量、实例或有序几何 hash 一经断言就逐项核验。

整个最终答案及未撤回额外断言均须审查，包括 notes、limitations、额外视图、源声明和精度表述。缺失信息保持缺失。unknown_reason 为 null 时，明确且语义等价的 notes 可以归一化为对应原因，需保存准确原句并经独立语义复核。几何、范围、测量值或来源不能从私有答案补入归一化。

## 当前引用与归一化

归一化只读本槽原 final、实际工具请求与结果、模型明确引用的当前产物。全部输入路径、字节 SHA 和准确原句绑定。模型可引用公开 frame、ROI、binding，也可明确引用能唯一定位的本槽工具调用或 API 调用。当前工具引用可解析到 canonical current-tool 引用，须同时保留原引用、真实请求、结果及当前源映射。模型无需引用未交付的私有 hash。空引用保持空，跨槽或有多个候选的含糊引用拒绝。

归一化算法和数据结构在模型运行前固定。具体原句、调用引用对应与语义注释只从事后原件转录，独立语义 review 在首次完整内容评分之前完成。任何评分接线纠正均保留初稿、失败和更改原因，只重读原件。

## 实际采用与工作分类

路由调用、A批量调用、B联合调用、最终事实采用分别记录。A一次外层工具内实际发出观察和普通 task 两个公开请求即登记批量路径。B实际 active_observation 附 task_query 才登记联合路径。内部 MCP 请求与外层模型工具分别计数。

B采用门须在最终答案实际使用同一个本槽联合公开响应的观察事实和量测事实，并正确说明 whole_objects。两个采用链各保留当前公开事实、实际外层交付或代码数据流、最终使用原句与来源引用。仅出现字段、调用接口或引用后台 full 不成立。采用观察与整体正确性分别列出。

所有实际业务工具均按原请求代码和结果登记，含首入口、失败和恢复。额外查询、缓存图片、原始源读取、数值重算、完整像素重算、反查和重复交图分别记录。有无新增任务信息及必要性以具体证据判断，无法证明时保留 unknown。批量编程和重新核算属于允许的模型行为，诊断分类本身不构成质量失败理由。

## 终态与成本

先核源、原进程终态、单次消费者、实际 original final、全部质量及采用，再由 root 封存质量并解锁成本。计费、耗时排行及原始 usage 不进入质量归一化。完整固定任务正信号沿原门限，A/B各3/3完整正确、B3/3联合事实采用、同源usage可比、完整耗时配对比中位≤0.90且至少2对更快、B原始 input+output 合计≤A。任何结果均收口本批。
