# 全装配面板巡检评分合同

对每个报告区域按对象内源三角集合匹配独立真值。对象、完整三角集合和中心须同时正确，中心各坐标使用米且绝对误差不超过 0.000001 m。允许多个包含端点的零基范围，也允许当前请求中可独立解析到同一完整源三角集合的引用。不同区域分别计数，保留遗漏、重复和多报。任务使用精确 1 m² 与有向单位法向 z≥0 的筛选。

区域的图像或原因另按当前槽原件验证。完整图像要能用该槽提供的视角和原图引用定位，并满足精确前向、无正面积遮挡、16 个表面像素、4 个达标边界像素和 RGB 门槛 24。多个区域可复用同一帧。六方向几何不可能与当前像素证据不足分别评分。正面积遮挡未知使用独立的全部前向方向证明。像素证据不足使用同一当前区域和视角的实际像素依据，前向几何方向须正确。对于已由本槽实际交付可读原图的区域，要求能回查的见证。几何上部分可见的区域可保留遮挡结论。

正式槽完成且所有区域字段和证据正确、无多报或不受支持的额外断言，才计为完整正确。插件槽需实际采用可核且能追溯至插件结果的事实。逐条标记净新增事实、等价重复或错误和截断恢复，单列无图全量请求次数与独有事实。未使用的结果不计为采用。

全批收益同时要求两组各三槽完整正确、插件各槽实际采用可核事实、配对完整时间中位降幅至少 10%、至少两对插件更快以及三槽累计 CLI 原始 input 加 output token 未增加。所有失败与未运行仍纳入预登记分母。供应商费用和模型内部时间以原件可确认的部分为限。
