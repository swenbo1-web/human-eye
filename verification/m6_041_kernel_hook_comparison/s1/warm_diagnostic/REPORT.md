# S1 七组暖读取诊断

每个资产七组交错配对。最初两个真实普通 Blender GUI 共启动 28 个独立 stdio。G60 的 14 个首轮服务均在第三个正确响应后，因校验程序按标签末尾 nearest 选择了不对应的历史结果而退出，保留原三个响应。按实际 query.mode 离线复核。为取得各槽尚未发出的 warm scan，另起一台相同资产的普通 GUI 和 14 个服务，严格按原次序重建相同三个前置读取后，只采用新取得的 warm scan；其余 42 个额外响应另列成本。共 126 个业务响应，固定比较中 84 个，3 台 GUI 和 42 个服务正常回收。逐份原始输入、返回、安装身份、缓存工作和进程退出核验共 545 项，失败 0 项。该诊断是观察到 S1 单次耗时后追加的固定样本，原始主矩阵及失败另行保留。
