# M6-041　串行 BVH 与 Hook 启动四臂对照

**决议为保留原 032 串行基线，R3 进入限定场景候选。** 在 G60 的实际“场景概览 → 最近对象 → 5 mm 全场扫描”流程中，032 加原包装启动的耗时中位为 **7.432 秒**，R3 加直启为 **2.756 秒**。七组配对全部更快，逐组降幅中位为 **62.48%**。单换内核已经贡献 **59.47%**。Yanyite 同一高盒反复读取触发了事先设定的退化门，限制了全局替换。[冻结方案](PLAN.json) · [总结果与去留](RESULTS.json)

## 一次任务可以省多少

四臂使用相同配置、同样修复过的 Hook 支持代码、相同序列和只读资产。每格新开一份普通 Blender 5.2 GUI、原版 Blender MCP 插件及产品进程。原始提示确实触发了场景概览。测试从返回的 12 个对象中定位 Target，再通过正式 stdio 入口查最近对象和 5 mm 内全部表面对。计时连续覆盖 Hook 调用、工具发现、两个业务回执及产品退出。[七组完整原始窗口与独立复算](s3/REVIEW.json)

| B | R3 | PowerShell 包装 | 2,934 ms | 3,342 ms |

正常使用中 Blender 可以已经打开。另计从每格新建 Blender 到源几何复核、再起 032 对照进程、关闭宿主的完整实验生命周期，A/D 中位为 **15.864/13.181 秒**，逐组缩短中位 **16.84%**。独立资源回放中，A/B/C/D 的同时进程组工作集采样峰值约 **643/634/593/579 MiB**，对应私有内存约 **1,276/1,268/1,254/1,219 MiB**。Job 记录覆盖受控子进程，采样单列于独立一组。七组主测的整个实验 Job CPU 中位依次为 14.27、10.41、14.03、10.42 秒，其中包含独立复核。模型回答、token、费用未进入本轮测量。[分段、进程与资源](s3/REVIEW.json)

## 决定暂缓默认替换的短任务

看到单次暖读取存在波动后，单独冻结七个配对组，对 G60 自然缓存和 Yanyite 同一选区重读作了复核。每个比较先在同组计算 R3 相对 032 的差值与比例。两个中位数同时高于 **5 ms 和 5%** 即触发原退化门。[补充诊断的冻结记录](s1/warm_diagnostic/PLAN.json) · [七组每次耗时](s1/warm_diagnostic/REPORT.md)

| 自然暖读取 | 032 / R3 中位 | 配对差中位 | 配对相对差中位 | 退化门 |
|---|---:|---:|---:|---|
| G60 最近查询 | 36.70 / 39.35 ms | +2.39 ms | +5.92% | 通过 |
| G60 全场扫描 | 44.62 / 32.84 ms | −13.80 ms | −30.94% | 通过 |
| Yanyite 同一高盒 | **39.81 / 45.45 ms** | **+5.47 ms** | **+9.62%** | **失败，5/7 组较慢** |

Yanyite 的源面和几何答案相同。七组中宿主选区采集跨度的配对差中位为 **+1.82 ms**，圆整见证的源面归属校验为 **+0.002 ms**。现有计时包含队列与传输，单凭这些跨度还无法将 +5.47 ms 的差归因到一个 BVH 运算。若另立修复，优先定位同一选区暖读的额外耗时，并以这七组现有结果为对照。[独立原始时钟复算](review/WARM_ATTRIBUTION.json)

## Hook 和真实使用边界

轻事件共 **84/84** 有效。A 与 C、B 与 D 各在同一安装、同一输入字节及相同审计要求下比较。普通提示、变换工具完成、间隙工具完成各七组。直启令三类轻事件分别缩短 **17.53% / 18.14%**、**17.08% / 17.03%**、**18.39% / 17.67%**，斜线两侧依次是 032 和 R3。六个对照均 7/7 更快。每格返回原 4 字节空 JSON、两条来源绑定的审计，Blender 连接与状态写入均为零。[Hook 逐格核验](review/S2_INDEPENDENT.json)

八个独立异常出口控制也通过。未知选项在四臂均退出 2，stderr 为逐字节相同的 290 字节。缺失配置在四臂均退出 0，返回相同的空 JSON。实验分别验证了受控进程的截止和取消回收。桌面 Codex 对这两个新安装命令的实际自动派发与信任、宿主对返回值和取消事件的处理仍为 **NOT_RUN**。本轮完整流程实际执行了隔离注册命令，沿用普通 Blender 插件和生产 stdio。[出口原件](s2/error_control/run/SUMMARY.json) · [命令与信任范围](s2/READY.json)
