# 区域局部首视角的三对工程实测

三对真实 Blender 对照均通过。每次冷观察少构造一帧，**4→3**。M09 直接从 `LEFT` 取得局部见证。全场与 M02 仍使用 `SCENE`，M06 保留六方向正面积遮挡的未知原因。两组每次交付的三张原始 PNG 逐字节相同。所有热读均复用原三帧，实际新增构图为零。

## 产品与取证边界

- 基线为 `08a5f3b29283270c97b6d9d6e217bbee6ca7bfc1`。候选 `1dd2f77ecf19d51ba52aa5757e861ed930a58135` 直接在该产品提交上修改两处源文件。wheel 从候选 Git 对象直接构建，143 项运行源码中 141 项与旧产品一致。两边实际加载的五项工具目录一致。 [安装核验](install/BUILD_INSTALL.json)
- 私有局部索引只在 `SCENE` 被证明存在正面积遮挡时，从已有覆盖掩码按相机顺序取首个完整候选。选择器与首次有效回执使用同一状态。回执仍验证实际原图及当前场景、相机和映射。离线验证了默认 `SCENE`、无候选、非正面积遮挡、错误或过期回执、无图请求。像素不足的控制让 `LEFT` 得到 9 个目标像素，随后实际反馈路径转到 `BACK` 得到 64 个。该控制使用合成缓冲，真实工程轮次使用 Blender 与实际渲染器。 [离线验收](checks/VIEW_CONTROLS.json)
- 六个独占副本按 `A1 → B1 → B2 → A2 → A3 → B3` 依次运行，默认简报请求的参数完全相同，每槽先冷观察后热重读。独立读取验证了前后网格、显示及指纹。在各自当前绑定下解析所有引用并重算像素。M02 为 50,557 表面像素／926 边界像素，M09 为 146,797／1,530。基线被移除的 M09 `SCENE` 每次均为 0 个目标表面像素。 [原始绑定及独立评分](checks/PAIR_REVIEW.json)
