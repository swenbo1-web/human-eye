## 一条消费接口的三个小改动

1. **直接交付有限池巡检结论。** 在产品默认观察结果中给出简短任务状态、已观察数、未观察数、仍有几何完整候选但尚未观察的区域/视图，以及停止原因和注册池范围。几何候选不保证未渲染视图的实际像素一定过门限。复用 `CoverageIndex.view_masks/classifications`、覆盖状态与实际收据计算，不重新遍历三角形、投影、遮挡或光栅。

   未观察必须继续区分：无几何完整候选、尚有未观察候选、已有实际视图但像素不足。当前场景预期 115 已观察、23 未观察（22 无正面候选、1 遮挡）、可继续获得几何覆盖的未观察区域为0、域外 triangle 48 单列。这个计数来自真实状态，禁止写死。有限池已无可补观察不等于所有表面已观察，也不等于域外组件已解决。

2. **每面直接关联当前完整视图见证。** 给每个 covered 区域选择实际已观察且几何完整、像素可读的一个确定性见证；以已有 region/view/pixel-row/image 引用连接位置、法向、像素和 owned anchor。选取遵循现有确定顺序，无需新排序模型。剩余面使用现有分类给出简短理由，必要时按相同分类合并视图列表。

   保留现有世界位置、像素定位、来源与域外信息；SCENE遮挡但其它视角完整必须能直接辨认。可加紧凑列/引用或整理默认摘要，不把完整 classifications、重复世界几何和调试数据全部塞回首包。不能把 readable 更名后当作 complete。相关 schema/契约变更明确标识，已有 full/debug 消费能力保持兼容；不做无关格式压缩重构。

3. **测试接线公开同一份 JSON 字符串。** 隔离测试的 Python namespace 增加 `last_observation_json`，值仅为最近一次实际成功交付的公开 JSON text 原文。模型可 `json.loads(last_observation_json)` 查询；无新 Store、文件发布器、工具或几何计算。开始下一观察时清空，失败不能冒用旧结果。ACTIVE 工具说明增加一句这个用法，公共题面不改。不要暴露 SERVICE_RESULT 的内部诊断或另造一份答案。

第1、2项属于产品投影；第3项是试验接线可用性改进。本批是同一消费接口的组合改进，不声称单变量算法归因，也不能把试验 namespace 功能称为正式桌面能力已经部署。
