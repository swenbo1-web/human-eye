# Reference-only intent holdout scoring

The two cases use the same natural prompt with only the reference name changed. The target has two disconnected evaluated surface components. Freeze the current source triangles and strict triangle-surface distances before either formal diagnostic or consumer starts. Formal text and geometry evidence remain in the private run root.

## Diagnostic

Verify each actual response, its production capture generation, target and reference instances, every original camera frame and finite-depth ownership, render count and the closed Blender process. Separately report whether its primary evaluated face is inside the independently nearest component, and whether the one actually published original frame contains 16 or more finite-depth pixels owned by that component. The reference AABB selection is a recorded mechanism, not the ground truth. A geometrical counterexample does not invalidate the capture or prohibit running the independent natural consumers.

## Natural

Score each untouched original final answer against its own fixture, raw wire and actual image buffers. Require a completed public CLI turn with original final and use only the two registered slots. Record a routing choice only when observed in the actual request. A correct answer requires all these facts.

1. Correct target and reference, and an unambiguous judgement of the nearer of the two target components to the reference's actual surface. Accept a clearly named component, position or a valid evaluated source row identifying it. Ties inside the correct component are allowed.
2. A link or actual attachment to an original PNG delivered in the same slot, with stable post-close bytes. An image from the other slot, a path with no image delivery, a reformatted image or a naked filename does not satisfy this criterion.
3. The zero-based row and column in that frame, as supplied by the model, have positive finite depth and target object ownership. The actual object-local evaluated source triangle agrees with its reported triangle and lies in the nearest component. Do not infer a different anchor from the PNG.
4. The final answer qualifies what the frame itself showed. It may describe sampled geometry and which piece was in frame, without treating the frame's occupancy as proof of geometric distance, full visibility or hidden surfaces.

A legitimate ordinary read, calculation, selection, or render may supply the evidence. Register first tool, first request with focus, actual reference-only use, any separate proof, first eligible delivered image, final image, new geometry proof, corrections, request/render failures, and actual costs. Compare attempt order, not just the final route.

Natural success requires both registered cases to succeed. A failed, unfinished or absent consumer stays in the denominator. Do not sum partial token guesses. Distinguish public CLI raw input, cached input, output and the raw and cache-subtracted sums. Single-dose elapsed times are measurements from this batch and have no old-model paired baseline.
