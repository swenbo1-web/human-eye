# 无坐标参照主动观察独立复核

管理员把本批派给实施会话「分析当前项目」一次。产品固定在 `b7fe4bb0dc2ce277ff5dd7a6198365253b716c09`。两道题使用同一个新装配和两份仅参照名不同的题面，均要求找出更接近参照实际表面的目标面片，并交付当轮 PNG、像素和源三角。

| 独立检查 | 普通参照 K | 斜长参照 T |
|---|---|---|
| 从求值网格精确计算的最近片 | 源面 0、1，平方距离 1/2 m² | 源面 2、3，平方距离 11/16 m² |
| 诊断现场两次登记请求 | 记录器报错，0 次进入取景、0 图 | 记录器报错，0 次进入取景、0 图 |
| 实装在同一已关闭捕获上的离线复放 | 首选源面 0，交付图含正确片 50,557 像素 | 首选源面 0，交付图含正确片 0 像素 |
| 两个独立自然消费者的实际操作 | 读场景、分片量测两次、定向出图，4 调 | 查目录、读场景、分片量测两次、定向出图，5 调 |
| 原答与本次原图 | 选对面片，行 23 列 487 对应源面 0 | 选对面片，行 23 列 487 对应源面 2 |
| 冻结的自然槽退出验收 | CLI 完成，Blender/CLI 退出 0，桥接收到连接重置、缺 EOF | CLI 完成，Blender/CLI 退出 0，桥接收到连接重置、缺 EOF |

两道自然题的原答内容均满足四项要求，各给出可打开的一张 TOP 原图。两张方片同形，原 PNG 字节完全相同，分别以本槽公开工具事件、帧文件和原始 NPZ 独立复算，得到不同的源面归属。自然任务内容成立 2/2，自动参照焦点调用 0/2，按原退出条件通过 0/2。两个已完成的公开模型回合各有原始用量，输入加输出为 25,601 和 46,073，扣缓存后为 11,777 和 21,113。这是两道不同题，本批未设置同题旧版对照。

## 失败归因

使用两个现场请求原件复现了诊断记录器异常。旧记录器只按目标对象筛登记项，两题目标相同，每次都匹配两项，在转交引擎之前退出。用完整公开参数匹配，每个请求都只有一条对应记录。现场两条错误回包和零构图计数均可与原账本核对。斜长参照的包围盒跨过两片之间的空隙。在 XY 投影中，较远面片的两个三角重心都落在盒内，距离盒底仅 0.75 m。复放时，引擎成功拍清了这片并报采样达标，真正较近的面片在图中没有像素。拍清所选面和选对观察重点需要独立核验。

## 后续优先级

1. 先补两项验收接线。以同目标、不同参照的两条真请求完整走一遍正式记录器，检查每条只登记一次。用真实 CLI 的正常结束和异常断线分别验证桥接退出凭据，按独立收据判定收尾，保留连接重置为可区分的失败。
2. 对“离参照实际表面最近”的任务，复用 M3 同次捕获的最近源面，在 M4 从该源面确定要观察的局部。此处直接在原安装调用 M3，两个求解的获胜源面对分别为 0/0 和 2/0，平方距离逐项等于独立真值，均走现有小网格 r3 路径。这是接入前的离线可行性。后续验证应覆盖并列、无有效来源、遮挡和换代，并保持显式闭盒原有语义。
3. 先在这两组封存输入按原取景预算验证首选面、实发图及像素，再用新盲题检查自然采用、原图交付、业务次数和首张正确图的时间。两个通过条件应分别记录，即选择了真正相关的源面，且实际图确实显示它。

独立核过原始归档 265 件、7,263,896 B，各成员 CRC、SHA-256 和松散原件相符。归档 SHA-256 为 `956d479d4d7d7a4516e3a9bea0f9f480f1cbce22bb4ab4cf3fea430fd08500a4`。后置离线检查及建议均未改动正式分母。
