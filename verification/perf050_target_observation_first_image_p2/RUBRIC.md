# 新装配任务评分

沿原五项评分，两组使用同一门槛。先核原答和实际工具证据，再看耗时和用量。

| 分项 | 通过条件 |
| --- | --- |
| 对象与区域 | 正确定位 M09 的倾斜矩形功能面，求值源三角为 0–1。等价几何描述或能唯一识别功能面的证据可用。 |
| 完整可读性 | 从实际采用的视角核两片源三角、四角及完整区域，几何前向、未出界、无正面积遮挡。实拍原图至少有 16 个选中表面、4 个达标边界像素。原图无完整证据时保留实际可验证的缺证说明。 |
| 原图与遮挡证据 | 答复显式交付实际收到的原图、可用 Markdown 文件引用或真实附件，其字节经闭槽后本机复读，与该槽实际图块同 SHA。允许独立证实的任意等价视角。用户点击另记。 |
| 整件最短表面距离 | 确认为 M09 到 M03 的完整当前求值表面，绝对误差至多 0.05 mm。M09 两片源三角确实构成其完整表面，几何完整性另核。 |
| 方向 | M09 最近点到 M03 最近点的世界方向，归一化后误差至多 0.5°。若提供点对，检查其实际表面和最短位移关系，接受已证实的任意等价最近点对。 |

工具返回实拍原图、模型最终明确采用、本机闭槽复读分别核验。只收到工具图片而无最终可用引用，按实际缺项记。几何无遮挡、原图可辨和闭体分类各自独立。工具调用按取数、独立新证、略去或失败、同事实复算和原图重取记录。单对分段成本只作诊断，保留原分母和原答。
