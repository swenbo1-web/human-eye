# 独立评分合同（未收集模型答案）

答案schema见consumer prompt；`minimum_distance_m`键本身已明确米，数字无需再附m字符串。可接受明确等价单位，但不能猜无单位且无米制字段的量。每份答案另绑定harness的资产hash、帧、当前源/请求和完整工具轨迹，不要求模型回填哈希/手组packet。来源绑定错误或答案泄漏使整对比较无效；保留记录，不换答凑分。

| 指标 | 确定规则 |
|---|---|
| 数值正确 0/4 | minimum_distance相对独立Fraction真值，绝对误差≤0.000001米；null/缺单位/NaN不得分 |
| 全并列集合正确 0/4 | 对象名称规范化后与真值集合严格相同，无漏项/多项/重复/焦点；数值显示容差不能扩充精确并列 |
| 3毫米结论正确 0/2 | met/not_met与几何真值相同；unknown得0 |
| 正确性总分 | 上述合计0–10；另报告nearest_exact、集合precision/recall、遗漏名称和错选名称，不能平均掩盖漏并列 |
| 完整任务 0/1 | 正确性10分＋全部场景覆盖有本次证据＋未留影响全局结论的未决＋预算内终答＋无写入。任一缺失即0 |
| unknown/证据校准 0–2 | 2=清楚区分已证/未决、工具域外与真实几何、补查后解决与仍未知；1=局部表达含混但未虚构全局完成；0=抹掉影响结论的未知/把pruned写成已测/M3资格/错误引用来源 |
| 假阈值放行 | 真值不足3mm却答met，独立硬错误；不能拿其他正确题抵消 |
| 无依据全局放行 | 尚有影响结论的未决，却声称complete/全场满足或安全移动；单列，不因数值碰巧猜对而给完整任务信用 |

这里只为用户所问的全局断言计分；仅best_known、局部pair或碰巧匹配的partial值另留诊断，不当作已证明的全局答案。已有可靠反例可单独证明not_met，已证零距离也可证明最小值为零；这些仍不能补出未解决的全部并列集合。证据不要求模型重算完整几何，直接充分的正常工具事实可以支持答案。

**校准满分不等于任务完成。** T04有明确真值；若P只返回unknown/partial且模型停止，记complete=0、相关答案遗漏，最多校准2。不得把“符合插件支持限制”当几何任务已完成。若模型在同一原答/预算内调用允许的native补查得到正确全局证据，可以完成；补查的所有往返、脚本、传输及时间都计P成本，不给免费原生补充。

插件错误被模型合理质疑、纠正或回退是有效行为；“信任Human Eye”不是评分项。N可用精确Python/Blender数学；P不可因盲信而压过N。正表面间距不代表实体穿透/运动安全，超出问题的放行声明标注。

另记P是否实际调用HE、完整结果是否实际交付、答案使用了哪些对应事实，并分栏“完全未用”“HE不足后的native回退”“充分HE事实后再次读取/计算”及理由。重复核验是否必要由具体来源/错误/任务要求复核，不因合理质疑扣质量分。P自由选择纯native仍是有效P臂行为，但不能称为“已证明HE事实被消费”或工具调用本身证明理解；正确终答与公开工具轨迹一起核，不推断隐藏思维或因果信任。

两臂各四题作为完整分母，失败/未运行/超时/拒绝不删除。超时记录实际已耗时间与右删失，**不把预算截止当已完成耗时**。答案提前unknown的实际响应虽快，完整任务仍失败；仅在双方正确完成的配对上报告速度比，并同时给该配对子集覆盖率、全四题完成率和遗漏。

先由标准库按独立key规范化数值/集合，再由无实现历史的独立人工评审复核覆盖/依据/unknown。评审先见中性编号答案、题目、key与必要已交付证据，评分冻结后才揭N/P映射和耗时；不得先看路线解释。答案正文/工具引用可能自行透露条件，保留原文并称去标签审查，**不宣称完全双盲**。若未来加模型评委，单独授权和分账，不把它算第三实验臂。
