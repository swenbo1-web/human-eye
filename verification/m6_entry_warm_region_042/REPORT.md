# M6-042 Codex 入口与 Yanyite 同区暖读

## Codex 自动入口

**自动入口资格待验，阻塞在精确命令的信任。** 实际运行桌面随附的独立 app-server（0.171.0-alpha.13.2）和独立 CLI 随附的 app-server（0.152.1）。在四次最终发现检查中，两种真实后端分别识别到 R3 的 PowerShell 包装 H0 和直启 H1。四条注册均启用且返回 untrusted。隔离工作区的项目级 Hook 在工作区未获信任时也被宿主忽略。真实响应、注册哈希、原 stderr、早期失败及正常退出均留档。

前端未操作，真实模型回合为零。自动派发、相关提示同回合消费、工具调用前后去重、取消以及三组耗时对照均未运行。桌面随附二进制的 app-server 证据只用于后端发现和信任检查。需要本人分别打开两个实验工作区，在 Codex 的 Review hooks 中核对并批准对应轻事件预检命令。桌面每次只批准当前实验工作区的项目级定义。实际 G60 连接及新增 PostToolUse 的定义也须在冻结后按宿主显示审阅。原试验对照与启动参数见 [宿主记录](entry/REPORT.md)。

**041 的暖读退化本轮未复现。** 三个独立普通 Blender GUI、24 个全新生产 stdio 产品进程、24 次首读和 24 次暖读全部有效。12 个暖读配对的 R3 减 032 中位差为 **−2.75965 ms**，逐对相对差中位数为 **−4.73947%**。原门要求两项分别严格超过 +5 ms 和 +5%，且至少两个宿主的耗时差中位数为正。042 未触发修补资格。041 七对原结果 +5.4657 ms、+9.6177% 保留。

## 同一几何的阶段回放

H3 的最后一个正式配对后，经同一普通 Blender 插件和 032 安装取一次完整局部捕获。随后在七对新的独立进程中将同一份捕获分别交给 032 与 R3。独立复核了 262 个原生源面与 173 个选区顶点的映射，以及距离、点对、方向和见证。工程预检独立保留，正式回放共 56 次计算，实时 Blender 请求和 stdio 写出为零。

普通回放的第二次读取，R3 完整回放中位差为 +1.5317 ms（+10.22394%），其中局部测量中位差为 +1.5297 ms。捕获校验 +0.0017 ms、网格数组准备 −0.0024 ms；投影和编码的每项差量均在 0.002 ms 内。分步观测的求解子段为 +1.5161 ms，见证归属子段为 +0.0190 ms，同属测量内层。回放计的是复用同一局部几何后的实际运算，原采集和排队只在实时记录中计。首轮捕获核验失败及后续恢复回执俱保留。

正式门未复现退化，候选修补、修补后编辑失效检验及 G60 回归未进入本轮。完整入口与回放各保留自己的证据分母。
