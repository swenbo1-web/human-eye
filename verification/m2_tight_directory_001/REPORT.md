## 候选与入口

产品提交为 `fac9b4373575d653cc96f39f1dcb225300cd5977`，137 源摘要为 `6acb3ac7f014a590a279994f44be07c581af53a2da4dafae8dba9cd58eaea0bb`。隔离安装版本为 `9.7.2+dir.r1`。基线为 `00b13060` / 137 源 `4ebc3910`，测量准备提交为 `ceb31981`。

既有 `human_eye_scene_observe` 接受显式 `query.mode=directory` 与 `include_image=false`。query 仅含 mode。目录请求经原请求期限、只读锁与加载来源校验，进入宿主 evaluated 顶点范围聚合，再经服务校验与 MCP 单份 JSON 返回。

七个产品文件承接 query 校验、服务分流、宿主采集、MCP/typed 接线及发布。宿主同步既有 SceneResidency，同代目录使用 captures 中独立 key；冷态遍历全部实际 evaluated 顶点，以原 world forward 公式计算 tight bbox。center 定义为该 bbox 的中点，并覆盖 subnormal 与有限大数。

目录摘要绑定 host core 的 schema、kind、状态、单位、坐标系、对象、coverage、执行权限以及 binding 原始五字段 host_source_sha256、host_identity、frame、subframe、scale_length。运行来源 provenance 在服务校验后追加。capture_state 与 cache_hit 独立交付。目录的摘要与状态具有独立作用域，后续 selected task 执行正常网格采集与精测。

不支持的场景、缺失求值、空网格、非有限坐标及超预算输入明确拒绝。覆盖完成要求全部对象成功。目录路径的插件三角化、faces/edges 数组与跨宿主完整顶点传输计数为零，Blender evaluated mesh 内部仍包含自身几何数据。

## 正确性与来源

- 同一候选的离线 16 个测试方法通过，包含 12 个新定向方法与 4 个旧接口控制。
- 隔离安装真实 MCP 完成 21 次观察，其中 17 次目录观察，覆盖 13 类变化与重新连接。包含姿态、几何、单位、帧/subframe、改名、替换、撤销/重做、场景、删除和重载。
- 旋转非盒、凹形及孤立顶点采用独立 evaluated 坐标枚举与 Fraction 中点核验。目录后 selected task、完整 overview、delta 和 nearest 控制可达。
- 另以隔离安装的真实 typed worker 完成 1 个功能会话、7 RPC、81 项严格坐标核对，目录后 selected/full delta 基底均正确。该次复用同 SHA 资产的既有求值 oracle，进程退出为 0。
- 原生向量化在冻结的三资产 3514 个顶点上逐点符合实际 Blender oracle。Blender 附带 Python 3.13.13 / NumPy 2.3.4 已纯计算复核。通用 sum 与左折叠的不等价反例一并保存，通用逐位等价仍待证明。

## 准备、失败与限制

- 资产构建进程为 0.841 秒，隔离构建安装为 4.099 秒。旧工作量预录、原生及 selected 预检分别约 2.815、1.435、2.283 秒，均排除正式性能样本。
- 预实施草稿的半值相加中心公式会使最小 subnormal 值归零，源码审查发现后采用有限和优先、溢出时半值相加的中点公式。极小值与有限极大值反例已验证。
- 首轮离线 QA 因 cache_hit 元数据全包比对和 MCP 内部/外部错误封装层选择不当而失败，修复 QA 后同源通过。原件与源码快照均保存。
- 首轮真实功能 QA 的 21 条业务记录完成，但 fixture 的 quit_blender 在阻塞 accept 循环中无法退出，最终强制结束自有进程，整轮为 false。修复为同步脚本退出后，完整同序重放通过。两轮耗时分别约 13.286 与 3.132 秒。
- 原生通用浮点等价措辞已在测前修正。三输入的实测数值等价证据及通用反例均保存。准备阶段的一次纯导入错误也保留记录。
- 正式矩阵的 36 个 owned Blender 与 27 个实际 Python runtime 均有正常退出凭据。历史预检中缺失的实际 runtime 退出证明继续标 unknown。
- 原生失效处理有同源 SceneResidency 及 16 项 fake-handler 回归证据，原生各类变更的完整实机序列待验证。原生 OS/Python 内存峰值为 unknown，产品进程生命周期峰值及阶段 trace 已按采样口径保存。
- 完整 JSON Schema 引擎核验、同世界几何替换的实机孤立反例、模型回答质量/轮次/token/费用、完整工程协调和管理员审计成本均待验证或统一计量。
- 先前 M4 对照的完整净收益准入结论独立保存。本批完成 M2 工程候选与成本核验，默认接入决策待管理员审核。
