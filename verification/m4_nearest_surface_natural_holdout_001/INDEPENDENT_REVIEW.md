# 最近表面主动取景自然盲测独立复核

固定产品 `4225256485a82a9ddbdeeca61e1bbd3275574a6e`，正式证据 `156ac3c97f42a69536f74afff0df04b3e0ab7c4c`。两个真实模型回合交付的答案均合格，最近表面主动取景的自然采用为 0/2，预先登记的完整机制门槛未通过。

## 两次自然消费

只替换参照名的两个题面要求比较同一目标两片表面到参照的真实最短间隙，并交付较近片的本轮原图和可查像素。复核从 Blender 重新打开后保存的有序顶点与源三角独立求出两片之间的选择。Unit H 的包围盒会选错，Unit J 的正确答案又与 Unit H 相反。固定的安装源、wheel 与 Git 共校验 146 个文件。正式冻结及其执行计划逐项展开，共核 192 个互异文件路径。正式 ZIP 的 523 项按长度、CRC、SHA-256 和本地原文件复核，ZIP 摘要为 `2f7a99982b4fda8279c05a3047424e95d7ec2c4f818e7068fa80f4e05739873e`。

| 参照 | 较近片源三角 | 较近 / 较远间隙（m） | 最终 TOP 图中较近片像素 | 原答像素（零基行、列）及源三角 |
| --- | --- | --- | ---: | --- |
| Unit H | 1、3 | 1.015504801 / 1.954561971 | 143,685 | (101, 24) → 1 |
| Unit J | 0、2 | 0.625000000 / 4.480862082 | 89,861 | (24, 216) → 0 |

两槽的第一步都是普通 `read_scene`。随后各用两次插件 `source_region` 传入显式源行，分别求两片距离，第四步用普通 `render_view` 绘制一张 TOP 原图。四个测量回包都给出了各自的间隙和真实表面的点对。两张图均可从原答链接在闭槽后读回，实际 CLI 图块、PNG、有限深度和对象内源三角逐像素相符。每题首次实绘、首次交图和最终引用都指向本槽同一帧。两题各用 4 次业务、1 次实绘，整槽为 49.151 s、46.437 s，CLI 输入加输出为 44,911、44,899。本批只有候选臂，无法估算整题提速。

两个正式槽各有 7 对原交换，逐一核到双向 EOF，4 个业务的回包与实际 CLI 事件一致，最后一条响应已送达，零在途。CLI 与 Blender 两槽退出码都是 0。Windows 转接子进程 Thin 两次均观测到退出码 1，缺自身退出记录，发起退出的一方未知。无模型预飞的漏末包和强制连接重置都被拒绝。

## 封存后显式复放

另用两槽各自的终态捕获驱动同版已安装的 MCP 服务，明确提交 `active_observation`、目标、参照与 `task_region.relation=nearest_surface`，使用默认详情。每案一次独立冷服务调用和一次软件构图，共增加 0 个 Blender、0 个模型。输入输出流在进程内，时钟不参与正式评价。

| Unit J | 0 / 1 | SCENE | 47,317 / 18,956 | (201, 483) → 0 |

两份公开简报分别为 4,471 B、4,455 B，各有一张原 PNG、可读路径、图引用和可独立重算的真实表面点对。命中三角、距离、同帧像素及同源归属均核对。每份简报给出全目标对参照的一组最短距离和一对命中源三角，取景范围登记到单个目标源三角。两题的另一连通片距离均需独立求值。显式复放与两个自然消费者各自记账。

## 下一轮优先项

实际模型拿到的同一观察工具在嵌套 schema 中列出了 `nearest_surface` 和适用场景，顶层工具说明没有这个词，也没有最近表面取景示例。此次同时观测到两份原答都用了两片各自的距离。两条事实足以区分入口发现和任务证据覆盖两个可检验问题，样本无法判定模型采用当前路线的原因。

优先试一次顶层说明改动，在同一工具入口写清目标、参照和最近表面取景的最短调用，以及单个回包的证据范围。用新装配和自然题面，对现有说明与候选说明记录首次定位、是否先枚举源行、首图及像素是否被原答使用、两片比较是否完整和总调用。若入口已采用而比较题仍需逐片补测，再单独评估按需返回各连通片的最短距离与来源。正式实验只完成本批。
