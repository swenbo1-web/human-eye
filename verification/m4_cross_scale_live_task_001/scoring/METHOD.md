# Formal scoring procedure

Apply the frozen `RUBRIC.md` to N1 and P1. Keep both original slots and the nine criteria per slot even when an original fails or is unrun. An unstarted formal slot after an unsuccessful qualification has all nine criteria marked `unrun`. Keep eligibility, runtime status and answer quality as separate recorded fields.

Reduce each original answer to criterion annotations after its original bytes are sealed. Quote the original text verbatim for a pass. A `fail` identifies an actual contradiction or omission. `unverified` identifies unavailable current evidence needed to decide an otherwise stated claim. Preserve legitimate alternative numerals and identities. Reported decimal geometry is checked using the larger of half the printed unit and `1e-6` in SI units. Assess an image statement on its own captured geometry, including ROI identity, facing direction, framing, owner pixels and contrast. A repeated image or shared view label does not merge the distinct frame identities. A proven image qualifies for the cited target even if the same frame contains other geometry. A reported extra completeness or geometry statement is judged separately from whether a frame qualifies.

Run `formal.py evidence` after original answer seals or, if qualification failed, after the final qualification record. Evidence checks use the frozen Blender-derived truth, byte-bound original terminal array, read-only state guard, original owner and stdio wire replies, and verified public CLI receipt classifications. The frame's original PNG must have been delivered and match its same-slot color archive. The frame's object/instance ordering, evaluated-triangle offsets and display mask must match terminal geometry. Measure surface and contrasting boundary ownership from the original arrays. For completeness, require that all region vertices project within the orthographic frame in a direction for which the independent finite-view oracle certifies clearance.

Run `formal.py grade` after evidence. If a sealed answer exists, provide an annotation JSON with `--claims`. Each original is keyed by `N1` or `P1`, with `answer_sha256` and a `gates` mapping using the registered gate names. For geometry passes include `triangles`, `center_world_m`, `area_m2`, and `unit_normal`, recording reported numerals as strings to preserve printed precision. For witness passes record `resolved_delivered_ref` and `direction`. The manual annotation must identify the actual stated source and distinguish quoted reference identifiers from a reviewer-resolved alias. Check the unknown explanation against finite-pool positive-area blockage and the lack of a valid complete frame. Record contradictions and unresolved claims with their original near-quote if present. The grader verifies binding and numeric gates but does not generate manual annotations or read model reasoning.

No scorer action invokes Blender, rasterization, the product, a model or a provider service. Qualification image and answer artifacts remain qualification-only.
