## 二、需要先补的最小 M2 合同

以下为**待主线确认的接口要求**，不是已实现 schema。

1. **完整目录**。在任何候选完整顶点/面展开前返回固定 scope 内全部对象 ID、实例 ID、世界米制保守 AABB、bounds 状态与依据、对象域状态、目录完整性。空表、重 ID、未覆盖隐藏/实例等情况必须有明确出口；已支持域之外不能悄悄消失。最多 256 对象沿现有限制。
2. **边界可信且便宜**。首版可限定已验证的静态 mesh 来源；如计划取 8 个包围角点，必须证明它包住与精算相同的当前求值表面，并计入获取/转换/外扩成本。修改器、变形、无边界、非有限值、不明坐标系等无法证明时标 unknown、保留候选。未验证的原始 mesh 边界不能代表求值网格。若获取这些边界仍需逐对象 to_mesh/遍历全部顶点，前置取数门没有通过。
3. **同一状态取数**。目录绑定运行源码、宿主/文档实例、scope、对象全集、单位、帧、求值配置和可信场景代际。后续所选网格与 M3 结果必须绑定它。`host_identity` 的 document_epoch / object_instances 仅是身份，不含几何变化序号；现有 selected revision 也不能证明未读取的其他对象没变。应选择可信单次主线程读窗口，或证明覆盖全部相关变更的代际机制。多次 TCP 调用加客户端 RLock 本身不够。没有该保证就显式失效，不能沿用旧上界/排除证明。
4. **选择性读取**。已有 BlenderSceneHost/MCPHost.capture_task_scene 可复用 selector 解析和完整网格读取，但需要上述版本绑定，并避免每批重复捕获焦点。现有 service task pair fact 只能处理两 selector，不存在自动多对象最近表面聚合入口。ProcessHost/worker 的对应接线若纳入下一批，须单独列任务。
5. **查询域与来源不足**。目录 AABB 不替代几何/拓扑准入。某行无法证明适用于新查询合同，记为未决；不能借“远处未读取”隐藏原合同要求拒绝的输入。若全量准入不可避免，须如实在收益门扣除。新 unsigned triangle-surface 最近任务不能悄悄复用 legacy top1 的 solid/nonpenetrating 成功语义。

最小接线点在 `LiveSpatialService.observe` 的普通 capture 之前，显式识别这一个新的只读最近表面任务。目录由 M2 采集、M4 仅产出下一批读取需求、M3 返回所读双网格的真实表面量测。旧 task 双对象入口直接走原路径。首版不需要新平台、后台服务或持久化索引。

## 三、接口具备后的确定性 M4 计划

输入为上述目录、唯一焦点、原请求期限/字节/次数预算，以及已读网格与 M3 有效量测。输出至少含同一目录绑定、待读 ID 列表、已读/严格排除/未决 ID 与依据、下一步或停止原因；M4 不输出执行权限，也不把包围距离当真实答案。

采用最多 256 行的数组。计算每对象与焦点 AABB 的 L∞ 距离下界 `L=max(0, max_k(a_min[k]-b_max[k], b_min[k]-a_max[k]))`，端点需先被证明向外包络，减法向下舍入。数值不可靠的行按 `L=0` 保留。先按下界、再按稳定 ID 排序，复杂度 O(N log N)、额外空间 O(N)。无需树；树的构建、失效和证明成本目前没有受益证据。

初始 `U=∞`，包围盒不能直接给出可用的表面距离上界。先读焦点与最小下界候选，用现有 M3 得到有效距离才更新 U。M3 公布的是正确舍入的 binary64 距离，安全排除阈值至少向上取相邻浮点值，并包含已证明的比较余量；溢出变成 ∞ 则停止剪枝。仅 `L > U_safe` 可免读，等号、近边界、重叠及 unknown 全保留。读取一批后重新根据真实量测更新 U，不把预算次数重置。首版保守采用小批；每个批次的固定 RPC 与重复焦点成本都需要入账。

同一来源的每一候选最终都须是已精算，或有严格边界排除证明，才能报告 complete。M3 unknown 不提供 U，也不凭空提供最近者。预算/期限用尽或来源变化返回明确 partial/unknown 和未决项，不输出“已证明最近”。并列按 M3 输出的 binary64 距离值保留，不再做展示小数舍入；不能宣称物理等距或有理精确跨对象排序。

- **全重叠**时 L 均为 0，可能全部读取；这是一类无取数收益的合法退化。
- **0 距离**仍需处理所有无法严格排除的候选，以返回完整并列集合，不能命中第一个就停止。
- **变化/失效**需清掉本代际的候选计划、U 和排除证明。旧缓存只有在现有完整内容键条件成立时才能复用。
- **明确两对象**完全绕过目录策略；对象少、几何轻或预测省不回额外目录/RPC 成本时也应使用原路径。阈值由同任务完整测量确定，当前没有事实可给出常数阈值。
