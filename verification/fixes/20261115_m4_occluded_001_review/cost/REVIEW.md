# M4 遮挡迁移：根侧独立成本与消费复核

本轮只读取已保存源码、原始 CLI、请求回执和数组；没有调用产品、模型、Blender 或 raster，也没有执行作者成本生成器。独立脚本 review_saved.py 的修订版通过 580 项断言，保存 RESULT.json。原作者结论与本轮独立重算分开。

六槽各只有一个原始 turn.completed usage，原始、consumer 和 COST 数字一致；六槽仍全部保留。N2 的质量状态采用质量审查输入，本子任务不替代独立语义评分。

按完整正确任务比较，配对1 P/N=0.8027450917950069，配对3=0.7831980498422703；配对2保留失败槽原时长，但速度比为 null，三对中位也为 null。没有排除 N2 的调用、图片或 token 来美化成本。原预登记 limited_positive_signal=false 正确保留；N2 的额外错误不是 P 的质量退化。

同一 run_slot 从输入/来源检查前计到 SLOT_RESULT 写入关闭后；当前 launcher 克隆并检查原共同代码对象。独立逐槽确认开始→消费者→final→cleanup→结果关闭的包含关系及串行顺序。六槽累计 818.5322113 秒，父批 825.6306093 秒，额外 7.098398 秒协调开销没有塞进某一组。各阶段不能相加两次。

作者 COST.bytes.CLI_text 实际引用 consumer.public_text_bytes，含助手公开消息；不等于模型收到的工具文本。本轮直接计算 raw MCP content 文本并与服务器 RESPONSE 逐项相同，得到上表 90155/142301 B。不是作者总 token 算错，主要是字段标签容易误读。

## 单一下一候选：主回复直接保留精确源面绑定

brief-v4 regions 包含 object_index、triangle_count、中心、半边、法向和见证，但没有局部源三角编号。不能因此说引擎没有映射：产品帧公开 buffers 已带 patch_roi_ids、face_patch_ids、face_patch_offsets、patch_owners；P1 tool03、P2 tool03、P3 tool03 甚至实际打印过这些 keys。共用工具描述没有解释此产品扩展映射，主 brief 也没有直接交付它。

本轮仅从已保存数组索引，无几何计算，恢复每槽 61 面、122 个支持源三角和4个余项；TOP(135,175) 得到 RackRoof[2,3]，LEFT(234,483) 得到 RackBase[10,11]。P1/P3 最终 JSON 中全部手写重建的源面绑定与该映射一致。P2 没有同类完整 JSON，整表语义由质量子复核负责，本成本侧确认其请求里确实写了同类全三角匹配。

建议只新增一项主回复源面绑定表示，直接复用已有映射，不同时增加拾取 API、改图片策略或前置取数。优先沿用 unsupported 已有的零基、对象内、闭区间表示：source_triangle_index_ranges。每个 range=[first,last]，单面也表示为[t,t]；排序、相邻区间合并，索引空间与现有 source triangle scope 一致。这样客户端可直接关联原生目标及已存在的 raw triangle_id。

本场景离线序列化：原 brief 23944 B；若每面添加源面整数列表则新增412 B；采用上述统一 ranges 则新增539 B，总24483 B。这里只比较一次实际主回复的字节代价，未测 tokenizer 或模型净收益，不做多格式性能竞赛。

范围编码能省连续细分的输出：纯编码示例10000个连续编号列表48891 B，单闭区间10 B；10000个交错编号则 ranges128891 B，最坏仍随编号数量线性增长。因此候选应至少覆盖连续细分与打乱/交错编号，记录实际完整 payload；不能以当前每面两三角的例子承诺任意高面数模型都很小，也不能截断编号后伪称完整。

这项候选可证明省去“为获源面身份而再次几何匹配”，不能提前承诺同时消除18见证像素重算或全部模型补查。它针对三槽共有的真实问题；新候选应固定版本单项验收，再测完整消费成本，不在本批旧结果上删除耗时后推算收益。

## 本轮验证与修订记录

独立脚本通过580项：raw usage同源、共同时钟算术/包含/串行、36次业务请求与回执/CLI对应、19块正式交付图片逐哈希回读关系、raster计数、保存映射和所用归档字节一致。正式模型样本始终为六槽；断言数不是样本数。

首个独立脚本 review_saved_R1.py 将 COST.CLI_text 误解为工具文本，N1断言失败；查明作者该字段实际为助手公开消息后分别核对两种文本，修订脚本通过。保留旧脚本；没有改原成本文件或运行新模型。初期路径探查误用了不存在的 runtime_archive/formal 层级，已依据实际平面归档索引读取；一次 raw event 探查未过滤 result=null，已改为仅处理 completed MCP项。上述均为审查工具错误，未改变实验结果。

没有完整人工/编排模型费用测量，没有纯图像模型消融，没有实时 Blender 数据采集。本结论只覆盖该固定合成捕获重放任务与保存证据。
