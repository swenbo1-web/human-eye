本次仅复核公开交接包的实际完整三角几何、TRUTH、六份匿名答案和业务工具记录。六份答案各三对距离、见证点定位、最终文字坐标舍入均通过冻结数值合同。三对均严格分离；4 mm 判断依次为否、是、是；仅在指定三个候选中，Peer_000 唯一最近。

## 独立计算与证据强度

脚本仅导入 Python 标准库，不导入产品求解器或原作者验证器，不执行消费者代码。输入世界顶点按 JSON 解码出的 binary64 值转换为 `Fraction`，保留实际捕获的世界几何；不以理想局部模型替代实际世界坐标。

1. 从 Target 已保存变换矩阵的 z、x 两列叉积自行构造法向，不读取参考证明的方向或产品返回的支持证书。对 Target 与三候选的全部顶点作精确有理投影，确认全部三角索引均被覆盖。两集合的严格正支持差给出所有三角表面之间的全局欧氏距离下界，同时证明严格分离，无需实体闭壳分类。
2. 独立遍历 Target 靠近最大支持面的顶点和候选完整三角集合，找到表面上可达到的距离上界。浮点运算仅负责提出候选三角；上界点、非负且和为 1 的重心坐标、距离平方均以有理数重新构造和验证。该阶段完全不使用消费者答案点。
3. 六份答案的工具点分别按对应对象的完整三角集合定位，构造具有精确有效重心坐标的实际表面点。把这对实际表面点的距离上界，与步骤 1 的独立全局下界比较。这是“表面归属 + 全局下界 + 达到该界的上界”证据，不是仅查点间距与表面接近两项必要条件。
4. 最终文字坐标逐分量同时与业务工具点、构造的实际表面点比较，距离单独按 1e-6 m 门限比较；不扩大距离门限，不强制相同参考三角或相同等距点。

平方根通过整数平方根和有理数得到向外的 30 位十进制界；JSON 展示为浮点的边界只是便于阅读，精确平方值一并保存。

这里的“最优”按冻结数值合同判定，内部证书要求最优差不超过 1e-15 m，实际最差小于 9e-17 m。不声称浮点或格式化端点与数学上的精确极小点具有符号恒等关系，也不把实际二进制几何的亚飞米差异说成已证精确连续等距点集。该精度说明适用于六格同一标准，不为任一路线放宽要求。

本复核不评采用率、组别、成本，也不以执行完成替代几何正确。未把部分记录的闭合实体分类 unknown 算成间隙或分离 unknown；全顶点严格支持分离已独立成立。关于源绑定、消费者业务论证和执行状态的总判分由根与另一独立质量审阅汇总。
