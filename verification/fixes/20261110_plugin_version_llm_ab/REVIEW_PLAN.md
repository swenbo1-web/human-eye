## Coverage and scoring

The model must call actual installed geometric execution, exercising capture and ledger paths changed in B. If a common thin MCP adapter is required because the current public tools do not expose this programmatic entry, both arms use identical adapter bytes. Adapter routing can construct the task and forward it; it cannot calculate a solution, supply an expected answer, or assign candidate poses. Such results are identified as a sandbox adapter experiment, not desktop MCP deployment acceptance.

Quality is scored without referring to A/B latency: actual required operation invoked; reported status equals independent native result; numerical claims agree with raw actual geometry; no claimed change for a no-op/unreachable case; unchanged endpoint poses, protected vertices, static data and sentinel. The positive case must meet area loss <= .4 + 1e-6; the no-op remains unchanged; an unreachable task must not be called achieved. Model answer quality and product geometry correctness are separate columns. Failed and unrun sessions remain in the denominator.

Root will independently recompute areas and protected/end transforms from saved native arrays using the previously reviewed standalone math, not product predictions. The implementation audit is supplemental evidence, not root execution. Product work and QA initialization/archive work stay separate.

## Cost interpretation

Record prompt submission through complete final answer; full setup through confirmed cleanup; LLM/tool waiting where visible; installed product entry and constituent costs; tool/RPC counts, setters, captures, saves, preparation/validation counts; delivered bytes/images; actual input/output/cached tokens when present. Nested timings are not added as disjoint costs. Model requests and provider retries are retained. Unavailable dollar costs are not inferred from Pro token counts.

Report all six pair ratios, per-task medians/ranges and aggregated descriptive medians. A small observed difference is not stable causal proof, and an unfavorable difference is not discarded as noise. Successful simplification alone does not pass speed acceptance. Do not extrapolate three-bone fixture results to complex scenes, learned repair, or plugin-versus-native superiority.

Formal installation, original assets, competing branches and source algorithms are outside this experiment's modifications. Only isolated owned fixture processes are executed and cleaned up.
