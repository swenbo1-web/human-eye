## 算法审阅结论

新增 plane 判据 `gap > isqrt(floor(best_num * normal_sq / best_den))` 对整数 gap 等价于严格平方距离下界大于当前 best；等界保留。队列右移只影响访问顺序，实际剪枝使用未移位精确 AABB；没有把浮点优先级当成证明。树按当前最优原三角对处理等值时重新计算较早 pair，避免直接沿用较晚 pair 的描述符。

准备复用只在 query-local 持有者中使用；当前代码核对 mesh 对象身份、pair 身份和三角准备对象身份。此次测试覆盖实际支持的同查询使用，不把它宣称可跨任意原地修改/长期缓存复用。当前公开调用建立新的来源快照，持久 cache 的来源失效仍由外围层负责，本批未重跑外围完整缓存矩阵。

一处可证明的小简化：树遍历在零距离后仍保留后续访问以维护最早三角对见证；若 `best_pair == (0,0)`，距离和词典序都已达到绝对下界，可以立即结束。当前缺少这一捷径。该项仅为源码推导的机会，没有为它新增矩阵，也没有将它列为错误结果或当前闭壳失败根因。

## 对下一结构方向的判断

赞成根提出的“正支撑间隙充分证书”独立几何事实，优先于继续微调 fan/节点证书覆盖。任意非零方向上，所有当前顶点的严格正投影间隙证明两组三角及凸包不交；方向即使来自近似公开见证，最终全顶点精确检查仍是有效证明。

边界必须放在事实合同里：它不证明 embedded 闭壳，旧 `closed_solid_relation` 和旧集合完整性不能因此改为成功。新显式事实可回答表面几何分离及最短表面间隙；4 mm 使用同源精确最短距离界，不把投影下界当成真实最短距离。证书失败只能回退/未知，不能推断穿插；任一候选距离/关系未知时，相应集合完整性仍未知。全顶点与距离必须绑定同一次实际来源，零/非有限方向、位宽或取消不能用 epsilon 放行。本意见是数学和合同审阅，未执行根提案或新实验。
