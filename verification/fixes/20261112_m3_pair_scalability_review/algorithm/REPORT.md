## 正确性与接线判断

### 整数投影与候选覆盖

`surface_geometry.py::_closed_candidate_trees` 的三行来自非退化三角的 edge、normal×edge、normal；它们非零且两两正交。逐行 gcd 约简与正2次幂缩放不改变可逆性。全部实际顶点经同一个精确整数线性映射后形成 outward bounds，因此投影 AABB 不相交可以安全排除原三角相交。

该映射只用于相交候选；世界树仍负责距离和点/射线查询，未把投影长度当世界距离。两壳的候选树全部构建成功才一起赋回，位宽失败不会留下半壳使用新坐标、另一壳使用旧坐标的状态。原取消、期限与总工作异常不被可选位宽 fallback 吞掉。

`candidate_pairs` 保留自树 LL/LR/RR 覆盖和无序对不重枚举；单三角叶重用节点边界成立，因为其节点箱就是该三角箱。节点排除仅接到同壳自交，未将源 ID 证书用于不同对象。

### shared-simplex 与二维 cone

廉价叶判定的严格同侧平面排除是正确充分条件。闭半空间情况下，若另一三角的零距顶点只来自共享源顶点，交集只能落在允许的共享 simplex；共面共享边还检查两第三顶点位于相反开侧。没有统一跳过相邻面。

节点证书需要：同一个 anchor 属于每个后代三角；每片三角二维投影非退化；合并 cone 的正叉积和最终全部支撑方向包含检查证明角宽小于π；边界保存全部源 ID。两个节点投影被一条直线分开，在线源点总计至多两个，且两点投影不重合，才能推出每对后代的交集仅为同源点/边。源 ID 不同的重合点不会因此混为同一顶点。独立32例检查支持这条证明链，未找到反例。

### 准备绑定与 unknown

当前 `classify_closed_solids` 已核有序 left/right 对象身份，入口清理 holder 的旧 pair/trees/contact；surface 同时核 pair 身份、prepared 三角对象及树所属 pair。它们是本次请求内捕获的固定几何，不是跨请求的可变对象缓存。保持这个前提时未发现新的误复用；跨请求或原地改数组后仅凭对象身份复用仍不属于已证明合同。

闭壳预算失败后留下合法的整数几何与世界树供表面距离使用是合理的：表面距离不要求闭壳合法。三个 closed unknown 没有被有效 distance 覆盖，成功缓存也没有收录 unknown。当前错误结果是无法完成任务，而非将分离或完整最近误报为已证实。

## 独立定位的实际最大成本

一个固定 Peer prefix 的成功计费总和精确等于262144：

| 阶段 | 工作量 |
|---|---:|
| 两壳准备、拓扑与树 | 34567 |
| Target cone 元数据 | 11621 |
| Target 自交遍历与判定 | 215956 |

最后一笔拒绝发生在 cone separation test；不是 full-intersection 或 ray 上限。最大单项：anchor 检查52111、BVH节点36576、平面点投影36312、节点证书尝试28494、构树20820。全部 cone/simplex 查找与元数据计费合计111210，占42.42%；完整相交只有1773对。

这些是实际执行的整数操作、遍历和元数据访问，未发现靠修改计数位置伪造减少；但“工作单位”仍是声明的操作代理，不是CPU指令或耗时。新版本增加平面/准备等计费后，同一个262144数值也不能当作旧版相同CPU工作上限。失败证明的是当前合同和计量下不完成，不能解读成几何任务不可计算。

### 空间树确实拆散了拓扑扇区

Target有508面、256源顶点。两处最大扇区分别以源顶点1和129为中心，各有67片关联面；现空间树将它们分别拆成62、63个最大同anchor子树，最大同anchor子树只有4面、3面。

507个内部节点中：362个没有所有后代共同的anchor；134个有 cone 元数据，但其中128个只含2面、5个含4面、1个含3面。另11个有共同anchor却不能保留 cone。**本次固定投影下，508面全部二维非退化**，所以不能把本例覆盖不足归因为“侧面投影退化”。

因此2775个成功证书只覆盖2934对并非偶然：当前证书要求“所有后代共有anchor”，而空间中位分割几乎不保留这种大分组。继续在这些节点上多试几个方向/边界，只会在小覆盖集上增加寻找成本。

## 保持原 closed 合同，什么方向有证据

若未来任务确实要求证明完整 embedded shell，应直接从拓扑扇区/投影 disk patch 建立批量嵌入证书，而不是先按空间分组再寻找共同anchor。本资产的原始来源清单中两个 cap 各126面/128顶点/253边、Euler=1、128条边界边，当前投影均非退化，是可以研究整体 patch 证明的具体来源证据。这里的 cap 分组来自 QA 原始 local 结构，**尚不是产品自动识别或合法嵌入证书**。

可研究的充分条件是：有效 disk 拓扑、投影内每片三角严格同向且非退化、投影边界简单且覆盖一致，再证明整体投影为单射；不同 patch 之间仍需完整相交/包含处理。不能只凭Euler=1、同法向或名义平面跳过自交。当前 MeshEntity 主要提供世界顶点与局部轴，不含可直接信任的原始 cap/挤出来源合同；不能把现有独立 prism oracle 搬进产品后仍称独立验证。

**纯 query 复用不是这次失败的解决办法。** 第一次 Target self 都未完成，没有合法成功证书可供另两对复用。成功后按相同实际源字节复用单壳资格原则上成立，但当前 candidate frame 来自有序 pair 的 first-left 三角，integer factor 也由整个 pair 决定；不能原样跨pair复用树或元数据。需要把不依赖pair的资格证明与pair坐标树分开，不能累计三个失败 prefix 伪装绕过单次预算。

## 下一项建议：需求直接求证分离，与资产合法性解耦

我已只读复核根的 `architecture/probe_separation.py` 与 `SUPPORT_FEASIBILITY.json`。其数学逻辑正确：对任意非零方向d，若所有实际顶点满足

`g = min_B d·(b-o) − max_A d·(a-o) > 0`，

则两个点集的凸包严格分离，所有表示三角及这些凸包的任意内部子集也不相交；距离平方下界为 `g²/(d·d)`。这不需要先证明每个网格是嵌入闭壳。public witness差仅用来提出方向，真正的证明是对全部实际顶点执行精确支持界，而不是相信“surface距离为正”。我没有再次执行根的四对支持扫描，其数值与调用量属于根证据。

根固定一次方向的saved-data结果，三对及控制全部有严格支持间隙，分别只需512/288/288/16个顶点点积；G508的两个达标间隙可直接由下界证明。这个机制比继续优化通用 self 审查更贴近当前4毫米空间任务，应作为唯一下一项。

必须明确以下语义与成本：

1. **新增的是充分的表示分离事实，不是原 closed-domain 资格。** 旧 `closed_solid_relation` 的 embedded-domain 承诺及失败原件保持；新字段/方法/summary合同必须显式说明。不能把 self 未核改写成“网格健康、闭壳验证通过”。
2. 未找到严格支持方向只表示该证书未建立。凹体虽然分离，凸包仍可能重叠；包含、接触、真实相交和无效方向也可能失败，不能反推 penetrating/touching。原普通核或unknown仍是明确出口，不展开无穷轴搜索。
3. 下界≥4毫米可证明达标；下界<4毫米不能证明不达标。Peer的不满足必须由原已知正确的表面距离或有效上界给出。阈值侧别用精确平方比较，不能用展示舍入的sqrt数值决定边界。
4. 顶点/三角索引、有限值、单位、实际evaluated字节与来源仍要成立。可以覆盖非流形/开放表示的集合分离，但要明示支持的是表示集合，而非未提供的物理体积。新事实不能授予写权限。
5. 根方向来自已经求得的真实距离见证；其获取成本不是0。若新链仍需距离和最近位置，先 surface 后支持扫描可以省掉本任务不需要的完整self审查，但需计入独立surface准备/树建立；不能拿512点积替代原约2秒距离计算报端到端收益。
6. 新事实验收需要至少包含凸包可分离但自交/开放的表示、凹体分离但凸包重叠、包含/接触、错误或零方向、反向输入、极大平移、阈值两侧。正确结果是“有证书时可靠完成，没有时保持未知或走既有合同”，不是仅在G508四对上都返回分离。

选择这项后，拓扑patch路线保留为真正需要合法闭壳的后续课题；本轮不同时开两条实现。旧 M3 的3/3 closed失败、0/15完整事实和候选额外计量均继续保存，不能以新合同补记为原批通过。
