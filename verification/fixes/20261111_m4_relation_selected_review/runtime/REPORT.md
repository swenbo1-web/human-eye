- `qa_instrumentation.host_work` 按 `id(host)` 去重模块别名，读取现有 `residency_work()`；before/after差分与保存的delta独立重算相符。`blender_host.py:594–639` 在实际执行 `to_mesh`、三角化、资源及世界坐标准备的相邻位置递增已有计数；成功请求和对应新资源输出共同确认这些计数的含义。它不是独立C追踪器，却能在此次已审源码路径上证明暖显示没有再准备资源。
- `world_transforms` 是宿主资源姿态的前向映射次数，不是整个请求所有数学计算或数组转换次数。新增 `.tolist()` 的交付转换与编码必须另计成本。

- `task_work` 计量的闭体/表面/排序调用，与原关系缓存命中及源码的compute闭包相符。它证明当前代码的调用计数；不是运行时任意潜在隐藏求解的普适证明。所审新增代码仅投影同次meshes，未见绕开该计数另求解的路径。
