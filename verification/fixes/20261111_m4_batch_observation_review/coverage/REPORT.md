但 center 是本题判定的实际输入，不是无用字段：评分明确使用 AABB center Z/Y/XY。删除后，下游还需中心、导轨高度中点、双管 XY 中点、候选半径与三个比较。离线独立用同一 AABB 和已知参照 ID 以 Fraction 运算，可以恢复四候选条件，只有N16满足。这说明**数据不丢失、无需重新采集**，不说明**模型计算负担消失**。

## 6. 三个变体证明了什么

- **重命名/ID 重排**：对象表、关系和已知 request 按固定 map 变换，投影不依赖 N16 等硬编码。没有要求消费者在改名后重新发现目标，不能当目标定位泛化测试。
- **90° Z 旋转**：顶点与证据坐标按精确符号交换变换，所有非坐标关系事实保持。证明有限等距变换下的保存数据/坐标投影一致；不是新求解，也不覆盖任意角度浮点变换、非均匀缩放或修改器。
- **同形干扰物**：新增一个固定平移对象，原 request 仍选原对象；请求新对象关系时明确缺口。证明不编造未提供的关系，不证明遇同形干扰时模型仍能自主选择正确目标。

原型公开函数在给定受检 frozen bundle 的范围内正确。没有必要把无关的任意输入防御流程加到这次审查；但也不能将这些有限 fixture 的断言扩展成产品入口、未知源或活体一致性测试。
