## 生命周期与预算

consumer 最早观察到完整 stdio STARTED 后只绑定一次实际 Windows runtime，只读验证基础解释器镜像、创建时间和有界父链，随后保留该句柄确认退出并关闭。正常 EOF 与缺 EXIT 两条本地真实进程控制均通过。缺 EXIT 继续记录 EOF unknown，已经持有句柄证明实际退出的情况可继续。无法绑定或退出未证会停止余槽。

正式次序固定 N1、P1、P2、N2、N3、P3，各一 fresh 用户轮次、12 工具和原绝对450秒期限。正式最多36次光栅，准备烟测实际4次，上限6次，新批总上限42次。旧64次单独保留。原 stdout 字节流与解析事件分开保存。

每槽窗口覆盖启动前至实际 CLI、actor、已绑定 stdio 结束和结果回读发布。BATCH_TIMING 只描述 run_batch 函数窗口。controller 初始导入和首次全源核验属于明确未测的 bootstrap，不扩称全进程总墙钟。
