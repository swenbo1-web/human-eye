## 失败和成本窗口

两次普通 Python 错误均由原工具正文中的 error 字段提取。

N1 第 3 次工具返回 SyntaxError，消息为 `closing parenthesis ')' does not match opening parenthesis '[' (<consumer-python>, line 20)`。

N3 第 2 次工具返回 ValueError，消息为 `could not convert string to float: '31/375'`。

原 MCP 返回 isError=true，CLI 将相应工具投影为 status=failed、error=null，并完整保留相同 content。冻结的业务原件绑定器随后记录不匹配，原失败结论保留。N3 另出现一次 CLI 内部 Reconnecting 事件，后续仍有最终回答和终止 usage。外层编排重跑为 0，provider 内部请求数及中断流 usage 覆盖仍未知。
