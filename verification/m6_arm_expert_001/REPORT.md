# M6-ARM-EXPERT-001：真实手臂扭转专家初版

分支 `codex/architecture-arm-expert` 从已审 `003f87a99c9f2ad6590b2d0ea597eb25cc552f07` 建立，resident 分支和原记录保留。新增独立产品模块 `human_eye_plugin/arm_twist_expert.py` 与真实学得的 `arm_twist_weights.py`；未修改 host／服务／数值核或另一实施线文件。

**交付了真实训练、冻结权重和可加载推理。尚未证明比现有直接几何方法更有实际价值，不默认替换算子。**

## 模型与输入

- 单款 NumPy tanh MLP：10 维局部特征、12 隐单元、145 个可训练参数，固定 seed 1729／600 步 Adam，一次训练约 **92.873 ms**；未搜索模型／超参数、未根据保留测试修改模型。
- 权重和 train-only 均值／标准差为实际数值张量，存于 4,578 字节的 `arm_twist_weights.py`，SHA `f9f1aced3003728f797d37a5c9a48786bc65425d4ddc0c5f83a81751b6952f1a`。采用已有 Python 包源码容器，随现有 `.py` 打包及来源 manifest 覆盖；没有引入模型注册平台。按需第一次加载，后续复用同一只读模型实例，普通 live_service 导入不加载专家或权重。
- 输入明确为同索引局部 patch、全局 vertex IDs、三角形、显式有序闭合截面、2..4 骨父子链 rest／pose 刚性矩阵及权重。402 点的测试 patch 直接可用，未送入旧 whole-asset 256 点入口。骨架 FK／矩阵及 LBS 构造复用既有 `rig_pose` 数学表达，未改已有来源合同。
- 输出是截面区域及对应全局顶点 IDs 的 **构造扭转异常严重度估计**。原模型没有自动识别手臂、采集任意表面、证明输入来源或执行修复。缺闭环／对应／权重等输入明确拒绝，非平面或不可可靠度量的截面、角度分支不确定则 unknown。结果标记 synthetic scope、caller-supplied source、`execution_authority=false`。

## 数据与隔离

`synthetic.py` 生成 77 个同索引局部样例，11 资产，每个 402 顶点／800 三角形／25 截面。train 8 资产 56 样例，validation 1／7，test 2／14；**形状、骨架、权重族均在 split 之间不交叉**，同一资产全部姿态留在同侧。16 项独立模型测试也检查实际 rest／weight 签名，不只相信 family 名称。

包含正常弯曲、合法小扭转、两种严重 LBS 扭转，以及相同资产／骨姿／权重／角度的独立保截面参考对照。异常严重度来自构造的二骨旋转混合闭式 `4α(1−α)sin²(θ/2)`；独立多边形面积验证它，未用模型特征阈值制造答案。labels、参考顶点、家族、seed、模式信息都不进入模型 packet。预处理仅用 1,400×10 训练特征，独立重算 mean／std 与冻结参数一致。阈值 0.15 在训练前固定。

数据 raw JSON 7,644,870 字节、gzip 2,624,307 字节，保存在 `run_01/dataset.json.gz`；raw SHA `6ccec485cc9fedb832324e3802e1ca4bc8529e55b2171afe4278803c62be1f4d`，冻结权重与最终验收都绑定该值。此数据只有合成轴向截面，不包含真实人物资产，也未验证整段动画。保留集形状和骨架未见过，但姿态仍是相同的少数固定角度，不能声称未见角度泛化。

## 固定保留测试与公平基线

独立几何基线消费同一 rest／current／sections，直接算 3D 有序多边形向量面积收缩，未访问标签、构造参考或模型特征。训练／评估完整记录为 `run_01/result.json`。

| test：14 样例／350 截面 | 学得模型 | 直接几何基线 |
|---|---:|---:|
| 构造任务严重度 MAE | 0.001096 | 0.002526 |
| 最大严重度误差 | 0.017497 | 0.093609 |
| 区域 precision／recall／F1 | 1／1／1 | 1／1／1 |
| 正异常样例平均定位 IoU | 1 | 1 |
| 正常样例误报 | 0 | 0 |
| 仅真正异常扭转的 MAE | 0.000864 | 约 1.10e−16 |

**模型没有提升这组数据的分类或定位，且直接基线对真正收缩的物理量更精确。** 模型总体 MAE 较低，主要因为构造任务允许正常 bend／小 twist 发生少量几何变化而将它们标为 0。它学习的是这种有限任务豁免，不能把这个优势写成几何测量更准确、全面积变化消失或判断了损伤。无正标签的分组 precision／recall／F1 按脚本零除约定记 0；应阅读该组误报数，而非把它当异常召回失败。

77 次同输入组件观察：特征提取中位 **2.556 ms**、纯网络 **0.0118 ms**，基线 **1.1425 ms**。最终新进程的 public analyze 在 14 个保存保留样例上中位 **2.6463 ms**、最大 3.268 ms；首次权重加载 1.0214 ms 另列。不能只拿网络的 0.0118 ms 冒称完整专家速度。当前没有速度收益，主要成本在特征构造，网络本身很小。这些是有限本机工程观察，不是整个 Codex 任务成本对照。

## 最终验收与下一缺口

`final/result.json`／`unit.log`：**81 项零失败、零错误**＝16 项模型、7 项构造、5 项基线及 53 项现有 rig_pose／surface_deformation 回归。包括真实权重改变预测、参数副本、一次加载复用、刚体／物理尺度不变、全局 ID 定位、同角度正常对照、错误输入／unknown 和实际 train-only 预处理。

最终验收不再训练；在新进程重新加载冻结权重，对保存的 14 个保留样例逐截面重放，预测与首次固定模型一致，源码前后不变。分支最终 134 源 fingerprint `97b30d0a1ad73e80f14b8f0ba073689482a9eec3d3495711691f9ed36debeea2`，产品代码 SHA `503ac8dcd8489bd668af4a452478b0faac49add38e728b7331840ed081c88e84`。早期接口仅收两骨，与三骨保留族冲突，在首次训练前已按真实输入扩为 2..4 骨；没有删第三骨或其权重规避测试。

最大缺口是**真实角色局部 patch 的可信采集／截面构造，以及更复杂形状、未见角度和允许形变的定义**。初版没有证明真实资产价值，也不能自行定位任意人物的问题区域。工程上可进一步复用／批量提取已有局部几何特征，但应先由根深审确定是否值得；本批没有第二训练或测试集刷分。几何基线保持默认，模型暂为明确调用的实验能力。

此批 Blender／GPU／外部 API／LLM 消费调用均为 0，训练子进程仅用单线程本地 NumPy；原文件、GUI、竞争分支和全局配置未变。自身 Agent Learning 未绑定、epoch 5、需重绑定；未借根句柄、未伪报同步。复跑训练使用 `train.py <输出目录>`（会重写我方权重），只读验收使用 `verify.py <输出目录>`，均使用已有 Python venv。
