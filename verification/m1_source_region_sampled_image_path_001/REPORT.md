# M1 单视图源选区采样原图路径验收

**通过隔离工程验收。** 候选只为已交付原 PNG 的单视图采样选区简报增加 `images[0].local_image_path`。真实第 2 调的正文从 7,879 B 增到 8,062 B，追加 183 B。原 PNG、选区、最近点对、采样状态和完整可见性 `unknown` 保持原值。 [实际冷、热回包](checks/POSITIVES.json) · [兼容与反例](checks/CONTROL_REVIEW.json)

## 来源与实现

历史 P1 第 2 调的内部 MCP、共有桥和 CLI `item_4` 实际交付同一张 4,015 B PNG，SHA-256 `815eed92ff73118535035ce7f9faf4bfbc798cae0f527ad0c3c7ecd624c4546f`。第 6 调依同 `ref` 重交这张图片并补路径，最终 `item_11` 明确引用它，Blender 关闭后从该路径读回同字节。第 2 调是 `observed_samples`，包含 26,212 个样本、一个已交付原图、空完整见证，生产记录没有矩形分支的 `view_attempts` 或 `constructed_frames`。 [原链路](checks/ORIGINAL_PROVENANCE.json) · [原 PNG](evidence/P1-original-SCENE.png)

新投影复用现有已验证 PNG 的读取和摘要。追加路径前核对单帧 SCENE 的视角、父绑定和源版本、显示参与、采样分组、帧身份、引用及确定性文件名。文件名和帧引用的哈希不包含独立生成目录名。候选从当前 `ReadContext` 中已有生产者的 `output_directory` 取得独立目录，以同槽规范绝对路径和实际磁盘拼写核验。相同 PNG 和 NPZ 同时复制到相邻生成目录也会省略路径。请求的生产者已换代或读锁正被其它线程持有时，省略可选路径。没有重复加载 PNG、NPZ 或几何。 [路径同槽对照](evidence) · [实际公开验收](checks/POSITIVES.json)

兼容包括旧完整见证、无图、零样本、隐藏、部分、矩形低对比或遮挡回退、普通、目标和全场观察及 `full`。失败控制覆盖身份、摘要、视角、作用域、错来源、缺图、错误、重复帧、大小写与跨槽别名。已获有效正采样且其它合同满足的一个像素允许附原图路径，连续完整性仍未知。 [矩阵逐项](checks/CONTROL_REVIEW.json)

**已知边界。** 扩展探针只改私有 producer 的 `frame.PNG_bytes`，声明 4,016 B。实际编码器读取和交付 4,015 B，原 PNG 的 SHA 与独立目录证明仍一致，候选继续附路径。路径以已读取和校验的真实字节为依据。该探针保留，未把私有计数字段视为独立媒体证明。
