# 导轨对照的工具增量判定

沿用原导轨评分文档、独立真值和产品候选采用规则。追加成本逐项绑定实际业务调用顺序和双向原始线包 SHA-256，原答和已审评分有独立哈希绑定。任何有效的同方向遮挡片都可让质量项通过。答案中两条挡片与 B 首包都一致，才满足原候选采用计数。逐端同时记录是否有后续独立求证，按实际行为报告，无法据此观测模型内部因果。

每格首条实际业务调用记 `initial`。此后，为了识别或几何求证指定受阻端的当前挡片而使用普通读算、full 或其他合法工具，每次各计一个追加，包含真实失败及其恢复。一次调用同时解决两个端面时，仍只计一次。为任务其他条件准备的笼统全场取数按原始请求及后续实际用途判断。仅在目标与取数链均有原件依据时计入。用于几何分量、相机选图、格式或用户答案其他条件的调用另列。存在无法定性的实际调用时，该格计数仅保留已确认项，配对不进入门限。调用方向或构图行为与完整耗时由实际账本另报。

每条人工注记含 `attempt`、`request_sha256`、`response_sha256`、`request_anchor`、`increment`、`aim`、`reason`、`blocker_targets` 和 `independent_reproof_targets`。目标是独立评分生成的区域标签。可附 `response_anchor` 和 `from_attempts`。请求锚为实际普通工具脚本中的原字符串、实际参数键值字符串或实际工具名。回包锚为实际 MCP 文本的一段。独立求证必须用真实成功交付的原文支持。恢复项必须绑定现有出错、内容未匹配或按固定预算会截断的前序尝试。每个真实、有审计证据的格含 `answer_sha256` 和按原序完整的 `attempts`。未运行、源无法绑定、或没有完整生命周期的格保留原状态，不参与配对。

门限为至少两对 B 的相关追加次数小于 A。每对列两臂次数和差额。质量、首包证据采用、完整任务时间及 CLI token 按各自原门限判定。
