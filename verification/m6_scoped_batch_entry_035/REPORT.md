# M6 035 同帧双区实验

连接器坏回执隔离修复通过。普通 BlenderMCP 的批量候选未达到性能门，保留原单区路径 A。

## 实测

| 口径 | A / B 耗时中位 | B 配对中位变化 | B 更快 |
| --- | ---: | ---: | ---: |
| 034 隔离助手，完整双区 | 983.668 / 668.569 ms | 快 31.98% | 6/6 |
| 035 普通 add-on，完整双区 | 496.115 / 509.940 ms | 慢 16.97% | 2/6 |
| 035 普通 add-on，首区可用 | 420.572 / 509.940 ms | 慢 41.74% | 1/6 |

配对比例按每轮先求相对变化再取中位。035 主测 12 槽、18 个真实业务回执、24 个区结果。完整回执两臂都保留精确距离、最短点对和规范源面。批量把宿主业务交换从两次减到一次，网格展开次数同为两次。A 第二次已经命中原整网格驻留。034 的宿主助手会在每次业务前后做额外的全场检查。035 使用未改的普通 add-on，在业务窗外做起止证据核查。

## 接入语义

035 只补双区回执校验失败后的原连接器失效规则。对两类无效回执均从真实本地 stdio/TCP 核对，当次无事实发布，同实例后续读取不进 TCP，新实例恢复。原 MCP ping 可继续。真实协议控制中的在途取消通知仍沿旧串行行为，原请求继续完成。普通 GUI 的取消、±Y 现场留出、模型消费和上线未运行。原有资产与现场档案留在本机。

## 复核方式

在机器结果指定的固定公开基线中，依次应用 [034 双区实验补丁](patches/034_B.patch) 与 [035 连接器修复](patches/035_repair.patch)，可重建已核的候选源树。此分支保留原产品源码，补丁供隔离复核。用 [逐轮数据](RESULTS.json) 可复算上述 034／035 的配对统计和所有窗口；现场端到端复验还需私有场景与原始宿主档案。
