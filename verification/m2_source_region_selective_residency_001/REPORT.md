# M2 无图选区驻留实测

隔离候选 `ff0105db` 通过工程验收。装配和 Yanyite 各完成一组真实 Blender A/B，四槽全部安全关闭，12 条量测全部通过。六对结果的距离、方向、实际点对和两端求值源面一致，场景初末指纹一致。候选六条请求均未触发回退。

## 实际业务成本

|场景与请求|宿主 TCP 双向字节 A → B|业务耗时 A → B|
|---|---:|---:|
|装配冷读|111,796 → 116,374|90.596 → 89.394 ms|
|装配同盒复读|6,727 → 4,848|22.650 → 21.366 ms|
|装配换对象和盒|6,564 → 8,880|26.268 → 24.495 ms|
|Yanyite 冷读|134,781 → 139,402|633.519 → 615.754 ms|
|Yanyite 同盒复读|29,712 → 4,886|582.759 → 341.792 ms|
|Yanyite 同对象换盒|17,486 → 19,813|581.050 → 353.671 ms|

- 两次同盒复读在 Blender 主线程重新核对绑定后只发确认。候选的网格展开、三角化、世界坐标变换、选盒扫描和几何传输均为零。Yanyite 双向字节下降 83.56%，业务耗时下降 41.35%。候选本地仍物化并校验已保留的私有包，精确求解继续执行。
- Yanyite 同对象换盒复用两对象的世界网格，精确筛选仍检查目标 27,304 点、53,264 三角。两臂同样发送 115 点、148 三角，含参照整件的 8 点、12 三角。候选业务耗时下降 39.13%，该请求的双向字节增加 13.31%。装配第三条换了对象对，候选实际新展开两对象的 24 点、44 三角。
- 冷读两资产的实际展开和返回点面数均相等，装配返回 20 点、22 三角，Yanyite 返回 233 点、313 三角。两资产首次连接的 Base64 启动源码均为 102,848 → 105,132 B。冷读完整双向字节增加 4.10% 和 3.43%，后续请求无启动源码。请求及响应分别计账。
- Yanyite 同盒、换盒的 Blender 调用区间 CPU 为 562.5 → 312.5 ms 和 562.5 → 343.75 ms。候选保留两个世界网格资源（27,312 点、53,276 三角）。连接器仅保留一个有界私有包，同盒为 25,772 B，换盒后为 13,547 B，上限 2 MiB。最后一次请求后的 Blender 进程工作集为 289,738,752 → 301,682,688 B。工作集覆盖整个进程，该差值包含缓存以外的分配。
- 完整 Blender 窗口为装配 2.737 → 2.213 s，Yanyite 5.980 → 6.000 s。Yanyite 三条业务合计减少 486.111 ms，业务外累计增加 505.868 ms。每资产仅一组配对，完整窗差只作本次成本记录。CPU 采样来自进程计数器，分段时钟有嵌套和重叠。

## 准入与证据

四个真实 MCP stdio 和本机 TCP 回放槽的 12 条请求通过与正式共用的闭槽核验，四个独立冷入口到达预约前。6 项准入反例、12 项连接器反例及 18 项实装驻留控制通过，另有 10 项带模拟 Blender RNA 的宿主控制，计入离线分母。旧归档 956 件按原件复核。预飞核验识别旧宿主对整数零的浮点序列化，同时保留负零区分。正式冻结后无补跑。

候选只构建、隔离安装各一次。标准公开目录与原部署保持既有行为，私有选区身份独立于全场。正式 4 Blender、12 业务，零图、零模型、零替补、零资产重建、零额外 API 或费用。
