## QA 与旧合同迁移记录

原六文件的 128 方法失败记录保留。旧 scheduler Mock.observe 注入改为当前实际 discover 函数注入，保留全部数值、有限三角与失效断言。只读 task 改核动作 journal 字节保持，selected bridge 改核既有 resident 初始化与热请求两类真实传输界。旧 129×128 理论门断言改为固定可剪枝平行三角的实际 1 米答案，4096+1 总面数早拒绝保留。算法 memo 期望仅更新为新的 bvh-v4 版本。已验证的最小修改同步到正常 verification 入口，原字节与精确 diff 均保留。

纯 QA 错误亦有原件。最初过严 socket 哨兵阻挡了既有 loopback fixture，后改为仅允许 loopback。迁移首跑的新增 audit 断言读到缺 task_work 的旧 overview event，修正为选择真实 task event。新机制 loader 首跑误用了旧测试路径，0 方法原件保留。机制第二跑结束后的 Fraction 证据不能直接 JSON 编码，修正为显式 numerator/denominator 后，第三跑完整保存。

node-wrap 原测试错误要求每个合法可分角域都获得证书。该固定对称几何的四条有限 support 线均含 anchor 加两侧不同边界 ID，共三个 ID，按已冻 online-ID 至多两个的合同必须保守 fallback。NODE_CASES 原字节保持，EXPECTATION_AMENDMENT 单列纠正，并新增两 root 均保留有效 wrap anchor 的断言。其他正例仍要求真正产生证书。

本 QA 未启动 Blender、真实 MCP 进程或模型消费者。实际隔离入口由根和入口代理另行核验。当前结果表明昂贵叶工作减少，但新增树、投影、metadata 与遍历仍未让闭壳验证完成。本批没有追加策略、放宽预算或新增调参样本。
