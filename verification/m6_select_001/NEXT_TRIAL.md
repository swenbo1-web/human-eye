# 下一批建议

建议批次为 M6-REAL-TASK-AUDIT-001，待规划者独立复核后派单。

## 可交付目标

围绕本次“任务条件下手臂修正”取得一个真实来源绑定的局部样本及明确任务，判断现有闭式几何是否覆盖。首个样本用于发现问题与核实数据链，样本外质量和速度需要后续独立数据。

开始前冻结原件、来源、静态版本、帧、rest/current 顶点、同索引 ID、三角形、闭合截面、权重及完整骨链矩阵。任务提供允许修改变量、固定端、u 区间、保护点、面积目标、容差和接受标准。现有 source 合同要求可信来源和 LBS 一致性。缺少的字段逐项交付，无法取得可信 patch 时以缺失清单结束该批。

## 基线与探针

1. 只读检查闭式域的每项条件，保留具体通过或拒绝原因。
2. 适用时调用现有 `clip(theta/2, interval)` 解并独立核验实际 LBS、面积、端姿态和保护量。域外例仍保留原任务，先分析直接一维几何求解能否作为同约束基线。
3. 在运行前固定探针输入与独立答案方法。骨矩阵、权重和目标全部来自实际任务。将不同操作类型的人工修正作为另一个待批准输出问题登记。
4. 若几何达到原质量目标，保留该路径并结束本次证据批。若实际失败，明确失败属于输入不充分、域检查、可行集、目标定义、解算或执行反馈，再决定模型输出任务。

## 模型与数据门槛

M6-SELECT-001 的候选数为 0，下一批训练数为 0。当前三骨域已有闭式最优答案。树/MLP 回归同一公式没有已证实的质量机会。RBF/形状基路线需要固定角色、真实接受修正、形状基及连续系数标签；点云/图路线需要真实跨角色输入和与任务一致的输出监督；时序路线需要序列和绕数标签。当前资料尚未满足这些路线的任务依据。
