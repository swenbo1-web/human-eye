## 已闭实际结果

- 断开宿主的输出合同 A/B 各 10/10，覆盖普通非空间提示、空间提示得到明确观察不可用、变换与间隙工具 Post 不追加重复文本、非法 JSON、错误注册事件与畸形 PreToolUse 拒绝。双方交叉使用对方身份固定时按 implementation_revision 和 build_id 不符拒绝，`allow_action=false`。候选 Windows console 另 3/3。断开试验持有未监听的专用回环端口，零 Blender 与局部状态账本。原始矩阵在 `RESULT.json` 和分臂 `HOOK_RESULTS.json`。
- 已封存 G60_D12 一次隔离 Blender，两臂先后对逐字相同的普通只读空间提示实际返回 `overview/complete/not_requested`。两份 12 对象与全部 72 个单臂世界包围盒坐标逐项相等且现场前置世界顶点独立核实。两次均为单一 `host.capture`，未授权执行，零实渲染，原始与终态世界网格相同。Hook 进程 1,234.472 / 1,202.521 ms，包含 Windows 包装和固定校验。内层宿主跨度 81.085 / 64.848 ms，Blender 工作行 60.699 / 54.340 ms。单对仅用于覆盖。受保护 desktop Hook、MCP、连接配置、状态及冻结源资产的哈希相同。本次 Hook 的 Blender 安全关闭并回收，退出 0。
- 原在线审阅以 `host_execution` 须为 null 误拒两臂。原件 `live/RESULT.json` 完整保存。闭槽派生 `live/CLOSED_HOOK_REVIEW.json` 通过 2/2。两份 `host_execution` 仅描述刚体可执行能力，其它字段、实际 TCP 捕获、无执行权限及世界网格共同确认没有执行操作。未重发任一原请求，无更多 Blender。

## 审计缺口

两个固定 launcher 的轻路径均在 `_LightService` 隔离生成失败。守卫开启后 `runtime_identity._bind_task_source()` 从 `sys.modules` 取未注册的 `_human_eye_hook_leaf_runtime_identity`，抛出 KeyError，由 Hook 主函数转为正常的空回包。普通提示与 Post 的 `host_hook_skip` 和对应 trace 因此在固定入口缺失。两份 traceback 保留在 `A/light_path_diagnosis.json` 和 `B/light_path_diagnosis.json`。候选普通 console 的旁证可实际写入缺失的轻路径记录。双方固定 launcher 的重路径真实记录各自 build_id、`host_hook` 和相关 `request_trace`，不受该缺口影响。

这里的 Hook 证据是对实际注册命令的隔离输入与输出核验，以及两条实际 Blender 几何读取。自动 Codex 宿主派发及信任生效没有执行。
