# M6-ARM-EXPERT-OPT-001：静态准备与批量特征收口

从 `ef84ecc59f107321225d0d832fde119ed0b91e3f` 继续，产品仅修改 `human_eye_plugin/arm_twist_expert.py`。权重、数据和阈值冻结，没有训练／模型选择／测试集调参。

`prepare_patch(patch)` 返回独立的 `PreparedArmPatch`，只读取静态 schema／unit、rest、索引／全局 IDs、骨链 rest、权重和拓扑；不要求 current 或 pose。准备一次后，用 `prepared.analyze(current_vertices, pose_matrices)` 获取完整报告，pose 保持原骨顺序。静态结构或 rest／weights 改变应重新准备，原输入后续修改不会污染已准备对象。没有全局 prepared 缓存或每姿态哈希。

一次准备保留分组索引、rest 几何／权重统计和骨链 rest 相对逆矩阵。热路径只校验动态 current／pose，并按截面长度分组批量求中心、协方差特征值和周长，恢复原截面顺序。`extract_features`／原 `analyze` 与 prepared 共用计算和报告，原 raw 的验证顺序保留。返回 context／区域索引为独立副本。

## 完整成本，固定候选只做轻量观察

输入为已解码的 Python patch，输出完整带索引报告；双方均不计数据文件读取／解压。最终 run02 共 466 次轻量本地调用，14 个保存保留姿态每模式各一次；没有重 CPU 搜索或反复刷最好值。

| 路径 | 中位耗时 ms |
|---|---:|
| 冻结旧版完整 raw 报告 | 2.62615 |
| 新版完整 raw 报告，含验证／准备／计算／输出 | 1.23940 |
| 静态一次 prepare | 1.00135 |
| 动态 current＋pose → 完整 prepared 报告 | 0.22630 |
| 几何基线完整 raw 索引报告 | 1.16325 |
| 几何同等一次准备 | 0.63065 |
| 几何 prepared 完整索引报告 | 0.56270 |

本次完整 raw 组件约减少 **52.8%**。两份七姿态资产序列分别从 **18.4325／19.0874 ms** 到 **3.9418／3.9564 ms**；后一成本还包含 harness 从首个完整 patch 构造静态输入时的 deepcopy，属于保守的完整准备流程。单独 prepare 和 hot 分项不含这份 harness 输入复制，不能混淆口径或将 hot 当作 raw。

冷权重导入／张量构造另列：旧 0.8131 ms，新 0.5586 ms；只是 Python 模块冷载入，未清 OS 文件缓存，不把该差异算成本轮算法收益。几何也获得缓存 rest／索引的预备机会，但其验证合同／标量实现与模型不同；这里不宣称学得模型能力优于几何，也不把组件耗时当整个 Codex 任务耗时。

## 发现与修正

独立审查实际复现：有限 rest 坐标乘 `1e155`／`1e200`，旧版会先返回角度分支或中心线 unknown，最初 prepared 实现提前 `eigvalsh` 却抛 `LinAlgError`。本批先算中心线条件，必要的静态数值失败延后，并在罕见批量特征值失败时仅对失败批次逐截面记录结果，动态阶段沿原先后次序处理。正常路径仍为批量计算；没有通过新增坐标上限掩盖回退。反例保留在两份独立测试中，最终全过。

修正前完整 optimized 源码未单独封存，不声称存在失败源码归档；失败来自本轮实际 review 工具输出。`benchmark_run_01` 是修正前的非最终来源，已有 `NOT_FINAL.md`；原记录保留，最终数字只来自修正后同源 run02。

这次优化只改变执行方式。保留测试仍只有 **2 资产、4 异常样例、14 个阈值阳性截面**；不把 350 个截面解释为 350 个独立资产。模型和几何分类／定位仍打平，真实异常的几何收缩量仍由直接基线更准确。真实人物局部采集、截面自动构造、未见角度与真实资产价值仍未验收，未扩域或自动修复。

本热点在本轮实现与必要正确性修正后收口，不继续第三轮。Blender／GPU／训练／外部 API 为 0，轻量数值运行使用单线程本地 NumPy；其他实施线、原资产、GUI 和全局配置未变。自身 AL 未绑定、epoch 5／需重绑定，未借根句柄。

复跑相关回归：`verify.py <新输出目录>`；成本及冻结旧版对照：`benchmark.py --out <新输出目录>`。两者都只读既有权重／数据，不调用训练。
