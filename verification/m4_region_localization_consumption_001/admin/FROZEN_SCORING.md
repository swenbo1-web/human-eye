# 冻结评分规则

评分先于速度与模型用量排名。六个正式槽全部进入分母。

1. Exact supported target set with no omitted, extra or duplicate region.
2. Every finite-pool-reachable region covered by actual current-slot complete front-facing readable frame evidence.
3. All finite-pool-unreachable regions have accurate bounded reasons and the unsupported source remainder is retained.
4. SCENE click identifies its actual surface center, front direction, extent and current image ref.
5. Origin +Z face is correctly distinguished from a back face and its SCENE visibility and any actually observed readable witness are correct.
6. Specified bottom -Z face remains unknown within the finite six-view pool, without an all-viewpoint impossibility claim.

原生身份可用源三角形集合、世界四角或唯一中心和朝向。机器可读集合由本次工具结果或最终答明确引用的本次文件承载。

覆盖必须具有该槽实际完整几何、正向、至少16表面像素、4个RGB距离至少24的边界像素及当前图引用。任意正确视角组合均可。

有限池未知与域外余量应保留。缺失、重复、多算或仍可补齐的未观察面都会影响完整巡检判定。三项定位分别核对图像像素归属、世界位置和有限相机池范围。

原始答文、引用文件、工具请求与结果、当前帧及生命周期均核不可变字节。普通工具业务错误保留并允许原合同内恢复。

旧图像只用于管理员真值准备。正式像素与图片归属读取各槽自己的新原件。图像实际交付与数组证据资格分别记录。

数值按有限有理数精确比较，支持等价十进制、分数及正比例法向。定位范围可用四角、中心与半边向量或世界边界。

归一化只摘录原始最终答、实际工具正文和明确引用的当前文件。程序验证字节绑定与几何像素事实，原文是否蕴含每项声明由独立审查核验。

质量包移除结构化时间、用量与成本字段。工具能力与答文可能透露路线，无法承诺完全内容盲法。六槽评分先封存，随后才解锁成本排名。
