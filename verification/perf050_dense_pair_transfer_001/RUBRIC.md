# 密集装配的共同验收

两臂使用同一题面、评分、独立真值和容差。分数基于未经改写的最终答复及其当轮工具原件。

| 分项 | 通过条件 |
| --- | --- |
| 功能面定位 | 正确定位 M4_Far_00 朝上矩形功能面。实际来源为三角 512–513。唯一明确的等价几何或引用可用。 |
| 完整可读性 | 所采用的实际原图包含完整区域、两片源三角和四角。当前全场几何证实前向、未出界且无正面积遮挡，像素至少 16 个表面和 4 个达标边界。原图须能在当轮交付中绑定到图像块和当前源。缺证答复按真实可验证的情况评分。 |
| 最终原图交付 | 原答显式给可用本机图像、Markdown 文件引用或真实附件。利用答复引用闭槽后从同槽文件读回和当轮原图块同 SHA 的字节。记最终另一次读图、展示和真人点击的实际状态。 |
| 整件最短表面距离 | M4_Far_00 到 M4_Focal 两整件当前表面的距离为 1 m。允许 0.05 mm 输出绝对误差。仅顶板几何的 √2 m 是独立区分输入范围的反例。 |
| 世界方向 | 前者最近点到后者最近点的归一化方向为世界 −X，允许 0.5°。 |
| 实际表面点对 | 给出一组有序最近点，分别在两件当前求值表面上，位移和距离与真值一致。允许同等的最近点对以及 0.05 mm 输出坐标容差。 |

记录首次实际量测请求和失败，按请求判定是否采用有序对象对入口。原生等价计算按同质量评分。输出的原图、最终引用和闭槽复读分别核验。CLI 耗时和账本按实际槽，单对时差作为诊断数据。
