# Formal scoring procedure

Apply the frozen `RUBRIC.md` to N1 and P1. Keep both original slots and the nine criteria per slot even when a slot fails or is unrun. If derived admission fails, mark all nine criteria of both unstarted slots `unrun`. Record admission, runtime status and answer quality separately.

Reduce each original answer to criterion annotations after its original bytes are sealed. Quote the original text verbatim for a pass. A `fail` identifies an actual contradiction or omission. `unverified` identifies unavailable current evidence needed to decide an otherwise stated claim. Preserve legitimate alternative numerals and identities. Reported decimal geometry is checked using the larger of half the printed unit and `1e-6` in SI units. Assess an image statement on its own captured geometry, including ROI identity, facing direction, framing, owner pixels and contrast. A repeated image or shared view label does not merge the distinct frame identities. A proven image qualifies for the cited target even if the same frame contains other geometry. A reported extra completeness or geometry statement is judged separately from whether a frame qualifies.

Run `formal.py evidence` after original answer seals or after a failed derived admission record. Verify the current freeze and admission bytes, old recovery freeze and unchanged false gate, old raw qualification seals and derived replay. Check that each started formal slot's original start and result receipts bind the same new freeze and admission. Evidence checks use the frozen Blender-derived truth and the same-slot detailed source receipts from before tool admission and after tool completion. Bind both to the generic worker PID, protected owned copy, registered deadline, READY fingerprint and original WORKER_CLOSED fingerprint. Compare original native and evaluated local/world coordinates, triangle and polygon order, transforms, display masks, layer collections and cameras across the two reads. Match both reads to the saved Blender reload arrays and visibility. Score closure only when the original file, process reaping and retained-handle exit also agree.

Bind the exact original PNG in the owner and stdio wire replies to its frame reference using the producer frame order or the ordinary image-attachment receipts. The frame's object/instance ordering, evaluated-triangle offsets and display mask must match terminal geometry. Verify against the frame's same-slot color archive and the verified public CLI receipt classification. Measure surface and contrasting boundary ownership from the original arrays. For completeness, require that all region vertices project within the orthographic frame in a direction for which the independent finite-view oracle certifies clearance.

Run `formal.py grade` after evidence. If a sealed answer exists, provide an annotation JSON with `--claims`. Each original is keyed by `N1` or `P1`, with `answer_sha256` and a `gates` mapping using the registered gate names. For geometry passes include `triangles`, `center_world_m`, `area_m2`, and `unit_normal`, recording reported numerals as strings to preserve printed precision. For witness passes record `resolved_delivered_ref` and `direction`. The manual annotation must identify the actual stated source and distinguish quoted reference identifiers from a reviewer-resolved alias. Check the unknown explanation against finite-pool positive-area blockage and the lack of a valid complete frame. Record contradictions and unresolved claims with their original near-quote if present. The grader verifies binding and numeric gates but does not generate manual annotations or read model reasoning.

`replay_frame_controls.py` checks the same scoring path against the two original qualification slots and their actual PNG content. New formal judgments require each formal slot's original delivery ledger and answer. No scorer action invokes Blender, rasterization, the product, a model or a provider service.
