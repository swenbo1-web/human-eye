# 多层遮挡全场任务的正式原生／插件对照

在同一个固定的 21 对象、148 顶点、184 三角合成场景中，两个正式槽均完成。**独立评分原生 8/9，插件 9/9。** 两路都找齐三个区域。插件组交付了 M09 的 `LEFT` 局部证据，原生组用满构图预算后缺少该区域的完整可读原图。插件组在本对使用更多工具和输入 token，完整窗长 **35.962 秒**。

## 准入和实际原答

新的离线准入使用恢复批两份真实资格原件。归档器只解析指定的 JSON 事实正文，将其后的普通图注与对应 PNG 按原序绑定。两种实际回复、图像或引用错配、正文损坏及正式 CLI 多文本顺序均通过回归。原生旧槽 `failed`、插件旧槽 `passed`、旧总资格 `false` 与旧正式未运行结果保留。新批资产构建和额外 Blender 资格均为零。两个正式 Blender 独立副本的前后显示、原生及求值网格和场景指纹一致。

正式启动前的一次 P1 启动器检查拦下了对已冻结准入脚本的编辑。差异留存为未采用提案，恢复冻结字节后才进入原 P1 槽。第一次检查没有创建 P1 槽、Blender 或模型，亦未消耗该槽的预算。最终两个正式槽绑定同一冻结和新准入。此次额外的启动器检查单列，未纳入两个 owned 槽的时长。
