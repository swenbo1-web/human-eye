# 003 准备期静态调整记录

根在冻结前发现资格器握手轮询存在一个有限竞态。原逻辑在 `HANDSHAKE.json` 尚不存在时进入循环，紧接着发现 `process.poll() is not None` 就抛出 `probe_exited_before_handshake`。child 可能在两次观察之间完成握手发布并正常退出，原判断会误拒已经发布的有效握手。

调整由资格器作者在冻结前完成。退出分支再次观察已原子发布的握手文件，存在时进入原有身份、环境与 PID 校验，缺失时才保留退出前未握手错误。该调整只消除轮询时序误判，原握手期限、实际退出和严格身份条件继续适用。

本项来自源码审查。没有为其启动探针、engine、renderer 或补充准备样本。最终实际字节绑定见 `STATIC_RESULT.json`。

资格器作者同时记录了一次准备期静态自查修正。新增 probe 来源绑定曾放在没有 `handshake` 参数的作用域，最终移入接收该参数的 `environment_checks`。最终源码同时核 probe 路径和冻结摘要。此项没有实际启动样本。

最终清理函数把 kill 与有界 wait 分成两个保护段，kill 抛错后仍尝试通过原持有句柄等待退出。任何清理错误继续保留并使 confirmed 为 false。
