## 核验内容

- bridge.py 与 bootstrap.py 和已验收 VIEW 文件逐字节相同。native_tools.py 的唯一行级差异是增加 D:/he_complete_witness_001 受保护研究目录，既有真实 raw/patch 缓冲与默认帧复用入口保留。
- PLAN 只含 P1/P 一个正式消费者，固定 sol/medium/default、450 秒、12 业务调用、6 raster。SOURCES 使用同一个 ledger，preparation6、formal6、total12、per-owner6，四项源输入 SHA 与实际文件一致，绑定当前 d8ad 产品与 141 源文件。
- qual_driver 创建唯一 Q1 目录和一次启动标记，经真实 TCP 发 initialize、tools/list 和一次 active_observation(include_images=true)。退出路径通过 finally 发 stdin 结束、等待进程并调用既有 held-handle cleanup。清理和来源回读后的时刻达到原期限时判失败。
- launcher 先核私有资格结果、实际 run SHA、相同 FROZEN、prompt、源输入以及仅含资格阶段的 ledger 前缀，再独占创建正式目录并只调用一次原真实 route。资格缓存、图片与判断材料不进入正式 actor 配置或 prompt。正式 Python 文件审计阻止读取其它 Dcomplete 输出。
- 原真实 route、consumer、archive、结果绑定和 cleanup 的函数及 code 对象沿用原入口。新命令在核对旧容器参数后改为本批 6/12 限额及 VIEW bridge 路径。前后 pointer proof 不通过重新加载旧模块改变引用。
- 早期 source 枚举曾遗漏私有判定 JSON/schema。本次准备阶段已修正，最终 source_file_list 强制四项私有判定材料存在并加入冻结，继承 VIEW 与 Routed 来源闭包。动态 QUALIFICATION、QUALITY 和启动记录均不作为新来源输入。
- 最终 prompt 给出支持域、通用完整/可读定义、既有 16/4/RGB24 像素条件及公开目标名 Panel_A。未给正确 ROI、正确相机、答案数量、资格结果或示例答案。最终题面 SHA 与 PLAN 一致。
