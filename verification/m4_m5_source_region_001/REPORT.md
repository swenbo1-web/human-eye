## 入口与当前来源

```json
{
  "session_id": "example",
  "include_image": true,
  "query": {
    "mode": "source_region",
    "region": {
      "object": {"name": "Obj_07"},
      "source_triangle_indices": [0, 1, 2, 3]
```

首次选择返回自包含 region_ref。后续请求用该公开返回值替代 region，选择新的 reference。region_ref 绑定 document_epoch、host/instance、完整场景当前 generation、有序几何摘要及所选源三角集合，区域身份独立于参考对象参数。来源变化使旧引用以具体原因失效，新的当前选择重新绑定。

索引域为当前求值捕获网格的对象内三角行。区域子网格保留原始三角及顶点反向映射。M3 复用现有精确表面距离内核，私有 holder 传递已有 exact 最近点，逐源三角验证归属后交付原捕获行号。量测覆盖完整所选集合，参考对象使用完整表面。

通用 SceneObservationImages 从矩形门控中提取，提供 RGB、depth、object owner、triangle owner 及完整映射。图像保留全部场景遮挡几何，区域相机拟合所选源顶点，深度覆盖全场。当前可见性给出实际选中面像素、可见／未见面行和图像引用。完整曲面可见性继续为 unknown。旧矩形完整见证、active 默认／region_task 及 M5 whole_objects 保留各自入口和语义。

## 一次优化及取舍

R0F 已在第二次请求复用区域准备和图像。真实首个冷请求的 frame validation 和选中像素阶段为 10.7086 ms。候选复用本实例刚发布帧的完整当前数组，消除该路径重复的 NPZ 解码。

私有 proof 绑定原 frame 对象、相机／来源／路径元数据、不可变数组元数据快照和当前完整 buffer／mapping 内容摘要。每次仍读回 PNG／NPZ 并核对哈希、owner、dtype、shape 和 PNG RGB。保存帧、外来或元数据变化帧进入原解码校验。旧 Active 默认路径保持原解码行为。

候选初稿存在 NPZ 写完至首次读盘哈希之间的完整性窗口，独立 synthetic 反例证明替换有效 archive 可被错误接受。该失败保留。修正后的私有路径先由固定 NumPy 编码器生成 immutable BytesIO 字节并固定 SHA，再写盘和核首次读回，成功后授予 proof。旧路径与候选均通过精确替换反例。此修正属于同一候选的完整性收口。
