# 唯一数组复用候选独立源码复核

当前候选通过25项定向控制及2项实际文件出版窗口控制。SOURCE_REVIEW.json与PUBLICATION_WINDOW_REVIEW.json固定实际import源码SHA。active_observation_images为221c97dd5a1474d6cdb08434ff8ef219bcc2427af05246aea751fa0ec8a916d0，source_region为8be8ba75b7416eac187d211850387b4df7a4fbe45a230eb0ac00e52036557131。本复核没有修改产品源码。

## 源码与正常入口

优化开关只由source_region创建SceneObservationImages时启用。默认Scene路径及ActiveObservationImages沿原NPZ解码路径。独立控制实际调用旧Active的render_next和observe_frame，取得可读区域并记录1次np.load。source_region正常入口在追加host_binding、source_revision和image_ref后仍得到fresh_payload_reuses为1、frame_array_decodes为0。其后同prepared热请求保持同一帧且新增raster为0。

复用准入同时依赖同实例原frame对象、独立保存的验证元数据签名和全部当前数组的dtype、shape、nbytes及内容SHA。数组包括color、depth、object owner、triangle owner、patch owner、源面偏移和patch映射，以及owner元数据。private proof保留原签名和不可变数组摘要元组，调用者修改frame中的arrays描述不能更新原证据。

每次validate_frame仍读取PNG及NPZ并核SHA。新出版路径先用NumPy编码为私有压缩bytes并取得原SHA，写盘后核首次读回SHA，再授予复用证据。原shape、owner范围、三角到对象/patch对应和PNG RGB解码逐像素核对继续执行。shallow dict、deepcopy、saved frame及描述变化控制均走原np.load路径。

## 篡改与出版窗口

5种buffer单独变异、face_patch_ids、face_patch_offsets、owner_schema数组、frame的owner/mesh/camera身份及已出版PNG/NPZ字节篡改全部被拒绝。修改NPZ为另一个具有相同数组的合法archive并同步调用者SHA时，验证走原解码且接受，保留原saved-frame语义。

初稿存在真实出版窗口。文件写完后、首次Path.read_bytes取得SHA前替换为另一个有效NPZ，旧路径拒绝frame_array_payload_mismatch，初稿fresh路径接受与源buffers不同的磁盘color。PUBLICATION_WINDOW_REVIEW_02_CONFIRMED保存原失败及源码SHA。修正后同一精确文件反例在旧路径与fresh路径均拒绝，fresh错误为actual_frame_array_bytes_required。PUBLICATION_WINDOW_REVIEW保存最终结果。

更早的PUBLICATION_WINDOW_REVIEW_01_ENCODER_SIMULATION替换了NumPy编码器输出，仅作为发现窗口的初始模拟证据。本复核沿用NumPy编码器正确序列化输入数组的现有信任边界，没有把该模拟提升为需要自证第三方编码器的要求。

私有压缩bytes的临时长度在frame.temporary_encoded_archive_bytes及work同名字段记录。frame.stages.private_encoded_archive记录起止、保留字节0和生命周期。BytesIO分配器开销及进程RSS没有测量，完整两请求业务收益仍由根的固定三对实测决定。

## 区域相机、当前来源与范围

R0F相机由所选区域顶点拟合XY范围并由全场bounds给保守深度。transport的ReadContext选择key包含当前完整capture source binding与全场有序几何摘要，内部区域准备按region_id查找，reference另进入量测key。该路径没有global-camera标识或固定跨度依赖。区域帧绑定实际region-fit camera specification及source binding。

region_ref含源对象、实例、当前generation和全场有序几何。每次请求先fresh捕获并验证。reference对象或其它遮挡物移动会改变完整几何摘要或generation，旧引用得到具体失效错误，新显式区域选择进入当前新准备。reference参数从B切换C保持同状态准备和帧复用。该缓存与旧引用路径的产品源码在本次唯一候选中没有修改。

本复核合计运行3次数组控制及3次出版窗口控制，产生16份合成PNG与16次mock raster buffer返回。实际Blender、公开live请求、production attention raster和付费模型调用均为0。所有初稿及最终结果分别保留。
