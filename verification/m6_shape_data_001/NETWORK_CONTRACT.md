## 目标、输入与坐标

目标为给定异常观察、原拓扑、用户允许的宽区域和正常周边，预测逐顶点三维修正。正常点的监督位移为零。当前监督来自同源人为凹陷与未扰动配对，只覆盖这一构造问题族。

每图使用 384 个宽允许域顶点及两环观测 halo。允许域的结构边界与 halo 为固定点，内部为可写点 F。相同 patch 的正常及六个损坏观察使用同一允许域和拓扑。模型函数只接收观察坐标、局部邻接、宽允许 mask 和固定/halo mask。

来源、角色、文件名、源顶点 ID、样本编号、生成中心/半径/幅度、真值支持和正常内部坐标留在追踪或监督侧。邻接数组的本地索引只用于寻址，不进入数值特征或 embedding。

令 c 为固定/halo 观察点的均值，l 为观察 context 边长度的中位数，q_i=(p_i-c)/l。c、l 都从当前异常观察取得。若中位边长非正、非有限或特征非有限，记录输入不适用。观察法向按已有三角形 winding 的面积加权叉积计算，未使用参考法向。保持源拓扑的方向约定，不以质心方向强制翻转自然凹面法向。面积法向和为零时保留零向量并计数，当前231例的context零法向出现次数为0。

输出恢复为 p'_i=p_i+l·delta_i，仅向原始 binary64 观察副本的 F 写入位移。固定边界与外部点保持原始数组值。零残差直接保持输入，避免经归一坐标反构造导致无意误改。

## 唯一网络

采用宽度 24、权重共享的局部消息传递 cell，加旋转协变向量残差头。位置在传播过程中保持观察值，最终只输出一次残差。

7 维 node 标量为以下各一维。

- 归一观察径向长度 ||q_i||。
- 观察 Laplacian 的有符号法向投影 n_i·(mean_j q_j-q_i)。
- 观察 normal variation，mean_j(1-n_i·n_j)。
- 归一平均邻边长度 mean_j ||q_j-q_i||。
- log(1+degree_i)。
- 宽允许域 mask。
- 固定边界/halo mask。

4 维有向 edge 标量为 ||r_ij||²、n_i·n_j、n_i·r_ij、n_j·r_ij，其中 r_ij=q_j-q_i。原网格无向边展开为两个方向，无 self edge。self 信息由残差与 h0 注入保留。前五项 node 连续量及四项 edge 连续量只使用训练观察拟合均值/标准差，两个 mask 保留 0/1。标准差下限固定为1e-6。预处理共 18 个持久化标量，计为非训练参数。

上述 node 邻接统计与法向从完整当前观察的原始邻接和 incident 面计算，再取 context 对应行。消息传递仅在保存的两环 context 图内进行。当前准备实现读取完整观察网格，完整动态准备成本应计入运行入口。源索引仅用于取数，进入网络的图索引已经局部重编号。

node encoder、edge MLP、node update和alpha head采用Linear → SiLU → Linear，最后一层无激活。beta head为单层Linear24→1。每个Linear都有bias。

| 模块 | 维度 | 可训练参数 |
| --- | --- | ---: |
| node encoder | 7→24→24 | (7×24+24)+(24×24+24)=792 |
| 共享 edge MLP | (24+24+4)→24→24 | 1872 |
| 共享 node update | (h24+mean-message24+h0_24)→24→24 | 2352 |
| 共享 LayerNorm | 24 个 scale 与 24 个 bias | 48 |
| node alpha head | (h24+h0_24)→24→1 | 1201 |
| edge beta head | 最后一次 edge message24→1 | 25 |
| 合计 | K 步共用 cell 参数 | **6290** |

每步为 m_ij=phi_e(h_i,h_j,e_ij)，a_i=mean_j m_ij，h_i←LayerNorm(h_i+0.1·phi_v(h_i,a_i,h0_i))。alpha 与 beta 两个末层初始权重和 bias 均为零，使初始网络为 no-op。

最终 delta_i=alpha_i·n_i+mean_j(beta_ij·r_ij)，固定点硬置零。辅助支持分类头不在本首轮配置内。模型参数量由上表复算，实际实现另用参数张量计数核对。

几何标量在平移和 proper rotation 下不变，n_i 与 r_ij 随同一旋转变换，因此残差随旋转变换。尺度由观察 l 归一并在输出恢复。该构造限定为一致 winding 下的 SO(3) 旋转协变。全局反转法向和镜像的行为需另行核实。它沿用等变图网络中“标量系数乘相对向量”的方法，并加入观察法向基，属于本任务的具体设计。[EGNN 原论文](https://arxiv.org/html/2102.09844v3)

MeshGraphNets 支持将网格邻接用于消息传递、共享局部计算及逐节点输出。论文实验属于物理系统模拟，本合同的 6290 参数配置和连续凹陷恢复效果仍需本任务检验。[MeshGraphNets 原论文](https://arxiv.org/abs/2010.03409)

## 一种直接局部基线

唯一直接恢复基线为**带残差门控的鲁棒二次 MLS 局部投影**，另保留 no-op。它只读取同一异常观察、拓扑与宽允许域，每个可写点独立拟合观察周边，并从冻结观察同时产出一次位移。

具体初始配置如下，当前不实现或测量。

1. 在同一冻结两环context图内，以观察边长度取测地邻域d_G≤8l，只保留观察法向与当前拟合点法向点积≥0.5的同表面样本。至少需要12个点与满秩二次设计矩阵，否则该点返回零位移并记录原因。
2. 在观察切平面坐标拟合 z=a u²+b uv+c v²+d u+e v+f。距离权重为 exp(-(d_G/(4l))²)，使用三次固定 Tukey IRLS，截断常数 4.685，残差尺度取 1.4826·MAD 并保留数值下限 1e-4·l。
3. 令 r_i 为观察点到拟合曲面的有符号法向残差。门限 tau 为训练正常控制上 |r_i|/l 的 99.5% 分位数，训练集确定后固定。
4. 位移为 -sign(r_i)·max(|r_i|-tau·l,0)·n_i，固定边界/halo 硬置零。它保留低残差观察形状，逐点决定是否修正，运行时没有标签定位。

基线的窗口、IRLS 次数、常数与门限规则在后续比较前冻结。训练正常数据上的门限校准次数和成本单列。验证/保留测试不重新校准。数值不适用点回退为 no-op，仍计入全部质量分母。

局部多项式拟合可逼近曲面，鲁棒统计可减少异常样本和跨锐特征样本对拟合的影响。上述 Tukey 门控是本合同的简化适配，原论文的 robust MLS 使用 forward search。原证据主要涉及扫描噪声、离群值和锐特征。连续、空间相关的凹陷可能污染整个拟合邻域，本基线在该问题上的收益待实测。[MLS 原论文](https://www.dgp.toronto.edu/~hertzman/courses/csc2521/fall_2004/alexa-pointsets.pdf), [Robust MLS 原论文](https://sci.utah.edu/~csilva/papers/sig2005.pdf)

## 完整允许域损失

对每个损坏观察，A 为全部宽允许域，S 为实际非零逆位移点，N=A\S，N_F为N中的自由点。S仅用于监督损失和评估。标签为delta*=(reference-observation)/l，覆盖A的所有点，正常点标签为零。当前231例包含88,704个允许域顶点观察，其中受损6,042、正常82,662，正常自由点66,793。这个分母按观察累计，包含同源patch重叠。

定义E_i=||delta_i-delta*_i||²，L_A、L_S、L_NF分别按各自实际点数取均值。损坏case的位移损失为0.2L_A+0.4L_S+0.4L_NF。正常控制S为空时使用L_A，支持域指标记null。一般空集合项取0，移除该项权重并按剩余权重和重新归一，避免除零。每图再加0.05倍全输入边上的监督残差梯度误差均值，固定/halo的目标和输出均为零。批损失按图等权平均。

分别保存S、N、N_F、A和边的计数与未加权误差。正常点质量同时按完整N与N_F报告，固定点零误差的数量单列。支持点数量小时仍有明确监督权重。损失中的标签权重与支持集合不传入前向特征，不形成推理路由。

## 单次首轮训练与一次优化

首轮实现建议为 PyTorch CPU、float32、单线程、无 AMP、无 dropout。训练种子固定 1729，记录 Python/NumPy/框架版本和确定性设置。现有两个指定 Python 均未发现 torch。训练运行库准备属于未来训练批的显式前置与成本，本批安装/训练均为零。官方提供 CPU 运行方式与 AdamW，具体 wheel 版本和散列应在准备时固定。[PyTorch 官方安装入口](https://pytorch.org/get-started/locally/), [AdamW 官方文档](https://docs.pytorch.org/docs/stable/generated/torch.optim.AdamW.html)

首轮固定 batch=4，包含一个正常控制和三个损坏观察，损坏的两半径/三幅度按固定循环均衡采样。不同训练来源按源组等权，单图内的真实支持位置不参与采样选择。每个 batch 是四个互不连边的图。

优化器为 AdamW，lr=1e-3、betas=(0.9,0.999)、eps=1e-8、weight_decay=1e-5、foreach=False、fused=False，梯度范数上限 1。固定 1200 步，余弦退火到 1e-4。验证在步 0、400、800、1200 执行，首轮质量结果来自固定第 1200 步，不通过多随机种子、追加步数或验证最优快照搜索获取有利成绩。

首轮后只确定一个有证据的质量失败或完整成本瓶颈，冻结一次修改和一次优化验证。若需要重新训练，仍用同一网络、源划分和种子，最多再 1200 步。若优化的是拓扑/准备复用，模型权重保持即可。初版与优化版的选择先在验证来源完成，再冻结最终版并仅打开一次保留测试。达不到质量目标时保留 no-op 或直接基线，并给出本模型的淘汰结论。

## 首轮质量门槛

以下为本次合同选定的门槛，交规划复核，当前没有取得对应成绩。按来源组和各成员文件分别报告，最后汇总，原始case、patch、文件和独立组分母分别保留。

- 对每个损坏case先计算支持RMSE相对no-op的比值，再汇总比值。全体中位数≤0.70，每个验证/测试来源组及成员文件的中位数均≤0.85，全体p95≤1.05，最大值≤1.25。正常控制的支持指标为null。
- 允许域改善取逐损坏case的`1-RMSE_model/RMSE_noop`后取中位数，至少20%，同时保留最坏样例及每个r/a条件的实际值。
- 在其余质量门槛均通过的前提下，支持域相对MLS的逐case改善率中位数至少10%，允许域误差和正常点尾部误改同时保留比较。MLS支持RMSE≤1e-6·l时，模型也在此阈内的case改善记0，超出阈值则记负的`RMSE_model/(1e-6·l)`，逐例另报绝对误差和此分支分母。若直接基线已达到同等恢复质量，依据完整成本决定本候选去留。
- 原本正常点误改逐case的p95≤0.02l、最大值≤0.10l。正常控制逐case另要求允许域RMSE≤0.01l、p95≤0.02l、最大值≤0.05l。正常点分别按N与N_F统计。均同时报告米制值，跨样例统计使用各自尺度。
- 边界和域外逐位保持。相对输入新引入的退化面/翻面为零。最终候选按完整 incident 影响域做端点耦合检查，无新增禁止相交且无未决候选。原有质量标记与未评估项保留。
- 形状误差、保持误差和接触分别按自己的必达项判定。所有尾部退步和数值失败计入分母。

这些门槛同时约束恢复和正常保持，no-op 的正常保持成绩无法单独满足损坏恢复要求。校准过的直接基线也按相同目标、划分和耦合范围评价。
