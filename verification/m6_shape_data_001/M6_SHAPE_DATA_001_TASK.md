## 有限数据构造

每来源最多 12 个固定正常 patch，总计最多 48 个；选择规则在生成前冻结。按可复算的几何覆盖规则取不同位置和形状，不按任何模型结果挑点。要有自然凹面、凸面、曲率变化及有效边界附近的正常控制；这些是“保持源形状”的负例，不据此断言原角色艺术质量完美。

局部 patch 需有足够上下文与明确允许域，建议 128～512 个可处理顶点；使用离线数组，不修改产品入口预算。记录源顶点/面映射、上下文 halo、拓扑连通及跨 patch 重叠。所有一个来源的 patch 及其派生副本留同一组；近重复和镜像类同组。生成前冻结候选顺序，收录所有入选/拒绝及原因，不能用反复换 patch 筛出有利结果。

每 patch 沿用一个未扰动控制加两半径、三幅度的六个局部凹陷，最多 **336 个观测样本**。复用已核查的边图距离、平滑紧支撑生成规则和逆位移标签；不同 patch 各有一个预先确定中心。原七例原样保留为历史，不重新生成覆盖。没有新的异常家族、生成公式竞赛或参数搜索。

正常坐标仅用于生成与标签。实际监督包含完整宽区域的位移，不能只给损坏点；明确正常点/损坏点数量和损失分母，防止大量零位移掩盖损坏处失败。记录退化、翻面、支持域朝向和局部网格质量。若一例不适合生成凹陷，按预登记规则拒绝并记录，不暗改符号。训练数据准备不要求对所有样本反复跑全网格接触；记录哪些耦合项未测，训练后候选验收再做对应完整域检查。

输出少量固定顺序、同尺度的真实几何对照图，含正常、浅损坏、重损坏；不使用 AI 图片替代几何。完整网格、NPY、OBJ、图片留本机私有目录，公共 Git 仅脚本、来源/分组摘要、计划、统计、报告和散列。无需发布所有 336 份完整角色 OBJ；按需存局部数组及稳定映射，避免重复占用。
