## 质量先行及评分合同

运行前冻结独立真值及评分方法。复用根已检查的同代几何：三对约 0.003000005905、0.004999987091、0.012000011061 米，均分离，4 毫米判断为否/是/是，最近者仅 Peer_000。这些数值只进入私有评分材料，不进入消费者上下文或工具说明。

评分按当前实际三角几何，所有格使用同一标准：三个关系、三个间隙、三个阈值判断、三对定位与限定集合内最近者都正确，才记该格完整正确。间隙绝对误差不超过 `1e-6 m`；最终坐标与其真实几何证据点每分量误差不超过 `1e-6 m`，数值舍入可按这一范围核对。任何一组有效最近见证都可以，不要求和插件/评分者选到相同三角形或同一个等距点。见证须在各自表面上，点间距与真实最短值相符；对舍入坐标采用每点欧氏 `sqrt(3)*1e-6 m` 误差界，点间距采用两点误差界，不通过扩大距离本身误差判分。

优先核消费者工具记录中的完整精度见证，再核最终文字坐标舍入。若只有舍入坐标，核独立几何中是否存在与各坐标误差箱相容的合法最近点对或等价解析证据；不能仅凭“各自接近表面＋点间距误差合格”两项必要条件就宣布最近见证成立。N/P 使用相同方法。

## 机制与完整成本

自然采用单独评分，不混入答案正确性：至少 2/3 个 P 消费者从真实声明发现并请求新 `spatial_relation + surface_proximity`，正确使用其结果，且没有为同一个已完整回答的问题再进行原生几何重算，才记新事实直接消费机制成立。用原生答对仍给质量分；只使用旧 closed 或错误请求后回退不能说新能力已自然采用。把首次目录/身份解析、必要新信息补查、验证未知、重复已有事实的重算分开；不能将所有原生调用都叫“不信任”。

每格分开保存：采集对象/顶点/三角数据量、内部缓存可得占用、宿主及模型可见收发字节、工具 schema/目录/说明开销、图片数量、实际 input/cached/output/reasoning usage、工具调用/RPC、拒绝/回退、提示到最终答案、输入检查到真实进程退出的全格时间。系统不能暴露的内存、provider请求数、细分延迟、费用或 usage 留未测，不拿字节换算 token，不把未归因等待称模型推理。

主成本沿旧合同：**双方均 3/3 完整正确**后，P 完整单格时间中位数不高于 N，P 三格累计实际 input+output token 不多于 N，且这两项至少一项改善 **10%**，才算本任务有用净收益。cached/reasoning是usage子项时不重复加总。时间/token一升一降为取舍，不算通过；缺usage不判净收益通过。报告所有单格、配对差、范围、中位数及总量，不挑最快格。若 P 质量优于 N，报告质量收益，不能用不完整 N 的时间包装成同质量加速。

token 采用每格最终累计 usage；只有逐请求 usage 时才按请求去重求和，不累加流式累计快照，保留原始字段语义。任一失败、not_run、usage 未测或不足双方各三格，都不得将幸存格改作主收益分母。

准备、smoke、构建/安装复用核查、模型试验、独立审核分别计账。研发准备成本不摊成每次用户查询，也不从总投入隐去。小样本同场景是工程价值筛选，不承诺统计稳定或复杂场景泛化。
