# Archived acquisition through actual installed production stdio

Run with the registered isolated Python:

```
python -I -B -X utf8 verification/m1_source_region_no_image_measurement_packet_001/harness/run.py --binding <PRODUCT_RUN_BINDING.json> --mode standard|evidence --output D:/he_m1_source_region_no_image_measurement_packet_001/<fresh-arm> --suite all
```

`standard` omits the production option; `evidence` forwards the actual
`--region-task-evidence` option to installed `production_server.main`.
Every output root is exclusive. Twelve case processes are separate; the three
positive captures cannot be selected by invented session identifiers.

`fixtures.py` verifies the archived index, ZIP, on-disk members and exact request
before use. Holdout A1/B1 use original full #2 and brief #3. Independent P1 uses
original full #1. Its brief control changes only response_detail: original #3
has a different reference and is not presented as a paired request.

`replay.py` bootstraps the exact installed source manifest once, then uses the
normal production config constructor, LiveSpatialService.observe wrapper,
request budget, MCP parser/argument validator, formatter and PNG encoder.
Only source/active acquisition is replaced by the authenticated closed producer.
The producer's runtime binding is preserved: initialize separately attests the
current installed formatter. Valid region_ref requests use the installed actual
reference validator and the original ordered face counts. A changed, still
well-formed epoch is correctly signed before exercising the stale-source gate.
No request arguments or received replies are rewritten. Natural request trace
IDs differ across processes; compare those dynamic fields explicitly rather
than claiming complete raw-reply byte equality.

Compatibility includes actual source-image unknown, source-image measured,
prediction, ordinary targeted observation and a strong targeted LEFT-path
positive, plus clearly labelled producer status/fact absence controls. The
targeted path uses its original state-file authority; SCENE remains without a
local path and the legitimate LEFT path resolves to the original 2,526-byte PNG.
Expanded handler and real region_task/cache compatibility are the independent
root-owned suite, not implied by this acquisition substitute.

The local held consumer saves all raw TX/RX, complete stdout/stderr, call clocks,
Popen/exit/pipes/handle receipts and actual stdin/stdout EOF. Both old-file write
and network attempts are forbidden; final old source pins are checked unchanged.
`PREFLIGHT.json` maps exact filenames and records the two baseline-only runs.
The first stale control was syntactically rejected; its full originals and
runner bytes remain under preflight_01. Corrected preflight_02 completed all 12
cases with exact stale-generation rejection and valid recovery. There were no
candidate, model, Blender, or raster executions during this preparation.

Ordinary source dependencies are the existing finite StdioClient, archived
fixture loader and verified-source bootstrap listed by SHA in PREFLIGHT.json.
No old files, installed products or evidence branches are modified.
