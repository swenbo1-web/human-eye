## 原件定位

同名本机运行根内的 sealed/RAW_INDEX.json 可逐项定位 ZIP 原件。slots/A 与 slots/B 中的 03-K 和 04-T 分别保存原 MCP 请求及回包。producer、每次实际构图收据和 state.json.active_observation 内的 PNG/NPZ 可从 FORMAL_SCORE.json 逐帧核查。原实际宿主线包在 worker_wire，登记证据及进程闭槽收据在各槽。preflight/registration 与 preflight/close-windows 分别保有实装登记与 Windows 关闭。发布的两个便携预检脚本仅将本机路径参数化，确切执行代码留在本机冻结脚本镜像。
