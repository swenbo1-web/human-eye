**现场质量通过 2/2，候选保留在隔离分支。** 两条有图任务保持原像素和量测事实。首次少展开 17 个网格，但本场景两个业务请求合计增加 **14.08%** 宿主 TCP 字节，实测调用耗时增加 **12.97%**。默认路径仍用基线。

## 质量及实际开销

- 两题六视角矩阵、裁剪和实际 `SCENE` 取景一致。M21 与 M19 的原 PNG 分别为 3,956 B 和 3,871 B，均逐字节一致。RGB、float64 深度与还原至同槽原对象实例和对象内原源面的逐像素归属均通过。局部像素计数分别为 28,348 和 1,866。量值分别为 0.5 m 与 1.352081728298996 m，方向、实际最近点及两侧源面归属一致。
- 宿主业务 TCP 合计为 156,553→178,597 B。首个请求内的压缩源码 Base64 字符数为 105,132→109,960，第二次双方均为 0。候选每次内层目录约 9.9 KB、六相机约 8.9 KB、显示约 4.1 KB。换区时基线已经保有 21 个驻留资源，零新增几何。候选第二次仍发送新范围内的完整网格。上述子字段按内层 JSON 序列化测数，实际外层 TCP 字节另计。
- 外层 MCP 应答合计 159,771→128,581 B，减少 19.52%。两次客户端调用合计 369.968→417.936 ms。没有模型消费者，未测模型上下文和 token。
- 服务内的宿主读取为首条 62.697→91.953 ms、次条 14.361→30.301 ms。候选锁内两段 8.437 和 7.730 ms，含完整候选目录、排除验证及末尾绑定检查。排除结构检查为 0.789 和 0.457 ms。标准路径没有相同粒度的锁内阶段，完整宿主 worker 各段按 [RESULT.json](RESULT.json) 的原时钟区分。
- 真实软件栅格为每臂两次。M21 纯栅格 18.680→17.949 ms，M19 44.828→44.085 ms。含 PNG 和 NPZ 发布的构图阶段为 110.525→109.621 ms、104.068→102.853 ms。独立核验、启动与后置真值在原完整试验窗口内。两臂分别为 5,320.728 和 5,315.334 ms，包含 Git、wheel 和实装逐件验签等试验准备。完整窗口仅代表这次轨道单对。

## 合同与证据

冻结前使用实际隔离安装、生产 stdio、回环 TCP、同一评分器和真实关闭，A/B 两路回放通过，两个冷进程均到达预约前。产品实验入口显式启用。标准 A 与候选标准工具目录逐项相同。另做九项独立评分反例，并复验非有限顶点、无效环、错位紧界、期限、预算、触边、未知及 X 提前退出掩盖 Y 溢出。之前的薄挡片证据仍采用封存证明，此次现场分母限轨道。

正式后，用已安装候选的标准入口补做旧 `region_ref` 同一会话走通。首图与封存原图同字节，复读同一原图并保持量测，热读新增栅格为零。一次补查命名空间拒绝和后续通过原件均保留，单列于补查归档。现场和离线分母分别计量。

正式 2 次独立 Blender、4 次业务、4 次正式构图，均闭槽退出 0。隔离候选构建与安装各一次。模型、替补、重新构建场景与额外 API 费用均为零。原配置和资产沿用锁定版本。574 件主原件及 38 件补充原件在本机封存，公开证据仅含代码、摘要及计量。

若继续做此方向，优先验证同一捕获代只交一次相机与目录、同代的已核保留网格按需复用。先用固定冷请求和实际换区代价测净效果，再考虑扩大资产域。
