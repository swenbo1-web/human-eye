## 算子与有限合同

`preview_axial_redistribution(patch, task)` 读取原 `arm-twist-patch-v1` 和明确任务。任务冻结首末完整 pose 矩阵、允许 u 区间、截面面积损失目标、角度/位置/面积容差及保护 ID。返回 `candidate/no_op/unreachable/not_applicable`、前后实际几何目标和保持量。只有 candidate 携带两条中/末骨完整 local basis 变更、三个 pose 矩阵和预测点；不可达状态只给最佳允许 u 及几何事实，不给可执行候选。

先验证完整输入再判断 no_op。沿现有 `_parse_patch` 验证点、面、ID、权重、父链和截面边；新增数学域守卫包括三骨共同轴线和骨头位置、轴向 pose、同圈恒定且仅相邻骨混合的权重、两关节中心真实 50/50 截面、可靠凸有序平面截面、轴向有序中心线、逐点输入 current 与所声明 LBS 相符。保护区必须是所有且仅纯首/末骨权重点。域外/不可靠情况明确不适用，不靠重置姿态降低分数。

从相对首骨的 pose × inverse(rest) 取额外 u 与 θ，去除各骨 rest roll，并保留首骨共同刚体运动；不直接平分原始骨矩阵的总转角。允许 u 位于 0 与 θ 之间，避开 ±180° 分支。本域两混合带均有 50/50 圈，实际最大截面损失的解析式为 `max(sin²(u/2), sin²((θ-u)/2))`；域内最优为 θ/2，受限时夹到给定区间。候选直接用原 rest、weights 和新 pose 做 LBS 点计算，再测有序截面的三维面积，不循环搜索、采集或询问模型。

首末 pose 直接保持，中骨重新分配扭转，末骨由完整父/子与 rest-relative 关系得到局部补偿。pose 矩阵采用 patch 的 armature 空间；固定对象变换下才对应固定世界姿态。纯模块不含 bone tail、约束、对象或场景来源字段，不能据此声称已经验证这些实际 RNA 状态或获得写入授权。原生 QA 单独记录实际骨长、头尾和全局姿态。目标是所列截面面积，不是完整体积、损伤或美术质量判断。

## 固定任务与独立几何

复用原种子 1729 的 train/round、train/elliptic、three_even/linear/0 两资产；每份 402 点、800 面、25 个有序截面。原始 ID、rest roll、权重、点面及截面逐字段对照既有保存数据，raw dataset SHA `6ccec485cc9fedb832324e3802e1ca4bc8529e55b2171afe4278803c62be1f4d`。环 8/16 分别位于 1/3、2/3 关节中心，每圈 16 点同为 [.5,.5,0] / [0,.5,.5]；每资产 194 个纯首末保护 ID。

任务目标统一为最大截面面积损失 ≤0.4；CPU 角差 ≤0.001°、位置 ≤1e-9 m、J 差 ≤1e-8。`cases.py` 在预览运行前固定八任务；patch/task 参数不带 metadata、label_severity、参考点或已知解。oracle 用独立 NumPy FK/LBS、Newell 三维面积向量及另一份原平面投影鞋带面积，未调用产品的协方差特征、severity 或标签。

最终 10/10 离线方法通过：8 固定任务 + 1 原资产/50:50 合同 + 1 薄自交守卫，0 failure/error/skip。前两次开发检查各9方法通过但后续审查发现凸性容差带缺口；日志保留，不能用初次全绿冒称无缺口。最终只改凸性判断：排除每边两端点后，其余点必须严格同侧且超过误差带，不可靠就退出。

## 一次原生可实现性验证

Blender 5.2.1 LTS，factory startup / disable-autoexec / background，一个独有进程，四个既定正例，不增加新的效果样本。脚本以原 rest 矩阵构造三骨及 roll、原点面和权重，一份 Armature modifier，LBS，保体积关闭。先建立原姿态，再只按声明赋中/末两骨 basis；首骨在候选阶段没有 setter。四份完整原生点、rest、权重、头尾、局部/整体矩阵和面积原件在 `native_01/case_01..04.json`，可重新独立计算，不只有成功摘要。

Native 门在运行前冻结：角 ≤0.001°、位置 ≤5e-6 m、截面 J 误差 ≤2e-5。未用它放宽 CPU 门；不是把 float32 原生 packet 直接送入 CPU 1e-9 合同的验收。

四例首末完整全局姿态均过门：最大角差约9.71e-6°、最大平移差2.98e-8 m。头尾中心线最大变化5.96e-8 m；194保护点最大位移1.91e-7 m；原生全点与预测最大差2.48e-7 m。J 对独立解析值最大误差1.41e-7。原 rest/权重/骨长/对象变换/单位在候选前后逐值相同；选区外 sentinel 的点面及矩阵相同。输入 patch/task 与运行源字节保持，blend 未保存。

另由独立审计脚本直接读取原生完整点数据，用标准库 math 重算 Newell 面积、解析 determinant、逐点 LBS、端点/头尾/环中心和保护量；未导入产品或既有 oracle，739 项检查通过。全部环面积比对解析的最大误差约1.03e-6，仍低于预登记2e-5；这是所有环的误差，区别于上面的最大J误差。25环中心最大变化8.58e-8 m，独立LBS与原生全点最大差约2.13e-7 m。完整脚本与 `INDEPENDENT_NATIVE_AUDIT.json` 封存，没有新效果试次。

跨运行时的证据有明确边界：native 在 Blender Python 中按同一冻结定义重新生成四份输入并求预览，并非直接导入 `cpu_final` 候选的原字节。两端候选矩阵最大差2.22e-16，但原输入哈希不同，不能称逐字节同一；IDs/截面/拓扑/保护ID一致，原生权重是原权重的准确float32转换，静态点和骨姿差异已量化。CPU完整packet/task在事后重新生成，严格匹配原预跑canonical SHA后才写入 `cpu_final/INPUT_PACKETS.json`，`INPUT_RECONSTRUCTION.json`明确标记不是测前完整快照。原生运行时的原double输入未完整另存，已有其每次hash及全部实际RNA原件；不补造缺失原件。独立审计最初错误要求跨runtime输入hash相同的过强断言失败保存在 `INDEPENDENT_AUDIT_INITIAL_ERROR.json`，改按实际数值和各自绑定核验，没有重跑效果或放宽门限。

这是 CPU 预览候选在原生夹具中可实现的证据，不是已经接通产品骨姿 setter、当前 GUI、原作者人物资产、动画或通用 IK；也未验自接触、表面三角形方向或连续运动路径。native 设置了12次初始骨姿、8次候选骨姿（每例2），8次回读、4份生成夹具；产品 setter=0。

## 模型与实际成本

冻结原专家/权重/阈值，不训练、不修改标签。`cpu_final` 对7个有效域任务做7份静态准备，前诊断7次、四个候选后诊断4次，共11次模型调用；两个 no_op 重用原诊断，不重调用，不可达/域外不伪造成功后诊断。候选求解本身8次 preview 的模型调用始终0。

120°两形状模型最大 severity 约.75037→.17813，-150°约.93326→.32499；这些不等于几何J，未参与求解/准入。已有几何直接给出最优u，模型没有改善候选、求解次数、目标或定位；本批新增学习收益未证明。诊断保持可选，不把分数降低当修复成功。

固定CPU collection：8个 preview 合计约29.90 ms，正例单次约4.25–4.85 ms；模型首次构造约.60 ms，7份静态准备合计8.17 ms，11次诊断合计2.86 ms。collection 主段155.40 ms另含独立验收和记录成本；导入、造输入及源冻结不在该段内。preview 主段包括完整域检查与LBS/面积计算，不能仅把闭式角度的运算当完整成本。有效7任务共12次产品LBS、7份rest面积、7份current面积及5份候选面积；非共轴在这些计算前退出。没有模型或几何搜索循环。

原生 probe 主段117.28 ms，launcher 含 Blender 启动/退出约956.85 ms，均为一次观察，嵌套不能相加。它们不含 Codex 规划/工具往返，未作完整MCP任务或无插件agent收益对照。全批开发与验收实际执行3轮单测（8、8、9次preview）、collection 8次、native4次，共37次preview，模型总调用11次；重复的是同一冻结八任务及一项守卫，不累计为新资产覆盖。外部API/训练/Google调用均0。
