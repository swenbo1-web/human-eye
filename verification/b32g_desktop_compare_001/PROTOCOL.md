# 桌面版与 032 + Hook 候选同宿主对照

A 取自当前桌面 `human_eye_live` 的实际启动注册。B 取自已发布的 `31792523ecb48a500b8eed0ecb531c7ecc8e767e`。两个隔离安装的分发文件逐件与原安装对齐。A 启动器保留原字节，B 启动器与管理器仅更新共同 Python 的绑定及相应固定摘要。两个实验臂使用桌面注册的同一个 `python.exe`、同一套依赖和相同进程标志。产品源与现有桌面注册只读。[安装及环境绑定](BUILD_BINDING.json)

## 测量范围

| 路径 | 对照与计时 |
| --- | --- |
| 固定启动和轻量 Hook | 每种条件六组 AB/BA 交错新进程。依次覆盖固定身份、普通提示、两种原注册工具后置和畸形前置。记录外部进程窗、退出、原 stdout、trace 内部时钟及实际连接和状态写入计数。 |
| 真实只读空间 Hook | 同一隔离 Blender 进程中的 G60/D12，六组交错。核对对象、当前包围盒、采集、图与写权限。记录端到端及宿主分段。 |
| 真实普通 MCP | G60/D12 与 D48 各一隔离 Blender，同场景 A/B 共用其实际会话。每输入六组交错，从固定 launcher 启动各自新 MCP 进程，同输入一次首业务及两次暖读。记录初始化、首业务、两暖、退出、完整窗口和实际线包。 |
| 求解内核 | 另用同一冻结捕获中的世界网格和共同参数复放准确求解。比较 G60/D12 单对与 D48 的全部 47 对。记录近点、方向、精确排位、两版可比工作计数；计时含内核归一与树构造，排除导入和预制试验输入。 |

各类计时串行执行。实时 MCP 的冷口径为新 MCP 进程，Blender 在首次对应请求后为共用的热宿主。所有一手回包、实际开始顺序、失败或未运行、进程关闭和保护摘要均留档。统计使用每对原始值、两臂各自中位、配对比值变化中位以及胜场数。结果等价和实际工作量分别判读，轻量基线缺审计时记录其功能差异。A 和 B 为两套完整发行，版本总差异只归于整版对比。[同宿主输入和分段冻结](EXPERIMENT_BINDING.json)

正式桌面、信任和默认接口保持原注册。实验调用真实固定入口所用注册命令。宿主自动触发和供应商模型阶段单列边界。实验使用零模型与零新增费用。
