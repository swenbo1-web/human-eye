# 入口说明自然对照评分

先冻结资产、真值、题面、两臂工具目录和启动接线，正式顺序 A1、B1、B2、A2。第 1 题是 K，第 2 题是 T。每槽一回合，正式质量和阶段时钟逐槽记录。

每份原答核对两个分离片各自的表面距离。一份匹配同代全连通片、指定参照的实测包可证明该片距离。全局最近面事实只计一个分离片，第二片需要相应测量或已交付几何的独立演算。接受对独立真值相差不超过 1 毫米的合理报告舍入，绝不合并两片或以对象包围盒代替真距离。若普通计算或直接演算，保留实际工具结果或实际已交付几何和原答推导。

原答须指出真实最近片，交付同槽实际送达的原 PNG 可查路径或引用，并用所报零基像素和当前源三角复核。相关原图内至少 16 个属于目标且真实最近片的正有限深度像素，并如实说明帧内能见范围。首张实绘、首次图交付、最终引用分开审计。等距来源和合法普通步骤合格。

早期采用要在枚举源网格、指定面、自己计算或普通取景之前，实际传入明确最近表面关系与正确目标、参照。仅目录查看单列。采用须通过真实生产最近源归属和原回包。完整机制还需要这次早期调用产出的首张实际构图能看见正确片，并最终引用这张同槽图，原答质量和真实关闭同时通过。B 两题完整且同题至少一题相较 A 新增早期采用、另一题无退化，才记小样本入口收益。

只统计实际调用、原始文本及 PNG、端到端往返、总窗和原始 CLI token。不将图传输、缓存输入或包内重复证据冒充新求解。Thin 实际退出与自身退出记录分别列，末包须有双向凭据和真实 CLI 完成事件。
