# M1/M2 无图选区量测 MCP 验收

隔离候选 `ba79e2f1` 通过现场工程验收。装配和 Yanyite 各完成一组真实 Blender 对照。4/4 正常关闭，12/12 业务通过，六组同题结果的距离、方向、显示点对及实际求值源面一致。独立用当前几何与旧完整捕获复核选区；将实报最近点连线归一后，与所报方向的最大差值为 0。

## 接口

在隔离证据端显式启用 `--source-region-measurement` 后，现有 `human_eye_scene_observe` 的工具声明增加 `query.mode=source_region_measurement`。这一模式要求两个明确且不同的对象、一个世界坐标闭盒、单项 `surface_proximity` 和显式 `include_image=false`。它选择三个顶点都在闭盒内的当前求值三角，量测其表面到参照整件表面的最短距离。

同一形态支持省略 `response_detail`、`brief` 和 `full`。正文给出闭盒、两个对象、选区面数、米制距离、世界方向、最近点和每端一个经验证的源三角号。零距离的方向为 `not_applicable`。在显示点舍入后无法证明源面归属时，附带精确有理坐标，证据不足则明确失败。旧 `source_region` 继续提供原简报、全文与图片，局部量测回包独立于原 `region_ref`。此次只安装隔离候选，正式部署继续使用原配置。

A 为 `ff0105db` 的公开旧简报，B 为生产工具的新模式。这里比较两条公开路径。上轮私有入口的增量收益保持原账本。

两臂首次连接的启动源码均为 105,132 B，暖请求为零。冷读宿主响应从装配 72,470 B 降至 6,195 B，从 Yanyite 3,318,955 B 降至 29,192 B。实际场景点面发送量从装配的 416 点／744 三角降至 20 点／22 三角，从 Yanyite 的 27,312 点／53,276 三角降至 233 点／313 三角。Yanyite 冷时两臂均展开目标和参照两对象；减少的是传输和本地整场解析、准备。

B 两次同盒热确认都没有展开、重建、筛选或重传几何。Yanyite 换盒复用原有世界网格，仍筛 53,264 个目标三角，实际发送 115 点／148 三角。旧 A 的两条暖请求已能走全场驻留增量，均发送零新几何。因此 Yanyite 换盒时 B 的宿主流量更高。B 仍求解最近点，A 同盒可复用既有测距计算。现场 Yanyite 同盒的本地测距阶段为 0.739 → 32.916 ms，包含实验守卫的宿主 TCP 区间为 322.936 → 541.897 ms。账本保留两侧分段和重叠。

装配三条业务合计少 36.02%，完整窗口 2.321 → 2.194 s。Yanyite 三条业务合计少 31.97%，完整窗口 8.002 → 8.426 s，增加 5.30%。Yanyite 冷后本地引擎工作集为 128,081,920 → 64,360,448 B，按整个进程读数记录。B 的保留私有包实测 25,772 B，换盒后 13,547 B，上限 2 MiB。单资产只有一组配对，完整窗口包含启动、守卫、回读和关闭。自然入口采用、模型用量和整题收益尚未实测。
