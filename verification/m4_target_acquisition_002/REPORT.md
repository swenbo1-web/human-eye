## 缓存控制

同一独立 main 副本内，对原排除的 Far11 执行精确 fixture 顶点写入，再恢复原点序。其矩阵保持 identity，实际 world 点等于固定变换 `(z+9/8,y−1/8,67/32)`，289 点每步、两步共 578 次赋值。该方案在执行前替换了存在 TRS 分解误差依赖的理想矩阵 setter 准备方案，旧准备保留为 0 次执行。

完整见证数实际 **1 → 0 → 1**，Far11 从排除变为保留遮挡物，再被排除。中间态六向均有独立严格正面积阻挡；来源 revision、绑定、owner 和 depth 重新生成。三阶段 PNG 相同，保存的深度和对象归属证明中间态已变化。恢复后事实和全部归一 buffer 与初始相同。

fixture 578 次赋值与产品 setter 0 次分账。源 blend 保持原字节，测试副本终态指纹恢复。该控制覆盖固定几何变化导致的缓存失效，实际对象矩阵 setter 变化属于未运行项。
