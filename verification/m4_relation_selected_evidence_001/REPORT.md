## 功能、来源与恢复失效

离线基线有效执行 14 项，另有 8 项候选专属测试跳过。候选 22 项全部通过。默认冷态和暖态结果在精确核对运行来源后，仅将该来源值替换为比较标记并去除 trace，其他字段、事实、诊断、计数及响应字节逐项相同。新测试覆盖字段选择、子集、别名、重复、重排、歧义、非法与集合外请求、原有 unknown、缓存隔离和变更失效。定向旧回归覆盖关系、nearest、来源与 ReadContext。

实际入口使用原始资产的七个拥有生命周期的独立实例，按预登记顺序执行，全部正常退出。共记录 92 次关系请求、38 次原生补读或 QA oracle、一次登记修改和七次关闭，共 138 条宿主收到事件。保护源的 153 项摘要前后相同。每个原始场景候选会话有五轮 OFF、vertices 和 full 显示切换。只在登记的测试副本中执行一次 N28 顶点修改，原资产文件保持保存前的字节。

独立来源检查使用八组宿主原始 local 顶点、实际世界矩阵、单位和实际 loop triangles，共核对 16 个对象记录。Fraction 前向变换与冻结原始资产逐值对应，原生实例 ID 也与关系绑定一致。一次修改后，宿主 generation revision 增加，关系 scene_revision 和 scene_fingerprint 失效更新，随后 full 读取使用同一新代。N28 间隙从约 0.023 米更新到约 0.013 米，变更后的 OFF 与 full 事实一致。

42 组同轮 vertices/full 对 OFF 比较中，追加宿主 RPC、捕获、to_mesh、三角化、宿主世界准备、归一化与关系求解计数全部为零。六个原始场景冷请求的已有工作相同，每次一次捕获、四次网格求值及三角化、一次归一化、三对闭体和表面求解。变更后 OFF 重新构建一个资源并求解三对关系，随后 full 复用新代，追加求解为零。

已知刚体变换为 `(x,y,z) -> (-y+0.125,x-0.25,z+0.5)`。独立核对 32 个场景对象的前后矩阵，最大矩阵读回差为约 `1.49e-7`。所选世界顶点与名义变换的最大差为约 `1.02e-8` 米，低于提前固定的 `1e-6` 米范围。本批覆盖一个原始资产及其受控变体。

## 实际成本与一次回退定位

实际关系工具定义从 1150 增至 1713 个紧凑 JSON UTF-8 字节，增加 563 字节。nearest 定义保持 961 字节。原始任务关系正文分别为 OFF 5361 字节、vertices 8192 字节、full 9015 字节。显示顶点增加 2831 字节，附加三角面再增加 823 字节。列表转换和编码有真实 CPU 与分配成本。

同候选运行时的 20 组配对中，full 单次入口中位耗时为 38.8599 毫秒，OFF 关系加同字段原生补读的总中位耗时为 80.8703 毫秒。对应正文为 9015 与 9004 字节。这个比较只适用于包含顶点及三角面的同字段路线。vertices-only 另列相对 OFF 的开销。原生补读的实际网格求值、三角化与世界映射计数由执行脚本记录。

上述耗时含同一 QA helper 的场景核对、Python profiler、事件与回执写入。宿主 profile 区间约占每次暖请求的主要部分。它们描述这套受控工程入口，不能直接推算日常生产延时或模型完整任务收益。两个冷样本分别报告首次应用请求，操作系统缓存沿用机器当前状态。

默认暖请求的回退在现有保存 trace 上做一次分段定位。差异主要出现在 host.capture 及包含 QA profile 的宿主工作区间，产品本地的验证、缓存与编码跨度较小。产品宿主源码未改动，各暖请求的采集与求解计数一致。分段相关性不足以证明回退的因果来源，不能据此抹去观察到的 3.57% 增加。本批没有追加阈值、变更提示或反复试跑。

原有 request_trace 提供编码跨度和进程生命周期峰值 RSS。各候选进程峰值约为 92.79 至 92.96 MB，基线约为 92.56 至 92.74 MB。该指标包含解释器、加载与此前请求，不能当作单次几何投影的峰值分配。

Python profiler 没有暴露 bpy 的 to_mesh 和 calc_loop_triangles C 调用名称，C_calls 空表的含义是该观测通道未测得。实际门限使用原有 residency 累计计数、成功捕获路径、实际 Python 捕获调用以及原生补读成功操作计数。scene.hash 成功跨度标识实际归一化执行，scene.validate 的外层跨度按其原范围保留。

## 记录修正与复核范围

首轮离线测试把原有 unknown 回包的 isError 标志误设为 false，三个失败记录和旧测试文件保留。修正预期后两版定向验收通过。独立来源检查首轮遗漏了登记 patch 写入 Blender 时的 binary32 存储转换，24 个顶点的小数参考比较失败。旧检查器和失败记录保留，按原登记合同独立执行 IEEE binary32 转换后来源检查通过。保存记录分析器首启有一处括号语法错误，错误脚本与 stderr 保留，修正后完成离线分析。上述修正均发生在验收脚本，产品候选字节保持固定。

新增模型消费者、图片与付费 API 调用均为零。模型是否减少补查、能否正确使用几何、完整任务时间与 token 收益尚未运行。Agent Learning 自身绑定仍需重绑定，本批按管理员允许的本地工作单记录，未使用其他对话句柄。
