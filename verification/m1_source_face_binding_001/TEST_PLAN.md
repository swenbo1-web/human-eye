# 源面绑定定向验收

使用保存的 QP 与 P1 SERVICE_RESULT、PNG 和 NPZ，以及独立源几何夹具。测试调用公开结果投影与保存图片编码入口，新增观察、几何求解、raster 和模型调用均为零。图像编码调用和历史结果中的 work 字段分别记录。

固定检查覆盖默认 brief/full/raw 源面集合、对象重排、面重排、region 行重排、稀疏源面号、四三角细分矩形、同物体多面、unsupported 混合、零基面号及零面物体的表示边界。夹具显式保存顶点、三角形和独立区域面号。矩形来源用面积与边界证据验证，消费反查只读取对象、范围、绑定和既有 offsets/owner。

保存缓冲逐像素检验 global triangle ID、对象 owner、patch owner 与默认简报反查一致。不同绑定的相同局部索引分别建键，保持作用域。

无映射的旧响应按旧 schema 处理。错误映射通过原投影失败回退路径退出。比较新增字段和版本以外的完整值，保存输入与图片字节摘要，核对完整性、unknown、world、见证和缓存计数。

runner 仅从已保存源码中加载投影相关函数及原 PNG 验证函数。遥测记录函数使用本地计数接收器，未建立 MCP 连接。此隔离方式避免执行 live service 或几何模块，同时执行真实默认与 full 编码函数。

输出目录独占创建，保留任何预检或测试失败。报告区分逻辑检查、验证断言、旧保存像素和新执行调用，复核者是本验收脚本与独立夹具的作者。
