# 主动覆盖001的管理员 oracle 复核

本目录为管理员答案侧。可共享的结论位于 `PUBLIC_SUMMARY.json`、`CAMERA_CHECK.json` 和 `CANDIDATE_COMPARISON_PUBLIC.json`。目标身份、逐视角矩阵、遮挡物明细和最小子集保存在 ADMIN 与 PRIVATE 文件中，候选运行器只接收全场 geometry 和六个公共 camera。

## 原草案与独立方法

原五份草案按原字节保留在 `original/`，源 SHA256 写入管理员证明。草案 generator 含顶层写文件行为，本复核读取源码与已有数据，从未导入或执行它。

`recheck_oracle.py` 从整场有理数顶点和三角形重新发现矩形。它核四个不同顶点、两片非退化同向共面三角形、唯一闭合矩形边界、邻边垂直与对边相反。front 来自原三角形绕序。其余对象逐一验证为八角点、十二三角形、六个完整矩形面、外向绕序的闭轴对齐箱体。其他检视面处于同平面且互不重叠。

独立遮挡方法将箱体八个角沿登记方向投影到检视面，以所有支持半平面描述其凸投影，再枚举边界直线交点求与目标矩形的交集。有理数面积严格大于零才计遮挡。该方法使用完整箱体投影，既没有调用候选三角形判定，也没有复用草案的 hull／顺序裁剪函数。

独立几何发现和三十六项连续可见判断、每个正面积遮挡量及穷举最小子集全部对应草案，差异为零。候选池可覆盖五个检视面，一个在登记候选池内未覆盖。原布局保持固定。旧草案的 local-view 术语按本批完整全场相机合同解释。

## 精度、绕序与边界

候选的几何权威输入为原 JSON Fraction，参考与优化窄阶段精度一致。管理员另将同一坐标转为实际 binary64，再按精确二进制值恢复 Fraction，三十六项判断仍一致。该检查记录渲染量化影响，原分数输入继续保留。

一个中心射线清楚、角落有小箱体遮挡的定向控制得到严格正面积，判非完整。另一个仅接触矩形边界的控制面积为零。两个控制在本目录使用独立半平面法执行，主布局未重采。

## 六个完整 camera

公共相机 SHA256 为 `3db530d292c0e300792173b793d4ed29506d3ed5bd8ec8649ef5a2de406637c6`。方向表示场景点朝相机，光轴观察方向相反。view 的前三行依次为 right、up、场景朝相机方向；TOP 使用Y上向种子，其余使用Z上向种子。全部采用共同的全场AABB中心、逐方向对称投影范围每侧5%边距、512方形画面。

独立标量矩阵检查覆盖每个相机的全部二百顶点，原始 binary64 hex、方向、roll、center、span、near/far 和严格闭NDC包含均通过。全场NDC边界最小余量约0.090909。几何包含使用直接闭区间比较。浮点basis的一致性误差单独按64 ulp核对，边界接受条件保持精确。

相机审查合计六十三项，其中六十二项为本目录独立检查，一项绑定渲染侧边界证据。渲染侧另有七十四项输入/存储buffer检查，含六个 NDC ±1 边界全保留、各向外一ulp全拒。原near/far标量端点的实际投影浮点值另列保存。该边界协同没有增加raster或PNG生成。

几何完整可见与像素可读继续使用各自证据。图片覆盖最小性的最终判定还需实际owner缓冲和可读像素下限。

## 候选资格对照

管理员比较器读取实际开发版 reference 和 optimized 输出，只返回聚合资格结论。两份输出各自的几何发现集合、front、全部三十六项 complete/status 与bitset对应，差异均为零。输入输出 SHA256 留在公共比较摘要，逐项私有证据留在 PRIVATE 文件。

三角形见证字段已核存在、正报告面积及完整/遮挡状态的一致性。逐三角形见证面积的独立数值复算仍未测，连续可见真值由独立箱体投影建立。

本目录范围为当前固定的水平矩形与已验证闭轴箱体，以及六个完整camera。模型识别效果、任意自然语言重要性和候选池之外的可见性仍待后续任务。本子任务没有新增模型、provider、Blender、产品服务或API调用，没有Git操作，也没有修改旧原件或产品源码。
