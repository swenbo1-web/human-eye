# 区域任务留出题正式评分

以独立重开真值、当前独立初末捕获、实际 MCP 回包、原始模型回答和闭槽文件为准。两臂各七项，每项一分。场景资产内部标签、精确答案和资格轨迹均只在验收侧使用。

1. **全场候选完整。** 答复给出全部符合题面世界面积范围和有向单位法向约束的最大共边、共面、同绕序矩形。多报、漏报和把非候选挡物列为候选均失败。若报告额外的面积或法向，这些值须与对应当轮面一致。
2. **当前源面和中心。** 各候选报告完整的对象局部求值三角集合及世界中心，或可在当轮前置回包唯一还原该集合的绑定引用。中心坐标的各轴容差为 0.00005 m。
3. **开敞小面原图。** 原答标明一张确实交付给模型的当轮对应原图。验视角、四角、完整场景的正面积遮挡、原 PNG 和三角归属缓冲。至少 16 个选区表面像素与 4 个对比边界像素，RGB 欧氏差至少 24。全场和局部同名 SCENE 时，以作用域、帧身份和源引用辨认。
4. **需换向候选原图。** 按同一完整见证要求，接受当轮任何由独立几何和真实像素支持的合法方向。全场默认方向受实际挡物遮挡时，不以已交付同名或其它作用域的图替代。
5. **六方向有据未知。** 针对未能完整观察的候选，答复把结论限定于六个允许方向并说明具名的真实正面积遮挡。可以分组列名或逐方向说明；具名关系须由当轮几何支持。区分“该方向无法完整观察”“部分像素可见”“所有像素不可见”。至少一个已证挡物可以支持该方向的正面积遮挡，最近顺序须有单独证据。
6. **距离、世界方向和实际点对。** 从中心世界 x 最小的那片选区到参考整件报告最短表面距离、世界方向和一组实际最近点。点分别在各自的源三角表面，长度和位移达到对应的独立下界。量值及世界坐标采用 0.00005 m 容差。
7. **最终两图闭槽均可复读。** 最终原答显式交付两个不同范围的当前原 PNG，以能打开的 Markdown 链接或真实附件给出。闭槽后按原答的具体引用打开，核当轮确已交付的原图块、同槽文件、作用域、帧与 SHA-256。裸文件路径、只给不透明引用、历史图和人工添图分开登记。

最终回答确实采用的原图和事实、原图重传、补查、首包形态、固定 CLI 重建、真实预算及整题成本独立记账。实际供应商内部上下文、宿主渲染和真人点击没有观察到时保持未测。
