## 判定标准

先按原语义合同独立评分并封存，再揭盲九格成本。逐项核目标选择、三个角色、关系、局部依据及错误/遗漏/unknown。局部交线点只证明可定位的边界穿越；不能在答案中变成共同体积严格内点或穿透深度。

结果分开判定，均预先固定：

- **质量通过**：P1 三格完整正确、无实质无依据或矛盾结论。只有比较双方均3/3完整正确，才比较同质量效率；失败和 unknown 不从分母剔除。
- **这项改动的净收益**：在质量通过后，P1 完整单格耗时中位数低于 P0，且累计实际 input+output token 不高于 P0。若时间与 token 一升一降，只报告取舍，不算已取得净收益。费用未知，不声称省钱。
- **完整任务相对原生的收益**：同质量条件下，P1 完整单格耗时中位数低于 N，且累计实际 input+output token 不高于 N。改进了旧插件但仍未达到原生，要明确分别报告。
- **机制检查**：逐格记录新证据是否实际被引用、最后原生读取补了什么、是否减少补查或重复数据；不以主观“更信任”评分。调用数和响应字节是解释性指标，不把调用数少但质量下降算收益，也不把没有自然调用的能力算成功。

不额外设一个事后百分比门槛，不以总耗时或某个最快格替换中位数。逐格报告、三轮配对差值、范围、中位数和总量同时保留。三次同场景重复只支持这个场景与设置下的局部结论，不称统计显著或大规模场景收益。

成本从输入检查前到实际关闭结束，包含目录、启动、工具错误/拒绝/回退和收尾；另列本次准备工作。完整响应字节、公开/内部RPC、实际 input/output/cached/reasoning 用量各按原边界计量，缓存与推理子集不重复相加，嵌套时钟不相加。取不到的模型请求数、美元、图片 token 和协调用量标未测。
