## 算法和支持域

一个对象对应一个连通、无孔、同向的完整平面矩形。边关联使用实际顶点索引与有向边，内部边要求成对反向，面邻接遍历要求连通。实际引用顶点须精确共面。单个边界环消费全部边界边，沿同向直线的连续边界点被简化，剩余四角须构成正面积矩形。顶点范围及三角形有向面积再次核对四角边界。

内部有向边抵消后，整个正向三角链的边界与矩形边界一致。离开边界的覆盖重数等于矩形绕数，结合正向面积条件，可证明该域内的矩形铺面。这里沿用精确 Fraction 语义，容差焊接与三角形两两相交计算均未引入。

参考使用清楚的流式三维叉积、绕序点积和向量面积累加。唯一候选在共面成立后，选择平面法线的一个非零分量，只计算对应二维有向行列式。共面使各三角法线平行，标量的零值、符号和面积总和分别对应原三维判定。候选因此删除实际算术工作。

规范有向四角决定 ROI 身份与 front，实际全部 `triangle_indices` 保留。完整网格身份继续绑定真实表示，细分后的来源身份会改变。两路共享同一个旧 `optimized` 遮挡代码对象，完整几何只解析一次。相机、精确裁剪、光栅器、16/4/RGB24 阈值、CoverageState 与短事实接口沿用已固定实现。

对象合并、多面片、任意多边形、曲面和语义定位需要独立的后续能力合同。当前源码入口默认选择清楚参考路径，采用本批选定候选时显式传入 `discovery_variant='candidate'`。

## 验收工具复用限制

本批由单控制器按 proof → legacy → correctness → observations → benchmark 顺序执行，五个阶段均读取并核对同一冻结来源。`PRE_BENCHMARK_GATE.json` 额外核旧发现真实数量、14 条正确性结果、四条观察链及唯一预算目录的8个意图后，才开始正式性能序列。

静态复审指出三个通用化硬化点。底层 phase API 对所有前置阶段的顺序约束仍有缺口，legacy helper 自身缺少显式通过判定，底层 reserve_render 可接受命名空间内其它预算路径。实际执行的顺序、来源、旧数量与唯一预算目录均有独立记录。验收工具的可复用范围限于本批已核定的单控制器流程，并发或对抗式调度需要先收紧这些接口。

审计首次逐行读取 `TRACE.jsonl` 时遇到一次 JSONDecodeError。文件实际包含连续的多行 JSON 对象，审计读取器已改为标准 JSONDecoder.raw_decode，全部16个事件原样保留并核对。`review/READBACK_ADJUSTMENT.json` 保留错误和修正事实，原日志字节继续保存。根控制器另有一次审计摘要读取将整数计数当作列表的 TypeError，按实际字段类型读取后完成，事实记录在 `review/ROOT_READBACK_ADJUSTMENT.json`。成本审计的独立读回也另发生一次相同日志分帧原因的 JSONDecodeError，事实保存在 `review/COST_AUDIT_READBACK_ADJUSTMENT.json`。共三次后验读回错误，均发生在正式算法、图像与性能结果保存之后。成本审计失败前读取器的源码 SHA 未单独捕获，该字段保留 unknown。后续通用消费者应明确该物理格式或先统一日志序列化。
