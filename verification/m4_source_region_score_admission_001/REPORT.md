## 公开事件和反例

候选对定时事件日志先按原项目公开工具头和明确的最终答复、turn 头筛选，再解码符合白名单的行。用量只保留输入、缓存输入和输出三个计数。失败仅识别事件头。原始 `stdout.raw.bin` 仅流式计算长度和 SHA-256。合成畸形非公开行被跳过，三个允许事件及指定用量字段保留。

九项反例经同一候选入口得到预期拒绝。包括反方向、同槽错图、错源像素、另一槽同字节 PNG、重新绑定摘要后的错捕获、错图像摘要，以及重复、缺少和替换必选项。原控制数据只在测试进程内覆盖或写到新证据目录。两批原档案的 **1,780 个成员** 均以 CRC、长度、SHA-256 和现存文件逐件复核。

## 冻结结果

最终预飞包含 15 个冷评分入口进程，覆盖四个候选正例、两个旧错误复现和九个反例。记录了实际入口、参数、进程 ID、结束状态、各次时间、传递加载文件和判定摘要。第一次全预飞的只读保护误拦 Yanyite 的历史 Git 对照。第二次全预飞中，三项 JSON 清单反例均被候选拒绝，旧测试匹配规则仍预期旧错误文本。两批失败归档保留。将许可明确到同一仓库的只读 Git 查询，并修正测试期望，候选评分源码未在两轮间改变。

冻结门以五项对照验证拦截。两份真实失败回执、失败标志、缺少完整案例、改动结果绑定均拒绝。主冻结收据绑定 2,160 个输入，包含实际执行的候选与传递依赖、进程、原件和结果。最终准入清单还绑定两个真值域的 13 个上游输入及既有产品安装凭据。旧预飞和本轮初始失败均保留为单独过程记录。

本轮 Blender、模型、构图、产品构建／安装、额外 API 和费用均为零。产品继续固定 `e8006670`。上述时间对应离线评分进程，历史两次业务实测的耗时和用量沿原记录。
