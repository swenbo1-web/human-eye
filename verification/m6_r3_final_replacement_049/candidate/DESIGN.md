# F 唯一候选及选择规则

以 043 修正版 R3 为主体。在任何距离或闭壳的版本专用准备前，仅用有序两侧的原生面数 n、m 计算选路。空输入或原总面数超限交原 032 拒绝。其余在 n×m ≤16,384 且 n²+m²+8(n+m)+124nm+4 ≤1,179,648 时走原 R3，否则用 032 的整套求解。公式来自 047 的新鲜单对计费保守上界。比较含等号。原生输入、绝对期限、窄相上限、实际计费上限和发布验证都由选中路线正常执行。两组 129 及 125 均按同一通则选择 032。

同一候选 wheel 内保存 032 的距离与闭壳几何模块，仅把相互导入绑定到同一套私有实现。每次只执行一版。闭壳、表面和空间关系共享同一对面数判别，因此交接的准备、树引用、位宽与工作账本来自同一套实现。031 原 032 信用、投影和窄相路径照旧。原 R3 的零键顺序、准备或租约复用、扫描 reducer 和统一缓存层保留；032 路径的内部准备不使用 R3 的 mesh cache。查询级缓存仍在隔离当前安装进程内，键、来源与失效机制照旧。每个真实距离求解的 Work 追加 solver_path，用于审计，公开结果合约保持。
