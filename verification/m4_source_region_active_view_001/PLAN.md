# M4-SOURCE-REGION-ACTIVE-VIEW-001

固定基线 `3e6a41afc151162bdde1d4ba2247541a4c9616b4`、143 源 `4064a22157012db95522501f66cba05f60ee17a34bb3b98ee8e51df8486490bd`。唯一改动目标是指定源区后，从已注册的拟合视角中取到一张可支撑完整几何和可读性的原图。固定反例为现有资产 `91129d2e` 的 N15 求值三角 20–21。使用实际首对 P1 第 3 调的合法请求复现基线，原生 RIGHT 是独立正例。原 N1/P1 质量、账本与所有失败保持封存。[首对独立复核](PERF050_READONLY_PRODUCT_PILOT_001_INDEPENDENT_REVIEW.md)

用实际生产相机、同槽几何和原栅格的独立复放已验证 TOP 61,845/0 与 RIGHT 86,955/1,300，按所选源三角边界计数。初版复用现有注册相机和相同显示范围，选择依据为当前几何及像素反馈。

1. **复用已有计算。** 在 `source_region` 只对所选全部三角能严格匹配现有单一有向矩形定义的情况启用。用已准备的选区、同代显示和拟合相机，复用 M4 单区域遮挡／视锥判定及原图像素判定。遮挡使用当前显示参与对象，包含其他未选三角。沿现有相机顺序优先选未被证伪的完整视角。先排除已证明遮挡、背向或出界的视图。真实帧中目标属面与原 RGB 需要达到当前 16 个表面像素、4 个对比边界像素和色差 24 的门槛，才与几何证据合成完整见证。边界按选区像素归属，避免把同一对象的邻面当成选区。真实对比不足则继续现有候选。区域定位与度量范围沿原合同，非矩形或证据不足的选区保留样本与未知语义。
2. **只交付一张原图。** 观察到合格帧立即停止。原公开帧上限、源面身份和选区量测回包兼容。候选未取得完整帧时按现有合同交付可绑定的部分样本或明确原因。每次实际图像构造仍走既有回调、期限和账本，未采用图仍计成本。候选计算复用一次场景捕获及当前可见状态。热重读零新增构图，无图请求零新视角工作。N15 应跳过已证明被挡的 SCENE，若先到 TOP 则必须识别实际边界不足，继续到可读 RIGHT，至多两次新构图。核实际 MCP 首包的见证和唯一 PNG 经现有 CLI 交付路径可用。验收只认候选实际回包中的原 PNG。
3. **验收到真实入口。** 先用封存捕获、原请求及同候选的既有 PNG／NPZ 做离线正反例。覆盖 SCENE 首图即可完成、几何全隐、TOP 低对比、同对象邻面、隐藏对象、等深归属歧义、非矩形／混合选区、无图、同代复用、预算或期限中止、独立来源和选区量测。等深归属不明时按实际样本描述，保留完整性未知。对同一 N15 冻结副本实际从 MCP 跑 A/B 各一次。每臂首次请求及一次同代重读，核对实际首次调用、正文与唯一原 PNG、最终选区范围、几何和 RGB 对比、实际构图分母、原点对量测一致、前后资产和关闭。报告选择、采集、构图、编码、传输及缓存成本，单槽时钟只作诊断。若首图正常的控制出现主要新增工作，报告其归因。产品只开一个候选，零模型、零额外 API、零付费、零资产重建及零替补。
