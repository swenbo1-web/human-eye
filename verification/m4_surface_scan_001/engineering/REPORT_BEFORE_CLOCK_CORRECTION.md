# M4-SURFACE-SCAN-001 工程首轮记录

## 固定输入与版本

候选提交为 `c6355a01a4c6ee204a0d676cd9309f02428fe3ba`，138 个运行源码的 SHA-256 为 `b3654f6f943c3fb6feff0011397c0a8c20872e41f35973e6baf53e3a5e277314`。隔离发行版为 `9.7.2+m4.surface.scan.r1`。

装配复用资格冻结的同一文件与登记姿态改动，24 个中性命名网格、530 个顶点、978 个三角形。主五序列各自新建一个 owned Blender 与一个安装版 MCP 进程，每序列依次执行冷读、重复读取、一次登记姿态改动后的读取。每次请求都只有 `surface_scan` 与 `threshold_m=0.002`，`include_image=false`，调用者没有指定对象或候选。

主五序列使用普通 `target_runtime_entry.py serve` 入口与实际 `BlenderMCPHost`。第二宿主的单独 `process_01` 记录使用安装版验证引导、现有 SDK 注入 `BlenderProcessHost`，随后进入原有普通 MCP 路由。其实际命令依次为 `capabilities`、`capture_surface_scan`、`shutdown`。

主请求预算保持 30 秒，客户端等待上限保持 35 秒。此次产品调用没有失败与重试。原资格准备阶段保存的失败仍保留在 `worker/attempt_01`。

## 完整性与质量

原工程验收器的五序列全部通过。15 个主状态分别核对全部 276 对，共 4140 个对象对分区。独立 Process 状态另核对 276 对。冷读与重复读取均得到 71 对匹配、41 对实测非匹配、164 对严格外界排除。登记改动后得到 72 对匹配、42 对实测非匹配、162 对严格外界排除。各状态均为 complete，unknown 与 deferred 均为零，候选召回率与最终召回率均为 100%，FP 与重复对均为零。

原工程验收器同时核对所有私有实测距离，以及公开见证点的表面归属和点间距离。距离与见证点的数值展示容差为 0.1 纳米。阈值分类直接使用既有独立 Fraction 真值，不使用展示值判断。

离线复审补充了两项验收器需求。原脚本新采集输入哈希，仍需逐项比对资格 READY 已承诺的真值与快照哈希。公开匹配距离已和见证点间距核对，还需直接和该对的独立最近距离核对，并检查 witness_status。根代理将对同一批原始记录执行独立补验。运行绑定脚本保持原字节，补验结果应与本报告一起审阅。

冷读构建 24 个驻留资源，读取 530 个顶点与 978 个面，执行 24 个对象的世界变换。重复读取没有资源读取、世界变换、几何核调用与规范化。姿态改动后命中 24 个来源资格缓存，没有重读资源，只变换登记对象的 8 个顶点，同时服务层重新计算 114 个候选对。

首序列冷读的 surface_scan span 为约 1647 毫秒，宿主 capture 为约 121 毫秒。改动后的 surface_scan span 为约 1691 毫秒，宿主 capture 为约 55 毫秒。Span 为包含子过程的墙钟时间，不能累加。完整原始 span、服务 trace 与客户端时间均在各 `RESULTS.json` 中。

原始字段 `full_service_and_delivery_trace_ns` 沿用了过宽的名称。它记录 MCP trace 内的工具处理及 content 编码，外层 stdio JSON-RPC 帧编码与写入位于该 trace 时界外。完整工具交付的验收时界使用 `complete_client_request_ns`，上表即来自此客户端字段。旧字段与原脚本按运行绑定保留原字节，本报告修正其解释。

隔离构建与安装总计约 4.039 秒，独立保留各命令过程记录。每序列的 Blender 启动、产品启动与元数据、只读 QA 快照、登记姿态改动均独立计时。内存数据包含请求前后工作集与进程生存期峰值，峰值数据不表示每请求局部峰值。
