## 独立解析与实际图像事实

目标位于 x=1、0≤y,z≤1，法向为 −X。六方向中，SCENE 和 RIGHT 为背面，TOP、FRONT、BACK 为边缘朝向，LEFT 为唯一正面。

M4_Near 的平面位置为

`d = 8589935 / 2147483648 = 0.004000000189989805`。

从目标沿 LEFT 方向 `(−1,0,1)` 到 Near 平面，坐标变为 `z_near=z+1−d`。Near 原三角形满足 `y+z_near≤1`，所以目标上的遮挡区域满足 `y≥0`、`z≥0`、`y+z≤d`。严格正面积为

`d²/2 = 73786983304225 / 9223372036854775808 ≈ 0.00000800000076 m²`。

独立 Fraction 推导、实际首遮挡三角的几何摘要与原日志 overlap_area_screen_exact 完全一致。x=0 的 M4_Focal 在该投影中只有零面积相切。实际 LEFT 相机包含目标与该遮挡区，其深度范围覆盖两者。

实际只构造了 SCENE 图片。PNG 为512×512、3223字节，实际 MCP 图片块与产品保存 PNG 逐字节相同。当前 NPZ 的 RGB 与 PNG 解码相同，owner、局部源面、patch 映射和图片引用均与本槽当前来源核对。目标有91559个可见表面像素、1127个对比边界像素，front_facing=false、readable=false，最终保持 unknown，完整见证为空。

LEFT 的结论来自实际运行生成的几何分类及独立解析。LEFT 图片未构造。API 的 status=complete 表示观察调用完成；目标 region 的 unknown、inspection 的 covered=0 和 finite_pool_exhausted 同时保留。
