# A 资格运行证据复核

`passed=true`，共 358 项检查。通过范围是保存的来源、运行、线缆、进程、预算及归档证据。本批结论保持 `not_realized`，目标完整可读见证为 0。B、正式12槽和额外控制观察均未运行。

## 原件和来源

逐项核对关闭运行根的272个原件及272个归档副本，共8507203字节，全部与归档清单 SHA 一致。A 的141份当前及安装源码均匹配冻结 manifest，来源摘要为 `b7868c46119b2f5dcb3ca426e78a2ac9bb45b51167a01d323516c7707eb81e76`，wheel SHA 为 `63ed8af520e56718903619420df2d8148ed49936adce7b071e002dc7c7d3c3cf`。实际 TCP bootstrap 中的宿主与驻留源码已按压缩原字节解码核验。本次全部输入路径、字节数和 SHA 收录 JSON。

## 实际次数与失败保留

累计3次 owned Blender 启动，包含1次资产 builder、1次业务前 PID 检查失败及1次成功 A 观察。实际产品观察1次，资格 raster 1次，正式 raster 0次。首次失败原件与脚本快照均保留，其附加 runtime handle 证明为 unknown，原 stdio 持有进程 exit0、句柄关闭事实同时保留。

成功 A 的 MCP 持有进程 exit0，reader、管道与句柄关闭。Blender owned Popen exit0并完成 wait/reap，原资产及场景指纹一致。Blender 的单独 Win32 handle_closed 状态没有记录。

## 实际字节与图片
