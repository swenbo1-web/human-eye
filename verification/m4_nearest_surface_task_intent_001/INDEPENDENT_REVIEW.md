# 最近表面取景与任务要求独立复核

四个正式会话都在读取网格前，把目标和参照交给最近表面取景。四份原答都使用该调用生成的首图与同帧像素。简单题和追加两片间隙的题各 2/2，均符合各自交付要求。两题都没有出现仅简单组早期采用的配对，因而未达到任务要求影响早期选择的预设条件。

## 两种任务实际相差什么

两组共用已安装的产品 `2f7f492d7d0fd1af2ff956228d31bd57b5e31ddc`。将 146 个运行源分别与 Git 对象、wheel、隔离安装和运行清单核对。每个参照的简单题为 396 个 UTF-8 字节，比较题为 468 字节，完整前缀相同，差异为一句“另请分别报告两片到参照实际表面的最短间隙（米）。”四槽实际发布的五个工具和请求模型配置一致。每槽使用新的模型对话与独占冷 Blender。执行顺序为 A1、B1、B2、A2。

依据独立重开的世界坐标网格，以有理数计算两片和参照的逐三角最短距。对 Item G，最近片的源三角为 0、2、4，间隙 0.559016994375 m。另一片为 2.839454172900 m，按参照外包盒会选错。对 Item Q，最近片为 1、3，间隙 0.625 m。另一片为 5.909473326786 m。无模型预飞中，直接使用安装所公布的示例，两道题均能得到正确获胜源面、距离、图及合法像素。调换所报源面，两题的像素复核均会拒绝。

四槽的主动首包都给了全局最近距离、精确点对和一个获胜三角。Item G 为目标源面 2、参照源面 1，Item Q 为目标源面 3、参照源面 0。这个目标源面能定位到近片，首包所列的取景范围只有这一行。

四槽随后都读取了目标的全部五个源面及参照网格，又对近、远两个完整连通片各发一次无图量测。近片请求重复了首包的最短距，同时将范围明确绑定到完整的近片。远片请求首次给出另一片的真实间隙。共八份逐片量测原包，所有点对均在当前目标与参照表面，距离与精确真值一致。两份简单题原答也自愿给出两片的数值。这些记录能说明各次请求增加了哪些事实，模型选择补查的内部原因未观测。

## 成本与边界

简单组与比较组合计业务 9 / 8，实绘各 2，实际图块各 2，PNG 各 6,260 B，正文 32,475 / 30,668 B。简单组原始输入加输出 85,856，减去所报缓存输入后为 34,144。比较组分别为 76,014 和 36,206。每种题型只有两个槽，各自的整槽时钟和 token 是路径诊断。上一批同一安装的两个比较题未早期采用。本批同时更换了装配与共同题面，不能据两批差异给单一改动归因。

29 次协议交换共含 17 次业务，逐次检查了原响应、末包、双向 EOF 与零在途。四个 CLI 与 Blender 进程均退出 0，四个 Windows Thin 进程均记录退出码 1，缺少 Thin 自身正常退出标记。本次独立读冻结记录时，首个版本沿用了上一批分臂安装记录的结构。按本批单份安装记录复核后，203 个互异输入路径和正式原件均核验。冻结、原答和自然运行分母原样计入。

下一项可单独试验用紧凑引用在主动首包标识获胜三角所属的完整连通片，继续提供已证的最近间隙，观察模型能否直接定位该片并减少读整网格、重复量近片的次数。另一片的距离仍需相应量测。可沿用本轮的原图、像素、数值和有序来源要求，并记录新增计算与回包字节。这项改动留待另批验证。
