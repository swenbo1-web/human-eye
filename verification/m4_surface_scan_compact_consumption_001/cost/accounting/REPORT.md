# 同九格原件的成本账本

本批在根匿名质量 seal 后离线解封。最终内容九份均完整正确，冻结主分类保留七份 complete_correct、两份 execution_failure。N2、O2 的重连错误、全部耗时和 reported usage 留在原固定格中。

N 为原生组，O 为旧扫描 OPT1，C 为 compact 展示候选。本次展示结构及真实工具描述一同变化，候选整体收益的归因范围由独立机制账本进一步核对。

## 共享准备与发布

九格 full 合计 738.9711436 秒，run_models 为 739.4098639 秒，外层正式进程为 739.4283762 秒。外层与九格和的共享差额 457.2326 ms 整体保留。

九个 CELL_FINAL_TIMING 文件发布合计 3.3657 ms，FORMAL_PROCESS 文件发布 0.2078 ms。记录这些耗时的 publication 回执自身写入另属未测。

bootstrap 已测 1073.7458 ms，总准备及前置协调未完整计时。既有安装复用耗时 O=4.0792139s、C=4.0945007s 是历史记录，本批重建0。

初始 ZIP 写入关闭 27.0849 ms，r2 为 27.0805 ms。行政 redaction、ZIP复核、回执、审核、交付及协调模型成本缺完整时界。

费用、订阅扣费、实际模型版本/effort、provider输入及请求数、弃流usage涵盖、完整准备、明确到盘状态等均保留未测。没有拼接旧六格成本与本轮质量。

## 复算材料

recompute.py 使用标准库离线读取 508 份源文件，执行 874 项检查，生成 LEDGER.json 和本报告。它只核既有九格，新增 Blender、产品服务、模型和 API 运行均为零。REUSE.json 记录旧六格账本 helper 来源。

本次全部描述性结果属于一个固定任务的三次重复，广域泛化和尾部稳定性另需证据。AL未绑定，host epoch5，未借其他聊天句柄。
