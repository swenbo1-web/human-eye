# M4 Assembly Evidence Consumption scoring

Score both original answers on the same ten gates, after the first packets and original answers are sealed. Retain the denominator of ten per arm. Use `pass`, `fail`, `unverified` or `unrun`. `fail` means the answer contradicts or omits a required fact. `unverified` means the necessary original evidence cannot be validated. `unrun` applies when a slot has no original final. Cite the original answer for each judged criterion. Evaluate the use of candidate fields and the purpose of later calls separately from quality.

| G08, G28 | Report each separated pair's global minimum surface gap in metres to at least six decimal places. The reported positive distance must agree with the independently certified value to its stated rounding and within the prior one-micrometre absolute allowance. |

Check both points against their actual triangle surfaces and the distance against the certified minimum, propagating the printed rounding. Verify any cited supporting triangle in its stated index domain. Equal valid alternatives pass. |

A common strict interior point passes when independent closed-shell winding and positive clearances verify the claim. A bare point or a zero surface distance is insufficient. Accuracy of any cited proof quantity, support scope and claimed point is checked from the current arrays. |
| S1 | Bind the identified operands and evaluated geometry to the current observation using a resolvable capture identifier or equivalent current scene, frame and evaluated geometry evidence. A verified scene fingerprint or revision may locate the source. Object names alone or proofs from the other arm do not pass. An independent host reread is optional. |

Pin the historic raw scene, world arrays, native snapshot and exact prism/ray oracle. Recompute zero-tolerance truth independently. Check each owned terminal read against the original file bytes and unchanged-scene guard, compare actual native and evaluated arrays to the frozen asset, and preserve each current face ordering. Cyclic vertex rotations and a permutation of oriented triangle rows leave geometric identity intact. A different tessellation passes when each triangle is bound to the same planar polygon, triangles have the polygon's orientation, and their directed edges cancel to exactly its boundary. Score support indices in the actual capture domain. Apply the prior world-geometry arithmetic bound of `2.9103830456733704e-11 m` when comparing computed coordinates.

Pin each original first tool result to its installed MCP request and exact stdio response, producer read context and owned terminal geometry. Check raw host selection, object/instance IDs and captured support rows. The candidate projection identifies same-capture rows and inherited strict proof checks. An independent recomputation uses current coordinates and does not treat inherited checks as external attestation. Keep source-binding and evidence-adoption results even when an answer is unrun or requests another source.
