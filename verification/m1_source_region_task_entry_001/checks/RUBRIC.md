# 指定选区与整件量测的正式评分

两臂使用同一套标准。每项一分，总分七分。依据固定题面、TRUTH.json、实际工具轨迹、独立初末求值和原始最终回答。

1. **范围。** 答复区分 N26 的当前求值三角 4、5 与 N26 整件。两次量测共同参考 N07 整件。允许沿用题面唯一指代及有效的当前引用。
2. **选区距离与方向。** 报告 21474841/1073741824 m 或误差不超过 0.00005 m 的等值，方向为世界 +Y。
3. **整件距离与方向。** 报告 6442455/1073741824 m 或同容差的等值，方向为世界 +Y。共同方向表述须明确适用于两次量测，且量值保持选区远于整件。
4. **选区最近点对。** 列出世界坐标点对，起点在当前 N26 的源三角 4 或 5，终点在 N07 实际三角表面。点对达到选区最短距，位移沿 +Y。面归属及位移采用 0.00005 m 容差。
5. **整件最近点对。** 世界坐标起点在 N26 整件的实际表面，终点在 N07 实际表面。点对达到整件最短距，位移沿 +Y。同一组三维坐标不能同时通过两个不同距离。接受达到各自下界的任何等价点对。
6. **当轮完整性与可读性。** 正式答复应说明当轮合格局部图可以完整呈现所选面和证据依据。核实际正向图的选区四角、全场 742 个非选中三角的遮挡、两个源面均有实像素、选区边界对比。接受任一实际合格视角及两臂共同允许的等价出图路线。几何候选和证明不足的局部像素单独登记。
7. **原图可回读。** 原答包含能打开的 Markdown 图片或链接，或真实附件。闭槽后按原答引用复读同一槽当轮合格原图，SHA-256 和原字节均一致。工具回包中出现路径、只给裸文件路径、同名全场图和人工展示分别记录。实际宿主显示与真人点击只在有证据时通过。

首包自然选择、工具名、简报或全文、补查与成本在质量得分之外报告。原题只读，初末场景要求一致。
