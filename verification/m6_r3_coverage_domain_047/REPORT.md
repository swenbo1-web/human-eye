## 两个计数上界

同一个有效单对距离求解中，把每个子问题视为左右两份原生面集的笛卡尔积。构树时每次只把一侧原生行分为不交两份。C 的贪心种子沿一边下降，只精算终端叶，沿途未处理的兄弟在堆中各出现一次。扩展、叶内过滤、全局早停及投影剪枝只消费或丢弃这些义务。A 的正常从根遍历、A/C 的线性按行枚举和经同一身份验证的复用树也保持这项唯一性。每个原生三角对至多进入一次窄相。因此，`n*m <= 当时窄相余额` 足以保证单对的窄相次数，等号允许。独立请求、不同账本或扫描与最近查询的重复必须分别计。

对 C 的普通表面距离账本，令 `P=n*m`。在原路径、有效绑定输入、无其他事实从同一账本追加工作时，一个可事前计算的保守计费上界为

```
U = n² + m² + 8(n + m) + 124P + 4
```

计数的逐项理由如下。

- 两个独立二叉 BVH 的一次原始计费上界分别为 `n²+2n−1`、`m²+2m−1`。每侧每行最多经历 `n` 或 `m` 层，节点数不超过 `2n−1` 或 `2m−1`。验面、最多三倍引用顶点、整数面准备及树包装成本计入前式。合法的缓存树复用路径有原建树工作重计，仿射回退按照已付验证和完整准备处理。
- 单个原生叶对至多计 75 单位。包含叶访问、盒检查、两套平面点积和界检、交集与最多 24 单位的共面裁剪、点面／点边／边边枚举。潜在笛卡尔树以至多 `P` 个非空终端分块，保守计访问、子键、入队及移位重检至多 `10P`。
- 可选工作只花已结算信用。原盒界复用至多 `2P`，已证明节点排除的保守收入至多 `2P`，严格叶排除的收入至多 `35P`。总支出上界 `39P` 覆盖方向尝试、失败、区间与测试，未重复抵扣被节省的必做工作。最终见证源面检查另留 4 单位。

只有 `U <= 当前总工作余额` 时，这条计费上界提供充分保证。它与某次运行的实耗独立。线性路径有更紧上界，独立证明也保留了稍紧的树开销估计。两种保守计量对本批矩阵的通过／不通过分类一致。[义务与计费证明](proof/DOMAIN_PROOF.md)

## G60 实有负载与首个未闭条件

原六个普通 GUI 的前后快照，从 12 个物体的原局部顶点和矩阵重新生成世界数组，逐位核对 native 面及世界几何摘要。每个实际表面对象对都是 60×60。单对潜在 3,600，条件计费上界 **454,564**。两个预算界覆盖原 A/C 各 462 个真实求解调用的输入形状。

原 18 个服务和 54 份完整回包中，每格最近查询 11 次求解，扫描 66 次，共 77 次，三臂全计 1,386 次。原记录中最近和扫描的提前排除、缓存命中、未知、延后均为零。概览缺逐对工作记录，保留未测。每格有 11 个最近查询的无向对象对在扫描再次求值，其中 1 个同顺序、10 个反顺序。扫描有逐对依赖键，最近查询未保留实际键。几何相同支持识别重复，缓存兼容仍须用各自来源、算法身份与有向键核对。A 每次实际窄相 91–656、工作 8,065–39,046，C 为 6–91、2,456–10,769。这些是实测范围。045 历史上 C 对 A 的整业务配对中位节省 83.13%，进程存活节省 67.37%。原件没有逐对耗时，不能用这些整业务数据分摊可切换负载的时间占比或估算混合入口提速。[G60 原件复算](g60/README.md)

第一个超出两个预算证明的完整答复条件，是**精确结果及见证能按现有合同发布**。面数与累计工作不限制 exact 位宽或 binary64 发布。已测 G60 的共同整数系最多 55 位，符合距离核的快速整数根盒条件。此条件只约束输入坐标。中间有理值、平方根和最终表示还要走各自的位宽及发布检验。全部 66 对的原生世界 AABB 重叠，现有框架中的盒间隙不能先验保证非零见证有足够表示余量。

纯算术反例进一步分离这两个条件。以 52 位二进制格点构造一个点和一条斜线段，其正交最近点在段内，精确距离严格为正，两个最近点却舍入成同一 binary64 坐标。相对整数只需 51 位，面数及工作界都很小，原发布器仍会省略见证。该例验证的是发布谓词缺少充分条件。它没有作为新资产送入求解器，也不构成 A/C 差异样本。真实 G60 的 54 个历史回包均通过原验证，属于已测结果。[算术检查和实物域](EVIDENCE.json)
