## Repetition and cache evidence

The 11 Target pairs recur in the same service's scan. All 11 have exactly the same bound unordered source geometry. One retains the same ordered endpoint direction; ten reverse it. Across 18 services that is 198 repeated geometrical pairs: 18 same-order and 180 reversed-order. The original scan still actually computes all 66, and measurement entries/computations grow from 11 to 77 with zero hits in every service.

The two call sites **both** request exact rank. The cache difference cannot be attributed to that flag. The original source uses an ordered key containing algorithm, parameters and two mesh representations. Nearest uses the ordinary read-resource/full-mesh representation; scan's actual audited calls use typed scan-resource dependencies. Scan's 1188 key digests are logged; nearest's 198 digests are not. Exact digest equality is therefore unmeasured. Same source geometry does not establish admissible result reuse or a common key, and no key or routing change is implemented.

## Remaining evidence limits

The public nearest reply exposes the winner's value and complete coverage, but not every nonwinning pair's distance/witness. Nonmatch scan rows have distance diagnostics; only published match witnesses are present in the full response. This audit reuses the original complete public truth checks and performs no new per-pair numerical oracle. Original polygon IDs are absent from the native hash snapshots/fixture; original triangle row order and coordinate bytes are preserved without inventing a polygon map.

This subtask establishes archival identity, original counters and historical benefit. It does not by itself establish a sufficient total-work/width/canonical-publication/compound-suffix condition or wall-clock guarantee. The fixed 129 counterexample and the parent source proof retain their own evidence and conclusions. A future selector's cost and any hybrid speed remain unmeasured.
