# 装配首包证据离线验收

**保留优化版作为隔离候选，进入独立复核。** 基线、首版和优化版在两个装配、三种响应模式下共 18 份结果，逐份独立复算均为 **10/10**。15 项安装入口反例全部通过。候选限于普通装配查询的显式 `brief` 路径，默认和 `full` 保留原事实与响应结构。

## 同次捕获能复核什么

首包原本就给出两片支撑三角的世界坐标。候选沿用这六个坐标和现有场景指纹、对象及实例绑定，附加四个已解析对象的点面计数、穿插候选行、两个支撑三角对应的顶点行，以及精确求解已确认的三项判据。索引为归一化捕获中的零基行号。复核方可用首包的六个点重新计算三角面是否非平行、两片三角是否相交成正长度线段、相交线段中点是否位于两片面的严格相对内部。

首包可以重放局部几何计算，并说明这六个点在捕获中的行位置。拿独立网格核对这些位置仍需要独立读回。当前证据未提供原生多边形编号、文件摘要、独立原生网格摘要或真实帧证明。第二装配使用历史实际数组配模拟捕获身份，装配001重放原生产宿主返回的资源数据。两者均逐项绑定核定的历史来源，当前执行范围是离线。

- 第二装配中，N16 与 N13 穿插。捕获三角行为 `[13, 11]`，对应顶点行 `[[1,10,2],[1,7,3]]`。独立精确裁剪得横穿线段约 **0.009999977425 m**。
- N08 正间隙约 **0.100007281 mm**，按题面零几何容差为分离，也是最近分离件。N28 正间隙约 **23.000000045 mm**。旧验收中的 0.25 mm 业务接触阈值适用于旧题。
- 装配001的捕获三角 `[42, 2]` 与顶点行 `[[17,41,42],[4,5,6]]` 可复算约 **0.031250020223 m** 的非退化横穿线段。该长度描述两片边界的交线。
- 边界相切和共面面接触保留 `touching`，未产生横穿支持。大坐标平移反例的严格横穿依然成立，最近可表示中点误差约 **1.242 nm**，超过 **1 nm** 定位预算，发布位置保留 `unknown`。错误捕获域在入口被拒绝。新捕获代际改变几何后，上一代的穿插信息不会进入新结果。

第二装配首包增加 **612 B**，装配001增加 **889 B**。两套正文均低于 **10,000 B** 目标，已复核的 Codex 0.152.1 MCP 输出和历史回放均保留了完整文字。schema 另计。历史装配001原有两次补查共 **2,565 B**，工具请求到回包共 **0.088 秒**，前一结果到发起追加的累计 **30.620 秒**包含模型决策与其他墙钟开销。本批没有模型调用，可观测的成本是新首包的字节与构造开销。

首版在现有读取上下文已经为本请求分离结果后，再深复制完整结果才挂接证据。优化版直接挂接到该请求持有的结果，缓存副本仍只保存原测量。独立投影计时每场景每版 **401 样本**，复用已归一化网格，计时外准备结果。第二装配投影中位 **67.2 → 7.1 微秒**，装配001 **69.3 → 7.2 微秒**。优化移除一次外层深复制，共减少 393 次复制调用，两组各自仍只校验一对支撑三角。仅投影的 Python 分配峰值中位 **9,696 → 4,472 B**。峰值由单独的追踪采样得出。

## 验收边界

138 项既有离线回归通过。安装使用固定 143 个运行源、两份可重放补丁和隔离 wheel，校对了仓库、源码、wheel 和安装字节。首次安装检查对正规化后的版本字符串期待错误，早期回放的审计读取时机和请求关联有误。交付检查还发现 Windows 应用补丁时改了两个文件的换行，已固定为沿用仓库字节，重建两版并重跑验收和计时。诊断原件均保留。原始装配、正式安装和默认部署保持原样。真实 Blender、模型、图片、raster、付费与 API 消费均为零。当前会话无 Agent Learning 写入工具，登记待补。

建议复核通过后做一次同资产配对消费，检查优化版能否减少 Codex 对完整网格的补查，并比较同题质量和完整耗时。附加字段可重放局部几何核验，独立宿主源证明仍应按任务需要取证。
