# 多层遮挡任务的简报首调实测

本轮只将原题面推荐的首调 JSON 增加 `"response_detail":"brief"`。正式插件槽首条业务调用确实采用该参数，交付 **10,728 字节**文字和三张原始 PNG。上一轮首次 `full` 为 **359,581 字节**，三张图按原序逐字节一致。本轮最终采用 M02 和 M09 的两张局部原图，沿用原九项独立评分，**9/9**。

## 图像与最终事实

| 区域 | 最终答复采用的证据 |
| --- | --- |
| M02 `[0,1]` | 首包 `SCENE` 原图，50,557 个目标表面像素和 926 个对比边界像素 |

首包带有区域行号、世界中心、半边向量、带方向法向、原图及遮挡原因。模型又用普通 Python 获取完整当前源数组，独立重算区域筛选、面积和单位法向。M09 的精确面积为 `√10/256 m²`，斜面单位法向为 `(0, −1/√10, 3/√10)`。M03 的具体身份和遮挡推导使用普通工具提供的额外几何依据。原答的「最大水平位移 1/6 米」应明确为各坐标轴上的分量上界。SCENE 方向的水平位移长度是 `√2/6 m`。独立逐向投影仍确认 M03 覆盖 M06。

第二次业务调用请求了合法的无图 `full`，桥接原样透传。该回包用了 **168,893 字节**，重述区域事实和 M06 遮挡。额外提供的 M09 候选与遮挡方向没有进入最终答复。该调用没有交付新原图或 M03 身份，产生一次 **318.361 毫秒**的全场索引。最终答复始终引用首包两张局部原图，本轮没有重复传图、普通构图、错误或恢复调用。其余三次业务调用用于上述独立几何与遮挡核验。逐条归因中，重复观察从两次降至一次。同事实的独立复算和当前遮挡物补证分开计数。 [实际首包](FIRST_PACKET.json) · [原答](answers/P1.txt) · [独立评分](scoring/QUALITY.json) · [逐条核验](checks/BRIEF_ENTRY_REVIEW.json)

## 范围与剩余依据

新槽消除了本次普通补图和重复图片传输，独立几何核验仍发生。优先审查简报对任务必需的标量面积和单位法向是否应直接交付，并区分有实际依据的遮挡物身份与现有通用遮挡原因。展开回包重跑全场索引、M09 先尝试被挡视角是各自有实测时间的工程问题。同题首调试验在本槽后收口。
