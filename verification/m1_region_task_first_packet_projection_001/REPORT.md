# M1 区域任务首包投影 001

**工程资格通过。** 同版标准入口原样保留显式 `full`。在隔离生产 stdio 上显式启用 `--region-task-evidence` 后，区域巡检的成功回复直接交付原有简报投影。端点在实际目录里说明了此行为。请求和服务调用仍按原参数执行，标准入口继续提供完整诊断。

## 原始任务

| 封存请求 | 标准正文 | 隔离正文 | 标准 stdio 响应 | 隔离 stdio 响应 |
| --- | ---: | ---: | ---: | ---: |
| 密集盲扫 P2 | 335,181 B | 7,521 B | 362,123 B | 19,881 B |
| 密集盲扫 P3 | 335,179 B | 7,521 B | 362,121 B | 19,881 B |

两份首包正文均减少约 97.8%。标准入口与基线的完整首条 stdio RX 2/2 逐字节相同，回复内容与历史原件 2/2 相同。隔离入口的省略、显式 `brief`、显式 `full` 三种形式均等于标准入口的实际简报，覆盖 2 份原件各 3 种形式。两份隔离首包各保有 3 个候选、2 个完整局部见证、1 个有理由的未知及其 6 条具名挡片。固定 33、34、35 B 工具头的结果及历史检查 12/12 保全内容。P2 六种派生坏绑定由原评分器识别。

每份实际响应继续提供同序的 3 张原 PNG，共 8,671 B。由实际进程的原始响应解码读回 6/6，并与封存 PNG 字节逐张核对。简报保有两个同名 SCENE 帧各自的作用域、帧身份和不透明引用。P3 的 3 个引用另外逐条对应旧公开 `read_images` 收据的作用域、帧及 PNG，旧进程关闭后路径字节仍可读。P2 的现场证据来自本批实际生产 stdio 的原图块和绑定。

## 兼容和失败

| 控制 | 实测 |
| --- | --- |
| 较小区域巡检 | 隔离显式 `full` 与实际标准简报相同，7,707 B 及 1 张原图 |
| 联合整件量测 | 9,605 B 及 1 张原图，量测成员与标准实包简报相同 |
| 无图巡检 | 6,873 B，保留仅预测语义及零原图 |
| 普通目标全文、独立选区全文 | 与基线及同版标准的对应回复一致，选区对照排除当次随机追踪 ID |
| 独立选区遮挡未知 | 原 partial 与原 PNG 保留 |
| 过期区域引用、无效详情、冲突对象、损坏图摘要 | 三臂 12/12 按预期拒绝，之后正常请求成功 |
| 成功回复发布前过期 | 三臂 3/3 返回 `live_request_expired`，无图块 |

工具目录仅增加 212 B 的入口说明，工具名和参数 schema 逐项对照相同。实际服务调用核对覆盖原查询、显式会话及独立进程生成的默认会话。所有有效路径使用一个封存生产记录进入现有编码，`response_detail` 没有传给服务。正式工程试验 9/9 启动并正常 EOF，69 个业务工具请求中 54 个成功、15 个预期拒绝。原始账本含 63 次服务调用、60 次封存生产记录取用，三次过期区域引用在取用前拒绝。过期期限控制进入服务和编码后由发布门拒绝，按实际计数。
