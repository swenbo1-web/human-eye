# M4 自动跨尺度取证

本批完成一次公开调用内的任务区域发现、局部取证和当前源面回绑，并完成一次依据首版真实热点的优化。独立质量及预登记性能条件通过，选择 R1 作为本批保留版本。管理员独立复审待完成，实际安装均位于本批隔离目录。

## 当前能力

调用者提供面积区间与有向单位法向 z 下界。引擎从一次完整全场捕获发现最大共边、共面、绕序一致的矩形分量，以精确平方比较筛选任务集合，为缺少可读像素且具有几何完整候选的区域拟合局部视窗。各局部继续使用同次捕获的全部场景三角参与遮挡。

```json
{
  "session_id": "example",
  "include_image": true,
  "query": {
    "mode": "active_observation",
    "region_task": {
      "area_min_m2": 0.0078125,
      "area_max_m2": 0.03125,
      "normal_z_min": 0.75
    }
  }
}
```

阈值采用有限 JSON int/float，排除 bool，整数值 float 归一为 int，其余浮点按最短十进制表示构造 Fraction。面积及法向门槛含等号，法向的正负条件分别处理。任务条件完整进入缓存键。region_task 使用全场发现，与 objects 选择互斥。原有对象观察、默认观察及 task_query 的 whole_objects 测量保持各自语义。

默认 brief 直接交付任务区域、世界位置、对象内当前源三角行、当前来源、完整见证或具体未知原因。顶层 frames 为选中图片，constructed_frames 保存全部实际构造，scopes 保存各自相机、来源及观察。三个 SCENE 通过 scope、frame_identity、image_ref 和实际 native block index 关联。

## 唯一一次优化及完整成本

首版真实资格先通过，随后冻结 FIRST_VERSION_HOTSPOT.json。首版全场六图的 render/publish 合计 319.9171 ms，反馈合计 75.0761 ms。优化保留真实全场 SCENE，并为未构造方向计算保守像素中心整数包围上界。全部剩余几何完整候选均低于原 16 像素门槛时，跳过该方向并转入局部取证。

双阶段投影采用向外区间，逐源三角检查视锥、面积和重心运算误差。发生裁剪、退化、数值放大或非常规投影时回到原观察路径。16 表面像素、4 边界像素和 24 RGB 对比门槛沿原值。预测跳过记录与实际 observations 独立保存。

三对交错顺序为 R0/R1、R1/R0、R0/R1。质量验收确认每对任务结果、全场有序几何、选中三图的相机、PNG、RGB、depth、对象 owner、源三角 owner、patch owner 和映射数组完全相同。每次主任务构造从 8 帧降到 3 帧，两版均交付概览与两个局部见证。

## 质量、状态与预算

独立质量模块完成 10,867 项检查，根生命周期及成本复核完成 3109 项检查。根汇总另核 742 份直接输入摘要。全部 8 个 owned、14 个公开请求、58 个真实构造帧和 44 个 native 图片块均保留原件。状态槽包含缓存图片再次交付。

默认旧入口的六图及既有 brief v5 通过。相同任务 full/brief 重复请求新增构造为 0。法向阈值改为 1 后只保留两个水平区域。独立未保存副本中水平面沿 X 增加 0.25 米及恢复，来源 revision 依次为 1、2、3，恢复后使用当前绑定。产品 setter 为 0，测试夹具执行两次预登记矩阵写入，源文件哈希保持一致。

三个正式优化 generation 和四个状态非缓存 generation 共保留 35 个方向跳过记录。独立向外重心运算证书排除 1708 个位于声称像素包围界外的源三角候选采样。未构造方向保留未观察状态。

水平局部 465 个及倾斜局部 1 个边缘或近等深像素的精确三角归属保留数值模糊。所有前景仍核对源三角成员关系，并在 `1e-8` 米余量下检查更近表面。可读性和几何完整性各有独立证据。

首版 42 项回归、优化 7 项回归、查询交付 27 项及独立 18 项优化控制通过。历史过期 schema 断言的 7 项失败在原接受基线同样复现，失败记录保留。单元测试的真实生产 raster 调用为 0，合成 PNG/NPZ 编码及 mock 输出单独列账，较早未 profile 的临时图片编码总量保留 unmeasured。

状态验收器的旧 brief 版本假设、缓存 generation 计数、派生凭据 str/Path 接线错误及根汇总误把状态通过数当作布尔值均已保存初稿、错误和更正。所有更正读取已有实测原件。模型消费者、训练及付费 API 调用均为 0，Agent Learning 当前聊天任务绑定待宿主同步。
