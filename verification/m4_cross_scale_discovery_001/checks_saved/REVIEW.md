# M4 跨尺度发现的独立质量验收

资格首槽、正式六槽及状态槽的保存证据通过本模块验收，共 10,867 项检查。571 份直接输入在汇总时复核摘要和字节数。判定原件为同目录 QUALITY_REVIEW.json，SHA256 为 `6ca4fa18f2ba549869e259b671c9d4c268bf7035ae2aeeef1aef7c19b4608463`。

## 区域、来源及图像

输入只含面积和有向单位法向条件。独立 Fraction 拓扑对照确认当前捕获包含 9 对象、54 点、56 三角，最大共面分量 24 个。22 个矩形覆盖 44 三角，方环及 L 形的 12 个三角继续参与遮挡。合格对象恰为 Obj_02、Obj_06、Obj_09，各自源面为对象内第 0、1 行。

两个开放区域均取得来自当前完整源几何的局部 SCENE 见证。水平区域有 50,557 表面像素、926 对比边界像素，倾斜区域有 71,531 表面像素、928 对比边界像素。完整性由独立精确前向投影及三角交集面积证明，可读性由真实 PNG/NPZ 的 patch-owned 像素复算。盖下区域保留 `positive_area_occlusion_all_front_views` unknown，六方向具体遮挡理由完整。

单次捕获的 document epoch、host/instance、对象内源三角行、有序原始点面及父子摘要均已核对。各 scope 的相机、patch 映射、frame identity、image reference 及原始 native block index 单独解释。三个选中图片都可使用 SCENE 名称。

每个实际构造帧均核 PNG 与 RGB、数组形状和原始摘要、深度、对象 owner、源三角 owner、patch owner 及独立世界射线最近表面。模糊边缘和近等深带的精确三角归属继续保留数值限制。所有前景像素仍核验其源三角成员关系，并在 `1e-8` 米余量下检查更近表面。

实际唯一构造为 58 帧，包含所有未选中交付的帧。14 个公开请求共交付 44 个 native 图片块，其中包含缓存图像再次交付。该计数由原始响应和构造路径去重对照。

## 三对同质量比较

三对首版与优化版全部通过。每对的完整有序世界几何、三个任务区域的几何与状态、概览及双局部相机、PNG、RGB、depth、对象 owner、源三角 owner、patch owner 和映射数组逐项相同。首版每槽构造 8 帧，优化版每槽构造 3 帧，选中交付均为三张。

PAIRED_QUALITY.json 含 114 项配对检查，SHA256 为 `72f55c999142879160e73a177f2442c344a09fd2d7d8707219218931405cf2cf`。根可据此进入已经预登记的完整服务与 owned 成本比较。

## 预测跳过的独立证书

三个正式优化槽及四个非缓存状态 generation，共有 35 个全场方向跳过记录。每个 generation 都保留真实 SCENE 图。所有跳过记录均逐区域说明保守像素上界或真实几何非候选，实际 observations 中保持这些方向未构造。

独立程序对实际发布矩阵传播双阶段仿射误差，通过向外 binary64 区间计算屏幕与重心运算图。1,708 个位于声称整数包围界外的源三角候选采样，均有至少一个重心上界严格低于原始 `-1e-10` 门槛，排除它们通过原采样测试的可能。每个声称包围界的整数格数量严格小于 16。该核验读取固定几何和发布矩阵，新增 raster 为 0。

## 保存验收器的修正

原状态脚本把旧入口预设为 brief v2，实际已存在的基线会在位置与 inspection 字段齐备时升级为 v5。首次失败 stderr、原脚本及仅改此表达式的派生 r1 保留。独立 AST 对照去掉新 region_task 的早分支后，既有默认投影函数与原基线完全相同。

状态缓存使用保存 generation 的帧计数及本次 capture 计数复核。该读取适配的完整源码差异和纯反例保存在 STATE_QUALITY.json。接收事件、实际提交和图片构造原件分别保留。

派生凭据脚本在已写完适配器后，曾因 `pin(__file__)` 的 str/Path 参数不匹配而失败。原脚本与准确错误记录保留，单独完成凭据。STATE_SAVED_CORRECTION_01.json 的 SHA256 为 `5e80f306173e2a506b8f279a29bed2ba3bbadb62cf8cc7626b762d667f12b6f9`。全部修正都读取已有原件，本模块新增 Blender、MCP、raster、模型及付费调用均为 0。

## 适用范围

本审核者参与上批独立 Fraction 答案及保存审核，本批承担独立来源、图像与任务质量验收。产品实现由其他代理完成。当前证据支持这一个固定资产上的自动区域发现和跨尺度取证。性能准入由根按照预登记三对成本判定。模型任务收益、任意非矩形区域和正式部署继续分别验收。
