# 独立验收方法

本批复用上批固定 Fraction 拓扑、源几何及静态证据的直接摘要，独立计算本次条件筛选。普通 float 门槛按最短十进制表示转 Fraction。面积使用平方比较，带方向法向在平方前区分正负，包含阈值相等。

任务结果来自当前完整捕获的最大共边共面矩形分量。验收按原对象名字与对象内源三角行对照独立集合，再核 document epoch、host/instance、原始点面顺序、父来源摘要和局部来源对应。每个 scope 保留自己的相机、帧及捕获索引。

图像验收读取原始 public MCP 返回和同 producer 原件，并核每个实际构造 PNG 与 NPZ。复用已固定的保存帧核验函数，独立核 RGB、depth、对象和源三角 owner、patch mapping、真实边界与可读门槛。跨尺度任务按 scope 与 frame identity 定位，独立核三个原始 native 图片块对应选中图片。未交付的实际构造图片仍计成本。

局部完整见证须由独立几何和实际可读图共同成立。开放倾斜面新增局部真实图在本批验证。真实遮挡沿原六方向精确证明，并检查结果保留具体 unknown。跳过全场方向的像素上界是预测能力证据，实际观察只来自已保存的图片。

两版本的正式比较先核三个任务区域、局部相机、同源映射、实际 RGB、owner 与 patch 结果，再比较三对服务、client 和完整 owned 区间。性能门槛来自预先固定合同。状态槽分别核旧入口、同条件缓存、条件变化、测试副本变更及恢复。

本验收者参与上批 Fraction 答案及保存证据审核，本批未编辑产品代码。原始失败、派生验收适配和数值模糊带均保留。
