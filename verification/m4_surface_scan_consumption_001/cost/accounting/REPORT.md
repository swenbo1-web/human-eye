## 可复算与保留项

recompute.py 使用 Python 标准库重新读取 320 个证据文件，执行 554 个断言后生成 LEDGER.json 与本报告。LEDGER.sources 保存每个读取原件的字节与 SHA256。根独立账本的 full/token/配对结果另外交叉核对，检查结论一致。

首次离线执行发现落盘 SCRIPT.py 使用 Windows CRLF，直接字节 SHA 不等于 worker 的原 code SHA。核明换行转换后，脚本对 CRLF→LF 的字节校验与 worker SHA 全部一致，原始文件保留。该核验工具修正没有变更六格输入或原件。
