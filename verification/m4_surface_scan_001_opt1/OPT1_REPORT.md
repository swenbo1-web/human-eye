## 改动与依赖来源

本次只修改八个既有运行文件。

- `SceneDeltaDecoder` 在完整解码后，为当前扫描生成私有 typed token。两条宿主的 getter 只交接当前 payload 对象的凭据，消费后释放 decoder 引用。普通 JSON 场景字段无法启用此凭据。
- 对象依赖包含宿主源码、decoder owner、宿主 instance/epoch、document epoch、对象 incarnation、resource id/revision、资源接纳序号及实际 matrix/scale。坐标正负零保持区别。相同版本内容冲突会被扫描协议拒绝，删除后重新接纳会改变序号。
- reducer 在本请求的目录、全集、来源和规范化校验后绑定当前 mesh。相同 typed class、当前 payload 身份和当前对象集合均成立时使用依赖快键，缺少绑定时沿原路径求值。
- 有序 pair 键保留算法版本、原数值参数和运行源码归属，测量继续保存在既有 2 MiB、256 项 store。阈值变化读取精确距离后重新分类，当前 coverage 和报告重新构建。
- 私有诊断增加逐 pair 的依赖键、命中状态及实际缓存计量。通用 task 和 solid 缓存继续使用其原合同。

附带数据限于当前对象和 decoder 原有资源范围，未增加几何数组副本。两条宿主、默认键回退、ordered witness、同面数几何变化、同名重建、rename、删除后重入、单位、epoch、A/B/A 阈值、unknown 恢复、低 cap、真实淘汰和字节计量均有定向反例。
