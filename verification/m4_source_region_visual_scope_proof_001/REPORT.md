# M4 有图选区几何筛选离线验收

**同一相机矩阵下，筛掉六视向都严格在视口外的对象通过验证。** 保守包围盒可以在已有相机上用于筛选。在冷路径用保守包围盒重新造相机时，旧帧的深度和源三角归属会改变，需使用独立相机与帧身份。

运行使用现有 `ba79e2f1` 安装，143 项源文件逐件核对 Git、wheel 与安装。主组四条正式源选区加一条历史 N12 零样本资格，再加两个 Yanyite 真实曲面选区，共七组。原公开请求、宿主几何、当前显示、生产相机和交付帧均绑定各自封存来源。

## 相机先验和成本

|输入|本轮证据|冷路径能否廉价获取|
|---|---|---|
|六视向与 512 尺寸|实装固定常量及封存相机|可预知|
|实例、显示、姿态与单位|同槽宿主收据、终态和原世界矩阵|已有宿主读取能力，需同代核对。此轮未计现场采集成本|
|选区 XY 尺寸|目标的真实求值顶点及原源三角|需准确目标几何或已验证同代资源|
|原相机全场深度|所有对象真实世界顶点紧界，包括隐藏参照|需完整求值或已验证同代精确紧界|
|保守深度|封存局部顶点极值加实装的向外仿射区间|现有目标宿主路径可读 `evaluated.bound_box`，本轮未证明 API 界值及冷开销|
|原域源面偏移|原全场精确三角数及对象原序|廉价上界不足以确证原偏移。实际派生域需保留对象和局部源行|
|量测参照|真实参照整件及其独立参与显示状态|需整件几何或可靠同代驻留|

将重构保守界用于原矩阵的筛选，七组保留集合与原紧界一致。将保守界用于重新构造**全场相机**，42/42 个视向的 view 与 projection 均发生位级变化，近面相同而远面改变；42 个视向的深度位改变，3 张 PNG、4 个 RGB 像素和 12 个源三角归属像素发生变化，对象归属保持。用同一套新矩阵比较全场和筛选，另 42/42 配对通过。新矩阵结果独立留档。

五组装配和轨道原相机的六向纯栅格累计约 934 → 842 ms。数值来自隔离软件回放；报告按视向分开记录原生产、实际栅格、PNG／NPZ 写入与验证，包含单次波动。数组 JSON 是按实际对象点面序列估算的载荷，宿主现场少读、TCP 减传和整题耗时在本轮均未实测。

## 失败边界

- 密集夹具原相机保留 14/14。原 SCENE／LEFT 帧逐字节复现。另用明确的局部相机对照，14 → 4 的同矩阵筛选保留了 M4_Far_00 的 M4_Near[0] 阻挡证据，精确正面积为 73786983304225/9223372036854775808 m²。历史轨道挡片 M12[10] 的两个 LEFT 正面积见证也保持。
- Yanyite 隐藏 Cube 始终保留 12 个量测三角，图中占 0 像素。仅保留目标选区会把 9,126 个可见选区像素错误增至 19,589，新增 10,463 像素均由更近的同对象未选面挡住。
- 五组实装反例覆盖未知界、触边与 ULP 邻界、超数值、丢行与同名、等深原序、换代与姿态、非默认视向回退及自遮挡。等深见证中调换原序会改变 4,513 个归属像素，RGB 和深度仍相同。全六视向旧判断的 X 轴提前退出可掩盖 Y 轴溢出，完整栅格会拒绝，误删后却能产生 6,049 个像素。离线筛选要求三个投影轴均可证有限，将此例判为未知。

最小下一步是在同一个真实冷 Blender 读窗口，只采集并核对当前 `evaluated.bound_box`、姿态、显示和实例，再与该次全量求值的紧界对照。先验证包围盒确实包含几何、记录未知回退和采集成本。原帧需要位级兼容时，应使用已验证同代紧界生成相机，保守相机单独验收。
