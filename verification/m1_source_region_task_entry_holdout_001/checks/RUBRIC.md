# 非共面选区留出题正式评分

按固定题面、TRUTH.json、各槽独立初末求值、真实工具轨迹和未改写的原答复核。共七项，每项一分。两臂同口径。

1. **量测范围。** 区分 Obj_08 当前求值三角 0、1、8、9 的整个并集与 Obj_08 整件，两次均以 Obj_04 整件为参考。图中可见的三角子集不可以代替量测选区。
2. **选区距离。** 报告 √14978/16 m 或误差不超过 0.00005 m 的等值。
3. **整件距离。** 报告 √14753/16 m 或同容差的等值。两者的对应和选区更远的关系须清楚。
4. **选区实际点对。** 用有明确单位和归属的世界坐标报告一组最近点。起点属于四片选区中的实际三角表面，终点在 Obj_04 的实际三角表面，点对长度达到该范围下界。归属与长度容差均为 0.00005 m。
5. **整件实际点对。** 两点分别属于 Obj_08 整件与 Obj_04 整件的实际表面，并达到整件距离下界。接受任一等价点对，选区同一点对不得替代不同的整件最短点对。
6. **有限方向中的部分证据。** 原答把底面 0、1 与竖面 8、9 分开。对有用的当轮原图，核实际视角和源面归属，确认报告的可见采样，并说明底面的缺证或从允许上方方向自遮挡的依据。保留整片完整性未知或明确有限方向无法取得全选区完整见证。单张图的有用局部像素不支持四片皆完整。只有几何候选、预览旧图、未经验证的完全可见或把零样本推广为任意方向不可见，均不算实际图像证据。真实尝试若证据不足，说明适用范围或原因可证明对不确定性的正确处理。
7. **当轮原图。** 原答用可打开的 Markdown 图片、链接或真实附件交付当轮有用原 PNG。闭槽后按原答引用读回，同槽真正原图和原始交付图块字节及 SHA-256 一致。裸路径与人工附件分开记录。缺正式图或读取失败按实记录，不能用历史图补分。

另记视角、采样面与像素、严格几何完整性、调用采用和补查。实际宿主显示或真人点击没有观察到就保持未测。量测和图像质量与首包、工具名和执行成本分别记录。
