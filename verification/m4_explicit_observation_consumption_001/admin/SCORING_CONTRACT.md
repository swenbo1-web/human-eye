# 显式观察入口消费评分合同

本批只有一个fresh P1消费者。正式输出位于 `D:/he_explicit_001/formal/P1`，任务质量分母为1。原六槽记录继续保留其独立范围。

## 原质量合同

只读复用原 `m4_region_localization_consumption_001/admin` 的冻结评分器、真值和归一化格式。目标集合、有限池余量、域外组件、三项位置与数值含义、16/4/24可读标准、身份兼容规则及生命周期条件均沿原合同。

适配器复用原Grader全部方法的代码对象，`frames`仅使用私有globals把BATCH映射到新输入清单。原六槽main不执行。单槽入口沿原判定表达式，并在评分时核对两个表达式的AST与原函数完全一致。

归一化仅收集当前最终答、真实工具正文及最终明确引用的本槽文件。逐项保留原文摘录和原始SHA，来源中的产品事实与原生补查分别记录。来源不足、事实缺失和最终答错误均如实保留。

## 三层资格

1. 真实调用层核对CLI模型工具事件、服务端原始请求与结果、当前隔离安装产品生产者执行和源码身份。保留首次工具及全部恢复，单独报告首步指令遵循情况。
2. 真实交付层核对实际v3正文、stdio与CLI工具回执、当前生产者图片及其同源引用。逐项记录实际交付和可观察截断。provider内部输入与定义可见性按实际证据报告。
3. 正确消费层同时核对原完整任务质量与最终答对产品事实的实际采用。覆盖、有限池剩余、域外组件、点击定位、原点遮挡与其它实际视角、底面有限池结论逐项记录产品、原生或混合依据。原生补查和整体重算照实记录。

单纯通过原生路径正确完成任务时，任务质量可单列通过，产品事实消费资格仍须实际来源证据。资格分层保留pass、fail或unmeasured，错误后的同窗口恢复同时保留首次失败。
