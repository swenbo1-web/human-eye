## 预算、收尾与限制

资格两槽均无模型调用。全批实际 owned Blender 启动 8 次，其中资格 2 次、正式 6 次。实际 raster 13 次，其中资格 2 次、正式 11 次。正式消费者 6 次，所有业务调用、失败和恢复都计入原预算。450 秒任务和 600 秒生命周期均沿同一 root 起点，实际结果、关闭及句柄记录逐槽保留。

N3 第六次业务调用尝试读取 type(value).__name__，被公共私有属性边界拒绝。第七次调用移除该属性后恢复。此错误及恢复已计入 N3 的十次业务调用和完整时间，完整原件用于判断测试边界对成本解释的影响。

六个 CLI 主进程实际退出码均为 0。CLI 启动的六个薄 Python 适配器由保留句柄确认退出，退出码均为 1，且未取得 EXIT 回执。实际退出和句柄关闭已证实，退出原因尚未定位。原接受合同允许在 EXIT 缺失时使用已证明的实际退出证据完成关闭判定，这项记录继续单列。owned actor、产品 MCP 和 Blender 的关闭证据分别核验。

注册至正式启动为 4328.079 秒，包含首次适配和两次无模型资格。唯一正式批次为 706.792 秒。正式结束至根成本决策为 2017.009 秒，包含保存原件审查。资格窗口是准备窗口内的分项，最终封存另有账本时界。首次适配与审查的工程投入由注册起点到最终封存的账本保留，协调者和审查代理的模型费用未计量。共享设备 fixture 的加载优势、P 自身相机生成、重复图片交付、原生恢复，以及后台 full 证据归档成本都保留。

本批只覆盖一个明确目标资产和固定六视图设备，各组三次模型消费。一般模型质量差异、真实自然路由、更多非平面资产、任意视角及群体尾部延迟仍需后续证据。当前配置的 resolved effort 没有供应商确认，配置参数与实际 CLI 请求来源一致的范围单独保留。

Agent Learning 当前聊天未绑定，任务登记仍待 host rebind，运行期间没有借用其他聊天句柄。旧 namespace 和旧封存原件按保护清单核查。Google API 和 key 按既有范围保持暂停。
