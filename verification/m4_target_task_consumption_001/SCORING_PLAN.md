# 目标任务消费的冻结评分规则

公共题面为 inputs/COMMON_TASK.txt，公共字段约定为 inputs/ANSWER_SCHEMA.json。N/P使用同一份任务内容，能力和首入口由各自路由说明提供。正确区域数、源面和位置仅进入管理员文件。consumer允许读取当前完整源网格和固定设备矩阵。

## 独立真值与实际图像

oracle.py只读取冻结世界源几何，以共享边连通分量、精确叉积、面积和有理数光线建立区域及有限池几何结论。admin/TRUTH.json保持管理员私有。像素事实逐槽从实际producer RGB、depth、对象owner和局部source-face缓冲计算。每个当前帧先核当前源、实际矩阵和producer哈希。P区域引用先映射到当前完整源面集合。N的源面集合或唯一世界几何描述使用同一独立区域集合。

完整见证要求同一张本槽实际图像在该方向几何完整、正向、无遮挡，并满足16表面像素、4对比边界像素和RGB欧氏距离24。四邻域中至少一个区域外像素达到阈值即计该边界像素一次。部分可读图、其他区域的清晰图、其他槽图片及未构造视图均不能提供完整见证。未构造图的像素状态保持未运行。

## 整个最终答案

固定顺序N1/P1/P2/N2/N3/P3，六槽为完整分母。每个区域的全部身份别名必须一致，源面集合须完整且没有重复区域。检查中心、范围、带方向单位法向、米制世界坐标、有限视图池几何完整性、实际完整可读见证和未知原因。源面、中心和范围采用精确有限有理数比较。单位法向单独允许2e-14双精度归一化误差，并保持方向和长度正确。

质量评分覆盖全部最终断言，包括表格、补充说明、未撤回的额外断言和遗漏。缺字段或含糊内容保留缺失，归一化不能用真值补填。N的唯一几何身份可以采用精确中心、范围和带方向法向共同绑定。P的ROI别名必须由当前源面实际映射。未知原因可由等价明确自然语言归一化，但须有准确原文引用和独立语义复核。

原文归一化绑定本槽PUBLIC_FINAL字节、当前工具请求/输出和模型明确引用的当前产物。每个支持引用包含唯一source_id、原件路径/SHA和准确连续原文。独立语义复核在首个完整内容评分前完成。额外事实及矛盾均单独登记，不能只抽取正确字段。

## 调用、事实采用与额外工作

P首入口调用只证明配置路由。实际采用要求至少一个任务相关产品事实有本槽真实产品公开输出出处，并在最终答案中实际使用，附当前来源引用。字段出现、日志读取和工具调用本身均不成立。采用与整体任务质量分别记录。

额外全部业务工具按实际请求代码和返回内容分类，可用existing_fact_query、cached_image_read、existing_buffer_lookup、raw_source_read、new_native_observation、new_product_observation、native_computation、format_artifact或unknown。另记录是否取得新增任务信息，是否重算已有事实、几何反查、完整witness像素重算或重复图片交付。分类须有请求/输出原文证据，必要性未经证明保持unknown。允许高效批量计算，重复核算诊断不充当禁止项或质量失败理由。

## 终态和成本

每槽先核实际routed producer、source、固定资产、请求窗口、原进程终态、零外层重试及六槽标签。失败和未运行留在分母。保存或评分接线错误仅修脚本并重新读取同一原件，保留初稿与修正记录。

质量与采用封存后由root解锁成本。完整任务时界包含检查、启动、消费者、所有工具、图片、清理、结果发布。各层嵌套范围分别报告。CLI原始input/output/cached/reasoning保持同源，工具响应文本、assistant公开文本、图片和重复交付分别计量。费用、图像token或provider内部请求数缺证据时保持未测。

有限任务正信号要求N/P各3/3完整正确、P3/3实际采用，完整时间P/N配对比中位≤0.90且至少2/3更快，P合计原始input+output≤N。保留每对原值和逆向结果，失败槽不充作成功速度。本批无论结果均收口。
