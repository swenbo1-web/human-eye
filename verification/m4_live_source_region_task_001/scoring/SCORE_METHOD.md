# M4-LIVE-SOURCE-REGION-TASK-001 scoring

Apply this method only after both original consumer outcomes are in the paired seal. Evaluate the original final answer in each slot. Use exact answer quotes and current-slot evidence for each decision. Grade each requirement once. Keep both slots and all ten requirements in the denominator. A missing final is `unrun` for all requirements. A missing or invalid evidence source makes its affected requirements `unverified`, even when numbers happen to match the historical run. Unaffected requirements remain scoreable. Full acceptance requires ten passes.

| Requirement | Pass condition |
| --- | --- |
| D1 Distance | The global minimum unsigned surface distance is in metres with at least six decimal places. Accept correct rounding to the supplied precision and the historical Blender world coordinate arithmetic difference within the oracle allowance of 1e-7 m. |
| D2 Closest point pair | Both points are labelled by object and expressed in world coordinates. Accept correct rounding to supplied coordinate precision with the same oracle allowance, provided the points localize the witness. |
| D3 Original source witnesses | Both points have original source witnesses that identify their support in the verified source domain. A valid incident source triangle, source vertex, uniquely identifying polygon, or equivalent checkable description is sufficient. A global triangle number is valid when its domain resolves to the required object and original local triangle. The Cube top plane plus the witness coordinate is an equivalent support description if uniquely identifiable from the checked geometry. |
| D4 Measurement scope | The complete 748 selected source triangles are measured against the 12 triangles of the original Cube surface, including selected triangles without frame samples. The two operands are surfaces. A vertex-to-vertex or image-only interpretation of the distance fails. |
| I1 Pixel count | The selected pixel count matches the actual cited SCENE frame. |
| I2 Source triangle counts | Both the sampled and unsampled counts match the actual cited SCENE frame and cover the full selection. |
| I3 Frame scope | The answer explains that unsampled source triangles have zero winning pixels in this SCENE frame, that this discrete view does not prove whole continuous surface visibility or a particular invisibility cause, and that Cube is outside the frame's display mask. Accept additional visibility evidence to the extent it actually proves the corresponding claim. |
| R1 Surface relationship | The answer states the selected surface and Cube surface are disjoint based on the finite, positive minimum over both complete operands. |
| R2 Solid inference | A positive unsigned gap alone leaves inside and outside open. Accept correctly proved strict containment of the selected surface inside the Cube solid using the actual closed shell and whole-selection geometry. An unknown answer must identify the specific missing evidence in the checks it actually performed, such as confirmation of a closed reference shell plus an interior test covering the selection. A claim about entire character solid overlap requires separate applicable proof. |
| S1 Current provenance | The answer supplies a traceable current geometry source together with target and reference identity, source witness IDs or a resolvable region reference, and an actual SCENE frame reference. Resolve literals and equivalent identifiers against the current slot's delivered results and retained evidence. Cross-slot, unresolvable, and merely generic references fail. |

Check numeric accuracy on the sealed public wording. Do not require a fixed answer template, a specific algorithm, an exhaustive face list, a particular identifier spelling when an equivalent reference resolves, or a reason for individual misses. Report execution and evidence failures apart from answer errors. When the two first frames cannot be shown to represent the same planned device, preserve the per-slot checks and mark the pair ineligible for the same-device claim. Never fill missing evidence from the other slot.

The offline verifier binds fresh readback to the frozen source by asset, frame, layer, units, object order, transforms, visibility, native and evaluated local vertices, polygons, ordered triangle rows and triangle-to-polygon mapping. It reconstructs metric world coordinates independently. It verifies the actual Cube triangles form one closed box, then proves the minimum with the six face clearances and an attaining selected vertex and reference point. It checks the actual saved SCENE matrices, dimensions, display mask, geometry offsets and buffer hashes. It remaps every foreground triangle owner to a verified source triangle, derives pixel and distinct-source counts and compares the normalized owner buffers across slots and against the prior SCENE frame. The frozen values in `EXPECTED.json` come from independent real-asset and DISPLAY001 evidence. No consumer-produced distance or visibility summary enters the oracle. The scorer performs no live Blender, render, public tool or model calls.
