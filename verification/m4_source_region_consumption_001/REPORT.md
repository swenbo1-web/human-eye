## 失败及实际采用

S1 的薄读取器误拒 CLI 随请求附加的标准 _meta。两次读取均未交付观测，模型诚实报告没有数据，九项内容门均记 unrun。其原答保留在三例分母。协议修正后继续 S2 与 S3，共同题面、工具说明、产品及评分字节保持原冻结内容。

S2 与 S3 各收到一份原 brief 和一块原生 PNG，原图片 SHA 与尺寸逐块核对。它们正确采用零像素、完整选区量测范围及内外判断的信息边界，却均未报告原距离、单位换算和见证，也未采用本例已有的表面分离事实。S2 另遗漏 Cube 参与显示。全部原答没有把正距离误推为实体外部，也没有武断判定内部。

两份回答都自述 JSON 中段被截断。原 MCP 及 CLI 完成事件中，117,623 和 117,620 字节文本均完整包含 0.37011719389236364 米和最近见证，检查未找到截断标记。模型后续实际可见文本及可能裁剪位置尚缺直接证据，原因保持待定位。

旧事件框架还将每例两次空 Codex 资源枚举视为额外工具，并把它们混入观测 owner 归档计数，产生 2 对 4、1 对 3、1 对 3 的错误。三份原 harness 状态均为 failed。独立审计核实六次资源枚举都只返回空列表，S1 对应服务端原 -32601 也原样保留。原记录与内容评分、真实交付事实分别列在证据中。

## 成本与输入组成

实际三个消费者、零补样。读取工具尝试共四次，六次通用空资源枚举，每例全部工具完成数分别为 4、3、3，均处于四次门限。新增 Blender、产品公开请求、栅格、PNG/NPZ 编码、训练与付费 API 调用均为零。

三个完整会话合计 134.387744 秒，原 450 秒任务及 600 秒进程期限均通过。CLI 均退出 0，MCP 保留句柄均确认退出 1 并关闭，normal EXIT 收据缺失仍为 unknown。原始 turn.completed 合计 input 95,115、cached input 62,464、output 2,913、reasoning output 299 tokens。推理字段单列，费用、图像 token 和 provider 请求次数未暴露。

三份原 brief 准备总量为 350,451 UTF-8 字节。按原 JSON 词法跨度无重复统计，源索引 214,844、坐标 90,099、绑定 40,557、任务 facts 3,434、其他 1,517 字节。索引与坐标合计约 87.0%。S2/S3 实际交付文本合计 235,243 字节，PNG 合计 3,776 字节。正常 S1 的 24,734 字节 PNG 未交付给模型。

自动输入准备、协议预检、协议修正和完整消费者窗口各自有原时钟记录。前期人工规划及适配代码编写的墙钟未完整测量。执行源存在运行前嵌套 SHA 承诺，原 runner 未逐项递归重 hash 全部嵌套源。独立运行审核期间一次元数据探查意外输出了 S1 summary 正文，该审核未参与内容评分，披露已保留。
