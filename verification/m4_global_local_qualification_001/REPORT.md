# M4 全场到局部取证资格

本批使用一个固定场景，完成全场、局部开放面和局部遮挡面三个真实只读会话。独立几何、图像原件、来源及生命周期的最终判定和文件摘要保存在同目录 DECISION.json。管理员独立复审待完成。

## 固定输入

产品提交为 `ccb608aa83de4b0e6671da89e0c8f387bd3f800e`，141 源文件摘要为 `7d2d4352f462c64a46e6fccf447c6f030c08b96e95517a3b2b6776ed50b69a6a`。本批执行前提交为 `caa3d9a94ef5e8fe36a173892ce97c5042e80cb7`，冻结 47 份输入和源码。资产 SHA256 为 `a2d55e9212a84d27489aa72a680092b4e91d94d9df27d29c5de40d8a4ca3d0c6`。

共同任务要求找出最大共边、共面、绕序一致的矩形分量，面积在 `[1/128,1/32]` 平方米内，带方向单位法向的 z 分量至少为 `3/4`，并提供完整可读的真实图像。公开任务采用中性对象编号。局部控制的对象由预先固定的独立 fixture 选择。

独立 Fraction oracle 从原始点面重建出 24 个共面分量，其中 22 个矩形覆盖 44 个三角形，方环及 L 形的 12 个三角形归入 unsupported。合格集合恰有 3 个小面。保存前和重开后的原生及 evaluated 点面顺序均与冻结 JSON 对应。

## 实际结果

| 会话 | 实际图像 | 目标结果 | 完整会话耗时 |
| --- | --- | --- | --- |
| 全场 | 六方向，6 次 raster | 开放水平面为 1 像素，倾斜面为 1–2 像素，均为 pixel_evidence_insufficient | 2765.0211 ms |

全场实际发布矩阵与静态六向推导吻合。独立整数像素中心上界为 1 或 2，低于 16 像素门槛。开放水平面在局部视窗中取得当前源面绑定的完整可读见证，形成一个实际可恢复的跨尺度取证案例。

盖下目标的六个前向方向都有正面积遮挡。公开主 reason 为 `finite_camera_pool_uncovered`，同一次 producer 的 region_evidence 精确说明为 `positive_area_occlusion_all_front_views`。两个局部会话各有五个方向保持 unrendered。六向几何判断及实际图像分别保留各自证据。

## 原件、成本及验收范围

实际资格使用 3 个 fresh owned Blender，会前另有 1 个资产构造与重开回读进程，准备耗时 666.6325 ms。共执行 8 次 raster，每槽仅执行一次公开 active_observation，消费者模型和付费 API 调用均为 0。全部原始请求、返回、图像、数组、错误和终态均归档，原运行文件保留。

655 项保存图像检查和 1121 项生命周期检查通过。图像检查覆盖 8 帧、2,097,152 个像素位置、701,991 个前景像素，核对 PNG 与 RGB、depth、对象 owner、源三角行、patch owner、相机、公开交付及当前来源。来源按各自 document_epoch、host_id、instance_id、对象内三角行及 ordered_geometry 对应，各 scope 的相机、捕获顺序和 object_index 单独保留。

有 1263 个边缘或近等深像素保留精确三角归属的数值模糊标记。所有前景像素仍核对来源三角成员关系，并在 `1e-8` 米数值余量下检查更近表面。局部开放面的几何完整性由独立射线及固定源面证明，可读门槛另从实际 patch-owned 像素核对。

验收脚本初稿包含字段接线及数值格式假设错误，涉及 PID 所在记录、可省略的 scope、运行时追加元数据的哈希阶段、有理方向及中心坐标解析、最终保存报告路径和视锥外像素中心。冻结源码、首次失败和后续派生适配器、diff、对应反例全部保留。修正均复核已有原件。实测采用冻结的布局、相机和门槛，每个请求执行一次。

fixture 作者审核构造及生命周期，参与过产品接线的代理审核保存图像，另一代理独立实现 Fraction 几何答案与任务资格。根复核原始结果、输入摘要和最终判定。完整会话耗时包含启动、附加源几何回读、保存和关闭，当前成本属于零模型资格运行。
