# 只读装配任务评分

先逐项核验实际回答与原始工具证据，再看分段成本。对两臂使用同一真值、容差和通过条件。

| 分项 | 通过条件 |
| --- | --- |
| 对象与区域 | 正确指出 N15 朝上最大的连通矩形面。用明确几何、原始面范围或能唯一识别该面的原图定位。 |
| 完整可读性 | 判断该面能否从当前可用视角完整看清。完整结论需要实际交付的可追溯原图，面和完整边界可辨认。若答复仍受阻，需与实际尝试的视角、挡片或明确证据限制一致，同时记录没有闭合正例交付。 |
| 原图与遮挡证据 | 回答所指原图可从该槽的真实工具回包或引用追溯。允许任意通过独立核验的等价取景。只呈现默认遮挡或只完成截面计算，记录为部分交付。 |
| 整件最短表面距离 | 对象为 N15 与 N23，使用完整当前表面。量纲正确，与独立真值的绝对偏差至多 0.05 mm。 |
| 方向 | 明确从 N15 最近点指向 N23 最近点，归一化后与真实方向夹角至多 0.5°。若报告见证点，核对其位于对应当前表面且点差符合真实最短距离。允许独立证实的等价最短点对。 |

正式质量满分要求五项齐备。保留每项的通过、失败和证据不足。模型仅引用公开工具实际收到的图才能计入图像采用。类型发现、源读取、实际几何计算、构图、原图回读和失败恢复分别登记。首次包的事实写入答案且没有同事实再求证，计直接采用。首次包后补一个独立必要事实，计新增证据。同一事实用相同材料再次求解，计重复核算。只取得字段或引用但模型没有采用，单独记录。

只发布该对的实际工具和窗数据。首调用前、调用间、末工具到答复均按真实事件记录，供应商内部时长无直接证据时留空。失败和未运行保留其原分母。
