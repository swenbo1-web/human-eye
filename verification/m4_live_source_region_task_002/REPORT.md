# 曲面选区原生与插件实测

两组在同一 Yanyite 曲面选区上完成答复，独立内容评分各 **10/10**。插件组首调成功交付默认 `source-region-brief-v2` 和原生 PNG。原生组第一条工具返回被 CLI 截断，触发运行归档校验失败。后续短结果、图像和原始答案已分别核对，保留两组质量与成本数据。

## 同场景证据

两组各启动一次独立 Blender 副本。冻结题面、评分、748 面选区、Cube 的 12 个参考三角、米制双精度世界坐标和 512 × 512 的 SCENE 相机一致。两组均量得约 **0.370117194 米**，给出选区顶点 24331、源面 48160／48161 与 Cube 面 0 的见证。实际帧的源面像素归属一致，两组各得到 **35,452** 个选区像素、**385** 个有样本面和 **363** 个无样本面。两幅 PNG 的字节一致，显示掩码均排除了隐藏 Cube，量测域包含 Cube。

两组都正确判定所测表面分离。原生组进一步依据实际 Cube 闭壳和覆盖整个选区的坐标界限证明选区严格在内部。插件组给出有依据的未知，指出需要补齐有效闭壳和完整选区的内外分类。两种答法均符合预先冻结的标准。

原生组首调用打印完整坐标和拓扑，工具端文本 4,151,338 字节，CLI 已完成工具事件保留 1,048,605 字节并附截断标记。后续三次工具返回逐个匹配，分别提供短几何、短数值与图像证据。CLI 正常退出并保留原答。原运行器因首条结果与 stdio 原件未完全相等，将 N1 标为失败。该状态与内容评分同时保留。

插件组首个模型请求和实际隔离产品 RPC 都省略 `response_detail`，并请求原图。测试桥展开 748 面输入，返回 **9,979 字节**简报及实际 PNG，CLI 完成事件与原结果一致。随后三次普通 Python 调用补核几何和原帧缓冲，复用首图，未增加构图。首调用产品服务用时 3.704 秒，其中宿主捕获 1.388 秒、选区准备 1.667 秒、构图与发布 0.545 秒、量测 0.055 秒。原生实际栅格化 0.214 秒、PNG 编码 0.016 秒、NPZ 编码 0.056 秒。插件实际栅格化 0.206 秒，PNG 与 NPZ 合并发布 0.078 秒。

这一次按 N1→P1 串行测试，P1 的完整窗口少 **7.746 秒**，约 **9.15%**。两组往返次数和构图次数相同。最大差异出现在首次工具输出大小，原生组的大文本截断与两组模型生成路径也影响总窗。一次配对和原生归档失败不足以建立稳定的端到端提速标准。

对照上一批 P1，本批从首调完整结果 165,555 字节改为默认简报 9,979 字节，少两次产品补读和一次 PNG 重复交付。两批实际完整窗口分别为 91.035 和 76.948 秒。两批模型行为有差异，以上比较用于定位重复工作。

## 签收与原件

两个正式槽使用同一最终封存摘要。两份干净解释器预检均通过，核实依赖路径、普通计算、标准 `_meta`、空发现及尝试计账，预检期间 Blender 和模型启动数均为零。一次并发编辑导致预检脚本哈希在启动准入时变更，运行器在创建副本和调用模型前拦截。保留原记录，并用最终文件重做两组预检和冻结。正式预算计入两次 Blender、两个消费者、零替补。原资产与关闭时载入几何核对通过。

两个 CLI 均正常退出，薄 MCP 子进程实际退出码均为 1，保留句柄确认退出，正常 EXIT 收据和退出原因仍未知。费用、供应商内部请求、图像 token 与实际供应商输入均未暴露。当前会话 ID 已记录，Agent Learning 写入工具仍不可用，登记待同步。

原答与逐项评分见 `answers/`、`scoring/QUALITY.json`，源和帧校验见 `scoring/EVIDENCE_VERDICT.json`，原件清单见 `RUNTIME_INDEX.json`。本地精确归档保存 693 件原件，共 169,942,257 字节。原资产副本、源几何和原始进程事件保留在本地。
