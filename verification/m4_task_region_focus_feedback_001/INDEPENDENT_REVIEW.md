- 首选源面落在任务区域为 2/4 → 4/4，交付原图中有至少 16 个区域像素为 3/4 → 4/4，两项同时成立为 2/4 → 4/4。若只计算首选三角自身达到 16 像素，则两臂分别为 1/4 和 2/4。四题证据均只表示帧中的实际采样。
- 复核从两份原题提取坐标，并从封存场景的全部当前求值顶点独立推回面集合。对八个真实 MCP 请求逐一核对参数、两臂实装、同代有序几何、对象实例、交付 PNG 的真实字节和 RGB，再从同帧 NPZ 的有限深度、对象与三角编号重算每个视角上的整组和首选面像素。两臂各 146 件运行源码与本臂 Git、wheel、安装逐件相同。
- 候选四次选择阶段分别为 0.3571、0.1603、0.7651、0.3634 毫秒。四个工具往返合计从 1,093.365 毫秒降至 919.374 毫秒。这一轮的 N19 单次往返从 356.286 毫秒增至 475.473 毫秒。这里只测量了两套装配上的几何观察。
- 对称几何的八项独立对照覆盖了参照交换、共同平移与三角重排。有闭盒时组员由闭盒确定，参照改变组内首选。只给参照时，用目标三角重心到参照世界轴对齐包围盒的距离提名；切换参照会改变入选组。用一个斜长参照三角验证了这种近似的边界。候选选中的三角到真实参照表面的距离平方至少 121/32，而另一个三角到参照存在距离平方 1/32 的点对。需要真实表面距离的任务应依据独立量测。

本批评估结构化任务约束和图像反馈。四题是已知问题上的回归，模型自然提取观察重点、未知装配泛化、交互整题耗时均未测。正式前评分器摘要失配的一次预检已留档，正式对照采用重新冻结的评分器，四槽各执行一次。
