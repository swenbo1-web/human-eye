## 本机独立复核入口

私有原件留在同名批次运行根。打开 sealed/RAW_INDEX.json 可按 SHA-256 复读 ZIP 中的每件原件。槽目录为 slots/RAIL_AUTO、slots/RAIL_TASK、slots/ASSEMBLY_AUTO、slots/ASSEMBLY_TASK。每槽的第三和第四个 MCP 往返对应表内两题。producer 记录绑定构图帧和原 PNG/NPZ，实际构图的周期见 construction 记录。worker_wire 下保有宿主进程的 TX、RX 和索引，WORKER_ADMISSION.json 将配对绑定到对应 MCP 调用。FORMAL_SCORE.json 包含每帧原件路径、摘要、正负像素和同帧停止决定，独立几何复核见 postflight。产品与证据单独提交。
