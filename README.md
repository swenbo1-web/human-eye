# Human Eye · 三维空间感知引擎

Human Eye 为 AI Agent 提供结构化三维观察、网格间隙测量、原生 Blender 图像与受预算约束的有限刚体动作。目标是让 Agent 使用可核验的几何事实和合适的视图完成三维任务。

当前落地优先面向Codex；总体目标、阶段依赖与验收出口见 [交付路线](docs/PRODUCT_ROADMAP.md)，已交付能力见 [项目进度](docs/PROGRESS.md)。

## 当前能力

- 对支持的静态网格输出未取整间隙、接触与穿入信息，明确区分精确值、界限和 unknown。
- 提供 MCP 与 Agent Hook 接口；自动触发依赖宿主的 Hook/运行时支持。
- 维护场景快照与变化检测；观察缓存不等同于动作授权或动作历史。
- 生成 Blender 原生全景与可选局部图，保留真实遮挡及全部几何的深度范围。
- 对有限轴盒严重亚像素间隙，自动选取侧视局部窗口；每次最多两张 384×384 图片。
- 对部分高顶点目标，在 XY／XZ 视图筛查有界局部放大机会；保留真实遮挡，明确区分投影包围界与真实薄截尺寸。
- 有限独立静态刚体动作保持原期限、步数/位移预算、回读及未知结果阻断；不认证扫掠路径或物理模拟。

## 已验证的有限收益

在同一 Blender 输入的旧版/新版观察对照中，25 µm 间隙从全景约 0.028 像素变为侧视局部约 94 像素宽的连续空气带；0.4 mm 侧间隙的连续图像核心约 95 像素。普通 4 mm 和完全遮挡场景不增图，五组全景像素一致。此结果来自解析构造资产与原生渲染，不能外推为任意复杂场景或模型整任务成功率。

新增五组真实 Blender 旧新 SDK 对照中，同一闭合盒体边界的 65 顶点目标从全景约 0.122 像素变为局部图约 96 像素；独立实际相机射线与 PNG 采样确认本资产的目标可辨。普通、完全遮挡和旧版任务间隙保持原图数，五组全景像素一致。单条中央射线不能证明完整可见性，该结果也不能外推到任意高复杂度资产。

完整本地回归为 1595 项：1594 通过，1 项既有 Windows 符号链接权限跳过。完整验收包含机器绑定、历史证据及真实 Blender 条件，公共源码的可移植测试集为86模块1520项，1507通过、13按条件跳过；它与完整本地验收计数分开。正式模型对照仍未执行。

## 安装与测试

运行引擎需 Python 3.10+、NumPy 2+ 与 Pillow 10+；公共开发测试建议 Python 3.11+。原生宿主实测版本为 Blender 5.2.1 LTS。

```sh
git clone https://github.com/swenbo1-web/human-eye.git
cd human-eye
python -m venv .venv
# 激活 .venv 后：
python -m pip install -e .
python -B verification/run_portable_tests.py
```

可移植测试不需要连接用户 Blender。真实宿主、固定发布安装、历史封存差分等测试须按各自条件运行；不要将直接发现全部历史测试的结果当成公共测试集结果。

MCP/Hook 的接口说明和配置模板位于 [examples](examples/) 与 [接入说明](docs/AGENT_SETUP.md)。模板中的机器路径必须换成当前环境路径。`examples/agents/target_runtime_entry.py` 是发布工具模板，固定本地发布包不随源码仓库上传；不能把模板当作当前机器已安装发布入口。

## 支持边界

任务间隙局部取景目前只支持严格外向、8 顶点/12 三角形的轴对齐闭合盒体，单轴正间隙、足够横向重叠且最佳正交间隙小于一个全景像素。三条可见性采样并非完整 ROI 可见性证明。

高顶点候选仅在旧版返回 `focus_budget_exceeded` 时尝试：焦点超过64顶点或128三角形、场景总顶点不超过4096、总三角形不超过2048；只开放 XY／XZ，SCENE 保留旧行为。现有几何准入不扩大，局部图不能代替精确间隙量测。任意复杂斜面、部分遮挡的任务收益、变形、动画、GPU 调度与学习模型尚有独立后续任务。

局部计划使用显式 V2（任务间隙）／V3（高顶点焦点）；旧消费者需通过源码身份及兼容检查，不能默认理解新增版本。图片提供视觉佐证，尺寸精度由捕获网格量测支持。详见 [高顶点观察合同](docs/DENSE_FOCUS_NATIVE_CONTRACT.md)、[任务间隙合同](docs/TASK_GAP_NATIVE_CONTRACT.md)、[开发与复现说明](docs/DEVELOPMENT.md)。

仓库只包含源码、测试及选定合同；本机凭据、连接状态、动作账本、虚拟环境、用户附件和大型历史验收产物不在上传范围内。历史文档中的本地证据链接可能指向未随仓库发布的档案。
